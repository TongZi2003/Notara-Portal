# Notara 官方网站（1:1 真实桌面端手帐界面复刻版）

以 Notara 自身的泛黄手帐棉纸（`techo`：`#ece7dc` / `#fdfbf7`）与独立出版物排版构建，且所有软件演示窗口、公开学习集书房与交互样课均 **1:1 复刻真实客户端界面**（直接复用 `themes.css`、`Notara WenKai` 字体、编译期 KaTeX 公式、像素角色头像与布面书架样式）。

## 核心脉络（器 → 序 → 法 → 核 → 源 → 信 → 契 → 跋）

1. **第一屏 · 见器知意**：以「**一间记得你每一步思考的自习书房。**」立住温暖实器，下方直接铺开 **1:1 真实桌面书房界面**（左侧 62px 书脊导航栏 + 横格纸课堂 + 右侧导读、结构化卡片与空间 `.canvas` 白板），支持实时切换高中导数、大学高数、计算机同桌盲测与私人书房书架四幕。
2. **第二屏 · 心智之镜（`#manifesto`）**：以「**以“人”为镜，可以明得失。**」题记与三段短序阐明人机分工哲学。
3. **第三屏 · 三段式混合教法（`#pedagogy`）**：以「**取百家教法之长，不拘泥于单一教条。**」讲清按认知火候动态切换的三段式教法（踮脚也够不着时高密度直讲铺底 → 够一下能触到时苏格拉底法搭梯 → 觉得掌握时费曼法同桌盲测验真 + 可插拔教法 `Skill`）。
4. **第四屏 · 五大核心工作流（`#workbench`）**：以「**让读过的每一份资料，真正长成你自己的知识体系。**」统摄支撑上述教法的工程闭环——
   - **01 会生长的知识图谱**：允许 PDF 讲义、错题卷、随堂笔记等异构资料持续 Merge 入图，虚线底图与亲证点亮实线随阶段收敛出高阶中枢；
   - **02 助手化的个人 Agent 编排**：常驻统一对话管理主 Agent（首页学习助手）协同独立的专题课堂从 Agent 与五类并发后台工作员从 Agent，自动回流精炼简报；
   - **03 可视化的空间推演白板**：原生 `.canvas` 画布支持 PDF 零拷贝区域钉入、多分支连线、函数图像与交互式 `flow` 关键步检验；
   - **04 记得习惯的老师与同学**：基于本地 L0/L1/L2 多尺度同构记忆，提供物理屏蔽解析的「同桌盲测」与标注为**试验功能**的个性化导师启发与连贯授课；
   - **05 双轨制的间隔复习排布**：严格分流「无提示独立提取升档轨（1→3→7→16→35 天）」与「提示/讲解辅助 1 天短复查保底轨」，叠加卡壳排毒重构与双向深刻复习。
5. **第五屏 · 资源市集与 AI 原生社区（`#sets` & `/library/`）**：以「**你只管安心看书，让私人 Agent 替你去市集与论坛淘干货。**」亮出 AI 定时巡站简报（路线图研发中）与多源活体课包市集（`.notara-pack` / `catalog.json` 无损追更 Merge、拓展包与一键净本分享），并清晰区分随包附赠的**开箱起步样卷**。
6. **第六屏 · 给中学生、大学生与终身学习者的三封公开信（`#letters` & `/letters/`）**：棉纸横格信笺排版，支持首页三联切换与独立路由全文分享。
7. **第七屏 · 纯粹契约（`#contract` & `/guide/`）**：本地 `.md` / `.canvas` 开放文件归属、BYOK 自接模型零差价、安静不越界。
8. **第八屏 · 跋 · 开发手记（`#postscript`）**：与《序 · 心智之镜》首尾呼应的坦诚造物后记——「**走过不少造轮子的弯路，才落定今天这张安稳的书桌。**」

## 本地构建与无头验收

在 `Notara-Desktop` 仓库内：

```sh
node apps/portal/build.mjs
python3 -m http.server 8080 --bind 127.0.0.1 --directory apps/portal/dist
NOTARA_DISABLE_EXTERNAL_GUI_OPEN=1 node scripts/test-learning-portal.mjs http://127.0.0.1:8080/
```

## 独立静态站仓与阿里云 ESA Pages 自动发布

在 `Notara-Desktop` 根目录运行：

```sh
node apps/portal/sync-standalone.mjs
```

独立仓（`TongZi2003/Notara-Portal`）自带 `esa.jsonc`（根目录保持 `/`），阿里云 ESA Pages 自动执行 `npm ci --no-audit --no-fund && npm run build` 并发布 `./dist`（含 `404.html`、`/install/` 兼容路由、`robots.txt` 与 `sitemap.xml`）。
