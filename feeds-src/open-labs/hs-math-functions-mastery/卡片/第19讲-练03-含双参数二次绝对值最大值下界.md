# 第19讲·练03：含双参数二次绝对值最大值下界

## 内容

对任意实数 $a, b$，记 $M(a, b)$ 为函数 $f(x) = |x^2 - ax - b|$ 在闭区间 $[0, 2]$ 上的最大值。

(1) 当 $a = 2,\ b = 0$ 时，求 $M(2, 0)$ 的值；

(2) 求证：对任意实数 $a, b$，恒有 $M(a, b) \ge \frac{1}{2}$；并求 $M(a, b)$ 的最小值。

## 参考理解

**(1)** 我们先看第 (1) 问的数值热身：当 $a = 2,\ b = 0$ 时，$f(x) = |x^2 - 2x|$（$x \in [0, 2]$）。把里面的二次式配方：
$$x^2 - 2x = (x - 1)^2 - 1.$$
当 $x \in [0, 2]$ 时，$x - 1 \in [-1, 1]$，故 $(x - 1)^2 \in [0, 1]$，从而 $x^2 - 2x \in [-1, 0]$。加上绝对值后，$|x^2 - 2x| \in [0, 1]$，在区间中点 $x = 1$ 处取得最大值 $f(1) = |1 - 2| = 1$（而在两端点 $x = 0, 2$ 处均等于 $0$）。因此
$$M(2, 0) = 1.$$

**(2)** 仔细品味第 (1) 问的图像，我们马上会捕捉到一个绝妙的启发：当 $(a, b) = (2, 0)$ 时，$x^2 - 2x$ 在 $[0, 2]$ 上只偏在 $x$ 轴下方（从 $-1$ 到 $0$），最大绝对值是 $1$；如果把抛物线稍微往上抬一点，让它上下对称分布在 $0$ 两侧，绝对值最大值是不是就能减掉一半？下面我们先用严格的不等式把无论参数怎么调都突破不了的地板压出来，再验证能否踩实这个地板。

**为什么我们挑选端点 $0,\ 2$ 与中点 $1$ 来做“首 $+$ 尾 $- 2 \times$ 中点”消元？** 记 $g(x) = x^2 - ax - b$。既然 $M(a, b)$ 是 $|g(x)|$ 在 $[0, 2]$ 上的最大值，那么由[[卡片/含参绝对值最值与闭区间逼近]]与[[卡片/必要性探路缩界与充分性回代]]，区间内的任意三点都必须受 $M(a, b)$ 约束。分别取左端点 $x = 0$、中点 $x = 1$ 和右端点 $x = 2$ 代入：
$$|g(0)| = |-b| \le M(a, b), \qquad |g(1)| = |1 - a - b| \le M(a, b), \qquad |g(2)| = |4 - 2a - b| \le M(a, b).$$
为了同时消去两个未知参数 $a$ 和 $b$，我们用左端点与右端点之和减去两倍的中点值：
$$g(0) + g(2) - 2g(1) = (-b) + (4 - 2a - b) - 2(1 - a - b) = 2.$$
这个结果竟然是一个与 $a,\ b$ 完全无关的常数 $2$。现在两边同时取绝对值并放缩应用绝对值三角不等式 $|A + B + C| \le |A| + |B| + |C|$：
$$2 = |g(0) + g(2) - 2g(1)| \le |g(0)| + |g(2)| + 2|g(1)| \le M(a, b) + M(a, b) + 2M(a, b) = 4M(a, b).$$
两边同除以 $4$，立即证得对任意 $a, b \in \mathbb{R}$ 恒有：
$$M(a, b) \ge \frac{1}{2}.$$

**如何构造参数 $(a, b)$ 证明最小值恰能取到 $\frac{1}{2}$？** 要使上述放缩链全部取到等号，必须同时满足 $g(0) = g(2) = \frac{1}{2}$ 且 $g(1) = -\frac{1}{2}$（或者符号整体相反，但二次项系数为正，抛物线中间低两边高，只能取两端正、中点负）。列式解出：
- 由 $g(0) = -b = \frac{1}{2}$，得 $b = -\frac{1}{2}$；
- 由 $g(1) = 1 - a + \frac{1}{2} = -\frac{1}{2}$，得 $a = 2$。

现在把构造出的具体参数 $(a, b) = \left(2, -\frac{1}{2}\right)$ 回代原函数检验整个区间 $[0, 2]$ 的充分性：此时
$$f(x) = \left|x^2 - 2x + \frac{1}{2}\right| = \left|(x - 1)^2 - \frac{1}{2}\right|.$$
当 $x \in [0, 2]$ 时，$(x - 1)^2 \in [0, 1]$，于是 $(x - 1)^2 - \frac{1}{2} \in \left[-\frac{1}{2}, \frac{1}{2}\right]$，从而对所有 $x \in [0, 2]$ 恒有 $f(x) \le \frac{1}{2}$，且在 $x = 0,\ 1,\ 2$ 处均恰好取到 $\frac{1}{2}$。这说明 $M\left(2, -\frac{1}{2}\right) = \frac{1}{2}$。综上，$M(a, b)$ 的最小值为 **$\frac{1}{2}$**。

## 学生理解
