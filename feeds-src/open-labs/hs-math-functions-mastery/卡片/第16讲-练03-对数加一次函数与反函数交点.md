# 第16讲·练03：对数加一次函数与反函数交点

## 内容

已知函数 $f(x) = \log_2(x + 2) + x$（$x > -2$）的反函数为 $y = f^{-1}(x)$，若曲线 $y = f(x)$ 与 $y = f^{-1}(x)$ 的交点为 $(x_0, y_0)$，则 $x_0 + y_0$ 的值为（　　）

A. $-2$　　　　B. $-1$　　　　C. $0$　　　　D. $2$

## 参考理解

我们看到题目给出 $f(x) = \log_2(x + 2) + x$ 后，第一反应可能会试着令 $y = \log_2(x + 2) + x$ 去反解 $x$ 关于 $y$ 的表达式，进而写出反函数 $f^{-1}(x)$ 再联立求解。但很快就会发现，未知数 $x$ 同时出现在对数真数和一次项里，根本无法用初等式反解出显式解析式 $f^{-1}(x)$。面对“求原函数与反函数交点却写不出反函数”的困局，我们需要先判断函数的单调性，再借助[[卡片/反函数交点与非对称反例辨析]]完成等价化归。

先验证 $f(x)$ 在定义域 $(-2, +\infty)$ 上的单调性。根据[[卡片/单调性定义证明与抽象单调]]，任取 $-2 < x_1 < x_2$，于是 $0 < x_1 + 2 < x_2 + 2$，由对数函数 $y = \log_2 t$ 严格递增得 $\log_2(x_1 + 2) < \log_2(x_2 + 2)$，同时 $x_1 < x_2$，两式相加即得
$$f(x_1) = \log_2(x_1 + 2) + x_1 < \log_2(x_2 + 2) + x_2 = f(x_2).$$
可见 $f(x)$ 在 $(-2, +\infty)$ 上**严格单调递增**。进一步当 $x$ 趋近于 $-2$ 右侧时 $f(x)$ 可以取遍任意小的负数，当 $x$ 无限增大时 $f(x)$ 可以取遍任意大的正数，因此 $f$ 是一一对应且反函数 $f^{-1}(x)$ 定义在 $\mathbb{R}$ 上。

接着用反证法说明为什么 $y = f(x)$ 与 $y = f^{-1}(x)$ 的任何交点 $(x_0, y_0)$ 都必定落在直线 $y = x$ 上。假设存在交点 $(x_0, y_0)$ 满足 $x_0 \neq y_0$：一方面点 $(x_0, y_0)$ 在 $y = f(x)$ 上，故 $f(x_0) = y_0$；另一方面该点也在 $y = f^{-1}(x)$ 上，由反函数坐标互换关系得 $f^{-1}(x_0) = y_0$，即 $f(y_0) = x_0$。若 $x_0 < y_0$，由 $f$ 严格递增推出 $f(x_0) < f(y_0)$，即 $y_0 < x_0$，与 $x_0 < y_0$ 矛盾；若 $x_0 > y_0$，同理推出 $y_0 > x_0$ 矛盾。因此必有 $y_0 = x_0$，交点一定满足 $f(x_0) = x_0$。

现在把 $f(x_0) = x_0$ 直接代入函数解析式，对数部分与一次项正好消去：
$$\log_2(x_0 + 2) + x_0 = x_0 \implies \log_2(x_0 + 2) = 0 \implies x_0 + 2 = 1 \implies x_0 = -1.$$
检验定义域条件：$x_0 = -1 > -2$ 合法，且对应的纵坐标为 $y_0 = x_0 = -1$。将点 $(-1, -1)$ 回代检验：$f(-1) = \log_2 1 + (-1) = -1$，故 $f^{-1}(-1) = -1$，确实是两曲线唯一的公共交点。因此 $x_0 + y_0 = (-1) + (-1) = -2$，对应选项 **A**。

## 学生理解
