# 函数自身对称与两函数互对称

## 内容

函数对称性最大的考场盲区，是把“**一个函数自身对称**”和“**两个函数互相镜面对称**”的表达式写混，结果把对称轴的正负号全盘算反。只需抓住“有几个函数在画图”以及“令括号内相加等于常数”，所有公式都不需要死背。

### 1. 「同一个函数自身对称」（只有一个 $y = f(x)$）

设函数 $f(x)$ 在 $\mathbb{R}$ 上满足以下恒等式，关键看**两侧括号内自变量表达式相加是否为常数**（系数符号相反）：

1. **自身轴对称**：
   $$f(a + x) = f(b - x) \iff \text{图像关于直线 } x = \frac{a + b}{2} \text{ 轴对称}.$$
   - 推算方法：令两括号内自变量相加再除以 $2$，即 $\frac{(a+x)+(b-x)}{2} = \frac{a+b}{2}$；
   - 特例：$f(x) = f(2a - x) \iff$ 对称轴为 $x = a$。
2. **自身中心对称**：
   $$f(a + x) + f(b - x) = 2c \iff \text{图像关于点 } \left(\frac{a + b}{2}, c\right) \text{ 中心对称}.$$
   - 横坐标：两括号内相加除以 $2$；纵坐标：两函数值相加除以 $2$；
   - 特例：若 $x = \frac{a+b}{2}$ 在定义域内，必有 $f\left(\frac{a+b}{2}\right) = c$。
3. **「复合函数偶/奇性」还原到母函数 $f(x)$（最易错）**：
   - 若已知 **$y = f(x + a)$ 为偶函数**，切忌直接平移错方向，一定要写出偶函数定义：用 $-x$ 替换表达式中的 $x$ 后相等，即 **$f(-x + a) = f(x + a)$**。再将括号内相加除以 $2$，立得母函数 $y = f(x)$ 关于直线 **$x = a$** 对称（不是 $x = -a$）。
   - 若已知 **$y = f(mx + a) - c$（$m \neq 0$）为奇函数**，写出奇函数定义：$\bigl[f(-mx + a) - c\bigr] + \bigl[f(mx + a) - c\bigr] = 0$。令整体 $t = mx$，即得 $f(a - t) + f(a + t) = 2c$，从而母函数 $y = f(x)$ 关于点 **$(a, c)$** 中心对称（伸缩系数 $m$ 不改变中心横坐标 $a$）。

### 2. 「两个不同函数互相镜面对称」

若在同一坐标系中分别画出曲线 $C_1: y = f(a + x)$ 与曲线 $C_2: y = f(b - x)$（这里有两个函数，它们各自并不一定自己对称）：
- 设点 $(x_1, y_0)$ 在 $C_1$ 上，点 $(x_2, y_0)$ 在 $C_2$ 上，要使它们在同一高度对应母函数同一点的函数值，需括号内相同：$a + x_1 = b - x_2 \implies x_1 + x_2 = b - a$；
- 两横坐标中点恒为 $\frac{x_1 + x_2}{2} = \frac{b - a}{2}$。故曲线 **$y = f(a + x)$ 与 $y = f(b - x)$ 关于直线 $x = \frac{b - a}{2}$ 互成镜面对称**（特别地，$y = f(x)$ 与 $y = f(2a - x)$ 关于 $x = a$ 互对称；$y = f(1 + x)$ 与 $y = f(1 - x)$ 关于 $y$ 轴 $x = 0$ 互对称）。

## 参考理解

### 对比清单与考场防混策略

1. **一图胜过十句口诀——区分 $x = a$ 还是 $x = \frac{b-a}{2}$**：
   | 条件类型 | 条件式示例 | 对称轴结果 | 速验法（代 $x=0$ 等具体点看对应） |
   | :--- | :--- | :--- | :--- |
   | **单个函数自身性质** | $f(1+x) = f(3-x)$ | 轴 **$x = 2$** | 令括号取特值：$f(2+t)=f(2-t)$，显然 $x=2$ 两侧对称 |
   | **两不同曲线互对称** | $y=f(x+1)$ 与 $y=f(3-x)$ | 互对称轴 **$x = 1$** | 取 $f(t)=t$ 试画 $y=x+1$ 与 $y=3-x$，交于 $(1, 2)$，显然关于 $x=1$ 对称 |
   一旦发觉分不清“相加还是相减除 $2$”，永远拿具体线性函数 $f(t)=t$ 或抛物线在草稿纸上代一遍，3 秒钟就能保真。
2. **注意「左右变量符号必须相反」才叫对称**：
   如果表达式写成 $f(x + a) = f(x + b)$（$a \neq b$），两侧括号内 **$x$ 前面的符号完全相同**，这时括号相减为常数 $(x+b)-(x+a)=b-a$，表达的是**周期性 $T = |b - a|$**，绝不是轴对称。这是考题最爱埋伏的第一道分辨关。
3. **分段伸缩复合的陷阱**：
   $y = f(2x - 1)$ 为偶函数时，把 $x$ 换成 $-x$ 得 $f(-2x - 1) = f(2x - 1)$，令 $t = 2x$ 得 $f(-1 - t) = f(-1 + t)$，因此母函数 $f(x)$ 的对称轴是 **$x = -1$**（而不是 $\frac{1}{2}$）。千万记住：判偶函数只换自变量 $x \mapsto -x$，不要错改系数去把 $-2x-1$ 配成对称轴为 $x=1/2$。

### 变式追问

1. 已知函数 $y = f(x + 2) + 3$ 是奇函数，母函数 $y = f(x)$ 的图像关于哪一个定点中心对称？必须满足 $f(2)$ 等于什么数值（若 $f(2)$ 有定义）？
2. 若在平面直角坐标系中同时作出 $y = 2^{x-1}$ 与 $y = 2^{3-x}$ 两条曲线，它们的交点横坐标和对称轴分别是哪一条竖直线？这与单条函数对称轴公式如何吻合？
