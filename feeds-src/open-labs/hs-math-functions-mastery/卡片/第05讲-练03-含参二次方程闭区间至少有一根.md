# 第05讲·练03：含参二次方程闭区间至少有一根

## 内容

已知闭区间 $I = [0, 2]$。

(1) 若关于 $x$ 的方程 $x^2 + 2ax + a + 2 = 0$ 在区间 $I$ 上至少有一个实数根，求实数 $a$ 的取值范围；

(2) 若关于 $x$ 的方程 $kx^2 + 2x + 1 = 0$（$k \in \mathbb{R}$）在区间 $I$ 上至少有一个实数根，求实数 $k$ 的取值范围。

## 参考理解

**(1)** 我们看到“在闭区间 $[0, 2]$ 上至少有一个实数根”，如果上来不管三七二十一直接写 $f(0)f(2) \le 0$，马上就会漏掉“两端点函数值同正，但抛物线向下弯进 $(0, 2)$ 里交出两个根或相切于一点”的一大片范围；而如果打算正面把“恰有一根在 $(0, 2)$”“有两根在 $(0, 2)$”“一根或两根踩在 $0$ 或 $2$ 上”全部逐条列举，边界开闭稍一疏忽就容易重漏。根据[[卡片/二次方程根的分布定参法]]，这里最清晰的做法是先展示**正面分类**怎么合并闭区间条件，再用**补集法（正难则反）**做一次彻底交叉校验。

设 $f(x) = x^2 + 2ax + a + 2$，其开口向上、对称轴为 $x = -a$，两端点值为：
$$f(0) = a + 2, \qquad f(2) = 4 + 4a + a + 2 = 5a + 6.$$
按**正面分类**，方程在 $[0, 2]$ 上至少有一根无非以下两类：
- **第一类：$f(0)f(2) \le 0$**（保证两端异号或至少一端点为根，必在 $[0, 2]$ 内至少有一根）：
  $$(a + 2)(5a + 6) \le 0 \implies -2 \le a \le -\frac{6}{5}.$$
- **第二类：$f(0) > 0$ 且 $f(2) > 0$，同时抛物线在 $(0, 2)$ 内向下压到 $x$ 轴或与 $x$ 轴相切**（此时需满足判别式非负且对称轴落在 $(0, 2)$ 内）：
  $$\begin{cases} a + 2 > 0, \\ 5a + 6 > 0, \\ 0 < -a < 2, \\ \Delta = 4(a^2 - a - 2) = 4(a - 2)(a + 1) \ge 0. \end{cases}$$
  前三条联立得 $-\frac{6}{5} < a < 0$，第四条给出 $a \le -1$ 或 $a \ge 2$，取交集即得
  $$-\frac{6}{5} < a \le -1.$$
（顺便检查 $f(0) < 0$ 且 $f(2) < 0$ 的第三类：因开口向上，整段 $[0, 2]$ 都位于 $x$ 轴下方，绝无实根。）两类取并集，直接拼出闭区间 **$[-2, -1]$**。

**为什么再用补集法检验一遍能确保绝对不漏重根或端点？** 反过来问：方程 $f(x) = 0$ 在 $[0, 2]$ 上**完全没有实数根**有哪几种可能？只有以下四种互斥情形：
- 全体实数范围内都无根：$\Delta < 0 \iff -1 < a < 2$；
- 两根（含重根）全在 $0$ 左侧（即 $< 0$）：需 $\Delta \ge 0$（$a \le -1$ 或 $a \ge 2$）、对称轴 $-a < 0$（$a > 0$）、且 $f(0) > 0$（$a > -2$），联立得 $a \ge 2$；
- 两根（含重根）全在 $2$ 右侧（即 $> 2$）：需 $\Delta \ge 0$、对称轴 $-a > 2$（$a < -2$）、且 $f(2) > 0$（$a > -\frac{6}{5}$），显然矛盾无解；
- 两根分居 $[0, 2]$ 两侧（一根 $< 0$ 且另一根 $> 2$）：只需 $f(0) < 0$ 且 $f(2) < 0$，解得 $a < -2$。

将上述无根情况取并集，恰好是 $(-\infty, -2) \cup (-1, +\infty)$，在 $\mathbb{R}$ 中取补集再次严格得到 **$-2 \le a \le -1$**。正反两路完全一致，证明 $a \in [-2, -1]$ 万无一失。

**(2)** 再看第二问 $kx^2 + 2x + 1 = 0$。与第一问最大的不同在于未知参数跑到了**二次项系数 $k$** 上，因此必须先排查退化与正负开口，绝对不能直接套判别式：
- **当 $k = 0$ 时**，方程退化为一次方程 $2x + 1 = 0$，唯一根为 $x = -\frac{1}{2} \notin [0, 2]$，故 $k = 0$ 不合题意；
- **当 $k > 0$ 时**，令 $g(x) = kx^2 + 2x + 1$。注意到对于一切 $x \in [0, 2]$，均有 $kx^2 \ge 0$ 且 $2x + 1 \ge 1$，因此 $g(x) \ge 1 > 0$ 恒成立（也可从抛物线开口向上、对称轴 $x = -\frac{1}{k} < 0$ 且 $g(0) = 1 > 0$ 看出在 $[0, 2]$ 上单调递增且恒正），方程在 $[0, 2]$ 上没有实数根；
- **当 $k < 0$ 时**，抛物线 $g(x) = kx^2 + 2x + 1$ 开口向下，且左端点高度恒为 $g(0) = 1 > 0$。开口向下的抛物线只要在 $x = 0$ 处处于 $x$ 轴上方，就必定在 $0$ 的左侧和右侧各与 $x$ 轴相交一次（且判别式 $\Delta = 4 - 4k > 0$ 自动满足）。要想右侧那个正实根落入闭区间 $[0, 2]$ 内，由于 $g(0) > 0$ 且开口向下，其充要条件正是右端点落到 $x$ 轴下方或恰好在 $x$ 轴上，即：
  $$g(2) = 4k + 5 \le 0 \implies k \le -\frac{5}{4}.$$

检验端点 $k = -\frac{5}{4}$：方程化为 $-\frac{5}{4}x^2 + 2x + 1 = 0 \iff 5x^2 - 8x - 4 = (5x + 2)(x - 2) = 0$，两根为 $x_1 = -\frac{2}{5}$ 与 $x_2 = 2 \in [0, 2]$，确实成立。综上，第一问 $a$ 的取值范围是 **$[-2, -1]$**，第二问 $k$ 的取值范围是 **$\left(-\infty, -\frac{5}{4}\right]$**。
