# 第12讲·练01：由正数与倒数和求分数幂分式值

## 内容

已知实数 $x > 0$ 满足 $x + x^{-1} = 5$，则分式 $\dfrac{x^{\frac{3}{2}} + x^{-\frac{3}{2}}}{x - x^{-1}}$ 的值为（　　）

A. $\dfrac{4\sqrt{3}}{3}$　　　　B. $-\dfrac{4\sqrt{3}}{3}$　　　　C. $\pm\dfrac{4\sqrt{3}}{3}$　　　　D. $\pm 2\sqrt{3}$

## 参考理解

我们拿到这道题时，第一反应可能会想去解二次方程 $x + \frac{1}{x} = 5$（即 $x^2 - 5x + 1 = 0$），算出 $x = \frac{5 \pm \sqrt{21}}{2}$ 再往分数指数幂里代入。但只要看一眼目标分式里的 $x^{\frac{3}{2}}$ 和 $x^{-\frac{3}{2}}$，就能立刻停下这个念头：带二重根号的数再开方、求立方，计算量既大又极易出错。正确思路是根据[[卡片/指对条件求值与整体代换法]]，把互为倒数的幂看成整体，通过平方降幂与因式分解直接把已知量 $x + x^{-1} = 5$ 塞进去。

**为什么我们先看结构消公因式，再决定什么时候开方？** 观察分子与分母：
- 分子 $x^{\frac{3}{2}} + x^{-\frac{3}{2}}$ 是典型的立方和结构，拆解得
  $$x^{\frac{3}{2}} + x^{-\frac{3}{2}} = \left(x^{\frac{1}{2}} + x^{-\frac{1}{2}}\right)\left(x - 1 + x^{-1}\right);$$
  （切记立方和公式中间是**减 $1$**而不是加 $1$，一旦符号记反就会算出 $5 + 1 = 6$，从而掉进选项 D 的圈套。）
- 分母 $x - x^{-1}$ 是典型的平方差结构，拆解得
  $$x - x^{-1} = \left(x^{\frac{1}{2}} + x^{-\frac{1}{2}}\right)\left(x^{\frac{1}{2}} - x^{-\frac{1}{2}}\right).$$

因为 $x > 0$，所以 $x^{\frac{1}{2}} + x^{-\frac{1}{2}} > 0$ 必定非零，分子分母正好可以干净约去公因式 $\left(x^{\frac{1}{2}} + x^{-\frac{1}{2}}\right)$，同时检验分母另一因子：$x + x^{-1} = 5 \neq 2$，故 $x \neq 1$，从而 $x^{\frac{1}{2}} - x^{-\frac{1}{2}} \neq 0$，分式合法有意义，瞬间化简成：
$$\frac{x^{\frac{3}{2}} + x^{-\frac{3}{2}}}{x - x^{-1}} = \frac{x + x^{-1} - 1}{x^{\frac{1}{2}} - x^{-\frac{1}{2}}} = \frac{5 - 1}{x^{\frac{1}{2}} - x^{-\frac{1}{2}}} = \frac{4}{x^{\frac{1}{2}} - x^{-\frac{1}{2}}}.$$

接下来用降幂平方公式求 $x^{\frac{1}{2}} - x^{-\frac{1}{2}}$：
$$\left(x^{\frac{1}{2}} - x^{-\frac{1}{2}}\right)^2 = x - 2 + x^{-1} = 5 - 2 = 3.$$
就在这一步开方时，整道题最核心的陷阱出现了：**为什么我们绝不能顺手只取 $+\sqrt{3}$ 而选 A？** 回头核对题干条件，题干只写了 **$x > 0$**，根本没有告诉你 $x > 1$ 还是 $0 < x < 1$。事实上，方程 $x + x^{-1} = 5$ 有两个互为倒数的正实数解：一个大于 $1$（即 $\frac{5 + \sqrt{21}}{2}$），此时 $x^{\frac{1}{2}} > x^{-\frac{1}{2}}$，于是 $x^{\frac{1}{2}} - x^{-\frac{1}{2}} = \sqrt{3}$；另一个落在 $(0, 1)$ 内（即 $\frac{5 - \sqrt{21}}{2}$），此时 $x^{\frac{1}{2}} < x^{-\frac{1}{2}}$，于是 $x^{\frac{1}{2}} - x^{-\frac{1}{2}} = -\sqrt{3}$。两者都完全符合题干的已知条件。

因此 $x^{\frac{1}{2}} - x^{-\frac{1}{2}} = \pm\sqrt{3}$，代回化简后的分式得：
$$\frac{x^{\frac{3}{2}} + x^{-\frac{3}{2}}}{x - x^{-1}} = \frac{4}{\pm\sqrt{3}} = \pm\frac{4\sqrt{3}}{3},$$
对应选项 **C**。
