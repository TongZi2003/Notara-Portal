# 含参二次函数动轴与区间最值

## 内容

二次函数 $f(x) = a(x - h)^2 + k$（$a \neq 0$）在闭区间 $[m, n]$ 上的最值问题，不论题目让参数跑在对称轴 $h$ 里（「动轴定区间」）还是跑在区间端点里（「定轴动区间」），本质都是比较**对称轴 $h$、左端点 $m$、区间中点 $\frac{m+n}{2}$、右端点 $n$** 四个位置的相对大小。

### 1. 标准分组：开口向上（$a > 0$）

抛物线开口向上时，离对称轴越近函数值越小，离对称轴越远函数值越大：

1. **求最小值 $f_{\min}$（分 3 段，比较 $h$ 与 $m, n$）**：
   - 当 $h \le m$ 时，函数在 $[m, n]$ 单调递增，$f_{\min} = f(m)$；
   - 当 $m < h < n$ 时，顶点落入区间内部，$f_{\min} = f(h) = k$；
   - 当 $h \ge n$ 时，函数在 $[m, n]$ 单调递减，$f_{\min} = f(n)$。

2. **求最大值 $f_{\max}$（只分 2 段，只需比较 $h$ 与中点 $\frac{m+n}{2}$）**：
   最大值一定在某个端点取得，只需判断哪个端点离对称轴更远：
   - 当 $h \le \frac{m+n}{2}$ 时，右端点 $n$ 离对称轴更远，$f_{\max} = f(n)$；
   - 当 $h > \frac{m+n}{2}$ 时，左端点 $m$ 离对称轴更远，$f_{\max} = f(m)$。
   （若题目允许，取等号 $h = \frac{m+n}{2}$ 时两端点同值，分入任意一段均可。）

### 2. 反向情形：开口向下（$a < 0$）

当 $a < 0$ 时图形上下翻转，上述两组策略**完全对调**：
- **最大值 $f_{\max}$ 分 3 段**（对称轴是否在 $[m, n]$ 内）；
- **最小值 $f_{\min}$ 分 2 段**（对称轴在区间中点 $\frac{m+n}{2}$ 的哪一侧）。

### 3. 「动区间」的等价转化

遇到定轴 $x = h$、动区间 $[t, t+d]$ 时，同样直接解不等式 $h \le t$、$t < h < t+d$、$h \ge t+d$（最小值）或 $h \le t + \frac{d}{2}$ 与 $h > t + \frac{d}{2}$（最大值），分界数线一画到底。

## 参考理解

### 高频易错与二次系数含参陷阱

1. **同时求值域（最值之差或最值之和）必须取分界点并集**：
   如果题目问闭区间上的值域 $[f_{\min}, f_{\max}]$ 或求“最大值减去最小值的差 $g(a)$”，那么区间 $[m, n]$ 被 $m, \frac{m+n}{2}, n$ 三个点切成 **4 段**：
   - $h \le m$；
   - $m < h \le \frac{m+n}{2}$；
   - $\frac{m+n}{2} < h < n$；
   - $h \ge n$。
   很多同学只按 3 段分，结果在 $m < h < n$ 内部把 $f_{\max}$ 取在左端点还是右端点算错。
2. **首项系数 $a$ 含参先判正负与退化**：
   当解析式是 $f(x) = a x^2 + bx + c$ 且 $a$ 本身含未知数时，对称轴是 $x = -\frac{b}{2a}$，不能一开始就写分 3 段；必须先按 $a = 0$（一次或常函数）、$a > 0$（开口向上）和 $a < 0$（开口向下）拆出外层大分支，再在各分支内划分子区间。
3. **半开区间要防止最值取不到**：
   如函数在 $(1, 3]$ 上当对称轴在 $x=1$ 左侧单增时，最小值其实是无从谈起的（只有左端点下界却取不到），此时绝对值或恒成立问题必须转用端点边界值核验。

### 变式追问

1. 若求 $f(x) = x^2 - 2ax + 3$ 在 $[-1, 1]$ 上的最值差 $M(a) - m(a)$，在哪四个区间上的表达式各不相同？它在哪个 $a$ 处取得最小差值？
2. 当已知 $f(x) = a x^2 - 2x + 1$ 在 $[1, 2]$ 上的最大值为 $5$ 时，如何用分类讨论避免遗漏 $a<0$ 或 $a=0$ 的解？
