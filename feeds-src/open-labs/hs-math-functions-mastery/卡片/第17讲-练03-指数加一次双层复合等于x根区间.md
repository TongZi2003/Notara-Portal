# 第17讲·练03：指数加一次双层复合等于x根区间

## 内容

已知函数 $f(x) = 3^x + 2x - 3$，则方程 $f\bigl(f(x)\bigr) = x$ 的实数根个数及所在区间分别为（　　）

A. $1$ 个，在 $\left(0, \frac{1}{2}\right)$ 内　　　　B. $1$ 个，在 $\left(\frac{1}{2}, 1\right)$ 内　　　　C. $2$ 个，分别在 $(-1, 0)$ 与 $(0, 1)$ 内　　　　D. $3$ 个，均在 $(-1, 2)$ 内

## 参考理解

我们看到方程 $f\bigl(f(x)\bigr) = x$ 时，千万不能试着把 $3^x + 2x - 3$ 代回自身——写出 $3^{3^x + 2x - 3} + 2(3^x + 2x - 3) - 3 = x$ 不仅完全无法展开化简，还容易被嵌套后的复杂式子吓住，从而误以为这样“套了两层”的方程可能会长出多个交错的实根（就像选项 **C**、**D** 诱导的那样）。而且这里方程的根本身是个无理数，代入整数特值试错也无从下手。面对这种右侧是自变量 $x$ 的自我迭代方程，第一步永远是检查 $f(x)$ 的整体单调性，再借助[[卡片/函数不动点与二周期点分析法]]判断它到底会不会产生额外的往返实根。

先验证 $f(x)$ 的单调性。根据[[卡片/单调性定义证明与抽象单调]]，在 $\mathbb{R}$ 上任取 $x_1 < x_2$：由于指数函数 $y = 3^x$ 严格递增，得 $3^{x_1} < 3^{x_2}$；又一次函数 $y = 2x - 3$ 斜率为 $2 > 0$ 严格递增，得 $2x_1 - 3 < 2x_2 - 3$。两式相加即有
$$f(x_1) = 3^{x_1} + 2x_1 - 3 < 3^{x_2} + 2x_2 - 3 = f(x_2),$$
故 $f(x)$ 在 $\mathbb{R}$ 上**严格单调递增**。

接下来用简短的 $3$ 行反证法说明：在 $\mathbb{R}$ 上，方程 $f\bigl(f(x)\bigr) = x$ 与方程 $f(x) = x$ 拥有**完全相同的实数解集**。一方面，若 $f(x) = x$，两边再同时作用一次 $f$ 即得 $f\bigl(f(x)\bigr) = f(x) = x$；另一方面，假设存在某个实数 $x_0$ 满足 $f\bigl(f(x_0)\bigr) = x_0$ 却有 $f(x_0) \neq x_0$：若 $f(x_0) > x_0$，利用 $f$ 在 $\mathbb{R}$ 上的严格单调递增性对不等式两边再作用一次 $f$，必推出 $f\bigl(f(x_0)\bigr) > f(x_0) > x_0$，与 $f\bigl(f(x_0)\bigr) = x_0$ 矛盾；若 $f(x_0) < x_0$，同理推出 $f\bigl(f(x_0)\bigr) < f(x_0) < x_0$ 矛盾。这就从根源上排除了所有非不动点的迭代根，说明选项 **C**、**D** 里的“多根”绝无可能。

于是原方程直接化归为求解：
$$f(x) = x \iff 3^x + 2x - 3 = x \iff 3^x + x - 3 = 0.$$
令辅助函数 $g(x) = 3^x + x - 3$（$x \in \mathbb{R}$）。同样作为两个严格递增函数 $3^x$ 与 $x - 3$ 的和，$g(x)$ 在 $\mathbb{R}$ 上连续且**严格单调递增**，因而它至多只有 $1$ 个零点。现在利用[[卡片/零点存在定理与二分估界法]]取关键分界点估值缩界：
- 在 $x = 0$ 处，$g(0) = 3^0 + 0 - 3 = -2 < 0$；
- 在 $x = \frac{1}{2}$ 处，$g\left(\frac{1}{2}\right) = \sqrt{3} + \frac{1}{2} - 3 = \sqrt{3} - \frac{5}{2}$，比较平方大小有 $3 < \frac{25}{4} = 6.25$，故 $\sqrt{3} < \frac{5}{2}$，从而 $g\left(\frac{1}{2}\right) < 0$；
- 在 $x = 1$ 处，$g(1) = 3^1 + 1 - 3 = 1 > 0$。

因为 $g\left(\frac{1}{2}\right) g(1) < 0$ 且 $g(x)$ 在 $\mathbb{R}$ 上连续严格递增，所以 $g(x)$ 存在唯一零点 $x_0$，且它严格落在区间 $\left(\frac{1}{2}, 1\right)$ 内。由此可知方程 $f\bigl(f(x)\bigr) = x$ 恰有 $1$ 个实数根，所在区间为 $\left(\frac{1}{2}, 1\right)$，对应选项 **B**。

## 学生理解
