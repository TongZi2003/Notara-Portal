# 第10讲·练01：和差对称抽象函数推周期求和

## 内容

已知定义在 $\mathbb{R}$ 上的非常值函数 $f(x)$ 满足对任意 $x, y \in \mathbb{R}$ 都有 $f(x + y) + f(x - y) = 2f(x)f(y)$，且 $f(1) = \frac{1}{2}$。则下列说法中正确的有（　　）

A. $f(0) = 1$ 且 $f(x)$ 为偶函数

B. $f(2) + f(3) = -\frac{3}{2}$

C. 对任意 $x \in \mathbb{R}$，均有 $f(x + 3) = f(x)$

D. $\sum_{k=1}^{2025} f(k) = -1$

## 参考理解

我们拿到这类对称叠加型的二元抽象函数方程时，由于题干只给了一步函数值 $f(1) = \frac{1}{2}$，没有给出单调性，也没有给出显式表达式，第一步往往会感到无从下手：既看不出明显的对称轴，又找不到像 $f(x+2) = -f(x)$ 那样直接能算出周期的递推式。其实破局的关键完全在于按[[卡片/抽象函数赋值与原型探路法]]执行“定值 $\to$ 奇偶 $\to$ 步长递推消项”的纯代数流水线。

先验证 **A**。很多同学习惯一开始就令 $x = y = 0$，得到 $2f(0) = 2\bigl[f(0)\bigr]^2$，解出 $f(0) = 0$ 或 $f(0) = 1$ 后不知该舍谁。如果卡在二选一上，只需再令 $x = 1, y = 0$ 代入原方程：
$$f(1) + f(1) = 2f(1)f(0) \implies 2 \times \frac{1}{2} = 2 \times \frac{1}{2} \cdot f(0) \implies f(0) = 1.$$
（即使直接用“非常值”排除 $f(0) = 0$ 也可以：若 $f(0) = 0$，令 $y = 0$ 得 $2f(x) = 0 \implies f(x) \equiv 0$，与非常值矛盾。）确定 $f(0) = 1$ 之后，立即令 $x = 0$ 代入原方程：
$$f(y) + f(-y) = 2f(0)f(y) = 2f(y) \implies f(-y) = f(y).$$
对任意 $y \in \mathbb{R}$ 均成立，故 $f(x)$ 为 $\mathbb{R}$ 上的偶函数，**A 正确**。

接着推演递推式与周期，顺便检验 **C**。既然题干给出了 $f(1) = \frac{1}{2}$，我们自然想到在方程中令 $y = 1$（把二元方程降为一元相邻步长递推）：
$$f(x + 1) + f(x - 1) = 2f(x)f(1) = f(x). \quad (*)$$
现在面对三项递推式 $(*)$，如何看出周期？切忌仅凭直觉以为步长相差 $2$ 就能导出周期 $3$ 或 $4$，最严密的做法是**把 $(*)$ 式连续往右平移两次，凑出正负号相抵的相邻项进行消元**：
- 将 $(*)$ 中的 $x$ 换为 $x + 1$，得 $f(x + 2) + f(x) = f(x + 1)$；
- 将 $(*)$ 中的 $x$ 换为 $x + 2$，得 $f(x + 3) + f(x + 1) = f(x + 2)$。

将上面两式左右两边分别相加：
$$f(x + 2) + f(x) + f(x + 3) + f(x + 1) = f(x + 1) + f(x + 2).$$
两边同时消去公共项 $f(x + 1) + f(x + 2)$，瞬间得出一个干净的半周期反号等式：
$$f(x + 3) + f(x) = 0 \implies f(x + 3) = -f(x).$$
由此立知选项 C 错把半周期反号写成了正号等式（例如 $f(3) = -f(0) = -1 \neq f(0)$），故 **C 错误**。由[[卡片/双对称推导周期性与求值法]]，将 $f(x + 3) = -f(x)$ 中的 $x$ 再换为 $x + 3$，立刻得到：
$$f(x + 6) = -f(x + 3) = -\bigl[-f(x)\bigr] = f(x).$$
从而严格推出 **$6$ 是函数 $f(x)$ 的一个周期**。

再来计算 **B** 与 **D** 中的具体函数值。利用三项递推式 $(*)$ 即 $f(x + 1) = f(x) - f(x - 1)$（或结合 $f(x + 3) = -f(x)$），我们可以把一个周期内的全部整数点函数值逐一算清：
- $f(1) = \frac{1}{2}$；
- 取 $x = 1$ 代入 $(*)$：$f(2) = f(1) - f(0) = \frac{1}{2} - 1 = -\frac{1}{2}$；
- 取 $x = 2$ 代入 $(*)$：$f(3) = f(2) - f(1) = -\frac{1}{2} - \frac{1}{2} = -1$（也可直接用 $f(3) = -f(0) = -1$ 互相验算）；
- 利用 $f(x + 3) = -f(x)$ 直接写出后三项：$f(4) = -f(1) = -\frac{1}{2}$，$f(5) = -f(2) = \frac{1}{2}$，$f(6) = -f(3) = 1$。

检验 **B**：$f(2) + f(3) = -\frac{1}{2} + (-1) = -\frac{3}{2}$，与选项一致，**B 正确**。

检验 **D**：先算一个完整周期（连续 $6$ 个整数点）之和：
$$f(1) + f(2) + f(3) + f(4) + f(5) + f(6) = \frac{1}{2} - \frac{1}{2} - 1 - \frac{1}{2} + \frac{1}{2} + 1 = 0.$$
再对总项数 $2025$ 做关于周期 $6$ 的带余除法：$2025 = 6 \times 337 + 3$（因为 $6 \times 337 = 2022$）。因此前 $2022$ 项分成 $337$ 个周期总和为 $0$，只需加上末尾余下的 $3$ 项：
$$\sum_{k=1}^{2025} f(k) = 337 \times 0 + f(1) + f(2) + f(3) = \frac{1}{2} - \frac{1}{2} - 1 = -1.$$
故 **D 正确**。综上，正确选项为 **ABD**。
