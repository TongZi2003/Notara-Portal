# 反函数交点与非对称反例辨析

## 内容

互为反函数的两曲线 $y = f(x)$ 与 $y = f^{-1}(x)$ 关于直线 $y = x$ 对称。高一同学最容易脱口而出“它们互为反函数，所以交点一定都在直线 $y = x$ 上”。这个命题**只在函数单调递增时成立，遇到单调递减函数则大错特错**。

### 1. 为什么「严格递增函数」的所有交点必在 $y = x$ 上？（纯反证法，3 行严密自证）

设 $y = f(x)$ 是严格单调**递增**函数，假设它与反函数 $y = f^{-1}(x)$ 存在一个**不在**直线 $y = x$ 上的交点 $(u, v)$（即 $u \neq v$）：
- 因为交点 $(u, v)$ 在 $y = f(x)$ 上，所以 $f(u) = v$；
- 又因为该点同时在 $y = f^{-1}(x)$ 上，由反函数定义互换坐标得 **$f(v) = u$**；
- 既然 $u \neq v$，不妨设 $u < v$，由 $f$ 严格单调递增立即推出 $f(u) < f(v)$，即 **$v < u$**，与前提 $u < v$ **矛盾**。
（同理 $u > v$ 亦推出 $v > u$ 矛盾。）因此**严格递增函数的反函数交点，100% 全部落在对称轴 $y = x$ 上**。

### 2. 为什么「单调递减函数」可以长出 $y = x$ 之外的交点？

把上面反证法里的“递增”换成“**严格递减**”：
- 如果 $u < v$ 且 $f$ 严格递减，则应该推出 $f(u) > f(v)$，即 **$v > u$**——**这与假设 $u < v$ 完全相容，毫无矛盾**。
- 所以对严格递减函数，完全允许出现不在 $y = x$ 上的**互反对称交点对** $(u, v)$ 与 $(v, u)$（其中 $f(u) = v$ 且 $f(v) = u$）。

### 3. 经典纯初等铁证反例：$a = \frac{1}{16}$ 时 $y = a^x$ 与 $y = \log_a x$ 恰有 $3$ 个交点

令底数 $a = \frac{1}{16} \in (0, 1)$，两递减函数 $f(x) = \left(\frac{1}{16}\right)^x$ 与 $g(x) = \log_{\frac{1}{16}} x$ 互为反函数：
1. **直线 $y = x$ 上必有一点**：设 $h(x) = \left(\frac{1}{16}\right)^x - x$（减函数减增函数 $=$ 严格减函数），$h(0) = 1 > 0$，$h(1) = \frac{1}{16} - 1 < 0$，故直线 $y=x$ 上有唯一对角交点 $(x_0, x_0)$（数值估算 $x_0 \approx 0.36$）；
2. **直线 $y = x$ 之外的一对精确有理数交点**：直接代入验证 $u = \frac{1}{4}$ 与 $v = \frac{1}{2}$：
   - 计算 $f\left(\frac{1}{4}\right) = \left(\frac{1}{16}\right)^{\frac{1}{4}} = \frac{1}{2}$，所以 $\left(\frac{1}{4}, \frac{1}{2}\right)$ 落在指数曲线上；
   - 计算 $g\left(\frac{1}{4}\right) = \log_{\frac{1}{16}}\left(\frac{1}{4}\right) = \frac{1}{2}$，所以 $\left(\frac{1}{4}, \frac{1}{2}\right)$ **也落在对数曲线上**。
   - 同理验证 $u = \frac{1}{2}$：$f\left(\frac{1}{2}\right) = \left(\frac{1}{16}\right)^{\frac{1}{2}} = \frac{1}{4} = \log_{\frac{1}{16}}\left(\frac{1}{2}\right)$，所以对称点 $\left(\frac{1}{2}, \frac{1}{4}\right)$ 同样是两曲线的公共交点。
于是 $y = \left(\frac{1}{16}\right)^x$ 与 $y = \log_{\frac{1}{16}} x$ 至少已有 **$3$ 个不同交点**（高阶可证事实上当 $0 < a < e^{-e} \approx 0.066$ 时恰为 $3$ 个交点，注意 $\frac{1}{16} = 0.0625 < 0.066$），而仅有 $(x_0, x_0)$ 一个在直线 $y = x$ 上。

## 参考理解

### 对高一考题的直接启示

1. **求解递减函数方程 $f(x) = f^{-1}(x)$ 时绝不能简单等价成 $f(x) = x$**：
   - 如遇到“解方程 $f(x) = f^{-1}(x)$”且 $f(x)$ 是分段函数或递减幂/指数函数，直接写成 $f(x) = x$ 会导致**整对整对漏掉不在 $y = x$ 上的对称交点 $(u, v)$ 与 $(v, u)$**；
   - 正确做法是把它改写为更对称的复合方程：**$f\bigl(f(x)\bigr) = x$**。事实上，交点 $(u, v)$ 满足 $f(u) = v$ 且 $f(v) = u$，消去 $v$ 恰好就是 **$f(f(u)) = u$**（即[[卡片/函数不动点与二周期点分析法]]所说的二周期点）。
2. **「$a > 1$ 时 $a^x = \log_a x$」同样能有 $0, 1, 2$ 个交点（都在 $y = x$ 上）**：
   不要因为 $a=2$ 时 $2^x$ 和 $\log_2 x$ 永远隔着 $y=x$ 互不相交（$0$ 个交点），就误以为 $a>1$ 时永不相交。当 $a$ 贴近 $1^+$ 比如 $a = 1.2$ 时：$1.2^x$ 在 $x=2$ 处取值 $1.44 < 2$、在 $x=10$ 处取值 $6.19 < 10$、而在 $x=20$ 处早已冲上 $38.3 > 20$。这直接说明 $y = 1.2^x$ 与直线 $y = x$ 在 $(1, +\infty)$ 上切开了 $2$ 个交点。由递增对称律，这时 $1.2^x$ 与 $\log_{1.2} x$ 在 $y = x$ 上恰有 **$2$ 个交点**（无需任何超纲知识，取具体数字代入比大小就一目了然）。

### 变式追问

1. 自己用数字检验底数 $a = \sqrt{2} \approx 1.414$ 时，$y = (\sqrt{2})^x$ 与直线 $y = x$ 在 $x=2$ 和 $x=4$ 处恰好取到什么关系？这是否说明 $y = (\sqrt{2})^x$ 与 $y = \log_{\sqrt{2}} x$ 在直线 $y = x$ 上至少有哪两个精确整数交点？
2. 对于递减幂函数 $f(x) = -x^3$（定义在 $\mathbb{R}$ 上），它和自己的反函数 $f^{-1}(x) = -\sqrt[3]{x}$ 在平面上共有多少个交点？哪些在 $y = x$ 上，哪些在 $y = x$ 之外（直接代 $x = -1, 0, 1$ 验证）？
