# 第12讲·练10：指数与平移对数方程两根和积

## 内容

已知实数 $x_1$ 满足 $2^{x_1} + x_1 = 5$，实数 $x_2$ 满足 $\log_2(x_2 + 1) + x_2 = 4$。关于 $x_1 + x_2$ 的值以及 $x_1 x_2$ 满足的范围，下列判断正确的是（　　）

A. $x_1 + x_2 = 5$，且 $x_1 x_2 \in \left(\frac{21}{4}, \frac{25}{4}\right)$

B. $x_1 + x_2 = 4$，且 $x_1 x_2 \in \left(\frac{15}{4}, 4\right)$

C. $x_1 + x_2 = 4$，且 $x_1 x_2 \in \left(3, \frac{15}{4}\right)$

D. $x_1 + x_2 = 3$，且 $x_1 x_2 \in \left(2, \frac{9}{4}\right)$

## 参考理解

这两道方程分别含有 $2^{x_1}$ 和 $\log_2(x_2 + 1)$，显而易见两者都不能用初等代数求根公式把 $x_1, x_2$ 精确解出来。如果只机械记忆“$a^{x_1} + x_1 = c$ 与 $\log_a x_2 + x_2 = c$ 的两根之和直接等于右侧常数 $c$”，就很容易一看到第一式右边是 $5$（或只盯着 $\log_2$ 里多了一个 $+1$ 却把右边配反）而直接把 $x_1 + x_2$ 猜成 $5$ 或 $3$，立刻掉进选项 A 或 D 的圈套。

**为什么我们先要把第二个方程的括号外也同步配凑出 $x_2 + 1$？** 根据[[卡片/指数对数反函数对称与恒过定点]]，反函数对称求两根之和的真正几何前提是：两条曲线 $y = 2^t$ 与 $y = \log_2 t$ 关于直线 $y = x$ 对称，而且它们必须交在**同一条斜率为 $-1$ 的直线 $y = c - t$** 上。为了把第二个方程里的 $\log_2(x_2 + 1)$ 还原成标准对数函数 $\log_2 t$，我们在方程 $\log_2(x_2 + 1) + x_2 = 4$ 两边同时加上 $1$，得到
$$\log_2(x_2 + 1) + (x_2 + 1) = 5.$$
令 $t_2 = x_2 + 1$（由真数大于零知 $t_2 > 0$），则上式完全化归为
$$\log_2 t_2 + t_2 = 5.$$
现在对比两个标准形式：
- 点 $A(x_1, 5 - x_1)$ 是指数函数 $y = 2^x$ 与直线 $l: y = 5 - x$ 的交点；
- 点 $B(t_2, 5 - t_2)$ 是对数函数 $y = \log_2 x$ 与同一条直线 $l: y = 5 - x$ 的交点。

因为 $y = 2^x$ 与 $y = \log_2 x$ 都严格单调递增且互为反函数（图像关于直线 $y = x$ 对称），而直线 $l: y = 5 - x$ 严格单调递减且自身也关于直线 $y = x$ 对称，所以每条曲线与直线 $l$ 都**至多且恰好有一个交点**，并且 $A$ 与 $B$ 必然关于直线 $y = x$ 严格对称。于是 $B$ 的横坐标等于 $A$ 的纵坐标，即 $t_2 = 5 - x_1$，从而
$$x_1 + t_2 = 5 \implies x_1 + (x_2 + 1) = 5 \implies x_1 + x_2 = 4.$$
（我们也可以不用画图直接做纯代数互逆验证：由 $\log_2 t_2 = 5 - t_2$ 得 $t_2 = 2^{5 - t_2}$，移项整理为 $2^{5 - t_2} + (5 - t_2) = 5$；由于函数 $g(x) = 2^x + x$ 在 $\mathbb{R}$ 上严格单调递增且 $g(x_1) = 5$，立得 $x_1 = 5 - t_2 = 4 - x_2$，同样得到 $x_1 + x_2 = 4$。）这一步直接排除了选项 A 和 D。

**为什么接着不能只停在 $1 < x_1 < 2$ 或盲目用均值不等式把 $x_1 x_2$ 写成 $\le 4$？** 因为 $x_1 + x_2 = 4$，我们要先精细缩窄 $x_1$ 的区间，进而判断乘积 $x_1 x_2 = x_1(4 - x_1)$ 究竟落在 $\left(3, \frac{15}{4}\right)$ 还是 $\left(\frac{15}{4}, 4\right)$（注意这两个区间恰好分居 $x_1 = \frac{3}{2}$ 两侧）。根据[[卡片/零点存在定理与二分估界法]]，考察严格单调递增函数 $g(x) = 2^x + x - 5$：
- 在 $x = \frac{3}{2}$ 处，因为 $2^{\frac{3}{2}} = 2\sqrt{2} = \sqrt{8} < \sqrt{9} = 3$，所以
  $$g\left(\frac{3}{2}\right) = 2\sqrt{2} + \frac{3}{2} - 5 < 3 + \frac{3}{2} - 5 = -\frac{1}{2} < 0;$$
- 在 $x = 2$ 处，
  $$g(2) = 2^2 + 2 - 5 = 1 > 0.$$
由零点存在定理及 $g(x)$ 的严格单调性，唯一零点 $x_1$ 必定严格落在开区间 $\left(\frac{3}{2}, 2\right)$ 内，即
$$\frac{3}{2} < x_1 < 2.$$
从而 $x_2 = 4 - x_1 \in \left(2, \frac{5}{2}\right)$，可见 $x_1 < 2 < x_2$，两者绝对不可能相等。

现在考察乘积关于 $x_1$ 的二次函数
$$P(x_1) = x_1 x_2 = x_1(4 - x_1) = -(x_1 - 2)^2 + 4, \qquad x_1 \in \left(\frac{3}{2}, 2\right).$$
该抛物线开口向下、对称轴为 $x_1 = 2$，因此在开区间 $\left(\frac{3}{2}, 2\right)$ 上严格单调递增：
- 左端点对应下界为 $P\left(\frac{3}{2}\right) = \frac{3}{2}\left(4 - \frac{3}{2}\right) = \frac{3}{2} \times \frac{5}{2} = \frac{15}{4}$；
- 右端点对应上界为 $P(2) = 2 \times 2 = 4$。
由于 $x_1$ 取不到 $\frac{3}{2}$ 也取不到 $2$，因此乘积严格落在开区间 $\left(\frac{15}{4}, 4\right)$ 内，对应选项 **B**。
