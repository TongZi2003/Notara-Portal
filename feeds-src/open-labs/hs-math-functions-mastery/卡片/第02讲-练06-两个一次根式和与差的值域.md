# 第02讲·练06：两个一次根式和与差的值域

## 内容

设函数 $f(x) = \sqrt{x + 2} + \sqrt{6 - x}$ 的值域为 $A$，函数 $g(x) = \sqrt{x + 2} - \sqrt{6 - x}$ 的值域为 $B$，则（　　）

A. $A = [2\sqrt{2}, 4]$，$B = [0, 2\sqrt{2}]$　　　　　　　B. $A = [2\sqrt{2}, 4]$，$B = [-2\sqrt{2}, 2\sqrt{2}]$
C. $A = [-4, -2\sqrt{2}] \cup [2\sqrt{2}, 4]$，$B = [-2\sqrt{2}, 2\sqrt{2}]$　　D. $A = [0, 4]$，$B = [0, 2\sqrt{2}]$

## 参考理解

先帮两个函数同时锁定定义域：使两个根式都有意义需要 $\begin{cases} x + 2 \ge 0, \\ 6 - x \ge 0, \end{cases}$ 即闭区间 $x \in [-2, 6]$。这两个函数的长相只差中间一个加减号，但求解路径却截然不同，如果混用套路，极易分别掉进“丢掉正负号检查”或“误用单调性代端点”的陷阱。

**为什么求 $f(x) = \sqrt{x + 2} + \sqrt{6 - x}$ 的值域 $A$ 不能直接代入端点，而要想到两边平方？** 因为在 $[-2, 6]$ 上，前项 $\sqrt{x + 2}$ 单调递增、后项 $\sqrt{6 - x}$ 单调递减，“增函数 + 减函数”并不保持单调性。如果只代入端点 $x = -2$ 和 $x = 6$，算出来的都是 $2\sqrt{2}$，显然漏掉了中间拱起的最高点。相反地，我们注意到两个被开方数相加时 $x$ 恰好抵消为常数：$(x + 2) + (6 - x) = 8$。根据[[卡片/根式函数值域代数与几何法]]，做平方配凑就能消掉一次根号，只留下一个二次三项式的算术平方根。

在落笔平方之前，必须先把**正负范围**定下来：两个算术平方根均非负且不可能同时为零（因为 $x + 2 = 0$ 与 $6 - x = 0$ 无公共解），所以对一切 $x \in [-2, 6]$ 必有 **$f(x) > 0$**。随后两边平方整理：
$$[f(x)]^2 = (x + 2) + (6 - x) + 2\sqrt{(x + 2)(6 - x)} = 8 + 2\sqrt{-x^2 + 4x + 12}.$$
把根号内配成顶点式：$-x^2 + 4x + 12 = -(x - 2)^2 + 16$。在闭区间 $x \in [-2, 6]$ 上，对称轴 $x = 2$ 恰好是区间中点，所以 $-(x - 2)^2 + 16$ 在 $x = 2$ 处取到最大值 $16$，在两端点 $x = -2$ 和 $x = 6$ 处取到最小值 $0$。代回去可得：
$$[f(x)]^2 \in [8 + 0,\ 8 + 2\times 4] = [8, 16].$$
这里剪除第一个错误分支：由 $[f(x)]^2 \in [8, 16]$ 开方时，千万不能习惯性地加上 $\pm$ 号写成 $[-4, -2\sqrt{2}] \cup [2\sqrt{2}, 4]$（对应陷阱选项 C）；因为前面已经确定了 $f(x) > 0$，开方必须舍去负支，得到 **$A = [2\sqrt{2}, 4]$**（也不能像选项 D 那样误把下界写成 $0$）。

**为什么处理减法函数 $g(x) = \sqrt{x + 2} - \sqrt{6 - x}$ 时，不建议平方而要直接用单调性？** 因为在 $[-2, 6]$ 上，$\sqrt{x + 2}$ 严格递增，而 $\sqrt{6 - x}$ 严格递减，加上负号之后 $-\sqrt{6 - x}$ 就变成了严格递增函数。于是 $g(x)$ 是两个严格递增函数之和，**在 $[-2, 6]$ 上整体严格单调递增**。我们直接代左右端点就能一步算出精确值域：
- 最小值 $g(-2) = \sqrt{0} - \sqrt{8} = -2\sqrt{2}$；
- 最大值 $g(6) = \sqrt{8} - \sqrt{0} = 2\sqrt{2}$。

因此 **$B = [-2\sqrt{2}, 2\sqrt{2}]$**。这里顺便检验一下如果盲目平方 $g(x)$ 会怎么踩坑：算得 $[g(x)]^2 = 8 - 2\sqrt{-(x - 2)^2 + 16} \in [0, 8]$ 后，一旦忘了判断 $g(x)$ 在 $[-2, 2)$ 上为负、在 $(2, 6]$ 上为正，直接取算术平方根就会错写成 $[0, 2\sqrt{2}]$（对应陷阱选项 A 和 D）。对比可知，正确答案为 **B**。
