# 第19讲·例1：含参二次绝对值闭区间上下界

## 内容

已知函数 $f(x) = |x^2 - ax| + a$（$a \in \mathbb{R}$）。

(1) 若对任意 $x \in [0, 2]$ 恒有 $f(x) \ge 1$，求实数 $a$ 的取值范围；

(2) 若对任意 $x \in [0, 2]$ 恒有 $f(x) \le 4$，求实数 $a$ 的取值范围。

**(1)** 我们拿到这道带绝对值又含参数 $a$ 的闭区间恒成立题时，最容易陷入的泥潭是一上来就按零点 $x = 0$ 与 $x = a$ 硬把区间拆成四五块分类讨论。依照[[卡片/必要性探路缩界与充分性回代]]，面对“对任意 $x \in [0, 2]$ 成立”的全称条件，第一步应该先挑顺手的特征点把参数范围快速压小。

- **第一步：端点探路缩界**。令 $x = 0 \in [0, 2]$ 代入第 (1) 问条件 $f(x) \ge 1$，立即得到：
  $$f(0) = |0^2 - a \cdot 0| + a = a \ge 1.$$
  仅仅这一个点，就把 $a < 1$ 的无穷多种可能一刀全部砍掉。
- **第二步：回代检验充分性**。当 $a \ge 1$ 时，由于绝对值具有非负性，对一切 $x \in [0, 2]$ 均有 $|x^2 - ax| \ge 0$，于是
  $$f(x) = |x^2 - ax| + a \ge 0 + a = a \ge 1$$
  天然恒成立。若想进一步看清不同参数段下内部零点与顶点的真实走势，不妨对照核查一下：当 $a \in [1, 2]$ 时，绝对值内部的零点 $x = a$ 与翻折抛物线的顶点 $x = \frac{a}{2}$ 同时落在 $[0, 2]$ 内，$f(x)$ 在 $x = 0$ 与 $x = a$ 两处落地取最小值 $a \ge 1$，中间在 $x = \frac{a}{2}$ 处拱起至 $\frac{a^2}{4} + a$，在右端 $x = 2$ 处取 $4 - a$；当 $a > 2$ 时，在 $[0, 2]$ 上恒有 $x^2 - ax \le 0$，$f(x) = -x^2 + ax + a$ 开口向下，最小值必在端点取得，而 $f(0) = a > 2 > 1$、$f(2) = 3a - 4 > 2 > 1$。因此第 (1) 问中实数 $a$ 的精确范围是 **$[1, +\infty)$**。

**(2)** 千万别以为第 (1) 问探完端点就直接过关了，第 (2) 问 $f(x) \le 4$ 正是要演示**“为什么只靠端点探路会放出假解，必须做完充分性内部校验”**。

- **第一步：先拿左右端点 $x = 0$ 与 $x = 2$ 探路**。
  由 $f(0) = a \le 4$；再代 $x = 2$，得 $f(2) = |4 - 2a| + a \le 4$：
  - 若 $a \le 2$，则 $4 - 2a + a = 4 - a \le 4 \implies a \ge 0$；
  - 若 $a > 2$，则 $2a - 4 + a = 3a - 4 \le 4 \implies a \le \frac{8}{3}$。
  于是两个端点已经把候选范围锁进闭区间 **$a \in \left[0, \frac{8}{3}\right]$**。
- **第二步：严密检验候选框 $\left[0, \frac{8}{3}\right]$ 内部的峰值**。
  注意到这里需要控制的是 $f(x)$ 在 $[0, 2]$ 上的**最大值 $\le 4$**，而绝对值翻折后区间内部可能藏着比端点更高的抛物线拱顶，必须按零点 $x = a$ 是否落出 $[0, 2]$ 分为两段核查：
  - **当 $0 \le a \le 2$ 时**：在 $[0, a]$ 上 $x^2 - ax \le 0$，故 $f(x) = -x^2 + ax + a = -\left(x - \frac{a}{2}\right)^2 + \frac{a^2}{4} + a$，内部顶点在 $x = \frac{a}{2} \in [0, 1]$，最大值为 $\frac{a^2}{4} + a \le \frac{4}{4} + 2 = 3 < 4$；在 $[a, 2]$ 上 $x^2 - ax \ge 0$，故 $f(x) = x^2 - ax + a$，其对称轴 $\frac{a}{2} \le a$，因此在 $[a, 2]$ 上单调递增，最大值为 $f(2) = 4 - a \le 4$。所以整个闭区间 **$[0, 2]$ 全部成立**。
  - **当 $2 < a \le \frac{8}{3}$ 时**：对任意 $x \in [0, 2]$ 均有 $x(x - a) \le 0$，所以整段区间上都去掉了绝对值：$f(x) = -x^2 + ax + a$。它的抛物线顶点横坐标 $x = \frac{a}{2} \in \left(1, \frac{4}{3}\right]$ 恰恰落在区间 $[0, 2]$ 的**正内部**。这时如果误以为端点 $\frac{8}{3}$ 成立就万事大吉，代回内部顶点看看：$a = \frac{8}{3}$ 时 $f\left(\frac{4}{3}\right) = \frac{16}{9} + \frac{8}{3} = \frac{40}{9} > 4$，早已冲破了天花板 $4$。因此必须压住顶点峰值：
    $$f(x)_{\max} = f\left(\frac{a}{2}\right) = \frac{a^2}{4} + a \le 4 \iff a^2 + 4a - 16 \le 0.$$
    解方程 $a^2 + 4a - 16 = 0$ 得正根 $a = -2 + 2\sqrt{5}$，结合前提 $2 < a \le \frac{8}{3}$（注意到 $2\sqrt{5} - 2 = \sqrt{20} - 2 < \sqrt{\frac{196}{9}} - 2 = \frac{8}{3}$ 且 $2\sqrt{5} - 2 > 2$），得到合法部分为 **$2 < a \le 2\sqrt{5} - 2$**。

将两段合格区间合并，第 (2) 问中实数 $a$ 的完整取值范围是 **$[0, 2\sqrt{5} - 2]$**。这道题两问对比下来十分鲜明：探路只能给出必要的大框，真正守住满分的，永远是对内部关键极值点的充分性回代。
