# 第12讲·练12：四个分数幂函数奇偶性与图像

## 内容

已知四个幂函数分别为 $f_1(x) = x^{\frac{2}{3}}$，$f_2(x) = x^{-\frac{1}{2}}$，$f_3(x) = x^{\frac{3}{5}}$，$f_4(x) = x^{-\frac{2}{3}}$。下列说法正确的有（　　）

A. 这四个函数中，定义域为 $\mathbb{R}$ 且图像经过原点的共有 $2$ 个，偶函数共有 $2$ 个

B. 当 $x \in (0, 1)$ 时，函数值的大小关系为 $f_4(x) > f_2(x) > f_3(x) > f_1(x)$

C. 函数 $f_1(x)$ 与 $f_4(x)$ 均在 $(-\infty, 0)$ 上单调递增，在 $(0, +\infty)$ 上单调递减

D. 方程 $f_1(x) = f_4(x)$ 共有 $2$ 个不同的实数根，而方程 $f_2(x) = f_4(x)$ 只有 $1$ 个实数根

## 参考理解

我们面对四个分数指数幂函数放在一起对比时，最容易出现的失误有两种：一是只盯着第一象限的图像草图，忘了先通过最简分数指数的分子分母奇偶性去核对**能不能取 $x = 0$** 以及**左半平面到底有没有图像**；二是在 $(0, 1)$ 区间比大小时，错把 $(1, +\infty)$ 上“指数越大图像越高”的规律直接套进来，或者把 $\frac{3}{5}$ 和 $\frac{2}{3}$ 之间的高低关系弄反。

**为什么我们先要把四个幂函数的最简分数形式 $\frac{p}{q}$ 一一拆开建档？** 依据[[卡片/幂函数第一象限图像与奇偶性]]，先将四个指数按既约分数 $\frac{p}{q}$（$q \in \mathbb{N}^*$，$\gcd(|p|, q) = 1$）列出各自的定义域、原点通过性与奇偶性：
1. $f_1(x) = x^{\frac{2}{3}} = \sqrt[3]{x^2}$：$p = 2 > 0$（偶）、$q = 3$（奇）。$x = 0$ 有意义且 $f_1(0) = 0$，分母为奇允许取负，定义域为 $\mathbb{R}$；分子为偶，故为**偶函数**。
2. $f_2(x) = x^{-\frac{1}{2}} = \frac{1}{\sqrt{x}}$：$p = -1 < 0$（奇）、$q = 2$（偶）。负指数不允许 $x = 0$，偶数分母不允许 $x < 0$，定义域为 $(0, +\infty)$；定义域不关于原点对称，故为**非奇非偶函数**。
3. $f_3(x) = x^{\frac{3}{5}} = \sqrt[5]{x^3}$：$p = 3 > 0$（奇）、$q = 5$（奇）。$x = 0$ 有意义且 $f_3(0) = 0$，定义域为 $\mathbb{R}$；分子为奇，故为**奇函数**。
4. $f_4(x) = x^{-\frac{2}{3}} = \frac{1}{\sqrt[3]{x^2}}$：$p = -2 < 0$（偶）、$q = 3$（奇）。负指数不允许 $x = 0$，奇数分母允许 $x < 0$，定义域为 $\{x \mid x \neq 0\}$；分子为偶且定义域对称，故为**偶函数**。

现在根据建档结果逐一判断四个选项：
- **先看选项 A**：定义域为 $\mathbb{R}$ 且图像过 $(0, 0)$ 的函数是 $f_1(x)$ 和 $f_3(x)$，共 $2$ 个；偶函数是 $f_1(x)$ 和 $f_4(x)$（切勿因为 $f_4(x)$ 挖掉了原点而怀疑它不是偶函数——定义域 $\{x \mid x \neq 0\}$ 关于原点对称且 $f_4(-x) = f_4(x)$），共 $2$ 个。因此 **A 正确**。
- **再看选项 B**：把四个指数按从小到大排成一列：因为 $-\frac{2}{3} = -\frac{4}{6} < -\frac{3}{6} = -\frac{1}{2}$，且 $\frac{3}{5} = \frac{9}{15} < \frac{10}{15} = \frac{2}{3}$，所以
  $$-\frac{2}{3} < -\frac{1}{2} < \frac{3}{5} < \frac{2}{3}.$$
  根据[[卡片/幂函数第一象限图像与奇偶性]]的“过 $(1, 1)$ 前后高低翻转规律”，当底数 $x \in (0, 1)$ 时，**幂指数越大，函数值越小（图像越低）**。因此大小顺序恰好倒过来：
  $$x^{-\frac{2}{3}} > x^{-\frac{1}{2}} > x^{\frac{3}{5}} > x^{\frac{2}{3}},$$
  即 $f_4(x) > f_2(x) > f_3(x) > f_1(x)$（也可取特值 $x = 2^{-30} \in (0, 1)$ 直观验证：$2^{20} > 2^{15} > 2^{-18} > 2^{-20}$）。因此 **B 正确**。
- **再看选项 C**：$f_4(x) = x^{-\frac{2}{3}}$ 在 $(0, +\infty)$ 上确实单调递减，结合它是偶函数（图像关于 $y$ 轴对称），在 $(-\infty, 0)$ 上确为单调递增；但 $f_1(x) = x^{\frac{2}{3}}$ 因为指数 $\frac{2}{3} > 0$，在 $(0, +\infty)$ 上**单调递增**，利用偶函数关于 $y$ 轴的对称性，它在 $(-\infty, 0)$ 上反而**单调递减**（呈过原点的向上开口尖底形），与 $f_4(x)$ 的单调方向正好相反。因此 **C 错误**。
- **最后看选项 D**：解两个函数相等的方程，最关键的是先取两边函数的**公共定义域**，切忌直接平方消分母产生增根：
  - 对于方程 $f_1(x) = f_4(x)$，即 $x^{\frac{2}{3}} = x^{-\frac{2}{3}}$，公共定义域为 $\{x \mid x \neq 0\}$。两边同乘正数 $x^{\frac{2}{3}}$，等价于 $x^{\frac{4}{3}} = 1 \iff \sqrt[3]{x^4} = 1 \iff x^4 = 1$，在实数范围内解得 $x = 1$ 或 $x = -1$（代回验证 $f_1(-1) = f_4(-1) = 1$ 均成立），共有 $2$ 个不同实根。
  - 对于方程 $f_2(x) = f_4(x)$，即 $x^{-\frac{1}{2}} = x^{-\frac{2}{3}}$，由于 $f_2(x)$ 要求 $x > 0$，公共定义域收紧为 $(0, +\infty)$。在 $x > 0$ 上方程等价于 $x^{\frac{2}{3} - \frac{1}{2}} = x^{\frac{1}{6}} = 1$，唯一解为 $x = 1$（负半轴根本不在 $f_2$ 的定义域内，因此绝对不可能出现第二个根）。
  所以两个方程的实根个数分别为 $2$ 个和 $1$ 个，**D 正确**。

综上，说法正确的有 **ABD**。
