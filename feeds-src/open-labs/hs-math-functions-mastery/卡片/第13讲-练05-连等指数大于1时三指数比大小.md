# 第13讲·练05：连等指数大于1时三指数比大小

## 内容

已知实数 $a, b, c$ 满足 $2^a = 3^b = 5^c > 1$，则下列结论正确的是（　　）

A. $2a < 3b < 5c$ 且 $a + c < 2b$
B. $3b < 2a < 5c$ 且 $a + c < 2b$
C. $3b < 2a < 5c$ 且 $a + c > 2b$
D. $5c < 2a < 3b$ 且 $a + c > 2b$

## 参考理解

我们遇到“三个不同底数的指数连等”时，最直接的思路往往是设出公共值后分别用 $\log_2 k, \log_3 k, \log_5 k$ 表示，再凭直觉以为 $a > b > c$ 乘上越大的系数 $2, 3, 5$ 后序列方向依然单调，于是随便猜成 $2a < 3b < 5c$ 或 $5c < 3b < 2a$；同时在比较 $a + c$ 与 $2b$ 时，很多同学算出倒数和 $\frac{1}{a} + \frac{1}{c} > \frac{2}{b}$ 后就直接反号猜成 $a + c < 2b$，却忘了倒数不等式反号必须满足“两端先化为同向单调或中间加桥”，不能凭空翻方向。

**为什么我们先设连等号整体等于 $k$ 并取常用对数作商？** 根据[[卡片/指对条件求值与整体代换法]]，令
$$2^a = 3^b = 5^c = k.$$
因为题设给定 $k > 1$，由指数函数的单调性可知 $a > 0, b > 0, c > 0$，且 $\lg k > 0$。对等式两端分别取常用对数，把三个未知数统一用同一系数 $\lg k$ 表达出来：
$$a = \frac{\lg k}{\lg 2}, \qquad b = \frac{\lg k}{\lg 3}, \qquad c = \frac{\lg k}{\lg 5}.$$

先比较 $2a, 3b, 5c$ 这三个正数的大小。根据[[卡片/作商换底与基本不等式比大小]]，因为它们全为正数且共享同一个公因子 $\lg k$，作商之后参数 $k$ 立刻消去，直接把系数塞回对数的指数位置即可比出真数高低：
- 比较 $2a$ 与 $3b$：
  $$\frac{2a}{3b} = \frac{2 \cdot \frac{\lg k}{\lg 2}}{3 \cdot \frac{\lg k}{\lg 3}} = \frac{2\lg 3}{3\lg 2} = \frac{\lg 3^2}{\lg 2^3} = \frac{\lg 9}{\lg 8} > 1 \implies 2a > 3b.$$
- 比较 $2a$ 与 $5c$：
  $$\frac{2a}{5c} = \frac{2 \cdot \frac{\lg k}{\lg 2}}{5 \cdot \frac{\lg k}{\lg 5}} = \frac{2\lg 5}{5\lg 2} = \frac{\lg 5^2}{\lg 2^5} = \frac{\lg 25}{\lg 32} < 1 \implies 2a < 5c.$$
合起来立即得到 $3b < 2a < 5c$，一举排除 A 与 D（说明系数乘上去后大小并非按底数单调排列，$2a$ 恰好夹在中间）。

接下来看 $a + c$ 与 $2b$ 的大小关系。我们先顺手检查它们的倒数：由 $\frac{1}{a} = \log_k 2$、$\frac{1}{b} = \log_k 3$、$\frac{1}{c} = \log_k 5$ 可知
$$\frac{1}{a} + \frac{1}{c} = \log_k 10 > \log_k 9 = \frac{2}{b}.$$
但注意，已知 $\frac{1}{a} + \frac{1}{c} > \frac{2}{b}$ 绝对不能推出 $a + c < 2b$（反例随手可见：例如取 $a=6, b=3, c=2$，$\frac{1}{6}+\frac{1}{2}=\frac{2}{3}=\frac{2}{3}$，而 $6+2 > 2\times 3$）。**为什么这里我们要转而比较 $\frac{a}{b}$ 与 $\frac{b}{c}$ 的大小，再套用基本不等式？**
我们把两段比值写成对数形式：
$$\frac{a}{b} = \frac{\lg 3}{\lg 2} = \log_2 3, \qquad \frac{b}{c} = \frac{\lg 5}{\lg 3} = \log_3 5.$$
现在拿简单分数桥 $\frac{3}{2}$ 把两个比值彻底隔开：
- 因为 $3^2 = 9 > 8 = 2^3$，所以 $\frac{a}{b} = \log_2 3 > \frac{3}{2}$；
- 因为 $5^2 = 25 < 27 = 3^3$，所以 $\frac{b}{c} = \log_3 5 < \frac{3}{2}$。
由此得到 $\frac{a}{b} > \frac{b}{c}$。因为 $b > 0$ 且 $c > 0$，交叉相乘即得
$$ac > b^2.$$
因为 $a > 0, c > 0$ 且 $a \neq c$，根据严格基本不等式：
$$a + c > 2\sqrt{ac} > 2\sqrt{b^2} = 2b.$$

综上，必有 $3b < 2a < 5c$ 且 $a + c > 2b$，对应选项 **C**。
