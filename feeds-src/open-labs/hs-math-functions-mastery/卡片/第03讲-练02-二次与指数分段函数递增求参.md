# 第03讲·练02：二次与指数分段函数递增求参

## 内容

已知函数
$$f(x) = \begin{cases} -x^2 + 2ax - 3, & x \le 1, \\ a^x + 1, & x > 1 \end{cases}$$
在 $\mathbb{R}$ 上单调递增，则实数 $a$ 的取值范围是________。

## 参考理解

这道题在分界点 $x = 1$ 的左右分别放了一段含参二次函数和一段含参指数函数。按照[[卡片/分段函数单调衔接与取大取小]]，要想让 $f(x)$ 在 $\mathbb{R}$ 上整体单调递增，同样需要同时守住三道关卡：左段递增、右段递增、分界点处左不高于右。

先看左段 $f_1(x) = -x^2 + 2ax - 3$（$x \le 1$）。它的二次项系数为 $-1 < 0$，图像是一条开口向下的抛物线，对称轴为直线 $x = -\frac{2a}{2(-1)} = a$。根据[[卡片/含参二次函数动轴与区间最值]]，开口向下的抛物线在对称轴左侧 $(-\infty, a]$ 上单调递增、在对称轴右侧 $[a, +\infty)$ 上单调递减。为了保证它在区间 $(-\infty, 1]$ 上单调递增，就必须让区间 $(-\infty, 1]$ 全部落在对称轴的左侧（允许右端点恰好压到对称轴上），即
$$a \ge 1.$$
这里剪除第一条错觉分支：千万不要把“对称轴在区间左/右侧”记反写成 $a \le 1$。我们画草图就能一眼确认：当 $a < 1$ 时（比如 $a = 0$），抛物线在 $[0, 1]$ 这一小段已经翻过顶点开始往下掉，显然不再递增。

再看右段 $f_2(x) = a^x + 1$（$x > 1$）。要使指数函数在 $(1, +\infty)$ 上严格单调递增，底数必须满足：
$$a > 1.$$
这里隐藏着本题最容易漏掉的细节边界：**左段对称轴给出的是 $a \ge 1$，而右段指数底数给出的是严格不等式 $a > 1$**。如果求交集时随手把 $a = 1$ 留了下来，我们代回验证一下：$a = 1$ 时右段变成常函数 $f(x) = 1^x + 1 = 2$（$x > 1$），于是取 $x_1 = 2 < x_2 = 3$ 会有 $f(2) = f(3) = 2$，不满足严格单调递增（同时指数函数的标准底数定义也要求 $a > 0$ 且 $a \neq 1$），因此 **$a = 1$ 必须舍去**。

最后列出 $x = 1$ 处的衔接约束：左段在实心端点 $x = 1$ 处取到的最大值是 $f(1) = -1 + 2a - 3 = 2a - 4$；右段在 $x > 1$ 时从空心起点 $(1, a^1 + 1)$ 开始向右上方严格递增。要保证对任意 $x_1 \le 1 < x_2$ 都有 $f(x_1) < f(x_2)$，必须要求左端点高度不高于右段的起步高度：
$$f(1) \le a^1 + 1 \implies 2a - 4 \le a + 1 \implies a \le 5.$$
这里同样核验边界 $a = 5$：当 $a = 5$ 时，左段在 $x = 1$ 处取到 $6$（且对所有 $x_1 < 1$ 严格小于 $6$），右段在 $x > 1$ 上是 $5^x + 1 > 5^1 + 1 = 6$，于是对任意 $x_1 \le 1 < x_2$ 均严格满足 $f(x_1) \le 6 < f(x_2)$，衔接等号完全成立。

联立三条约束 $\begin{cases} a \ge 1, \\ a > 1, \\ a \le 5, \end{cases}$ 取交集即得实数 $a$ 的精确取值范围为 $(1, 5]$。

## 学生理解
