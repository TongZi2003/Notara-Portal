# 第11讲·练02：双不等高对称中心与类周期不等式

## 内容

已知定义在 $\mathbb{R}$ 上的函数 $f(x)$ 的图像同时关于点 $(1, 0)$ 与点 $(2, 1)$ 中心对称，且当 $x \in [0, 2]$ 时，$f(x) = (x - 1)|x - 1|$。

(1) 求证：对任意 $x \in \mathbb{R}$，均有 $f(x + 2) = f(x) + 2$；

(2) 求函数 $f(x)$ 在闭区间 $[-2, 4]$ 上的分段解析式与值域，并求不等式 $f(x) \le 3$ 在 $\mathbb{R}$ 上的解集。

## 参考理解

**(1)** 我们拿到题目时，可能会隐约想起“双中心对称推出周期 $T = 2|a - b|$”，于是直接套公式以为 $f(x + 2) = f(x)$。然而只要动手算一下两个中心 $(1, 0)$ 与 $(2, 1)$ 的纵坐标，就会立刻警觉：它们的纵坐标一个是 $0$、一个是 $1$，**两中心纵坐标不同**。根据[[卡片/双对称推导周期性与求值法]]，只有两对称中心纵坐标相等时复合才会消去常数变成普通周期函数；当两中心纵坐标不等时，连续翻折一次会把函数在纵向上抬升一个定差，生成纵向每次加固定常数的类周期函数。

让我们用最稳妥的两步代数翻译来证明它。根据[[卡片/函数自身对称与两函数互对称]]：
- 因为图像关于点 $(1, 0)$ 中心对称，所以对任意 $x \in \mathbb{R}$ 有 $f(2 - x) + f(x) = 0$，即
  $$f(2 - x) = -f(x);$$
- 因为图像关于点 $(2, 1)$ 中心对称，所以对任意 $x \in \mathbb{R}$ 有 $f(4 - x) + f(x) = 2$，即
  $$f(4 - x) = 2 - f(x).$$

现在要凑出 $f(x + 2)$，只需把第二式中的 $x$ 替换为 $2 - x$（注意 $4 - (2 - x) = x + 2$）：
$$f(x + 2) = f\bigl(4 - (2 - x)\bigr) = 2 - f(2 - x).$$
再将第一式 $f(2 - x) = -f(x)$ 代入上式，负负得正立得：
$$f(x + 2) = 2 - \bigl[-f(x)\bigr] = f(x) + 2.$$
至此第 (1) 问严格证毕。同时不妨反手检验一下题设在 $[0, 2]$ 上的解析式是否与 $(1, 0)$ 对称自洽：当 $x \in [0, 2]$ 时 $2 - x \in [0, 2]$，代入计算 $f(2 - x) + f(x) = (1 - x)|1 - x| + (x - 1)|x - 1| = 0$，完全吻合。

**(2)** 接下来推导 $f(x)$ 在 $[-2, 4]$ 上的分段解析式。由第 (1) 问的结论 $f(x + 2) = f(x) + 2$（等价于向左侧反推时 $f(x) = f(x + 2) - 2$），根据[[卡片/类周期与伸缩迭代函数分析法]]，我们把左段 $[-2, 0)$ 与右段 $(2, 4]$ 分别拽回已知区间 $[0, 2]$：

- **当 $x \in [-2, 0)$ 时**：$x + 2 \in [0, 2)$，所以
  $$f(x) = f(x + 2) - 2 = (x + 1)|x + 1| - 2.$$
  按绝对值零点 $x = -1$ 展开：当 $x \in [-2, -1]$ 时，$f(x) = -(x + 1)^2 - 2$；当 $x \in (-1, 0)$ 时，$f(x) = (x + 1)^2 - 2$。
- **当 $x \in [0, 2]$ 时**：直接写出已知表达式 $f(x) = (x - 1)|x - 1|$。展开即：当 $x \in [0, 1]$ 时，$f(x) = -(x - 1)^2$；当 $x \in (1, 2]$ 时，$f(x) = (x - 1)^2$。
- **当 $x \in (2, 4]$ 时**：$x - 2 \in (0, 2]$，所以
  $$f(x) = f(x - 2) + 2 = (x - 3)|x - 3| + 2.$$
  按绝对值零点 $x = 3$ 展开：当 $x \in (2, 3]$ 时，$f(x) = -(x - 3)^2 + 2$；当 $x \in (3, 4]$ 时，$f(x) = (x - 3)^2 + 2$。

整合以上六段二次支（或记为三大段含绝对值形式），$f(x)$ 在 $[-2, 4]$ 上的分段解析式为：
$$f(x) = \begin{cases} -(x + 1)^2 - 2, & x \in [-2, -1], \\ (x + 1)^2 - 2, & x \in (-1, 0), \\ -(x - 1)^2, & x \in [0, 1], \\ (x - 1)^2, & x \in (1, 2], \\ -(x - 3)^2 + 2, & x \in (2, 3], \\ (x - 3)^2 + 2, & x \in (3, 4]. \end{cases}$$

我们接着分析其在 $[-2, 4]$ 及整个 $\mathbb{R}$ 上的单调性与端点拼接，以免把局部值域算错或解不等式时漏掉 $x < -2$ 的部分。先看基准段 $[0, 2]$：
- 在 $[0, 1]$ 上，开口向下的抛物线 $-(x - 1)^2$ 处于对称轴 $x = 1$ 左侧，故严格单调递增，函数值从 $f(0) = -1$ 增至 $f(1) = 0$；
- 在 $[1, 2]$ 上，开口向上的抛物线 $(x - 1)^2$ 处于对称轴 $x = 1$ 右侧，也严格单调递增，函数值从 $f(1) = 0$ 增至 $f(2) = 1$。
因此 $f(x)$ 在 $[0, 2]$ 上连续且严格单调递增，值域为 $[-1, 1]$。

推向一般区间：对任意整数 $k \in \mathbb{Z}$，反复使用 $f(x + 2) = f(x) + 2$ 可得当 $x \in [2k, 2k + 2]$ 时，$x - 2k \in [0, 2]$ 且 $f(x) = f(x - 2k) + 2k$。这说明 $f(x)$ 在每一个闭区间 $[2k, 2k + 2]$ 上都保持严格单调递增，值域为 $[2k - 1, 2k + 1]$。特别检查相邻两段的衔接处：第 $k$ 段的右端点值为 $2k + 1$，恰好等于下一段 $[2k + 2, 2k + 4]$ 的左端点值 $2(k + 1) - 1 = 2k + 1$。因此各段无缝衔接，**$f(x)$ 在整个 $\mathbb{R}$ 上连续且严格单调递增**。

由此立得：
- 在闭区间 $[-2, 4]$ 上，$f(x)$ 的值域为 $[f(-2), f(4)] = [-3, 3]$（验证：$f(-2) = -(-2 + 1)^2 - 2 = -3$，$f(4) = (4 - 3)^2 + 2 = 3$）；
- 要在 $\mathbb{R}$ 上解不等式 $f(x) \le 3$，只需注意到 $3 = f(4)$，不等式直接化为 $f(x) \le f(4)$。切忌因为题目上一句刚研究了 $[-2, 4]$ 就把解集错写成 $[-2, 4]$，因为 $x < -2$ 时函数值均小于 $-3 < 3$。结合 $f(x)$ 在 $\mathbb{R}$ 上严格单调递增，解集为 **$(-\infty, 4]$**。
