# 第10讲·练03：加常数抽象函数对称与不等式

## 内容

已知定义在 $\mathbb{R}$ 上的函数 $f(x)$ 满足：对任意 $x, y \in \mathbb{R}$，都有 $f(x + y) = f(x) + f(y) + 2$，当 $x > 0$ 时 $f(x) > -2$，且 $f(2) = 2$。

(1) 求 $f(0)$ 与 $f(1)$ 的值，并证明函数 $y = f(x)$ 的图像关于点 $(0, -2)$ 中心对称；

(2) 证明函数 $f(x)$ 在 $\mathbb{R}$ 上单调递增，并求不等式 $f(x^2 - 2x) + f(x) < 0$ 的解集。

## 参考理解

**(1)** 我们看到抽象方程 $f(x + y) = f(x) + f(y) + 2$ 时，如果按死记硬背的习惯去求 $f(0)$ 和判断奇偶性，很容易漏掉方程尾部的常数 $+2$，误以为 $f(0) = 0$ 并且 $f(x)$ 是奇函数。根据[[卡片/抽象函数赋值与原型探路法]]，面对带常数的线性抽象方程，必须老老实实做两步标准赋值，切忌跳步心算。

首先求 $f(0)$ 与 $f(1)$：
- 令 $x = y = 0$，代入方程得 $f(0) = f(0) + f(0) + 2$，两边抵消一个 $f(0)$ 立即解得 **$f(0) = -2$**；
- 已知 $f(2) = 2$，为了联系到 $f(1)$，自然令 $x = y = 1$，得 $f(2) = f(1) + f(1) + 2$，即 $2 = 2f(1) + 2$，解得 **$f(1) = 0$**。

接着证明对称中心：要证 $y = f(x)$ 的图像关于点 $(0, -2)$ 中心对称，根据[[卡片/函数自身对称与两函数互对称]]，需要证明对任意 $x \in \mathbb{R}$ 都有 $f(x) + f(-x) = 2 \times (-2) = -4$。为此在原方程中令 $y = -x$：
$$f(x - x) = f(x) + f(-x) + 2 \implies f(0) = f(x) + f(-x) + 2.$$
将前面求得的 $f(0) = -2$ 代入上式，得 $-2 = f(x) + f(-x) + 2$，移项整理立得：
$$f(x) + f(-x) = -4.$$
这说明曲线上任意一点 $(x, f(x))$ 关于点 $(0, -2)$ 的对称点 $(-x, -4 - f(x)) = (-x, f(-x))$ 仍在函数图像上，从而函数 $y = f(x)$ 的图像关于点 $(0, -2)$ 中心对称。

**(2)** 接下来我们用定义证明 $f(x)$ 在 $\mathbb{R}$ 上单调递增。根据[[卡片/单调性定义证明与抽象单调]]，面对抽象加法结构，必须把大自变量拆成小自变量加上正增量。任取实数 $x_1 < x_2$，则 $x_2 - x_1 > 0$。由题设“当 $x > 0$ 时 $f(x) > -2$”，立得
$$f(x_2 - x_1) > -2.$$
把 $x_2$ 写成 $x_1 + (x_2 - x_1)$ 代入方程 $f(x + y) = f(x) + f(y) + 2$：
$$f(x_2) = f\bigl(x_1 + (x_2 - x_1)\bigr) = f(x_1) + f(x_2 - x_1) + 2.$$
移项作差得到：
$$f(x_2) - f(x_1) = f(x_2 - x_1) + 2 > -2 + 2 = 0.$$
因此 $f(x_1) < f(x_2)$，这就严格证明了函数 $f(x)$ 在 $\mathbb{R}$ 上单调递增。

最后一步解不等式 $f(x^2 - 2x) + f(x) < 0$。这里藏着一个极其容易卡壳的地方：不等式左边是两个 $f$ 相加，右边是 $0$，很多同学只注意到第 (1) 问算出的 $f(1) = 0$，却把左边写成 $f(x^2 - 2x) + f(x)$ 后不知道怎么把两项合并成一个 $f$，甚至直接错误写成 $f(x^2 - x) < 0$，白白漏掉了方程里的常数 $+2$。

**为什么我们必须在不等式两边同时加上 $2$，先还原出 $f(a) + f(b) + 2$ 的完整结构？** 因为只有凑出 $+2$，才能合法地调用题干恒等式 $f(a) + f(b) + 2 = f(a + b)$。对不等式 $f(x^2 - 2x) + f(x) < 0$ 两边同时加上 $2$：
$$f(x^2 - 2x) + f(x) + 2 < 2.$$
于是左边直接合并为 $f\bigl((x^2 - 2x) + x\bigr) = f(x^2 - x)$，而右边的 $2$ 恰好就是题干给定的已知值 $f(2)$：
$$f(x^2 - x) < f(2).$$
由前面已严格证明的“$f(x)$ 在 $\mathbb{R}$ 上单调递增”，脱去函数记号 $f$ 得等价的一元二次不等式：
$$x^2 - x < 2 \iff x^2 - x - 2 < 0 \iff (x - 2)(x + 1) < 0,$$
解得 $-1 < x < 2$。最后我们还可以请出满足题设的合法一次原型 $f(x) = 2x - 2$（满足 $f(x+y)=2(x+y)-2=f(x)+f(y)+2$、$x>0$ 时 $2x-2>-2$ 且 $f(2)=2$）做快速验算：$(2x^2 - 4x - 2) + (2x - 2) = 2x^2 - 2x - 4 < 0 \iff -1 < x < 2$，分毫不差。故原不等式的解集为 $(-1, 2)$。
