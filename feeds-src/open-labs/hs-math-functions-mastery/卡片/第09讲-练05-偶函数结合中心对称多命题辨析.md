# 第09讲·练05：偶函数结合中心对称多命题辨析

## 内容

已知定义在 $\mathbb{R}$ 上的偶函数 $f(x)$ 满足对任意 $x \in \mathbb{R}$ 都有 $f(1 + x) + f(1 - x) = 2$，则下列说法中正确的有（　　）

A. 函数 $f(x)$ 的图像关于点 $(3, 1)$ 中心对称

B. $4$ 一定是函数 $f(x)$ 的最小正周期

C. $f(1) + f(2) + f(3) + f(4) = 4$

D. $f(2026) + f(0) = 2$

## 参考理解

我们读到题干给出“偶函数”和“$f(1 + x) + f(1 - x) = 2$”时，很快就能联想到一轴一中心推导周期 $4$。但多选题里最爱把“$4$ 是 $f(x)$ 的一个周期”悄悄偷换概念写成“$4$ 一定是最小正周期”，只要脑子里没绷紧“是否存在常数函数等反例”这根弦，就会在 B 选项上栽跟头。

**为什么我们先把半周期互补关系与周期 $4$ 的代数推演彻底写稳，再去逐项排查 B 中的“最小正周期”陷阱？** 根据[[卡片/函数自身对称与两函数互对称]]与[[卡片/双对称推导周期性与求值法]]，我们先翻译已知条件：
- $f(x)$ 是 $\mathbb{R}$ 上的偶函数，即 $f(-x) = f(x)$（关于 $y$ 轴 $x = 0$ 对称）；
- $f(1 + x) + f(1 - x) = 2$，括号内相加除以 $2$ 为 $1$，纵坐标和除以 $2$ 为 $1$，即 $f(x)$ 的图像关于点 $(1, 1)$ 中心对称。

把条件中的 $x$ 替换为 $x + 1$，立即得到半周期互补等式：
$$f(x + 2) + f(-x) = 2 \implies f(x + 2) + f(x) = 2. \quad (*)$$
在 $(*)$ 中再把 $x$ 换为 $x + 2$，得 $f(x + 4) + f(x + 2) = 2$。两式相减（或直接代入 $f(x + 4) = 2 - f(x + 2) = 2 - [2 - f(x)] = f(x)$），证明 **$4$ 是 $f(x)$ 的一个周期**。以此为基础，逐一审核四个选项：

先看 **A**。由已知 $f(1 + x) + f(1 - x) = 2$ 与周期性 $f(x + 4) = f(x)$（或直接利用 $(*)$），我们来计算 $f(3 + x) + f(3 - x)$：在 $(*)$ 中分别取自变量为 $1 + x$ 和 $1 - x$，有
$$f(3 + x) = 2 - f(1 + x), \qquad f(3 - x) = 2 - f(1 - x).$$
两式相加得
$$f(3 + x) + f(3 - x) = 4 - \bigl[f(1 + x) + f(1 - x)\bigr] = 4 - 2 = 2.$$
两侧括号内相加除以 $2$ 为 $3$，函数值相加除以 $2$ 为 $1$，故点 $(3, 1)$ 确实是函数 $f(x)$ 图像的对称中心（直观上看就是对称中心 $(1, 1)$ 向右平移半个周期 $2$ 后得到或者平移一个周期 $4$ 之前落于 $x=3$ 的另一个中心），**A 正确**。

再看 **B**。虽然我们证明了对任意满足题设的函数 $f(x)$ 都有 $f(x + 4) = f(x)$，即 $4$ 是它的一个周期，但**周期不等于最小正周期**。检验“一定成立”只需要找一个合法反例即可：考察常函数 $f(x) \equiv 1$（$x \in \mathbb{R}$）。
- 它显然是 $\mathbb{R}$ 上的偶函数；
- 对任意 $x \in \mathbb{R}$，$f(1 + x) + f(1 - x) = 1 + 1 = 2$ 也完全成立。
然而常函数 $f(x) \equiv 1$ 的任何正实数都是周期，并不存在最小正周期（当然更可以构造周期为 $\frac{4}{3}$ 或 $2$ 的其他模型）。因此“$4$ 一定是最小正周期”这一全称结论被常函数直接证伪，**B 错误**。

接着看 **C**。直接回到半周期互补式 $(*)$：$f(x + 2) + f(x) = 2$。分别令 $x = 1$ 与 $x = 2$，立得：
$$f(3) + f(1) = 2, \qquad f(4) + f(2) = 2.$$
两式相加即得 $f(1) + f(2) + f(3) + f(4) = 2 + 2 = 4$，这与 $f(0)$ 的具体取值无关，对所有符合条件的函数均成立，**C 正确**。

最后看 **D**。因为 $4$ 是 $f(x)$ 的一个周期，把 $2026$ 对 $4$ 做带余除法：$2026 = 4 \times 506 + 2$，所以 $f(2026) = f(2)$。再在 $(*)$ 中令 $x = 0$，立即得到：
$$f(2) + f(0) = 2 \implies f(2026) + f(0) = 2.$$
注意这里不能误以为 $f(2026) = f(0)$，例如取周期为 $4$ 的三角锯齿波（在 $[-2, 2]$ 上令 $f(x) = |x|$ 并以 $4$ 为周期向 $\mathbb{R}$ 延拓，易验证它是偶函数且满足 $f(1+x)+f(1-x)=2$），此时 $f(0) = 0$ 而 $f(2026) = f(2) = 2 \neq f(0)$，但两者之和恒为 $2$。因此 **D 正确**。

综上，正确选项为 **ACD**。
