# 第09讲·练01：函数对称与周期四个关系式辨析

## 内容

设函数 $f(x)$ 的定义域为 $\mathbb{R}$，下列关于函数图像对称性与周期性的结论中，正确的有（　　）

A. 若对任意 $x \in \mathbb{R}$ 都有 $f(1 + x) = f(3 - x)$，则函数 $y = f(x)$ 的图像关于直线 $x = 2$ 对称

B. 若对任意 $x \in \mathbb{R}$ 都有 $f(x + 1) = f(x + 3)$，则函数 $y = f(x)$ 的图像关于直线 $x = 2$ 对称

C. 函数 $y = f(x + 1)$ 的图像与函数 $y = f(3 - x)$ 的图像关于直线 $x = 1$ 对称

D. 若对任意 $x \in \mathbb{R}$ 都有 $f(x + 1) + f(1 - x) = 4$，则函数 $y = f(x)$ 的图像关于点 $(1, 2)$ 中心对称

## 参考理解

我们读完这四个选项时，往往会觉得它们的字面结构几乎一模一样，括号里全都是 $1, 3$ 和 $x$ 的加减组合。考场上一旦靠死背口诀去套“相加除以 $2$ 还是相减除以 $2$”，就很容易把单函数自身对称、周期函数以及两函数互对称混为一谈，甚至把选项 B 当成轴对称错选进来，或者把选项 C 算成关于 $x = 2$ 对称。

**为什么我们每次遇到这类表达式，第一步都要先分清“有几个函数在画图”以及“两侧括号内 $x$ 的符号是相同还是相反”？** 根据[[卡片/函数自身对称与两函数互对称]]，同一种括号表达式放在一个函数身上还是放在两个函数图像上，几何意义截然不同；同时自变量 $x$ 的系数符号决定了是“相加为定值”还是“相减为定值”。我们逐个选项做严格拆解。

先看 **A**。等式 $f(1 + x) = f(3 - x)$ 描写的是同一个函数 $y = f(x)$ 自身在两个不同自变量处的函数值相等。注意两侧括号内 $x$ 的符号一正一负，把两个括号相加可以消去 $x$：
$$\frac{(1 + x) + (3 - x)}{2} = \frac{4}{2} = 2.$$
这说明横坐标在 $2$ 两侧等距的点纵坐标完全相同，令 $t = x - 1$ 还可改写为 $f(2 + t) = f(2 - t)$。因此函数 $y = f(x)$ 的图像确实关于直线 $x = 2$ 轴对称，**A 正确**。

再看 **B**。等式 $f(x + 1) = f(x + 3)$ 虽然也是同一个函数在等号两边，但仔细看两侧括号内 $x$ 的系数符号完全相同（都是 $+1$）。如果企图把括号相加，得到 $2x + 4$ 根本消不掉 $x$；只有把两个括号相减，才会消去 $x$ 得到定差 $(x + 3) - (x + 1) = 2$。用 $t = x + 1$ 代换得 $f(t + 2) = f(t)$，它表达的是函数 $f(x)$ 以 $2$ 为周期，绝非关于直线 $x = 2$ 对称。为了在考场上彻底打消犹豫，我们可以立刻构造一个分段线性周期反例验证：令 $x \in [0, 2)$ 时 $f(x) = x$，并以 $2$ 为周期向 $\mathbb{R}$ 延拓。此时 $f(x+1)=f(x+3)$ 恒成立，但取 $x = 1.5$ 与其关于 $x = 2$ 的对称点 $x = 2.5$，算得 $f(1.5) = 1.5$ 而 $f(2.5) = f(0.5) = 0.5$，两者并不相等，故 **B 错误**。

接着看 **C**。题目明确给出的是两条曲线 $C_1: y = f(x + 1)$ 与 $C_2: y = f(3 - x)$，注意这里在坐标系中画出了两个不同的函数。我们不能直接把括号相加除以 $2$ 得出 $x = 2$，必须检验图像上对称两点的对应关系：设点 $(x_1, y_0)$ 在曲线 $C_1$ 上，点 $(x_2, y_0)$ 在曲线 $C_2$ 上，要使它们能够由母函数 $f$ 的同一个纵坐标取到，只需两个内层自变量相等：
$$x_1 + 1 = 3 - x_2 \implies x_1 + x_2 = 2 \implies \frac{x_1 + x_2}{2} = 1.$$
反过来，对曲线 $C_1$ 上任意一点 $(x, f(x+1))$，它关于直线 $x = 1$ 的对称点为 $(2 - x, f(x+1))$，将该点横坐标 $2 - x$ 代入 $C_2$ 的解析式恰好得到 $f\bigl(3 - (2 - x)\bigr) = f(x + 1)$，证明它必然落在曲线 $C_2$ 上。这里也可以随手用具体函数 $f(t) = t$ 速验：两直线 $y = x + 1$ 与 $y = 3 - x$ 交于点 $(1, 2)$，显然关于直线 $x = 1$ 镜面对称，绝不是 $x = 2$。因此 **C 正确**。

最后看 **D**。等式 $f(x + 1) + f(1 - x) = 4$ 描述的是同一个函数 $y = f(x)$ 自身的关系，且括号内 $x$ 的符号一正一负，相加为定值 $(x + 1) + (1 - x) = 2$，同时对应的函数值之和为定值 $4$。对图像上任意一点 $(x + 1, f(x + 1))$ 与另一点 $(1 - x, f(1 - x))$，它们连线的中点坐标恒为
$$\left(\frac{(x + 1) + (1 - x)}{2}, \frac{f(x + 1) + f(1 - x)}{2}\right) = \left(\frac{2}{2}, \frac{4}{2}\right) = (1, 2).$$
由于自变量 $x$ 取遍 $\mathbb{R}$ 时 $x + 1$ 也取遍 $\mathbb{R}$，这说明图像上每一点关于定点 $(1, 2)$ 的中心对称点仍在图像上，故 **D 正确**。

综上，正确选项为 **ACD**。
