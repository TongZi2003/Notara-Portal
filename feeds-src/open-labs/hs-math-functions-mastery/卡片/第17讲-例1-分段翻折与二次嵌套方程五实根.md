# 第17讲·例1：分段翻折与二次嵌套方程五实根

## 内容

已知函数
$$f(x) = \begin{cases} |2^x - 1|, & x \le 1, \\ 2 - |x - 2|, & x > 1. \end{cases}$$
若关于 $x$ 的方程 $\bigl[f(x)\bigr]^2 - m f(x) + 1 = 0$ 恰有 $5$ 个互不相等的实数根，则实数 $m$ 的取值范围是（　　）

A. $\left[2, \frac{5}{2}\right]$　　　　B. $\left(2, \frac{5}{2}\right]$　　　　C. $\left(2, \frac{5}{2}\right)$　　　　D. $\left[2, \frac{5}{2}\right)$

我们看到方程里既藏着带绝对值的分段函数，外面又套了一个关于 $f(x)$ 的二次式，直接分段代入绝对值去硬解会分裂出十几种情况，既繁琐又极易漏掉分界点处的根。根据[[卡片/复合嵌套方程换元拆层数根法]]，标准的破题节奏永远是“先拆两层”：令 $t = f(x)$，把原方程拆成“外层二次方程 $t^2 - mt + 1 = 0$ 有哪些实根 $t_i$”和“每条水平直线 $y = t_i$ 与 $y = f(x)$ 的图像相交出多少个 $x$”两个独立小步。同时注意到四个选项的区别全在端点 $2$ 和 $\frac{5}{2}$ 究竟开还是闭，我们必须把图像边界和二次重根情况逐一算透。

先根据[[卡片/水平与动直线数形结合定参法]]与[[卡片/函数图像平移对称与绝对值翻折]]画出 $y = f(x)$ 的分段草图并列出各高度对应的水平截线交点数 $N(t)$：
- **左段（$x \le 1$）**：$y = |2^x - 1|$。当 $x < 0$ 时，$2^x \in (0, 1)$，翻折后 $y = 1 - 2^x$ 从渐近线高度 $1$ 严格递减至 $(0, 0)$（注意水平线 $y = 1$ 在 $x \to -\infty$ 方向只是渐近逼近而永远碰不到）；当 $0 \le x \le 1$ 时，$y = 2^x - 1$ 从 $(0, 0)$ 严格递增到**实心右端点** $(1, 1)$。因此左段与水平线 $y = t$ 的交点数为：$t < 0$ 时 $0$ 个，$t = 0$ 时 $1$ 个，$0 < t < 1$ 时 $2$ 个，$t = 1$ 时 $1$ 个（仅 $(1, 1)$），$t > 1$ 时 $0$ 个。
- **右段（$x > 1$）**：$y = 2 - |x - 2|$。当 $1 < x \le 2$ 时，$y = x$ 从**空心左端点** $(1, 1)$ 严格递增到尖峰 $(2, 2)$；当 $x > 2$ 时，$y = 4 - x$ 从 $(2, 2)$ 严格递减趋向 $-\infty$。因此右段与水平线 $y = t$ 的交点数为：$t \le 1$ 时 $1$ 个（都在 $x \ge 3$ 这一支上，因为 $x = 1$ 是空心点），$1 < t < 2$ 时 $2$ 个，$t = 2$ 时 $1$ 个（仅尖峰 $(2, 2)$），$t > 2$ 时 $0$ 个。

将左右两段交点数相加，得到完整高度—交点个数表：
- 当 $t < 0$ 时，$N(t) = 0 + 1 = 1$；
- 当 $t = 0$ 时，$N(t) = 1 + 1 = 2$；
- 当 $0 < t < 1$ 时，$N(t) = 2 + 1 = 3$；
- 当 $t = 1$ 时，$N(t) = 1 + 1 = 2$；
- 当 $1 < t < 2$ 时，$N(t) = 0 + 2 = 2$；
- 当 $t = 2$ 时，$N(t) = 0 + 1 = 1$；
- 当 $t > 2$ 时，$N(t) = 0$。

现在转向外层二次方程 $g(t) = t^2 - mt + 1 = 0$。因为内函数值域覆盖 $\mathbb{R}$，外层方程的每一个互异实根都能还原出 $N(t_i)$ 个互异的 $x$。要使总实根数恰好为 $5$，我们必须按外层方程根的个数分类检查交点个数 $\{0, 1, 2, 3\}$ 的所有合法组合：
1. **外层判别式 $\Delta = m^2 - 4 < 0$（$-2 < m < 2$）**：外层无实根，总根数为 $0$，不合题意。
2. **外层判别式 $\Delta = 0$（即 $m = \pm 2$，重根只算一条水平线）**：
   - 若 $m = -2$，唯一重根 $t_0 = -1$，对应总根数为 $N(-1) = 1 \neq 5$；
   - 若 $m = 2$，唯一重根 $t_0 = 1$，两条重合为同一条直线 $y = 1$，总根数为 $N(1) = 2 \neq 5$（注意即使把 $2$ 误翻倍成 $4$ 也不到 $5$，而无论如何 $m = 2$ 必须排除）。
3. **外层判别式 $\Delta > 0$（即 $m < -2$ 或 $m > 2$，存在两个互异实根 $t_1 < t_2$）**：
   观察到外层方程两根之积恒为 $t_1 t_2 = 1$，这个硬约束极大简化了枚举：
   - 若 $m < -2$，则 $t_1 < t_2 < 0$，此时 $N(t_1) + N(t_2) = 1 + 1 = 2 \neq 5$；
   - 若 $m > 2$，则两根必满足 **$0 < t_1 < 1 < t_2$**（因为 $t_1 t_2 = 1$ 且 $t_1 \neq t_2$，较小根必严格落在 $(0, 1)$ 内，较大根必严格大于 $1$）。对照前面的交点个数表，既然 $t_1 \in (0, 1)$，那么 $N(t_1) = 3$ 就已经确定。于是要想总实根数 $N(t_1) + N(t_2) = 5$，等价于要求 $N(t_2) = 5 - 3 = 2$。
   在 $t_2 > 1$ 的区域内查看交点个数表，只有当 **$1 < t_2 < 2$** 时才满足 $N(t_2) = 2$（若 $t_2 = 2$ 则 $N(2) = 1$，总根数只有 $3 + 1 = 4$；若 $t_2 > 2$ 则 $N(t_2) = 0$，总根数只有 $3 + 0 = 3$）。

最后根据[[卡片/二次方程根的分布定参法]]，把条件“在 $m > 2$ 前提下，较大根 $t_2 \in (1, 2)$”转化为二次函数 $g(t) = t^2 - mt + 1$ 的端点符号条件：已知 $g(0) = 1 > 0$ 且 $g(1) = 2 - m < 0$（由 $m > 2$ 自动保证），因而必有 $0 < t_1 < 1 < t_2$；再使 $t_2 < 2$，只需抛物线在 $t = 2$ 处的函数值严格大于零：
$$g(2) = 4 - 2m + 1 = 5 - 2m > 0 \implies m < \frac{5}{2}.$$
检验端点 $m = \frac{5}{2}$：此时方程 $t^2 - \frac{5}{2}t + 1 = 0$ 两根为 $t_1 = \frac{1}{2}, t_2 = 2$，总根数为 $N\left(\frac{1}{2}\right) + N(2) = 3 + 1 = 4 \neq 5$，故右端点必须为开区间。

综上，实数 $m$ 的取值范围是 $\left(2, \frac{5}{2}\right)$，对应选项 **C**。
