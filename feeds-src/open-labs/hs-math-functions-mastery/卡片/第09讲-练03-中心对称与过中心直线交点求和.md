# 第09讲·练03：中心对称与过中心直线交点求和

## 内容

已知定义在 $\mathbb{R}$ 上的函数 $f(x)$ 满足：对任意 $x \in \mathbb{R}$ 都有 $f(1 + x) + f(3 - x) = 6$。若直线 $y = \frac{1}{2}x + 2$ 与函数 $y = f(x)$ 的图像在闭区间 $[0, 4]$ 上恰有 $5$ 个不同的交点，则这 $5$ 个交点的横坐标之和为________。

## 参考理解

我们读题后会立刻发现题干根本没有给出 $f(x)$ 的解析式，既不知道它是几阶多项式，也不知道它在局部的弯曲起伏，却硬生生要我们求出 $5$ 个交点的横坐标之和。这明显在提示我们：绝对不可能逐个解出每个交点的坐标，唯一可能的路线就是利用隐藏在方程中的整体对称性，把交点两两配对消元。

**为什么我们先要验算对称中心，并同时核对直线与区间是否都围绕同一个中心对称？** 许多同学一看到“共有 $5$ 个交点、对称轴或中心横坐标是 $2$”，不加验证就随口写“$5 \times 2 = 10$”。其实这个结论成立必须同时满足三个缺一不可的前提：函数自身关于点 $(2, 3)$ 对称、用来相交的直线也必须经过点 $(2, 3)$、并且限制交点的区间 $[0, 4]$ 也必须关于 $x = 2$ 对称。只要缺掉任何一条，交点就无法成对出现，不能盲目乘以 $2$。

第一步，根据[[卡片/函数自身对称与两函数互对称]]解析函数方程 $f(1 + x) + f(3 - x) = 6$。两侧括号内自变量表达式相加为 $(1 + x) + (3 - x) = 4$，函数值相加为 $6$，因此图像上任意一点 $(1 + x, f(1 + x))$ 与点 $(3 - x, f(3 - x))$ 的中点坐标恒为
$$\left(\frac{(1 + x) + (3 - x)}{2}, \frac{6}{2}\right) = (2, 3).$$
由此确定曲线 $y = f(x)$ 关于定点 $(2, 3)$ 中心对称。特别地，当 $1 + x = 2$（即 $x = 1$）时，代入原式得 $2f(2) = 6 \implies f(2) = 3$，这说明定点 $(2, 3)$ 本身就实实在在落在曲线 $y = f(x)$ 上。

第二步，检验已知直线 $y = \frac{1}{2}x + 2$ 与点 $(2, 3)$ 的位置关系。把 $x = 2$ 代入直线方程：
$$y = \frac{1}{2} \times 2 + 2 = 1 + 2 = 3.$$
这说明直线 $y = \frac{1}{2}x + 2$ 恰好经过函数图像的对称中心 $(2, 3)$。凡是经过定点 $(2, 3)$ 的直线，其自身作为一个几何图形也关于点 $(2, 3)$ 中心对称；同时再核查区间 $[0, 4]$：若 $x_0 \in [0, 4]$，则它的对称点横坐标 $4 - x_0$ 满足 $0 \le 4 - x_0 \le 4$，仍然完整落在闭区间 $[0, 4]$ 之内（区间中点恰为 $2$）。

第三步，建立交点配对关系。设 $(x_0, y_0)$ 是区间 $[0, 4]$ 上曲线 $y = f(x)$ 与直线 $y = \frac{1}{2}x + 2$ 的任意一个交点，即同时满足 $y_0 = f(x_0)$ 与 $y_0 = \frac{1}{2}x_0 + 2$。考察它关于 $(2, 3)$ 的中心对称点 $(4 - x_0, 6 - y_0)$：
- 由曲线对称性可知，$f(4 - x_0) = 6 - f(x_0) = 6 - y_0$，故该对称点必在曲线 $y = f(x)$ 上；
- 由直线过 $(2, 3)$ 可知，$\frac{1}{2}(4 - x_0) + 2 = 4 - \frac{1}{2}x_0 = 6 - \left(\frac{1}{2}x_0 + 2\right) = 6 - y_0$，故该对称点也必在直线上；
- 且横坐标 $4 - x_0 \in [0, 4]$。

这证明区间 $[0, 4]$ 内的交点只要不是 $(2, 3)$ 本身，就必然成双成对地关于 $x = 2$ 对称出现。因为前面已算出 $(2, 3)$ 本身就同时位于曲线和直线上，所以点 $(2, 3)$ 必定占据 $5$ 个交点中的 $1$ 个；剩下的 $4$ 个交点恰构成 $2$ 对互不重合的对称点，设其横坐标分别为 $x_1, x_2$ 与 $x_3, x_4$，则有
$$x_1 + x_2 = 4, \qquad x_3 + x_4 = 4.$$
因此这 $5$ 个交点的横坐标之和为 $2 + 4 + 4 = 10$。

## 学生理解
