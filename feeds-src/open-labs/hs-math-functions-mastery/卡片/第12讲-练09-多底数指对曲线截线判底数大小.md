# 第12讲·练09：多底数指对曲线截线判底数大小

## 内容

设 $a, b, c, d$ 均为不等于 $1$ 的正实数。在同一平面直角坐标系中，指数函数 $C_1: y = a^x$、$C_2: y = b^x$ 与直线 $x = -1$ 交点的纵坐标分别为 $y_1, y_2$，且满足 $0 < y_1 < y_2 < 1$；对数函数 $C_3: y = \log_c x$、$C_4: y = \log_d x$ 与直线 $y = -1$ 交点的横坐标分别为 $x_3, x_4$，且满足 $x_3 > x_4 > 1$。则下列判断一定正确的有（　　）

A. $a > b > 1 > d > c > 0$

B. 当 $x > 1$ 时，恒有 $\log_c x > \log_d x$

C. 曲线 $C_1$ 的水平渐近线与曲线 $C_3$ 的竖直渐近线相交于坐标原点 $(0, 0)$

D. 若 $ac = 1$，则曲线 $C_1$ 与曲线 $C_3$ 关于直线 $y = x$ 对称

## 参考理解

我们看到这道多选题把指数曲线截线放在了 $x = -1$ 处、把对数曲线截线放在了 $y = -1$ 处，故意避开了课本最习惯的 $x = 1$ 与 $y = 1$ 基准线。很多同学平时靠死背“底数越大曲线越贴近坐标轴”或者直接误认为“交点越高（或越靠右）底数就越大”，一旦基准线从 $+1$ 换成 $-1$ 就会立刻把大小顺序全部判反；同时面对选项 D 时，也很容易因为看到 $ac = 1$ 就顺手把 $y = a^x$ 和 $y = \log_{\frac{1}{a}} x$ 当作关于 $y = x$ 对称的反函数。

**为什么我们不用背图像贴轴口诀，而是把交点坐标直接代回解析式还原出底数？** 依据[[卡片/指数对数反函数对称与恒过定点]]，基准线的真正威力在于直接读出底数或其倒数，完全不需要靠猜：
1. **看两条指数曲线 $C_1, C_2$**：把 $x = -1$ 分别代入，得交点纵坐标为 $y_1 = a^{-1} = \frac{1}{a}$，$y_2 = b^{-1} = \frac{1}{b}$。已知 $0 < y_1 < y_2 < 1$，也就是
   $$0 < \frac{1}{a} < \frac{1}{b} < 1.$$
   因为 $a, b > 0$，各边同时取倒数必须把不等号全体反向，立即得出
   $$a > b > 1.$$
   （这印证了在左半区 $x < 0$ 时，图像位置越低的指数函数，其大于 $1$ 的底数反而越大。）
2. **看两条对数曲线 $C_3, C_4$**：把 $y = -1$ 分别代入，得 $\log_c x_3 = -1 \implies x_3 = c^{-1} = \frac{1}{c}$，$\log_d x_4 = -1 \implies x_4 = d^{-1} = \frac{1}{d}$。已知 $x_3 > x_4 > 1$，也就是
   $$\frac{1}{c} > \frac{1}{d} > 1.$$
   同样对正数取倒数并反向不等号，得到
   $$0 < c < d < 1.$$

由此我们逐一核验四个选项：
- **先看选项 A**：合并刚才推得的 $a > b > 1$ 与 $0 < c < d < 1$，恰好得到 $a > b > 1 > d > c > 0$，因此 **A 正确**。
- **再看选项 B**：当 $x > 1$ 时，由于 $0 < c < d < 1$，我们可以直接用基准线读图或换底代数判断。在 $y = \log_c x$ 与 $y = \log_d x$ 中，两者都过定点 $(1, 0)$ 且当 $x > 1$ 时函数值都为负；由于 $y = -1$ 上 $x_3 = \frac{1}{c} > x_4 = \frac{1}{d} > 1$，说明过 $(1, 0)$ 向下穿行时，$C_3$ 下跌得比 $C_4$ 更缓、图像始终在 $C_4$ 上方。也可以代数验证：对任意 $x > 1$，设 $\log_c x = u < 0$、$\log_d x = v < 0$，则 $c^u = d^v = x > 1$；或写为 $\log_c x = -\log_{\frac{1}{c}} x$、$\log_d x = -\log_{\frac{1}{d}} x$，由 $\frac{1}{c} > \frac{1}{d} > 1$ 知在 $x > 1$ 时 $0 < \log_{\frac{1}{c}} x < \log_{\frac{1}{d}} x$（同真数大于 $1$ 时底数越大对数越小），添上负号得 $-\log_{\frac{1}{c}} x > -\log_{\frac{1}{d}} x$，即 $\log_c x > \log_d x$。也可以取特值 $c = \frac{1}{4}, d = \frac{1}{2}, x = 4$ 直观复核：$\log_{\frac{1}{4}} 4 = -1 > -2 = \log_{\frac{1}{2}} 4$。因此 **B 正确**。
- **再看选项 C**：指数函数 $C_1: y = a^x$（$a > 1$）的值域为 $(0, +\infty)$，当 $x \to -\infty$ 时函数值无限趋近于 $0$ 但永不为 $0$，故其水平渐近线是直线 $y = 0$（即 $x$ 轴）；对数函数 $C_3: y = \log_c x$（$0 < c < 1$）的定义域为 $(0, +\infty)$，当 $x$ 从右侧趋近于 $0$ 时函数值无限趋近于 $+\infty$ 但不过 $y$ 轴，故其竖直渐近线是直线 $x = 0$（即 $y$ 轴）。水平渐近线 $y = 0$ 与竖直渐近线 $x = 0$ 恰好交于坐标原点 $(0, 0)$，因此 **C 正确**。
- **最后看选项 D**：当 $ac = 1$ 时，$c = \frac{1}{a}$，此时曲线 $C_3$ 的解析式为
  $$y = \log_{\frac{1}{a}} x = -\log_a x.$$
  而根据[[卡片/指数对数反函数对称与恒过定点]]，与指数函数 $C_1: y = a^x$ 关于直线 $y = x$ 对称的是**同底数**的对数函数 $y = \log_a x$，并非 $y = -\log_a x$（实际上 $y = -\log_a x$ 是由 $y = \log_a x$ 沿 $x$ 轴上下翻折得到的，它关于 $y = x$ 对称的对象是 $y = \left(\frac{1}{a}\right)^x = a^{-x}$，即 $C_1$ 关于 $y$ 轴对称后的曲线）。随便取 $a = 2, c = \frac{1}{2}$，点 $(1, 2)$ 在 $C_1$ 上，其关于 $y = x$ 的对称点 $(2, 1)$ 代入 $C_3$ 得 $\log_{\frac{1}{2}} 2 = -1 \neq 1$，立即可证不对称。因此 **D 错误**。

综上，一定正确的判断是 **ABC**。
