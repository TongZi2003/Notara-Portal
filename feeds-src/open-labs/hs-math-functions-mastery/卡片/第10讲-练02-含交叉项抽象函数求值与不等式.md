# 第10讲·练02：含交叉项抽象函数求值与不等式

## 内容

已知定义在 $\mathbb{R}$ 上的函数 $f(x)$ 满足对任意 $x, y \in \mathbb{R}$ 都有 $f(x + y) = f(x) + f(y) + 2xy - 1$，当 $x > 0$ 时 $f(x) > x^2 + 1$，且 $f(1) = 3$。则下列说法中正确的有（　　）

A. $f(0) = 1$ 且 $f(-1) = 1$

B. $f(x)$ 在 $\mathbb{R}$ 上单调递增

C. 函数 $g(x) = f(x) - x^2 - 1$ 为 $\mathbb{R}$ 上的奇函数且单调递增

D. 不等式 $f(x - 1) \le x^2 - 2x + 4$ 的解集为 $(-\infty, 3]$

## 参考理解

我们审视这个方程 $f(x + y) = f(x) + f(y) + 2xy - 1$ 时，最刺眼的是末尾的交叉项 $2xy$ 和常数 $-1$。如果我们直接硬套 $y = -x$ 或尝试直接用定义比较 $f(x_2) - f(x_1)$，很快就会被多出来的 $2xy$ 缠住而无法脱壳；同时如果看到“当 $x > 0$ 时 $f(x) > x^2 + 1$”就顺手误以为 $f(x)$ 在整个 $\mathbb{R}$ 上一定单调递增，便会直接掉入 B 选项的陷阱。

**为什么我们首先想到用 $(x + y)^2 = x^2 + 2xy + y^2$ 来吸收交叉项 $2xy$，从而把原方程化归为最标准的加法抽象函数？** 观察到等式右边有 $+2xy$，而 $(x + y)^2$ 展开刚好在 $x^2 + y^2$ 之外多出 $+2xy$，因此两边同时减去 $(x + y)^2$ 就能立刻拆成两边的平方项。再顺便处理常数项 $-1$：令方程两侧同时减去 $1$，把 $-1$ 配入两侧：
$$f(x + y) - (x + y)^2 - 1 = \bigl[f(x) - x^2 - 1\bigr] + \bigl[f(y) - y^2 - 1\bigr].$$
这正验证了选项 C 提示的辅助函数 $g(x) = f(x) - x^2 - 1$（切记不能错设成 $f(x) - x^2 + 1$，否则右侧相加后会出现 $+2$ 导致常数项无法对消）。用 $g(x)$ 改写原方程，一切瞬间豁然开朗：
$$g(x + y) = g(x) + g(y).$$
而且已知的另外两个条件也同步翻译成关于 $g(x)$ 的极其简洁的性质：
- 当 $x > 0$ 时，$f(x) > x^2 + 1 \iff g(x) > 0$；
- 由 $f(1) = 3$ 得 $g(1) = 3 - 1^2 - 1 = 1$。

先看 **A**。在原方程（或 $g$ 的方程）中令 $x = y = 0$，得 $g(0) = g(0) + g(0) \implies g(0) = 0$，故 $f(0) = g(0) + 0 + 1 = 1$。再在 $g(x + y) = g(x) + g(y)$ 中令 $y = -x$，得 $g(x) + g(-x) = g(0) = 0$，故 $g(-x) = -g(x)$，特别是 $g(-1) = -g(1) = -1$。代回 $f(-1)$：
$$f(-1) = g(-1) + (-1)^2 + 1 = -1 + 1 + 1 = 1.$$
因此 **A 正确**。

接着检验 **C**。前面已经证出对任意 $x \in \mathbb{R}$ 都有 $g(-x) = -g(x)$，且定义域 $\mathbb{R}$ 关于原点对称，所以 $g(x)$ 是 $\mathbb{R}$ 上的奇函数。再来用单调性定义严密证明 $g(x)$ 在 $\mathbb{R}$ 上单调递增：任取实数 $x_1 < x_2$，则 $x_2 - x_1 > 0$，由已翻译的条件可知 $g(x_2 - x_1) > 0$。于是利用 $g$ 的可加性做差：
$$g(x_2) - g(x_1) = g\bigl(x_1 + (x_2 - x_1)\bigr) - g(x_1) = g(x_1) + g(x_2 - x_1) - g(x_1) = g(x_2 - x_1) > 0.$$
故 $g(x_1) < g(x_2)$，$g(x)$ 在 $\mathbb{R}$ 上严格单调递增，**C 正确**。

再来辨析 **B**。虽然 $g(x)$ 在 $\mathbb{R}$ 上严格单调递增，但 $f(x) = g(x) + x^2 + 1$ 是在递增函数 $g(x)$ 的基础上叠加了一个对称轴在 $x = 0$ 的开口向上二次函数 $x^2$，它在负半轴区间单调递减，叠加之后未必能保持单调递增。根据[[卡片/抽象函数赋值与原型探路法]]“以合法原型一票证伪”的原则，由于 $g(x+y) = g(x) + g(y)$ 且 $g(1) = 1$、$x > 0$ 时 $g(x) > 0$，我们直接取最简单的正比例原型 $g(x) = x$，还原出合法母函数原型：
$$f(x) = x^2 + x + 1.$$
核对原型完全满足题干所有前提：$f(x+y) = (x+y)^2 + (x+y) + 1 = f(x) + f(y) + 2xy - 1$，$x > 0$ 时 $x^2 + x + 1 > x^2 + 1$，且 $f(1) = 3$。但二次函数 $f(x) = \left(x + \frac{1}{2}\right)^2 + \frac{3}{4}$ 在 $\left(-\infty, -\frac{1}{2}\right]$ 上严格单调递减（例如 $f(-2) = 3 > f(-1) = 1$），根本不在 $\mathbb{R}$ 上单调递增。故 **B 错误**。

最后解 **D** 中的不等式。注意题目给的不等式是 $f(x - 1) \le x^2 - 2x + 4$，千万不要拿它和 $f(x)$ 的非单调性硬碰硬，而是要把右边的二次式向 $(x - 1)^2$ 配方，强行改写成辅助函数 $g$ 的形式：
$$x^2 - 2x + 4 = (x - 1)^2 + 3 \implies f(x - 1) - (x - 1)^2 - 1 \le 2 \implies g(x - 1) \le 2.$$
接下来把右边的常数 $2$ 也写成 $g$ 的函数值：因为 $g(1) = 1$，所以 $g(2) = g(1 + 1) = g(1) + g(1) = 2$。于是原不等式等价转化为：
$$g(x - 1) \le g(2).$$
因为选项 C 已经严格证明了 $g(x)$ 在 $\mathbb{R}$ 上单调递增，所以可以放心脱掉函数符号 $g$，直接解得 $x - 1 \le 2 \implies x \le 3$，即原不等式的解集为 $(-\infty, 3]$，**D 正确**。

综上，正确选项为 **ACD**。
