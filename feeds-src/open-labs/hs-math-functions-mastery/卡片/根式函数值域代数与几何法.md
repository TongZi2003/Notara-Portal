# 根式函数值域代数与几何法

## 内容

在高一尚未学习三角代换与高阶工具之前，含一个或两个二次根号的函数值域问题，完全可以通过以下四类纯初等代数与平面几何工具稳妥解决。

### 1. 单根号代数换元法

适用于 $y = ax + b + \sqrt{cx + d}$（根号内外均为一次式）：
- 令 $t = \sqrt{cx + d} \ge 0$，反解 $x = \frac{t^2 - d}{c}$；
- 代入消去 $x$，将原函数转化为关于 $t \in [0, +\infty)$（或题干限制下的闭区间）的二次函数，利用配方法与对称轴位置求值域。

### 2. 平方配凑法（同号根号之和）

适用于形如 $y = \sqrt{x + m} + \sqrt{n - x}$（两被开方数相加为常数，或线性组合能消去 $x$）：
- 先确定定义域 $[-m, n]$ 并判定非负性 **$y > 0$**（因两算术平方根不会同时为零）；
- 两边平方：$y^2 = (m + n) + 2\sqrt{(x + m)(n - x)}$；
- 根号内是开口向下的二次函数，对称轴恰好是定义域中点 $\frac{n - m}{2}$，因此极易直接求出 $y^2$ 的值域 $[A, B]$（必有 $A > 0$），再开方取正值 $y \in [\sqrt{A}, \sqrt{B}]$。

### 3. 单调性叠加与分子有理化法（异号根号之差）

- **单调叠加型**：若形如 $y = \sqrt{x + 2} - \sqrt{5 - x}$，因为前项在 $[-2, 5]$ 单增、后项单减（取负后变单增），故“增 + 增 = 严格单调递增”，直接代入定义域端点 $x = -2$ 与 $x = 5$ 即得值域；
- **差式无穷大型**：形如 $y = \sqrt{x^2 + ax + b} - x$，遇到 $\infty - \infty$ 形式时做**分子有理化**（分母补加共轭根式），或将根式下配方后分析随 $x$ 增大的变化趋势。

### 4. 平面几何距离转化法（双根号平方和）

遇到 $y = \sqrt{(x - a_1)^2 + b_1^2} \pm \sqrt{(x - a_2)^2 + b_2^2}$（$b_1, b_2 \neq 0$）时，代数平方无法消去二次项，立即识别为平面直角坐标系中**$x$ 轴上的动点 $P(x, 0)$ 到两定点 $A(a_1, b_1)$ 与 $B(a_2, b_2)$ 的距离和或距离差**：
- **加号（$|PA| + |PB|$）**：利用「将军饮马」做一点关于 $x$ 轴的对称点，使两定点分居 $x$ 轴两侧，连线交 $x$ 轴时取最小值，无上界；
- **减号（$|PA| - |PB|$）**：使两定点位于 $x$ 轴**同侧**，利用三角形两边之差小于第三边 $|PA| - |PB| \le |AB|$（共线于 $AB$ 延长线与 $x$ 轴交点时取等号，还要单独检查斜率是否平行于 $x$ 轴使交点跑飞）。

## 参考理解

### 高频设坑点

1. **平方未声明非负导致值域出现负数**：
   求 $y = \sqrt{x + 1} - \sqrt{3 - x}$ 若用平方，$y^2 = 4 - 2\sqrt{(x+1)(3-x)} \in [0, 4]$，开方若盲目写 $[-2, 2]$ 只对了一半——因为该式恰好在定义域 $[-1, 3]$ 上跨越零点确实能从 $-2$ 取到 $2$；但若是 $y = \sqrt{x + 1} + \sqrt{3 - x}$，显然 $y \ge \sqrt{4} = 2$，开方必须舍掉负支。因此能用单调性直出的差式绝不瞎平方，必须平方时先写清楚 $y$ 的符号区间。
2. **「同侧减、异侧加」几何判据漏看平行退化**：
   对于 $|PA| - |PB|$，当 $A(a_1, b_1)$ 与 $B(a_2, b_2)$ 同侧且 $b_1 = b_2$（连线平行于 $x$ 轴）时，直线 $AB$ 与 $x$ 轴没有交点，此时 $|PA| - |PB| < |AB|$ 严格不取等号（上界是 $|AB|$ 但取不到，若为开值域是 $(-|AB|, |AB|)$），考场必须额外核验两点纵坐标是否相等。
