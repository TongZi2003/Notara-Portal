# 第08讲·练07：含参指数分式奇函数与恒成立

## 内容

已知函数 $f(x) = \dfrac{a \cdot 2^x + b}{2^x + 1}$（$a, b \in \mathbb{R}$）。

(1) 若 $f(x)$ 是奇函数，求实数 $a, b$ 满足的关系式；

(2) 在 (1) 的条件下，若 $a = 3$，判断并用定义证明 $f(x)$ 在 $\mathbb{R}$ 上的单调性；并求实数 $t$ 的取值范围，使得不等式 $f(x^2 - t) + f(2x) > 0$ 对任意 $x \in [-2, 1]$ 恒成立。

## 参考理解

**(1)** 我们看到指数分式函数 $f(x) = \frac{a \cdot 2^x + b}{2^x + 1}$，因为对任意实数 $x$ 都有 $2^x + 1 > 1 > 0$，所以函数的定义域为 $\mathbb{R}$，关于原点对称，且原点 $0$ 就在定义域内。按照[[卡片/奇偶性判定与分段解析式补全]]与[[卡片/奇偶加常数与中心对称指对模型]]的处理策略，只要 $0$ 在奇函数的定义域内，最快的突破口就是先用 **$f(0) = 0$ 做必要性探路**：
$$f(0) = \frac{a \cdot 2^0 + b}{2^0 + 1} = \frac{a + b}{2} = 0 \implies b = -a.$$
到这里千万别急着下结论，因为 $f(0) = 0$ 只是奇函数的**必要条件**而非充分条件，必须把 $b = -a$ 代回原式验证它是否对**一切** $x \in \mathbb{R}$ 都满足 $f(-x) = -f(x)$：
当 $b = -a$ 时，$f(x) = \frac{a(2^x - 1)}{2^x + 1}$。对任意 $x \in \mathbb{R}$，计算
$$f(-x) = \frac{a(2^{-x} - 1)}{2^{-x} + 1} = \frac{a(2^{-x} - 1) \cdot 2^x}{(2^{-x} + 1) \cdot 2^x} = \frac{a(1 - 2^x)}{1 + 2^x} = -\frac{a(2^x - 1)}{2^x + 1} = -f(x).$$
（注意即便 $a = b = 0$，此时 $f(x) \equiv 0$ 同样满足 $f(-x) = -f(x)$。）因此 $a, b$ 满足的充要关系式是 $a + b = 0$（即 $b = -a$）。

**(2)** 当 $a = 3$ 时，由 (1) 得 $b = -3$，所以解析式具体化为
$$f(x) = \frac{3 \cdot 2^x - 3}{2^x + 1} = \frac{3(2^x + 1) - 6}{2^x + 1} = 3 - \frac{6}{2^x + 1}.$$
先用“分离常数”看清趋势：由于指数函数 $2^x$ 在 $\mathbb{R}$ 上单调递增，分母 $2^x + 1$ 随之增大，因此 $\frac{6}{2^x + 1}$ 减小，前面带负号后函数整体呈**单调递增**趋势。按照题目要求，我们用严格的**定义作差法**（参考[[卡片/单调性定义证明与抽象单调]]）来完成证明：
任取 $x_1, x_2 \in \mathbb{R}$ 且 $x_1 < x_2$，作差得
$$f(x_1) - f(x_2) = \left(3 - \frac{6}{2^{x_1} + 1}\right) - \left(3 - \frac{6}{2^{x_2} + 1}\right) = \frac{6(2^{x_1} - 2^{x_2})}{(2^{x_1} + 1)(2^{x_2} + 1)}.$$
因为指数函数 $y = 2^x$ 在 $\mathbb{R}$ 上严格单调递增，且 $x_1 < x_2$，所以 $2^{x_1} < 2^{x_2}$，即 $2^{x_1} - 2^{x_2} < 0$；又 $(2^{x_1} + 1)(2^{x_2} + 1) > 0$，所以 $f(x_1) - f(x_2) < 0$，即 $f(x_1) < f(x_2)$。由此严格证明了 $f(x)$ 在 $\mathbb{R}$ 上是**增函数**。

接下来处理闭区间恒成立不等式：$f(x^2 - t) + f(2x) > 0$ 对任意 $x \in [-2, 1]$ 恒成立。根据[[卡片/奇偶性与单调性联合脱壳法]]，先利用奇函数性质移项反号，将不等式化为外层相同符号的比较：
$$f(x^2 - t) > -f(2x) = f(-2x).$$
因为 $f(x)$ 在整个 $\mathbb{R}$ 上严格单调递增（无定义域断点或边界截断），所以可以直接安全脱去外层 $f$ 符号，等价转化为：
$$x^2 - t > -2x \iff t < x^2 + 2x \qquad \text{对任意 } x \in [-2, 1] \text{ 恒成立}.$$
于是问题彻底转化为求二次函数 $h(x) = x^2 + 2x$ 在闭区间 $[-2, 1]$ 上的最小值。这里要小心防止只代区间两端点算成 $h(-2) = 0$ 或 $h(1) = 3$ 的错误：将 $h(x)$ 配方得 $h(x) = (x + 1)^2 - 1$，它的对称轴直线为 $x = -1$，恰好落在闭区间 $[-2, 1]$ 内部，且开口向上，故最小值在对称轴 $x = -1$ 处取得：
$$h(x)_{\min} = h(-1) = (-1 + 1)^2 - 1 = -1.$$
要使 $t < h(x)$ 对 $[-2, 1]$ 上所有 $x$ 都成立，只需 $t$ 严格小于 $h(x)$ 的最小值（注意此处为严格不等号“$>$”，故 $t$ 不能等于 $-1$），即 $t < -1$。因此实数 $t$ 的取值范围是 $(-\infty, -1)$。
