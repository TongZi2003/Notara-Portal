# 第01讲·练04：复合指数式求解析式与值域

## 内容

已知函数 $f(x)$ 满足 $f(2^x + 1) = 4^x + 2^x + 2$（$x \in \mathbb{R}$），则 $f(x)$ 的解析式（含定义域）为________，函数 $y = f(x)$ 的值域为________。

## 参考理解

我们拿到这类由 $f\bigl(\varphi(x)\bigr)$ 还原 $f(x)$ 的问题，第一反应当然是设括号里面的整体等于 $t$，再把 $x$（或 $2^x$）反解出来代回右边。但这里连续埋着两个极易丢分的暗坑：第一个暗坑是写完二次式就以为大功告成，忘了标注新元 $t$ 必须满足的取值范围，甚至顺手把区间最小值算到抛物线顶点上；第二个暗坑是在标注 $t$ 的范围时错把 $2^x > 0$ 当成 $2^x \ge 0$，结果把开区间端点误写成闭区间端点。

**为什么我们换元时先不急着展开，而必须先写全 $t$ 的精确范围？** 根据[[卡片/函数解析式换元与消元法]]，令 $t = 2^x + 1$。因为自变量 $x$ 取遍全体实数 $\mathbb{R}$ 时，指数函数 $2^x$ 的值域是 $(0, +\infty)$（严格大于 $0$，无论 $x$ 取多小的负数都只能逼近 $0$ 而不能等于 $0$），所以：
$$t = 2^x + 1 > 1.$$
接下来用 $t - 1$ 替换表达式里的 $2^x$。注意到 $4^x = (2^x)^2 = (t - 1)^2$，并不需要真的用对数把 $x$ 解出来再代回去那样绕远路，直接整体替换得：
$$f(t) = (t - 1)^2 + (t - 1) + 2 = (t^2 - 2t + 1) + (t - 1) + 2 = t^2 - t + 2 \quad (t > 1).$$
把自变量字母换回习惯记号 $x$，第一空的完整解析式就是 $f(x) = x^2 - x + 2\ (x > 1)$。

**为什么求 $y = f(x)$ 的值域时绝对不能代入二次函数的顶点纵坐标？** 观察 $f(x) = x^2 - x + 2 = \left(x - \frac{1}{2}\right)^2 + \frac{7}{4}$，它确实是一条开口向上、对称轴为直线 $x = \frac{1}{2}$ 的抛物线。然而根据[[卡片/含参二次函数动轴与区间最值]]，此时函数的定义域并不是 $\mathbb{R}$，而是被截断在了 $(1, +\infty)$，对称轴 $x = \frac{1}{2}$ **完全落在了定义域的左侧外部**。如果忽视定义域限制，就会错算出最小值 $\frac{7}{4}$；正确的做法是抓住对称轴右侧抛物线严格递增的性质：当 $x \in (1, +\infty)$ 时，$f(x)$ 随着 $x$ 的增大而严格递增，且 $x$ 可以无限接近左边界 $1$ 但永远取不到 $1$。因此下界对应靠近左端点 $x = 1$ 的高度 $1^2 - 1 + 2 = 2$（开边界，取不到），上界趋向 $+\infty$。

由此得出第二空：函数 $y = f(x)$ 的值域为 $(2, +\infty)$。
