# 抽象函数赋值与原型探路法

## 内容

抽象函数题（只给一个不含显式表达式的函数方程，如 $f(x+y) = f(x)+f(y)$ 或 $f(x+y)+f(x-y)=2f(x)f(y)$）是高一拔高和高考多选压轴的常客。破解它需要“两条腿走路”：**赋值做严密推理，原型只做辅助验证与排错**。

### 1. 常用「科学赋值动作库」（以 $x, y$ 可任意取值为例）

| 赋值组合 | 常用目标与立刻收获 | 避坑校验 |
| :--- | :--- | :--- |
| $x = y = 0$（或 $1$） | 求锚定特殊值 $f(0)$ 或 $f(1)$ | 若令 $f(0) = f(0)f(0)$ 得 $f(0) \in \{0, 1\}$，绝不可直接把 $0$ 舍掉，须结合题干“$f$ 不恒为零”或其他条件排除 |
| $y = -x$（或 $y = \frac{1}{x}$） | 把 $f(x)$ 与 $f(-x)$ 绑定到同一个常数，判断**奇偶性** | 需先证明 $f(x) = -f(-x)$ 对定义域全体成立；如果赋值出现分母零点要分类补漏 |
| $y = a$（取具体常数） | 检验是否出现**对称方程**或**周期方程** | 如在已知 $f(a)=0$ 时，将 $y = a$ 或 $x = a$ 代入观察是否出现 $f(x+2a)=-f(x)$ |
| $y = x$ | 探索平方/倍增关系（如 $f(2x)=2f(x)$），或取 $x = \frac{t}{2}$ 证非负性 $f(t)=[f(\frac{t}{2})]^2 \ge 0$ | 检验定义域是否允许除 $2$ 且值域开闭是否匹配 |

### 2. 高一必熟「纯初等原型函数对照库」（严密只用来找灵感和排除错项）

| 函数方程特征 | 高一常见合法原型 | 典型误区与排除用“捣乱原型” |
| :--- | :--- | :--- |
| $f(x+y) = f(x) + f(y)$ | 正比例函数 $f(x) = kx$（$k \in \mathbb{R}$） | $f(x) = 0$ 常值函数常用来排除“必为单调”或“必非常值”的错误选项 |
| $f(x+y) = f(x)f(y)$ | 指数函数 $f(x) = a^x$（$a>0$）或常值 $0$ | 注意若题干允许常函数 $f(x)=0$，则 $f(0)$ 未必是 $1$ |
| $f(xy) = f(x) + f(y)$（$x,y>0$） | 对数函数 $f(x) = \log_a x$（或 $0$） | 偶函数模型 $f(x) = \log_a |x|$（若定义域扩至 $x \neq 0$）可用来排错“必递增” |
| $f(xy) = f(x)f(y)$ | 幂函数 $f(x) = x^\alpha$（或 $x^{p/q}$） | 常函数 $f(x)=1$、偶函数 $x^2$、奇函数 $x^3$ 可试出多个不同奇偶结论 |
| $f(x+y)+f(x-y)=2f(x)$ 变体 | 一次或分段常值周期函数 | 当仅考察周期性/奇偶性而不限定连续时，构造带跳跃的分段周期函数往往能一招击碎错误选项 |

## 参考理解

### 严守「特例仅可证伪，不可证真」逻辑底线

1. **多选题防“拿原型当全部真相”陷阱**：
   遇到“已知 $f(x+y)=f(x)+f(y)$（且没有补充单调性或连续性）”，如果直接套入正比例函数 $f(x) = kx$，你会误以为“$f(x)$ 必单调”或“$f(x)$ 必有反函数”是对的。虽然原型 $kx$ 在高一最常用，但在不加任何单调性前提下，$f(x)$ 甚至可以是常函数 $f(x) \equiv 0$（当不限制非常值时）或其它复杂对应关系。**只能用原型验证一个全称选项是错的（找出一个反例即可否决），绝不能因为原型满足就断言原方程必然成立，正面选项必须严格靠代数赋值导出。**
2. **赋特值求出 $f(a)=0$ 时警惕乘除法约分**：
   例如从 $f(x) + f(-x) = 2f(x)f(y)$ 导出 $f(0) = [f(0)]^2$，一定要分两种分支检验；同样在推出 $f(x + c) = f(x)f(c)$ 时，如果想除以 $f(c)$ 证明等式，必须先用条件说明 $f(c) \neq 0$（否则可能存在另一批使全段坍缩为零的退化解）。
3. **与赋值法配对后的周期链**：
   对于对称叠加型方程如 $f(x+y)+f(x-y) = 2f(x)f(y)$，即使不借助任何后续章节的具体函数原型，纯凭赋值依然可以严密推导出全部性质：先令 $x=y=0$ 得 $f(0) \in \{0, 1\}$；若 $f(0)=1$，令 $x=0$ 得 $f(y)+f(-y)=2f(y) \implies f(-y)=f(y)$（偶函数）；若另知某点 $f(a)=0$（$a\neq 0$），令 $y=a$ 得 $f(x+a)+f(x-a) = 2f(x)f(a) = 0 \implies f(x+2a)=-f(x) \implies T = 4a$，全程只需要代换推理就能严格证明。

### 变式追问

1. 已知定义在 $\mathbb{R}$ 上的函数 $f(x)$ 非常值函数，满足对一切 $x, y \in \mathbb{R}$ 有 $f(x+y) + f(x-y) = 2f(x)f(y)$ 且已知 $f(1) = \frac{1}{2}$，$f(0) \neq 0$。只用代数赋值推算，能不能算出 $f(0), f(2), f(3)$ 以及它的正周期 $T$（提示：$f(x+1)+f(x-1)=f(x)$ 往后写三行消去两项）？
2. 已知函数 $f(x)$ 定义域为 $(0, +\infty)$，对任意正实数满足 $f(xy) = f(x) + f(y)$，且当 $x > 1$ 时 $f(x) > 0$，试说明赋值和单调证明各需哪两步即可直接解不等式 $f(x) + f(x-3) \le 2f(2)$。
