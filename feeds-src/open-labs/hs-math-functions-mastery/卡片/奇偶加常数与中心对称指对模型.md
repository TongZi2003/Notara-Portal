# 奇偶加常数与中心对称指对模型

## 内容

考试极少直接把裸奇函数摆上台面，最常考的包装方式是给一个奇函数 $g(x)$ 加上纵向平移常数 $C$，构成 $f(x) = g(x) + C$，再通过隐藏的指数、对数或分式结构伪装起来，让人看不出它关于点 $(0, C)$ 中心对称。

### 1. 「奇函数 + 常数 $C$」的核心代数恒等式

设在关于原点对称的区间 $D$ 上，$f(x) = g(x) + C$，其中 $g(-x) = -g(x)$：
1. **对称和定值公式**：
   $$f(x) + f(-x) = \bigl[g(x) + C\bigr] + \bigl[g(-x) + C\bigr] = 2C.$$
   几何意义是 $y = f(x)$ 的图像关于定点 **$(0, C)$ 中心对称**（更一般地，若对称中心横坐标移到 $a$，则有 $f(a+x) + f(a-x) = 2C$）。
2. **对称区间最大最小值之和定理**：
   如果 $f(x)$ 在闭区间 $[-m, m]$（或开区间 $(-m, m)$）上存在最大值 $M$ 与最小值 $m_0$，由于 $f(x) = g(x) + C$ 上奇函数 $g(x)$ 的最大值与最小值必互为相反数（即 $g_{\max} + g_{\min} = 0$），因此必然有：
   $$f_{\max} + f_{\min} = M + m_0 = 2C.$$

### 2. 高一必背四大「纯初等奇函数模型」与隐蔽拆分母型

以下四组初等函数全部为严格奇函数（且只需纯指对/代数运算即可两行证明 $g(-x) + g(x) = 0$）：

| 模型分类 | 标准表达式 $g(x)$（均为奇函数） | 考场常见加常数/平移伪装式 | 快速拆分方法 |
| :--- | :--- | :--- | :--- |
| **指数分式型** | $g(x) = \dfrac{a^x - 1}{a^x + 1}$ 或 $\dfrac{1}{a^x + 1} - \dfrac{1}{2}$ | $f(x) = \dfrac{2^x}{2^x + 1}$ 或 $f(x) = \dfrac{2a^x + 1}{a^x + 1}$ | 分子分母拼凑：$\dfrac{2^x}{2^x+1} = \dfrac{1}{2} + \dfrac{2^x - 1}{2(2^x+1)}$（即 $C=\frac{1}{2}$）；计算 $f(x)+f(-x)$ 直接验证等于常数 |
| **指数互反和差** | $g(x) = a^x - a^{-x}$ | $f(x) = \dfrac{a^x - a^{-x}}{2} + C$ | 显然 $a^{-x} - a^x = -(a^x - a^{-x})$，偶组合为 $a^x + a^{-x}$ |
| **根式对数对称型** | $g(x) = \ln\bigl(\sqrt{x^2 + b^2} + x\bigr)\ (b>0)$ | $f(x) = \ln(\sqrt{x^2 + 1} + x) + C$ | 验证互反倒数：$(\sqrt{x^2+b^2}+x)(\sqrt{x^2+b^2}-x) = b^2$，当 $b=1$ 时直接得 $g(-x)+g(x)=\ln 1 = 0$ |
| **分式对数型** | $g(x) = \ln\dfrac{a + x}{a - x}\ (x \in (-a, a))$ | $f(x) = \ln\dfrac{1 + x}{1 - x} + x^3 + C$ | 互换真数分子分母即取倒数：$g(-x) = \ln\dfrac{a-x}{a+x} = -g(x)$ |
| **代数假分式型** | $g(x) = \dfrac{bx}{x^2 + k}\ (k>0)$ | $f(x) = \dfrac{x^2 + 2x + 1}{x^2 + 1} = 1 + \dfrac{2x}{x^2 + 1}$ | 分子降次分离出常数 $1$（或代入互反点算 $f(1)+f(-1)$ 定出 $2C$） |

## 参考理解

### 通用试探：看不出拆分时先“首尾相加试算 $f(x) + f(-x)$”

很多时候题干会把模型包在一个长串多项式或复杂对勾分式里，一眼很难拆成 $g(x) + C$。这时**不要盲拆，直接硬算 $f(x) + f(-x)$**：
- 例如面对 $f(x) = \frac{3^x - 1}{3^x + 1} + \ln\left(\sqrt{x^2 + 4} + x\right) + 5$ 求 $[-10, 10]$ 上最大值 $M$ 与最小值 $m$ 之和。注意到 $\ln(\sqrt{x^2+4}+x)$ 里是 $4$ 而不是 $1$。如果盲记它是奇函数就会大意以为常数是 $5$；但老实代算一次 $f(x) + f(-x)$：
  $$\left(\frac{3^x-1}{3^x+1} + \frac{3^{-x}-1}{3^{-x}+1}\right) + \ln\Bigl[(\sqrt{x^2+4}+x)(\sqrt{x^2+4}-x)\Bigr] + 10 = 0 + \ln 4 + 10 = 10 + \ln 4.$$
  立刻发现真正的对称中心纵坐标是 **$C = 5 + \frac{1}{2}\ln 4 = 5 + \ln 2$**，因此 $M + m = 10 + 2\ln 2$。
  这个案例精准提醒我们：$\ln(\sqrt{x^2 + b^2} + x)$ 在 $b \neq 1$ 时是“**奇函数 $+ \ln b$**”，永远拿 $f(x) + f(-x)$ 算一遍才最保险。

### 易错断点

- **忽视定义域对称区间才能用 $M+m=2C$**：若函数是在 $[-2, 5]$ 上求最值，而不是在 $[-m, m]$（或关于中心横坐标对称的 $[a-m, a+m]$）上，则 $M+m=2C$ 完全不成立，必须另算区间延伸段的值域；
- **多选误把“$f(x) = g(x) + C$”当奇函数用来直接代 $f(-x) = -f(x)$**：奇函数必须对称中心在 $(0, 0)$，当 $C \neq 0$ 时对称方程是 $f(x) + f(-x) = 2C$ 而非 $0$，在配合单调性解不等式时必须先配出 $f(u) > 2C - f(v) = f(-v)$ 再脱壳。

### 变式追问

1. 若已知函数 $f(x) = \frac{e^x}{e^x + 1} + \ln\left(\sqrt{4x^2 + 1} + 2x\right) + \frac{x^3 + 3}{x^2 + 1}$，请直接计算 $f(x) + f(-x)$，它的对称中心坐标是多少？
2. 遇到非中心在 $y$ 轴上的分式指数式 $f(x) = \frac{2^x}{2^x + 4}$ 时，尝试代入 $x = 1$ 左右两侧的变量配对，即计算 $f(x) + f(2 - x)$ 会得到什么定值？
