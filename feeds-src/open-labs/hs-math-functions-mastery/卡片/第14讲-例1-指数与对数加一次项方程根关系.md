# 第14讲·例1：指数与对数加一次项方程根关系

## 内容

已知实数 $a, b, c$ 分别满足 $2^a + a = 5$，$\log_2 b + b = 5$，$2^{c+1} + c = 4$，则下列结论正确的是（　　）

A. $c < a < b$ 且 $ab > 6$
B. $a + b = 5$ 且 $5 < ab < 6$
C. $a + c = 5$ 且 $ab < 5$
D. $b = 2^c$ 且 $b < a$

我们刚读完题目，可能会产生两种不太顺畅的念头：一是试图解出 $a, b, c$ 的精确值，可不论 $2^a + a = 5$ 还是 $\log_2 b + b = 5$，都是把指数、对数和一次项混加在一起的方程，高一根本解不出具体数字；二是单靠粗糙放缩去卡每个字母的整数范围，比如只算出 $1 < a < 2$、$2 < b < 4$、$0 < c < 1$，如果只卡到这一步，去算乘积 $ab$ 只能给出宽泛的 $2 < ab < 8$，面对选项里的 $5 < ab < 6$ 或 $ab > 6$ 依然会束手无策。

**为什么我们想到先凑出完全一样的单调母函数骨架，把“三个解不出的方程根”连到“同一个公共单调函数”上？** 根据[[卡片/构造初等单调函数与同构比大小]]与[[卡片/指数对数反函数对称与恒过定点]]，右边常数全都可以对齐到同一个目标值 $5$，而第一个式子已经呈现“$2^{(\cdot)} + (\cdot)$”的清晰形状。只要利用对数恒等式 $b = 2^{\log_2 b}$（注意题目中 $\log_2 b$ 有意义已隐含 $b > 0$）并给第三个式子两边补上 $1$，就能让三个式子同时落进同一把单调递增的标尺里。

我们构造辅助函数：
$$g(t) = 2^t + t, \qquad t \in \mathbb{R}.$$
由于指数函数 $y = 2^t$ 在 $\mathbb{R}$ 上严格递增，一次函数 $y = t$ 在 $\mathbb{R}$ 上也严格递增，根据“增函数 + 增函数 = 增函数”，可知 $g(t)$ 在 $\mathbb{R}$ 上**严格单调递增**，因此它具有一一对应性（函数值相等必有自变量相等）。接下来逐一改写三个已知等式：
1. 第一式直接记为 **$g(a) = 2^a + a = 5$**；
2. 第二式中，因为 $b > 0$，由对数恒等式把 $b$ 改写成 $2^{\log_2 b}$，于是
   $$\log_2 b + b = 2^{\log_2 b} + \log_2 b = g(\log_2 b) = 5;$$
3. 第三式把 $2^{c+1} + c = 4$ 两边同时加上 $1$，凑出与指数部分相同的自变量 $c + 1$：
   $$2^{c+1} + (c + 1) = 5 \implies g(c + 1) = 5.$$

由于 $g(t)$ 在 $\mathbb{R}$ 上严格单调递增，上述三式立刻脱掉外层函数外壳 $g$，得到精准的等量桥梁：
$$a = \log_2 b = c + 1.$$
从这里一眼便能推出两层关键关系：
- 一方面，$b = 2^a$，再代入原始第一式 $2^a + a = 5$，立刻算出 **$a + b = 2^a + a = 5$**，直接排除认为 $a + c = 5$ 的选项 C，也立刻知道 $c = a - 1$ 且 $b = 2^{c+1} \neq 2^c$（排除 D）；
- 从反函数图像视角（参考[[卡片/指数对数反函数对称与恒过定点]]）也能相互印证：$a$ 是 $y = 2^x$ 与直线 $y = 5 - x$ 交点的横坐标，$b$ 是反函数 $y = \log_2 x$ 与同一条关于 $y = x$ 自身对称的直线 $y = 5 - x$ 交点的横坐标，两交点关于 $y = x$ 对称，横纵坐标互换后必定满足 $a + b = 5$。

现在剩下的唯一胜负手就是确定乘积 $ab$ 到底落在 $(5, 6)$ 内还是超过 $6$。因为我们已经把 $b$ 表达为 $5 - a$，所以 $ab = a(5 - a)$ 是一个关于 $a$ 的开口向下二次函数，对称轴为 $a = \frac{5}{2}$，只需要把 $a$ 的所在区间卡得比 $(1, 2)$ 更精准一些即可。

我们来细化 $a$ 的范围：
- 先看上界：计算 $g(2) = 2^2 + 2 = 6 > 5$，由 $g(t)$ 严格递增得 **$a < 2$**；
- 再测试 $\frac{3}{2}$ 作为下界：$g\left(\frac{3}{2}\right) = 2^{\frac{3}{2}} + \frac{3}{2} = 2\sqrt{2} + \frac{3}{2}$。因为 $(2\sqrt{2})^2 = 8 < \frac{49}{4} = \left(\frac{7}{2}\right)^2$ 且均为正数，所以 $2\sqrt{2} < \frac{7}{2}$，从而
  $$g\left(\frac{3}{2}\right) < \frac{7}{2} + \frac{3}{2} = 5 = g(a).$$
  再由 $g(t)$ 严格递增，立即卡死 **$\frac{3}{2} < a < 2$**。

有了 $\frac{3}{2} < a < 2$，注意到二次函数 $h(a) = a(5 - a) = -\left(a - \frac{5}{2}\right)^2 + \frac{25}{4}$ 在对称轴左侧区间 $\left(\frac{3}{2}, 2\right)$ 上**严格单调递增**，因此把两个开区间端点直接代入就得到 $ab$ 的严格界限：
$$\frac{3}{2} \times \left(5 - \frac{3}{2}\right) < ab < 2 \times (5 - 2) \implies \frac{21}{4} < ab < 6.$$
由于 $\frac{21}{4} = 5.25 > 5$，自然严格满足 **$5 < ab < 6$**，于是选项 A（声称 $ab > 6$）被彻底排除，唯一正确选项为 **B**。
