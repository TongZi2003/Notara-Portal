# 第02讲·练04：含对数分式在去点区间的值域

## 内容

已知函数 $f(x) = \dfrac{(\log_2 x)^2 + 2\log_2 x - 3}{\log_2 x + 1}$，则 $f(x)$ 在集合 $\left\{x \in \left[\dfrac{1}{4}, 4\right] \,\middle|\, x \neq \dfrac{1}{2}\right\}$ 上的值域是（　　）

A. $\left[\dfrac{5}{3}, 3\right]$　　　　B. $\left(-\infty, \dfrac{5}{3}\right] \cup [3, +\infty)$　　　　C. $\left(-\infty, 0\right] \cup [4, +\infty)$　　　　D. $\left(-\infty, \dfrac{5}{3}\right) \cup (3, +\infty)$

## 参考理解

我们看到这个分式结构的分子是关于 $\log_2 x$ 的二次三项式，分母是关于 $\log_2 x$ 的一次式，而且题干特意把 $x = \frac{1}{2}$ 从区间 $\left[\frac{1}{4}, 4\right]$ 中挖了出去——正是因为当 $x = \frac{1}{2}$ 时，分母 $\log_2 \frac{1}{2} + 1 = -1 + 1 = 0$。碰到这种“二次比一次”的分式结构，最直接的思路并不是对着复杂的分子硬算单调性，而是按照[[卡片/分式与对勾型函数值域法]]把分母整体设成新变量，把分式拆成“整式加简单倒数”的形态。

**为什么我们设 $t = \log_2 x + 1$，而不是只设 $u = \log_2 x$？** 因为设 $u = \log_2 x$ 后分母仍是 $u + 1$，还得再做一次多项式除法；直接把分母整体记作 $t = \log_2 x + 1$，那么 $\log_2 x = t - 1$，回代进分子就能一步消去一次项：
$$(\log_2 x)^2 + 2\log_2 x - 3 = (t - 1)^2 + 2(t - 1) - 3 = t^2 - 4.$$
于是原函数瞬间化简为标准结构：
$$h(t) = \frac{t^2 - 4}{t} = t - \frac{4}{t}.$$
接下来必须先精准锁定新元 $t$ 的取值范围。因为 $y = \log_2 x$ 在定义域上严格递增，当 $x \in \left[\frac{1}{4}, \frac{1}{2}\right) \cup \left(\frac{1}{2}, 4\right]$ 时，$\log_2 x \in [-2, -1) \cup (-1, 2]$，所以整体加 $1$ 后得到：
$$t \in [-1, 0) \cup (0, 3].$$

到了这里有两处常见的错误岔路需要当场剪除。第一处错觉是把 $h(t) = t - \frac{4}{t}$ 当成对勾函数去套均值不等式，误以为在 $t = 2$ 处会取到极值 $0$ 或 $4$（从而错选 C）。事实上，这里两项是**相减**而不是相加，属于**飘带型函数**。第二处错觉是以为函数只要能写出统一解析式就可以直接把区间两端点 $t = -1$ 和 $t = 3$ 代进去连成闭区间 $\left[\frac{5}{3}, 3\right]$（对应陷阱选项 A），却忘了区间中间在 $t = 0$ 处断开了。

**为什么 $h(t) = t - \frac{4}{t}$ 必须在 $[-1, 0)$ 和 $(0, 3]$ 两个分支上分别求值域？** 根据[[卡片/单调性定义证明与抽象单调]]，当 $t_1 < t_2$ 同属 $(-\infty, 0)$ 或同属 $(0, +\infty)$ 时，作差得
$$h(t_2) - h(t_1) = (t_2 - t_1) + \frac{4(t_2 - t_1)}{t_1 t_2} = (t_2 - t_1)\left(1 + \frac{4}{t_1 t_2}\right).$$
因为 $t_1$ 与 $t_2$ 同号，必有 $t_1 t_2 > 0$，从而 $h(t_2) > h(t_1)$；也就是说 $h(t)$ 在 $(-\infty, 0)$ 与 $(0, +\infty)$ 上**各自严格单调递增**，但从负数跳到正数时图像穿过铅直渐近线 $t = 0$ 发生从 $+\infty$ 到 $-\infty$ 的断裂，整体并不单调。

因此我们按两个连通区间分别代入端点并考察趋近 $0$ 的趋势：
- 当 $t \in [-1, 0)$ 时，$h(t)$ 严格递增，左端点处 $h(-1) = -1 - \frac{4}{-1} = 3$ 可以取到（闭端）；随着 $t$ 从左侧逼近 $0$，$-\frac{4}{t}$ 趋向 $+\infty$，所以这一支的值域为 $[3, +\infty)$。
- 当 $t \in (0, 3]$ 时，$h(t)$ 同样严格递增，随着 $t$ 从右侧逼近 $0$，$-\frac{4}{t}$ 趋向 $-\infty$；右端点处 $h(3) = 3 - \frac{4}{3} = \frac{5}{3}$ 可以取到（闭端），所以这一支的值域为 $\left(-\infty, \frac{5}{3}\right]$。

最后把两支的值域取并集（注意题目给的 $x = \frac{1}{4}$ 和 $x = 4$ 都是闭端点，切勿漏掉方括号而错选 D），得到原函数的值域为 $\left(-\infty, \frac{5}{3}\right] \cup [3, +\infty)$，对应选项 **B**。
