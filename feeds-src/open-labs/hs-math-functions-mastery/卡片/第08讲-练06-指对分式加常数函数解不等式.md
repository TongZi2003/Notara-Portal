# 第08讲·练06：指对分式加常数函数解不等式

## 内容

已知函数
$$f(x) = \frac{5^x - 1}{5^x + 1} + \ln\frac{2 + x}{2 - x} + 3,$$
则不等式 $f(m^2 - 1) + f(m - 1) > 6$ 的解集为（　　）

A. $(1, 3)$　　　　B. $(1, \sqrt{3})$　　　　C. $(-1, 1)$　　　　D. $(-\infty, -2) \cup (1, +\infty)$

## 参考理解

我们看到这道题把不等式写成 $f(m^2 - 1) + f(m - 1) > 6$ 的形式，里面既是指数分式又是分式对数，右边却出现了一个恰到好处的常数 $6$。如果直接把 $m^2 - 1$ 和 $m - 1$ 硬代入解析式去解指数对数混合不等式，马上会因为同时出现 $5^{m^2-1}$ 和 $\ln\frac{2+m-1}{2-m+1}$ 而完全算不动；反之，如果只看出了单调性而忘记受限于对数真数的有限开区间定义域，脱壳后解出 $m > 1$ 或 $m < -2$ 就会直接误选选项 D 或选项 A。

**为什么我们先锁定义域，再看“奇函数 $+$ 常数”与单调性？** 根据[[卡片/奇偶加常数与中心对称指对模型]]与[[卡片/奇偶性与单调性联合脱壳法]]，遇到外层抽象与内层具体混合的函数不等式，第一条红线是先把定义域算死：分母 $5^x + 1 > 0$ 恒成立，而对数项要求
$$\frac{2 + x}{2 - x} > 0 \iff (2 + x)(2 - x) > 0 \iff -2 < x < 2.$$
因此 $f(x)$ 的定义域是关于原点对称的**有限开区间 $(-2, 2)$**。这就立刻给不等式里的两个自变量加上了硬约束：
$$\begin{cases} -2 < m^2 - 1 < 2, \\ -2 < m - 1 < 2. \end{cases}$$
逐个解出：由 $-2 < m^2 - 1 < 2$ 得 $-1 < m^2 < 3$，即 $-\sqrt{3} < m < \sqrt{3}$；由 $-2 < m - 1 < 2$ 得 $-1 < m < 3$。两者取交集，在脱壳之前我们就已经把合法参数 $m$ 的大前提限制在开区间 $(-1, \sqrt{3})$ 内（选项 A、C、D 的真假几乎已经藏不住了，但我们仍需严格完成对称转化与单调性验证）。

接着检验 $f(x)$ 的对称性：令 $g(x) = f(x) - 3 = \frac{5^x - 1}{5^x + 1} + \ln\frac{2 + x}{2 - x}$。对任意 $x \in (-2, 2)$，均有 $-x \in (-2, 2)$，且
$$g(-x) = \frac{5^{-x} - 1}{5^{-x} + 1} + \ln\frac{2 - x}{2 + x} = \frac{1 - 5^x}{1 + 5^x} - \ln\frac{2 + x}{2 - x} = -g(x).$$
可见 $g(x)$ 是 $(-2, 2)$ 上的奇函数，从而对任意 $x \in (-2, 2)$ 都有 $f(x) + f(-x) = 6$，即 $6 - f(v) = f(-v)$。

再来判断 $f(x)$ 在 $(-2, 2)$ 上的单调性（严格使用高一初等代数变形）：
- 第一部分 $\frac{5^x - 1}{5^x + 1} = 1 - \frac{2}{5^x + 1}$。随着 $x$ 增大，$5^x$ 严格增大，分母 $5^x + 1$ 增大，$\frac{2}{5^x + 1}$ 减小，故 $1 - \frac{2}{5^x + 1}$ 在 $(-2, 2)$ 上严格单调递增；
- 第二部分 $\ln\frac{2 + x}{2 - x} = \ln\left(-1 + \frac{4}{2 - x}\right)$。随着 $x \in (-2, 2)$ 增大，分母 $2 - x$ 正值减小，$\frac{4}{2 - x}$ 增大，真数 $-1 + \frac{4}{2 - x}$ 严格增大，而外层 $\ln t$ 单调递增，故第二部分在 $(-2, 2)$ 上也严格单调递增。

两个增函数相加，所以 $f(x)$ 在整个定义域 $(-2, 2)$ 上**严格单调递增**。

现在可以安全完成转化与脱壳：不等式 $f(m^2 - 1) + f(m - 1) > 6$ 等价于
$$f(m^2 - 1) > 6 - f(m - 1) = f(1 - m).$$
注意这里因为 $m - 1 \in (-2, 2)$ 且定义域关于原点对称，所以 $1 - m = -(m - 1)$ 也必然落在 $(-2, 2)$ 内，两个括号都在同一严格递增区间 $(-2, 2)$ 中，安全脱去外层 $f$ 符号得
$$m^2 - 1 > 1 - m \iff m^2 + m - 2 > 0 \iff (m + 2)(m - 1) > 0,$$
解得 $m < -2$ 或 $m > 1$。最后将其与前面锁定的定义域大前提 $m \in (-1, \sqrt{3})$ 取交集，舍去越界的 $m < -2$ 与 $[\sqrt{3}, +\infty)$，最终得到精确解集为 $(1, \sqrt{3})$，对应选项 **B**。
