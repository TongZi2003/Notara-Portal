# 第17讲·例2：含参二次双层复合等于x与求解

## 内容

已知函数 $f(x) = x^2 - 2ax + 2a$（$a \in \mathbb{R}$）。

(1) 若方程 $f\bigl(f(x)\bigr) = x$ 与方程 $f(x) = x$ 在 $\mathbb{R}$ 上有完全相同的实数解集，求实数 $a$ 的取值范围；

(2) 若 $a = 2$，求方程 $f\bigl(f(x)\bigr) = 1$ 不同实数根的个数以及所有实数根之和。

**(1)** 我们看到第一问要求 $f\bigl(f(x)\bigr) = x$ 与 $f(x) = x$ 有完全相同的实数解集。刚拿到手时，最自然的尝试是把 $y = x^2 - 2ax + 2a$ 直接回代进去求 $f(f(x)) = (x^2 - 2ax + 2a)^2 - 2a(x^2 - 2ax + 2a) + 2a = x$。但如果直接硬展开，马上会得到一个最高次为 $4$ 次且处处带着参数 $a$ 的庞大四次方程，既分不开根，也很难看出它与二次方程 $f(x)=x$ 之间有什么联系；而如果只在因式分解后随手令余因式判别式严格小于零，又往往会漏掉余因式恰好在边界与已知根重合时对应的闭区间端点。

**为什么我们不用直接展开四次式，而是先拿 $f(y)$ 去减 $f(x)$？** 因为任何一个满足 $f(x) = x$ 的实数，再次套上函数关系后必定满足 $f\bigl(f(x)\bigr) = f(x) = x$，这说明多项式 $f(x) - x$ 必然能作为因式整除 $f\bigl(f(x)\bigr) - x$。为了不靠长除法硬凑而把公因式直接摆出来，我们记 $y = f(x) = x^2 - 2ax + 2a$，此时 $f\bigl(f(x)\bigr) = f(y) = y^2 - 2ay + 2a$。两式结构完全对称、常数项又完全相同，根据[[卡片/函数不动点与二周期点分析法]]，我们先让两式直接作差**消去含参常数项 $2a$**：
$$f\bigl(f(x)\bigr) - y = f(y) - f(x) = (y^2 - x^2) - 2a(y - x) = (y - x)(y + x - 2a).$$
现在把等式左边添上一个 $(y - x)$ 变成我们需要的 $f\bigl(f(x)\bigr) - x$，右边同步加上 $(y - x)$，公因式 $(y - x) = f(x) - x$ 就顺理成章地完整提取出来了：
$$f\bigl(f(x)\bigr) - x = (y - x)(y + x - 2a + 1) = \bigl(f(x) - x\bigr)\bigl(f(x) + x - 2a + 1\bigr).$$
先把两因子分别整理成关于 $x$ 的标准二次式：
- 一阶不动点方程 $P(x) = f(x) - x = x^2 - (2a + 1)x + 2a = (x - 1)(x - 2a) = 0$，解集永远非空，包含 $\{1, 2a\}$；
- 余因子方程 $Q(x) = f(x) + x - 2a + 1 = (x^2 - 2ax + 2a) + x - 2a + 1 = x^2 - (2a - 1)x + 1 = 0$。

因此原问题“$f\bigl(f(x)\bigr) = x$ 与 $f(x) = x$ 同解”，当且仅当余因子方程 $Q(x) = x^2 - (2a - 1)x + 1 = 0$ **要么没有实数根，要么它拥有的每一个实数根都已经包含在集合 $\{1, 2a\}$ 里**。这正是后续分类必须逐一核实的全部情形（切勿仅算到 $\Delta_Q < 0$ 就草草停笔）：

- **情形一：$Q(x) = 0$ 无实数根**。此时判别式 $\Delta_Q = (2a - 1)^2 - 4 < 0$，解得 $-2 < 2a - 1 < 2$，即 $-\frac{1}{2} < a < \frac{3}{2}$。
- **情形二：$Q(x) = 0$ 恰有一个实数根（即 $\Delta_Q = 0$）**。此时 $2a - 1 = \pm 2$，得两个边界参数，必须逐个代回去核验重根是否落在 $\{1, 2a\}$ 中：
  - 当 $a = \frac{3}{2}$ 时，$Q(x) = x^2 - 2x + 1 = 0$ 有唯一根 $x = 1$；此时 $\{1, 2a\} = \{1, 3\}$，$1$ 已经属于解集，故 **$a = \frac{3}{2}$ 符合题意**；
  - 当 $a = -\frac{1}{2}$ 时，$Q(x) = x^2 + 2x + 1 = 0$ 有唯一根 $x = -1$；此时 $\{1, 2a\} = \{1, -1\}$，$-1$ 恰等于 $2a$ 也已经属于解集，故 **$a = -\frac{1}{2}$ 同样符合题意**。
- **情形三：$Q(x) = 0$ 有两个不相等的实数根（$\Delta_Q > 0$）**。要想这两个互异实根全部落入二元集合 $\{1, 2a\}$ 内，唯一的可能就是 $Q(x) = 0$ 的两个根恰好就是 $1$ 和 $2a$。但由 $Q(x) = x^2 - (2a - 1)x + 1 = 0$ 的韦达定理，两根之积恒为 $1$，即需 $1 \cdot 2a = 1 \implies a = \frac{1}{2}$；代回检验此时 $\Delta_Q = (1 - 1)^2 - 4 = -4 < 0$，与前提 $\Delta_Q > 0$ 矛盾，故情形三不存在满足题意的参数。

综上，合并情形一与情形二，$a$ 的完整取值范围是闭区间 $\left[-\frac{1}{2}, \frac{3}{2}\right]$。

**(2)** 接下来我们看第二问：当 $a = 2$ 时，函数解析式具体确定为 $f(x) = x^2 - 4x + 4 = (x - 2)^2$，要求 $f\bigl(f(x)\bigr) = 1$ 的实数根个数与全部实根之和。同样地，如果强行展开四次方程 $[(x-2)^2 - 2]^2 = 1$ 会徒增高次因式分解失误的风险。因为右边是具体常数 $1$ 而不是自变量 $x$，根据[[卡片/复合嵌套方程换元拆层数根法]]，最清晰的办法是**令内层函数整体为新变量 $t = f(x)$，把嵌套结构拆成外层与内层两道低次问题**。

先锁定内层变量 $t = f(x) = (x - 2)^2$ 的值域为 $t \in [0, +\infty)$。再解外层方程 $f(t) = 1$：
$$(t - 2)^2 = 1 \implies t - 2 = \pm 1 \implies t_1 = 1, \qquad t_2 = 3.$$
核对值域限制：$t_1 = 1 \ge 0$ 且 $t_2 = 3 \ge 0$，两个外层实根均落在内层函数值域 $[0, +\infty)$ 内部，且 $t_1 \neq t_2$，因此接下来两条水平线在内层图像上解出的自变量一定互不重合：
- 当 $(x - 2)^2 = 1$ 时，解得 $x_1 = 1$，$x_2 = 3$；
- 当 $(x - 2)^2 = 3$ 时，解得 $x_3 = 2 - \sqrt{3}$，$x_4 = 2 + \sqrt{3}$。

检验四个解均互不相等，因此原方程共有 **$4$ 个**不同的实数根。此外从对称性来看，两对交点分别落在对称轴为 $x = 2$ 的同一条抛物线 $(x-2)^2$ 的两条不同水平截线上，每一对两根之和均为 $2 \times 2 = 4$（也可直接相加 $1 + 3 + (2 - \sqrt{3}) + (2 + \sqrt{3})$ 验算），从而所有实数根之和为 $4 + 4 = 8$。
