# 指数对数反函数对称与恒过定点

## 内容

指数函数 $y = a^x$ 与对数函数 $y = \log_a x$（$a > 0$ 且 $a \neq 1$）同底时互为反函数，在平面直角坐标系中关于直线 $y = x$ 严格对称。掌握这面“镜子”，就可以把原本拆成两章死记的图像和方程关系一次统一起来。

### 1. 镜面对称下的完全对应关系表

| 几何与代数属性 | 指数函数 $y = a^x$ | 对数函数 $y = \log_a x$ | 镜面对应规则 |
| :--- | :--- | :--- | :--- |
| **定义域 $\leftrightarrow$ 值域** | 定义域 $\mathbb{R}$，值域 $(0, +\infty)$ | 定义域 $(0, +\infty)$，值域 $\mathbb{R}$ | 自变量与因变量集合完全互换 |
| **恒过定点（锚点）** | $(0, 1)$（推广 $a^{x-h}+k$ 过 $(h, 1+k)$） | $(1, 0)$（推广 $\log_a(x-h)+k$ 过 $(1+h, k)$） | 坐标 $(u, v) \leftrightarrow (v, u)$ 互换 |
| **渐近线边界** | 水平渐近线 $y = 0$（靠近 $x$ 轴不接触） | 竖直渐近线 $x = 0$（靠近 $y$ 轴不接触） | 水平 $y=0$ 翻折为竖直 $x=0$ |
| **单调方向** | $a>1$ 严格增；$0<a<1$ 严格减 | $a>1$ 严格增；$0<a<1$ 严格减 | 互为反函数保持严格单调方向相同 |

### 2. 不背口诀的「基准线截点读底数」法则

当多条不同底数的指数曲线或对数曲线画在同一张图里时，无需死背“谁更贴近坐标轴”：
- **看多条指数函数 $y = a_i^x$**：直接做一条竖直线 **$x = 1$**，它与各条曲线交点的**纵坐标**就是底数本身 $a_i$。自上而下依次读出纵坐标，底数大小一目了然（注意在 $x < 0$ 一侧与 $x > 0$ 一侧上下次序恰好颠倒，切勿在左半区误读）；
- **看多条对数函数 $y = \log_{a_i} x$**：直接做一条水平线 **$y = 1$**，它与各条曲线交点的**横坐标**就是底数本身 $a_i$。自左向右读出横坐标，大小顺序一次排清。

### 3. 反函数对称方程 $a^x + x = c$ 与 $\log_a x + x = c$ 的两根之和模型

考虑同底数 $a > 0, a \neq 1$ 的两个方程（常以“$x_1$ 满足 $a^{x_1} + x_1 = c$，$x_2$ 满足 $\log_a x_2 + x_2 = c$”形式出现）：
- 把两式分别改写为直线与曲线的交点横坐标：
  - $x_1$ 是 $y = a^x$ 与直线 $l: y = c - x$ 的交点 $A(x_1, y_1)$ 的横坐标；
  - $x_2$ 是 $y = \log_a x$ 与直线 $l: y = c - x$ 的交点 $B(x_2, y_2)$ 的横坐标。
- 因为直线 $l: y = c - x$ 的斜率为 $-1$，**垂直于对称轴 $y = x$**，直线 $l$ 自身也关于 $y = x$ 对称；而两曲线同样关于 $y = x$ 严格对称。
- 又 $y = a^x$ 与直线 $y = c - x$ 单调性相反（若 $a > 1$ 则一增一减，至多只有一个交点；甚至当 $a > 1$ 时由增函数+减函数=唯一零点），因此交点 $A$ 与 $B$ 必然**关于直线 $y = x$ 对称**，即 $(x_2, y_2) = (y_1, x_1)$。
- 代入点 $A$ 落在直线 $y = c - x$ 上：
  $$x_1 + x_2 = x_1 + y_1 = c.$$

## 参考理解

### 高频易错与边界警报

1. **平移后先找真数/指数零点，切莫机械套原点定点**：
   函数 $y = \log_a(2x - 3) + 4$ 的定点，不是令 $x=1$，而是**令真数整体等于 $1$**（$2x - 3 = 1 \implies x = 2$），此时对数部分恒为 $\log_a 1 = 0$，得定点 $(2, 4)$。同理，对于 $y = a^{3x-6} - 2$，**令指数整体等于 $0$**（$3x - 6 = 0 \implies x = 2$），得定点 $(2, -1)$。
2. **「两根之和定值模型」在 $0 < a < 1$ 时的前提核查**：
   当 $0 < a < 1$ 时，$y = a^x$ 递减，而直线 $y = c - x$ 也递减，两者都是减函数，有可能出现多个交点或无交点吗？虽然此时交点集合整体依然关于 $y = x$ 对称，但如果出现超过 1 个交点，对应配对的两个交点 $A, B$ 必须确实是一对关于 $y=x$ 对称的互反点（若曲线自身对称轴交点处 $A=B$，则 $x_1 = x_2 = c/2$ 仍然满足 $x_1+x_2=c$；但若任意指派两个不配对的交点就不满足 $x_1+x_2=c$）。因此考试绝大多数考题取底数 $a > 1$（保证唯一交点），遇到 $0 < a < 1$ 时务必先通过图像确认交点个数是否唯一。
3. **非同底对称直线模型**：
   如果题干给出 $a^{x_1} + x_1 = c$ 与 $\log_a(x_2 + 1) + x_2 = c$ 这种带有微小平移的表达式，不要直接背 $x_1+x_2=c$，而是把后者恒等配凑：令 $t = x_2 + 1$，原方程等价于 $\log_a t + (t - 1) = c \iff \log_a t + t = c + 1$。于是 $t$ 与另一个方程 $a^{x_1} + x_1 = c + 1$ 才刚好共用直线 $y = c + 1 - x$，立刻推得 $x_1 + t = x_1 + x_2 + 1 = c + 1$（甚至需微调直线平移）。永远画图找“反函数+斜率为 $-1$ 的同一条直线”才不会背错。
