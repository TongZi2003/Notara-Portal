# 第15讲·练05：指数加一次方程实根窄区间定位

## 内容

方程 $2^x + 3x - 7 = 0$ 的实数根所在的区间为（　　）

A. $\left(1, \frac{5}{4}\right)$　　　　B. $\left(\frac{5}{4}, \frac{3}{2}\right)$　　　　C. $\left(\frac{3}{2}, \frac{7}{4}\right)$　　　　D. $\left(\frac{7}{4}, 2\right)$

## 参考理解

我们看到这个方程同时出现了指数 $2^x$ 和一次项 $3x$，同时混有指数与一次项，没法用初等公式直接解出根。很多同学一眼看出根在 $1$ 和 $2$ 之间以后，面对四个长度只有 $\frac{1}{4}$ 的细分区间，往往会卡在“怎么徒手判断 $2^{\frac{3}{2}}$ 和 $2^{\frac{5}{4}}$ 的函数值正负”这一步，甚至想靠背小数值硬蒙，其实完全没有必要背多位小数。

**为什么我们先构造函数并确认零点唯一？** 令 $f(x) = 2^x + 3x - 7$（$x \in \mathbb{R}$）。由[[卡片/零点存在定理与二分估界法]]，指数函数 $y = 2^x$ 在 $\mathbb{R}$ 上连续且严格单调递增，一次函数 $y = 3x - 7$ 在 $\mathbb{R}$ 上也连续且严格单调递增，“增函数 $+$ 增函数”仍然在 $\mathbb{R}$ 上**连续且严格单调递增**。这就从源头上保证了方程 $f(x) = 0$ 在整个实数集上**至多只有一个实数根**，只要我们找到两个端点函数值异号，就能立刻把唯一实根夹在中间。

**第一步：先定位长度为 $1$ 的整数区间。** 挑选方便口算的整数点试值：
- $f(1) = 2^1 + 3 \times 1 - 7 = 2 + 3 - 7 = -2 < 0$；
- $f(2) = 2^2 + 3 \times 2 - 7 = 4 + 6 - 7 = 3 > 0$。

因为 $f(x)$ 在 $[1, 2]$ 上连续且严格单调递增，并满足 $f(1)f(2) < 0$，所以唯一实根 $x_0$ 必落在区间 **$(1, 2)$** 内。

**第二步：第一次二分，取中点 $x = \frac{3}{2}$ 检验正负。** 计算中点函数值：
$$f\left(\frac{3}{2}\right) = 2^{\frac{3}{2}} + 3 \times \frac{3}{2} - 7 = \sqrt{8} + \frac{9}{2} - 7 = \sqrt{8} - \frac{5}{2}.$$
这里不用去估算 $\sqrt{8}$ 等于多少小数，只需因为两边均为正数，直接**分别平方比较大小**：
$$(\sqrt{8})^2 = 8, \qquad \left(\frac{5}{2}\right)^2 = \frac{25}{4} = 6.25.$$
显然 $8 > 6.25$，所以 $\sqrt{8} > \frac{5}{2}$，从而得到：
$$f\left(\frac{3}{2}\right) > 0.$$
结合 $f(1) = -2 < 0$，异号区间成功从 $(1, 2)$ 折半缩小为 **$\left(1, \frac{3}{2}\right)$**（直接排除选项 C 和 D）。

**第三步：第二次二分，取新区间 $\left(1, \frac{3}{2}\right)$ 的中点 $x = \frac{5}{4}$ 检验正负。** 计算函数值：
$$f\left(\frac{5}{4}\right) = 2^{\frac{5}{4}} + 3 \times \frac{5}{4} - 7 = 2^{\frac{5}{4}} + \frac{15}{4} - 7 = 2^{\frac{5}{4}} - \frac{13}{4}.$$
为了比较正数 $2^{\frac{5}{4}}$ 与 $\frac{13}{4}$ 的大小，我们再次利用“正数两边平方保序”，把它们同时平方：
$$\left(2^{\frac{5}{4}}\right)^2 = 2^{\frac{5}{2}} = \sqrt{32}, \qquad \left(\frac{13}{4}\right)^2 = \frac{169}{16}.$$
连四次方都不用算，用最简单的整数桥 $6$ 一夹就看出来了：因为 $32 < 36$，所以 $\sqrt{32} < 6$；而 $\frac{169}{16} > \frac{160}{16} = 10 > 6$。于是
$$\left(2^{\frac{5}{4}}\right)^2 = \sqrt{32} < 6 < \frac{169}{16} = \left(\frac{13}{4}\right)^2,$$
从而 $2^{\frac{5}{4}} < \frac{13}{4}$，立刻得出：
$$f\left(\frac{5}{4}\right) < 0.$$
现在把 $f\left(\frac{5}{4}\right) < 0$ 与刚才算出的 $f\left(\frac{3}{2}\right) > 0$ 配对，再次利用连续性与单调性，最终把方程 $2^x + 3x - 7 = 0$ 的唯一实数根精确锁定在区间 **$\left(\frac{5}{4}, \frac{3}{2}\right)$** 内，对应选项 **B**。

## 学生理解
