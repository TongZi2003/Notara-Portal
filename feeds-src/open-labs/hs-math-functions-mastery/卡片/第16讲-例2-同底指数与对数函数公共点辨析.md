# 第16讲·例2：同底指数与对数函数公共点辨析

## 内容

已知函数 $f(x) = a^x$ 与 $g(x) = \log_a x$（其中 $a > 0$ 且 $a \neq 1$），关于曲线 $y = f(x)$ 与 $y = g(x)$ 的公共点，下列说法正确的有（　　）

A. 当 $a = 2$ 时，两曲线没有公共点

B. 对任意 $a > 1$，两曲线都没有公共点

C. 若两曲线存在公共点，则所有公共点必定全在直线 $y = x$ 上

D. 当 $a = \frac{1}{16}$ 时两曲线至少有 $3$ 个不同的公共点，且当 $a = \sqrt{2}$ 时两曲线至少有 $2$ 个不同的公共点

我们拿到这道多选题时，很容易凭平时草图里的印象立刻下判断：草图里常常只画 $y = 2^x$ 和 $y = \log_2 x$，它们隔着直线 $y = x$ 越离越远，于是容易误以为“只要底数 $a > 1$，指数曲线永远跑在 $y = x$ 上方、对数曲线永远跑在下方”；同时又因为互为反函数的两曲线关于直线 $y = x$ 对称，容易脱口而出“对称曲线的交点一定全落在对称轴 $y = x$ 上”。要破除这两重直觉陷阱，我们需要根据[[卡片/反函数交点与非对称反例辨析]]，把递增与递减两种情况分别放到具体数值与纯初等反证推理中逐一检验。

先来看严格递增的情况，也就是判断 **A** 与 **B**。当 $a > 1$ 时，$f(x) = a^x$ 与 $g(x) = \log_a x$ 互为反函数且均为严格单调递增函数。假设它们存在一个不在直线 $y = x$ 上的公共点 $(u, v)$（即 $u \neq v$），由交点定义得 $a^u = v$ 且 $\log_a u = v$（即 $a^v = u$）。不妨设 $u < v$，由 $a > 1$ 时 $a^x$ 严格递增立即推出 $a^u < a^v$，也就是 $v < u$，与假设 $u < v$ 矛盾（$u > v$ 同理矛盾）。这说明只要 $a > 1$，两曲线若有公共点就**全部**只能落在直线 $y = x$ 上，等价于方程 $a^x = x$ 有实数根。

接下来分别代入 $a = 2$ 与 $a = \sqrt{2}$ 检验 $a^x = x$。对于 **A**，当 $a = 2$ 时，我们要说明对一切实数 $x$ 都有 $2^x > x$：当 $x \le 0$ 时，$2^x > 0 \ge x$ 显然成立；当 $0 < x < 1$ 时，$2^x > 2^0 = 1 > x$ 成立；当 $x \ge 1$ 时，记不超过 $x$ 的最大整数为 $n$（则 $n \ge 1$ 且 $n \le x < n + 1$），用数学归纳或逐项乘 $2$ 易知对正整数 $n$ 恒有 $2^n \ge n + 1$（$n=1$ 时 $2 \ge 2$，若 $2^n \ge n+1$ 则 $2^{n+1} \ge 2n+2 \ge n+2$），于是由 $2^x$ 递增得 $2^x \ge 2^n \ge n + 1 > x$。因此对全体实数 $x$ 恒有 $2^x > x$，$2^x = x$ 无实数解，从而 $y = 2^x$ 与 $y = \log_2 x$ 没有公共点，**A 正确**。然而 **B** 却把 $a = 2$ 的现象当成了所有 $a > 1$ 的通则，取底数 $a = \sqrt{2} > 1$ 试算整点即可击穿：当 $x = 2$ 时，$(\sqrt{2})^2 = 2$ 且 $\log_{\sqrt{2}} 2 = 2$；当 $x = 4$ 时，$(\sqrt{2})^4 = 4$ 且 $\log_{\sqrt{2}} 4 = 4$。可见 $y = (\sqrt{2})^x$ 与 $y = \log_{\sqrt{2}} x$ 至少在 $(2, 2)$ 与 $(4, 4)$ 处有 $2$ 个不同公共点（实际上从 $x = 1$ 时 $(\sqrt{2})^1 > 1$、$x = 2$ 时相等、$x = 3$ 时 $(\sqrt{2})^3 = 2\sqrt{2} < 3$、$x = 4$ 时再相等，也能直观看出直线 $y = x$ 穿过了指数曲线），故 **B 错误**。

再来检验递减的情况，也就是判断 **C** 与 **D**。当 $0 < a < 1$ 时，若我们照搬上面的反证法就会发现逻辑反转：假设 $u < v$，由于 $a^x$ 此时严格递减，推出的是 $a^u > a^v$ 即 $v > u$，与 $u < v$ 完全相容，不产生矛盾。这意味着当 $0 < a < 1$ 时，互为反函数的两曲线完全可能长出成对关于 $y = x$ 对称且不在 $y = x$ 上的公共点 $(u, v)$ 与 $(v, u)$。以 **D** 中的 $a = \frac{1}{16}$ 为例，我们逐一核对三个不同交点：第一，直接代入 $(u, v) = \left(\frac{1}{4}, \frac{1}{2}\right)$，算得 $f\left(\frac{1}{4}\right) = \left(\frac{1}{16}\right)^{\frac{1}{4}} = \frac{1}{2}$ 且 $g\left(\frac{1}{4}\right) = \log_{\frac{1}{16}}\left(\frac{1}{4}\right) = \frac{1}{2}$，所以 $\left(\frac{1}{4}, \frac{1}{2}\right)$ 确实是两曲线的公共点；第二，对称点 $\left(\frac{1}{2}, \frac{1}{4}\right)$ 满足 $f\left(\frac{1}{2}\right) = \left(\frac{1}{16}\right)^{\frac{1}{2}} = \frac{1}{4} = \log_{\frac{1}{16}}\left(\frac{1}{2}\right)$，同样是公共点；第三，在直线 $y = x$ 上考察辅助函数 $h(x) = \left(\frac{1}{16}\right)^x - x$，根据[[卡片/零点存在定理与二分估界法]]，因为减函数减去增函数所得 $h(x)$ 在 $\mathbb{R}$ 上严格单调递减，且 $h(0) = 1 > 0$，$h(1) = \frac{1}{16} - 1 = -\frac{15}{16} < 0$，所以必存在唯一实数 $x_0 \in (0, 1)$ 使得 $h(x_0) = 0$（即 $\left(\frac{1}{16}\right)^{x_0} = x_0 > 0$，两边取底为 $\frac{1}{16}$ 的对数亦得 $\log_{\frac{1}{16}} x_0 = x_0$）。点 $(x_0, x_0)$ 落在直线 $y = x$ 上，显然与前面两个横纵坐标不等的点互不相同。由此可知当 $a = \frac{1}{16}$ 时两曲线至少已有 $3$ 个不同的公共点，直接推翻了 **C** 的断言并证实 **D 正确**。

综上，本题正确选项为 **A、D**。
