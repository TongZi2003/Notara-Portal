# 第06讲·练01：一次分式函数单调性证明与求参

## 内容

已知函数 $f(x) = \frac{ax + 1}{x + 2}$（$x \in (-2, +\infty)$，$a \in \mathbb{R}$）。

(1) 若 $a = 1$，用函数单调性的定义证明 $f(x)$ 在 $(-2, +\infty)$ 上单调递增；

(2) 若 $f(x)$ 在 $(-2, +\infty)$ 上单调递增，求实数 $a$ 的取值范围。

## 参考理解

**(1)** 我们看到第一问明确要求“用函数单调性的定义证明”，这意味着即使把 $f(x) = \frac{x + 1}{x + 2}$ 分离常数写成 $1 - \frac{1}{x + 2}$ 一眼看穿它随 $x$ 增大而增大，也不能直接凭反比例平移性质口头断言单调性，否则在解答题中会直接失掉规范推导分。根据[[卡片/单调性定义证明与抽象单调]]中的“五步标准流程”，我们的目标是通过设元、作差、彻底因式分解、逐项定号，把差式的正负号定下来。

**为什么作差之后一定要通分并提取出 $(x_1 - x_2)$ 因子？** 因为只有把差式整理成各因子符号确定的纯乘除结构，才能对“任意”实数给出严密判定。具体步骤如下：

- **设元**：任取 $x_1, x_2 \in (-2, +\infty)$，且 $x_1 < x_2$；
- **作差**：计算 $f(x_1) - f(x_2) = \frac{x_1 + 1}{x_1 + 2} - \frac{x_2 + 1}{x_2 + 2}$；
- **通分与因式分解**：
  $$f(x_1) - f(x_2) = \frac{(x_1 + 1)(x_2 + 2) - (x_2 + 1)(x_1 + 2)}{(x_1 + 2)(x_2 + 2)} = \frac{(x_1 x_2 + 2x_1 + x_2 + 2) - (x_1 x_2 + 2x_2 + x_1 + 2)}{(x_1 + 2)(x_2 + 2)} = \frac{x_1 - x_2}{(x_1 + 2)(x_2 + 2)};$$
- **逐项定号**：由 $-2 < x_1 < x_2$ 可知，$x_1 - x_2 < 0$，同时 $x_1 + 2 > 0$ 且 $x_2 + 2 > 0$，因此分母 $(x_1 + 2)(x_2 + 2) > 0$；
- **收束结论**：由此得到 $f(x_1) - f(x_2) < 0$，即 $f(x_1) < f(x_2)$，所以 $f(x)$ 在 $(-2, +\infty)$ 上单调递增。

**(2)** 来到第二问，很多同学会顺手沿用分离常数思路 $f(x) = a + \frac{1 - 2a}{x + 2}$，看到 $x + 2$ 在 $(-2, +\infty)$ 上递增、前面带负号时递增，就写下 $1 - 2a \le 0$ 从而错答成 $\left[\frac{1}{2}, +\infty\right)$。或者在定义作差后没有仔细核对“单调递增”的严格不等号要求，把边界等号也一起收了进来。

**为什么必须沿着第 (1) 问的作差框架直接把 $a$ 代进去检验，并把 $a = \frac{1}{2}$ 彻底剪掉？** 沿着定义流程，任取 $x_1, x_2 \in (-2, +\infty)$ 且 $x_1 < x_2$，作差通分可得：
$$f(x_1) - f(x_2) = \frac{(ax_1 + 1)(x_2 + 2) - (ax_2 + 1)(x_1 + 2)}{(x_1 + 2)(x_2 + 2)} = \frac{(2a - 1)(x_1 - x_2)}{(x_1 + 2)(x_2 + 2)}.$$
已知 $-2 < x_1 < x_2$，所以 $x_1 - x_2 < 0$ 且 $(x_1 + 2)(x_2 + 2) > 0$。要使 $f(x)$ 在 $(-2, +\infty)$ 上单调递增，必须保证对任意满足 $x_1 < x_2$ 的实数恒有严格不等式 $f(x_1) - f(x_2) < 0$，这等价于分子系数满足 $2a - 1 > 0$，即 $a > \frac{1}{2}$。

现在专门回头核查最容易踩坑的边界值 $a = \frac{1}{2}$：当 $a = \frac{1}{2}$ 时，函数解析式变成
$$f(x) = \frac{\frac{1}{2}x + 1}{x + 2} = \frac{\frac{1}{2}(x + 2)}{x + 2} = \frac{1}{2} \quad \bigl(x \in (-2, +\infty)\bigr).$$
此时函数彻底退化为一条水平常函数。对于任意 $x_1 < x_2$，只能得到 $f(x_1) = f(x_2) = \frac{1}{2}$，无法满足单调递增定义中的严格小于关系 $f(x_1) < f(x_2)$，因此 **$a = \frac{1}{2}$ 绝对不能取等号**。当 $a < \frac{1}{2}$ 时，$2a - 1 < 0$ 反而导致 $f(x_1) > f(x_2)$（函数在 $(-2, +\infty)$ 上单调递减）。综上，实数 $a$ 的取值范围是 $\left(\frac{1}{2}, +\infty\right)$。

## 学生理解
