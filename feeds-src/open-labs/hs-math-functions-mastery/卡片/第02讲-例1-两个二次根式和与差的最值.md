# 第02讲·例1：两个二次根式和与差的最值

## 内容

已知函数 $f(x) = \sqrt{x^2 - 2x + 5} + \sqrt{x^2 - 14x + 85}$，则 $f(x)$ 的最小值为________；函数 $g(x) = \sqrt{x^2 - 6x + 25} - \sqrt{x^2 + 2x + 2}$ 的最大值为________。

## 参考理解

![[可视化/V01-第02讲例1-两个二次根式和与差的几何构造.html]]

> 全屏入口：[[可视化/V01-第02讲例1-两个二次根式和与差的几何构造.html|打开本例动态图解]]

面对两个二次根号内都含有 $x^2$ 项的表达式，如果尝试沿用上一题的“两边平方消根号”，平方后交叉项里仍然留着两个二次三项式的乘积（展开是四次式），不仅算不下去，还彻底丢掉了结构特征。

**为什么我们想到把每个根号里配成“$(x - a)^2 + b^2$”，转成平面上的两点距离？** 因为每个根号里的二次三项式判别式都小于零，把常数拆开就能写成两个平方之和：
- 对 $f(x)$：$x^2 - 2x + 5 = (x - 1)^2 + 2^2$，$x^2 - 14x + 85 = (x - 7)^2 + 6^2$；
- 对 $g(x)$：$x^2 - 6x + 25 = (x - 3)^2 + 4^2$，$x^2 + 2x + 2 = (x + 1)^2 + 1^2$。

按照[[卡片/根式函数值域代数与几何法]]，利用平面直角坐标系中的勾股定理（两点间距离公式），我们可以把 $x$ 看成 $x$ 轴上的动点 $P(x, 0)$ 的横坐标。先看第一问的 $f(x)$：两个根式恰好分别表示点 $P(x, 0)$ 到定点 $A(1, 2)$ 与定点 $B(7, 6)$ 的距离，即
$$f(x) = |PA| + |PB|.$$
这里立刻出现“选同侧还是异侧”的几何判断：当前 $A(1, 2)$ 和 $B(7, 6)$ 都在 $x$ 轴上方（同侧），如果不作对称直接连线 $AB$，线段 $AB$ 根本不穿过 $x$ 轴，无法直接在 $x$ 轴上找到共线点 $P$。因此我们借用“将军饮马”模型，作点 $B(7, 6)$ 关于 $x$ 轴的对称点 $B'(7, -6)$。对 $x$ 轴上的任意一点 $P(x, 0)$，由对称性恒有 $|PB| = |PB'|$，于是
$$f(x) = |PA| + |PB'| \ge |AB'|,$$
当且仅当 $P(x, 0)$ 落在线段 $AB'$ 与 $x$ 轴的交点上时取等号。因为 $A(1, 2)$ 与 $B'(7, -6)$ 分居 $x$ 轴两侧，线段 $AB'$ 必与 $x$ 轴相交（可验算直线 $AB'$ 斜率为 $\frac{-6 - 2}{7 - 1} = -\frac{4}{3}$，交 $x$ 轴于 $x = \frac{5}{2} \in (1, 7)$）。因此 $f(x)$ 的最小值就是两点 $A$ 与 $B'$ 之间的距离：
$$|AB'| = \sqrt{(7 - 1)^2 + (-6 - 2)^2} = \sqrt{6^2 + (-8)^2} = \sqrt{36 + 64} = 10.$$

再看第二问的 $g(x)$：设定点 $D(3, 4)$ 和 $C(-1, 1)$，那么 $g(x) = |PD| - |PC|$。对于距离之差的最大值，原则恰恰相反——**必须让两定点落在 $x$ 轴同侧**（这样才能用三角形两边之差小于第三边 $|PD| - |PC| \le |CD|$，若错选异侧只会得到反向结论甚至找不到等号点）。当前 $D(3, 4)$ 与 $C(-1, 1)$ 已经在 $x$ 轴上方同侧，根据三角形三边关系，对一切 $x \in \mathbb{R}$ 都有
$$g(x) = |PD| - |PC| \le |CD| = \sqrt{(3 - (-1))^2 + (4 - 1)^2} = \sqrt{4^2 + 3^2} = 5.$$
但千万不要算出 $|CD| = 5$ 就立刻收笔填答案，还有一个必须核验的几何条件：等号 $|PD| - |PC| = |CD|$ 成立，要求 **$P, C, D$ 三点共线且点 $C$ 位于点 $D$ 与点 $P$ 之间**（即射线 $DC$ 必须与 $x$ 轴相交）。如果 $D$ 与 $C$ 纵坐标相等（连线平行于 $x$ 轴），或者射线 $DC$ 朝背离 $x$ 轴的方向延伸（例如若题目反过来问 $|PC| - |PD|$ 的最大值，那么 $5$ 反而取不到）。

我们来核对本题两点坐标：$y_D = 4 > y_C = 1 > 0$，所以从 $D(3, 4)$ 出发经过 $C(-1, 1)$ 向下延伸的射线 $DC$ 一定能穿过 $x$ 轴。求直线 $DC$ 的方程：斜率 $k = \frac{4 - 1}{3 - (-1)} = \frac{3}{4}$，方程为 $y - 1 = \frac{3}{4}(x + 1)$，令 $y = 0$ 解得交点横坐标为 $x = -\frac{7}{3}$。此时回代原式验证：
$$g\left(-\frac{7}{3}\right) = \sqrt{\left(-\frac{16}{3}\right)^2 + 4^2} - \sqrt{\left(-\frac{4}{3}\right)^2 + 1^2} = \frac{20}{3} - \frac{5}{3} = 5.$$
等号确实能够取到，所以 $g(x)$ 的最大值为 $5$。两空答案依次为 $10$ 和 $5$。
