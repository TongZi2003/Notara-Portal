# 第01讲·练01：抽象复合与分式根式定义域

## 内容

已知函数 $y = f(1 - 2x)$ 的定义域为 $[-2, 1)$，则函数
$$g(x) = \frac{f(x - 1)}{\sqrt{9 - x^2}} + (x - 2)^0$$
的定义域为（　　）

A. $[0, 2) \cup (2, 3)$　　　　B. $(0, 2) \cup (2, 3)$　　　　C. $(0, 3)$　　　　D. $[-1, 2)$

## 参考理解

我们拿到这类既有抽象函数 $f$ 又有具体分母、根式和零次幂的混合定义域问题，最常见的一个弯路是看到“定义域为 $[-2, 1)$”，就直接把 $1 - 2x$ 或者把 $x - 1$ 强行塞进 $[-2, 1)$ 里去解。如果直接写成 $-2 \le x - 1 < 1$，立刻就会得到 $[-1, 2)$，正好掉进选项 D 的陷阱里。另一个高频失误是在求 $1 - 2x$ 的范围时只看端点顺手写成 $[-1, 5)$，忘了负系数 $-2$ 会把区间左右端点和开闭符号一并反转。

**为什么我们必须先锁定单一对应法则 $f(t)$ 的作用域，而不能直接替换自变量？** 因为根据[[卡片/抽象函数定义域替换法]]，题目说“函数 $y = f(1 - 2x)$ 的定义域为 $[-2, 1)$”，这个区间永远指的是最外层自变量 $x$ 的取值范围，也就是 $x \in [-2, 1)$；而同一对应法则 $f$ 括号内部的整体表达式才共用同一个合法区间。因此我们先把 $t = 1 - 2x$ 当作桥梁，在 $-2 \le x < 1$ 的条件下反推 $t$ 的取值范围：
- 当 $x \in [-2, 1)$ 时，两边同乘 $-2$ 必须把不等号调转方向，得到 $-2 < -2x \le 4$；
- 两边再同时加 $1$，就得到 $-1 < 1 - 2x \le 5$。

这就说明单层函数 $f(t)$ 括号里允许填入的真实区间是 $D_f = (-1, 5]$，左开右闭的顺序千万不能弄反（一旦粗心写成 $[-1, 5)$，后面就会误选成选项 A）。

接下来我们需要同时照顾 $g(x)$ 解析式里的每一处限制条件，让所有组成部分同时有意义：
- **抽象复合部分**：括号里的整体 $x - 1$ 必须落入作用域 $D_f = (-1, 5]$ 内，即 $-1 < x - 1 \le 5$，解得 $0 < x \le 6$；
- **分母中的偶次根式**：因为 $\sqrt{9 - x^2}$ 不仅在根号下而且处在分母位置，被开方数既要非负又不能为零，所以必须严格满足 $9 - x^2 > 0$，即 $x^2 < 9$，解得 $-3 < x < 3$；
- **零次幂部分**：任何非零实数的 $0$ 次幂才有意义，因此 $(x - 2)^0$ 要求底数 $x - 2 \neq 0$，即 $x \neq 2$（如果漏掉这一句，就会把 $x = 2$ 留在区间里误选成选项 C）。

最后我们把三条关于新自变量 $x$ 的条件放在数轴上取交集：
$$\begin{cases} 0 < x \le 6, \\ -3 < x < 3, \\ x \neq 2 \end{cases} \implies 0 < x < 3 \text{ 且 } x \neq 2.$$
因此 $g(x)$ 的定义域为 $(0, 2) \cup (2, 3)$，对应选项 **B**。
