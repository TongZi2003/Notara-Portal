# 对数糖水不等式与取倒数减整法

## 内容

当两个正对数值咬得极死（比如相差不足 $0.02$，连 $\frac{1}{2}, \frac{2}{3}$ 和均值不等式都插不进中间桥）时，在高一范围内有两套纯初等且可严格证明的高一解法：**糖水不等式**与**取倒数减整法**。

### 1. 代数糖水不等式与对数同加减变形

1. **分式糖水不等式**（纯初等作差即证）：
   若 $0 < b < a$ 且 $m > 0$，把浓度为 $\frac{b}{a}$ 的糖水再加入 $m$ 份糖变甜：
   $$\frac{b + m}{a + m} - \frac{b}{a} = \frac{m(a - b)}{a(a + m)} > 0 \implies \frac{b}{a} < \frac{b + m}{a + m} < 1.$$
   若结合单调递增对数，当 $1 < p$ 且 $0 < b < c$ 时立得 $\log_p\frac{b}{c} < \log_p\frac{b+m}{c+m}$（真数越靠近 $1$ 对数值越大）。
2. **对数底数真数同增型糖水结论**：
   若 $1 < b < a$ 且 $m > 0$（即真数小于底数、对数值在 $(0, 1)$ 内），底数和真数同加正数 $m$ 会让对数值变大并向 $1$ 靠拢：
   $$\log_a b < \log_{a + m}(b + m) < 1;$$
   对称地，若 $1 < a < b$（对数值 $> 1$），取倒数立即翻转：
   $$\log_a b = \frac{1}{\log_b a} > \frac{1}{\log_{b + m}(a + m)} = \log_{a + m}(b + m) > 1.$$
   - **纯高一严密证明思路（仅用基本不等式与有理数指数逼近）**：设 $k = \log_a b \in (0, 1)$，取任意满足 $k < r = \frac{p}{q} < M = \frac{1+k}{2} < 1$ 的有理数 $r$，对 $p$ 个 $\left(1+\frac{m}{a}\right)$ 与 $q-p$ 个 $1$ 应用 $q$ 元算术-几何平均值不等式得 $\left(1+\frac{m}{a}\right)^r < 1 + r\frac{m}{a}$，两边同乘 $a^r$ 且利用 $a^{r-1} < 1$ 可得 $(a+m)^r < a^r + rm < a^r + Mm$；由指数函数定义选取充分贴近 $k$ 的 $r$ 使 $a^r - b < (1-M)m$，即得 $(a+m)^k < (a+m)^r < b + m$，两边取 $\log_{a+m}$ 即证 $\log_a b < \log_{a+m}(b+m)$。
   - 例如瞬间秒判：$\log_{11} 7 < \log_{13} 9$（$1<7<11$ 同时 $+2$）以及 $\log_6 5 < \log_7 6$（$1<5<6$ 同时 $+1$）。

### 2. 取倒数减整法（反复减整取倒数放大差异）

当两个对数无法凑出相同 $+m$ 变化时，通用终极流程如下（以比大小两个大于 $1$ 的对数 $\log_a b$ 与 $\log_c d$ 为例；若都小于 $1$ 先取倒数再翻转方向）：
1. **剥整数部分（减 $1$ 降真数）**：
   写成 $\log_a b = n + \log_a\frac{b}{a^n}$，剥去共同整数部分 $n$ 后，余项全部落入 $(0, 1)$；
2. **取倒数（真底互换）**：
   把余项翻成倒数 $\frac{1}{\log_a r} = \log_r a > 1$（注意不等号方向反转）；
3. **重复减整或直接乘方拉开差距**：
   经过 1～2 轮“减整 $\to$ 倒数”，余数对数的底数与真数差距会被成倍放大，很快撞出不同整数界限或一眼能算的幂次。

**完整演示：比较 $A = \log_7 5$ 与 $B = \log_{10} 7$**
- 第一步：两者都 $< 1$，先取倒数比 $\frac{1}{A} = \log_5 7$ 与 $\frac{1}{B} = \log_7 10$；
- 第二步：同时减整数 $1$：$\log_5 7 - 1 = \log_5 \frac{7}{5}$，$\log_7 10 - 1 = \log_7 \frac{10}{7}$；
- 第三步：余项仍贴在 $(0.2, 0.25)$ 内难直接判，再次**取倒数**比较 $\log_{\frac{7}{5}} 5$ 与 $\log_{\frac{10}{7}} 7$：
  - 看幂次范围：$\left(\frac{7}{5}\right)^4 = \frac{2401}{625} < 4 < 5$ 而 $\left(\frac{7}{5}\right)^5 = \frac{16807}{3125} > 5$，故 $\log_{\frac{7}{5}} 5 \in (4, 5)$；
  - 另一侧：$\left(\frac{10}{7}\right)^5 = \frac{100000}{16807} \approx 5.95 < 7$ 而 $\left(\frac{10}{7}\right)^6 > 7$，故 $\log_{\frac{10}{7}} 7 \in (5, 6)$。
- 一眼拉开。$\log_{\frac{7}{5}} 5 < 5 < \log_{\frac{10}{7}} 7 \implies$（两次取倒数反号两次还原同向）$A = \log_7 5 < \log_{10} 7 = B$。

## 参考理解

### 严密边界提示

1. **「真数小于 $1$」或「同增同减混用方向」是大忌**：
   对数糖水公式 $\log_a b < \log_{a+m}(b+m)$ **必须确保 $a > 1$ 且 $b > 1$**，同时清楚辨别：当 $1 < b < a$（真数小于底数）时同加正数会变大；当 $1 < a < b$（真数大于底数）时同加正数反而会**变小**（向 $1$ 压缩）。如果不核对真数和底数谁大就盲目套同加变大，方向必反。考前可以用具体可心算点检验一下：$\log_2 4 = 2$，同时 $+2$ 变成 $\log_4 6 < 2$（真数大于底数时确实变小）。
2. **取倒数减整的每一步“取倒数”都要记清一次符号反转**：
   连分数链条通常翻 $2 \sim 3$ 次就够了，最好每次只用清晰的 $> $ 或 $<$ 标记最终量（或写“下面等价于比较倒数，方向相反”），防止翻着翻着自己晕掉最后一项的符号朝向。
