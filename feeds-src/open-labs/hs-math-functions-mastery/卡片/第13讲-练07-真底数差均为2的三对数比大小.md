# 第13讲·练07：真底数差均为2的三对数比大小

## 内容

已知 $a = \log_7 5$，$b = \log_9 7$，$c = \log_{11} 9$，则 $a, b, c$ 的大小关系是（　　）

A. $a < b < c$　　　　B. $b < a < c$　　　　C. $c < b < a$　　　　D. $a < c < b$

## 参考理解

我们看到 $a = \log_7 5$、$b = \log_9 7$、$c = \log_{11} 9$ 时，先拿常规分数桥试一试就会碰壁：三个数都大于 $\frac{4}{5}$（$5^5 = 3125 > 7^4 = 2401$，$7^5 > 9^4$，$9^5 > 11^4$），且全都落在 $(0.8, 1)$ 这段窄缝里；如果拿换底作商配均值不等式，因为每步跳动是 $+2$ 而非邻项乘积，尝试 $\sqrt{\lg 7 \cdot \lg 9}$ 也无法直接卡住两边真数与底数的比值。

**为什么这三个数能一眼看出“同加正数变大”的结构？** 仔细观察三个数的底数和真数：从 $a = \log_7 5$ 到 $b = \log_9 7$，再到 $c = \log_{11} 9$，恰好满足**底数和真数同时加上正数 $2$**，且每一次都满足 $1 < \text{真数} < \text{底数}$（即 $1 < 5 < 7$ 与 $1 < 7 < 9$）。

根据[[卡片/对数糖水不等式与取倒数减整法]]的对数糖水规律：当 $1 < u < v$（真数小于底数、对数值落在 $(0, 1)$ 内）且 $m > 0$ 时，把底数与真数同时加上正数 $m$，对数值会严格变大并向 $1$ 靠拢：
$$\log_v u < \log_{v+m}(u+m) < 1.$$
**如何不用任何超纲工具，纯用高一的基本不等式与有理数指数逼近严密证明这条规律？** 记 $k = \log_v u \in (0, 1)$，即 $v^k = u$。任取有理数 $r = \frac{p}{q}$（$p, q \in \mathbb{N}^*$）满足 $k < r < M = \frac{1 + k}{2} < 1$。我们把 $p$ 个 $\left(1 + \frac{m}{v}\right)$ 与 $q - p$ 个 $1$（各数均正且不全相等）代入 $q$ 元算术-几何平均值不等式，得
$$\left(1 + \frac{m}{v}\right)^{\frac{p}{q}} = \sqrt[q]{\left(1 + \frac{m}{v}\right)^p \cdot 1^{q-p}} < \frac{p\left(1 + \frac{m}{v}\right) + (q - p)\cdot 1}{q} = 1 + r\frac{m}{v}.$$
两边同乘正数 $v^r$，由于 $v > 1$ 且 $r < 1$，有 $v^{r-1} < 1$，结合 $r < M$ 便推出
$$(v + m)^r < v^r + r m v^{r-1} < v^r + M m.$$
因为 $r$ 可以由指数函数定义选取足够接近 $k$ 的有理数，使得 $v^r - v^k = v^r - u < (1 - M)m$，代入上式立得
$$(v + m)^k < (v + m)^r < u + M m + (1 - M)m = u + m.$$
最后因为底数 $v + m > 1$，两边取以 $v + m$ 为底的单增对数，即严密证得
$$k = \log_v u < \log_{v+m}(u+m).$$

直接把 $m = 2$ 先后套用到 $a, b$ 上：
- 由 $1 < 5 < 7$ 同加 $2$ 得 $\log_7 5 < \log_9 7$，即 $a < b$；
- 由 $1 < 7 < 9$ 同加 $2$ 得 $\log_9 7 < \log_{11} 9$，即 $b < c$。

**我们再用“取倒数减整法”对数值做一次独立交叉验算，确保方向万无一失。** 根据[[卡片/指对条件求值与整体代换法]]与[[卡片/对数糖水不等式与取倒数减整法]]，由于 $a, b, c \in (0, 1)$，先取倒数（方向反转），再分别剥离整数部分 $1$：
$$\frac{1}{a} - 1 = \log_5 7 - 1 = \log_5 \frac{7}{5}, \qquad \frac{1}{b} - 1 = \log_7 9 - 1 = \log_7 \frac{9}{7}, \qquad \frac{1}{c} - 1 = \log_9 11 - 1 = \log_9 \frac{11}{9}.$$
三项余数依然全在 $(0, 1)$ 内，再次取倒数（方向第二次反转，回到与原 $a, b, c$ 同向），转而比较 $\log_{\frac{7}{5}} 5$、$\log_{\frac{9}{7}} 7$ 与 $\log_{\frac{11}{9}} 9$：
- 因为 $7^5 = 16807 > 15625 = 5^6$，所以 $\left(\frac{7}{5}\right)^5 > 5 \implies \log_{\frac{7}{5}} 5 < 5$；
- 因为 $9^7 = 4782969 < 5764801 = 7^8$，所以 $\left(\frac{9}{7}\right)^7 < 7 \implies \log_{\frac{9}{7}} 7 > 7$；
- 因为 $11^{10} = 25937424601 < 31381059609 = 9^{11}$，所以 $\left(\frac{11}{9}\right)^{10} < 9 \implies \log_{\frac{11}{9}} 9 > 10$（且由 $\left(\frac{9}{7}\right)^8 = \frac{43046721}{5764801} > 7$ 知 $\log_{\frac{9}{7}} 7 < 8$）。

于是 $5, 8, 10$ 瞬间把三者彻底拉开：
$$\log_{\frac{7}{5}} 5 < 5 < 7 < \log_{\frac{9}{7}} 7 < 8 < 10 < \log_{\frac{11}{9}} 9.$$
由于经历了两次取倒数反号，最终大小方向与原数保持一致，再次确证
$$a < b < c,$$
对应选项 **A**。
