# 第13讲·练03：指数幂与对数四数关系辨析

## 内容

已知 $a = 2^{0.3}$，$b = 0.3^2$，$c = \log_2 3$，$d = \log_3 4$，则下列结论正确的有（　　）

A. $b < a < d$
B. $d < \frac{3}{2} < c$
C. $a > 3^{0.2}$
D. $c + d < 3$

## 参考理解

这道多选题表面上把四个指、对、幂数值与额外构造的和式、异底幂混在了一起，如果试图拿估计小数往里硬凑，很容易在 $a = 2^{0.3}$ 和 $d = \log_3 4$ 谁更大上卡壳（因为两者都在 $1.23$ 到 $1.27$ 附近），也很容易因为看到 $0.3 > 0.2$ 就误判选项 C。

**为什么我们先给 $a, b, c, d$ 逐个打上精确的分数区间标签？** 根据[[卡片/指对幂比大小三阶通法与中间桥]]，只要先算出 $b$ 并为 $a, c, d$ 找到几对好算的正整数次幂分数桥，四个选项就能一次性全部看穿。

先看选项 **A**（$b < a < d$）：
首先 $b = 0.3^2 = 0.09 < 1$，而 $a = 2^{0.3} > 2^0 = 1$，所以 $b < 1 < a$ 毫无悬念。关键在于如何纯初等地比较 $a = 2^{0.3}$ 与 $d = \log_3 4$：我们试探中间桥 $\frac{5}{4}$。
- 看 $a = 2^{\frac{3}{10}}$ 与 $\frac{5}{4}$：两边同时做 $10$ 次方（幂函数 $x^{10}$ 在 $(0, +\infty)$ 严格递增），左边得 $a^{10} = 2^3 = 8$；右边利用 $5$ 次方先放大：
  $$\left(\frac{5}{4}\right)^5 = \frac{3125}{1024} > \frac{3072}{1024} = 3 \implies \left(\frac{5}{4}\right)^{10} > 3^2 = 9 > 8 = a^{10}.$$
  由于底数均正且十次幂单调递增，立即推出 $a < \frac{5}{4}$。
- 看 $d = \log_3 4$ 与 $\frac{5}{4}$：检查 $4^4$ 与 $3^5$ 的大小，算得 $4^4 = 256 > 243 = 3^5$，即 $4 > 3^{\frac{5}{4}}$，结合 $y = \log_3 x$ 严格递增得 $d = \log_3 4 > \frac{5}{4}$。

于是 $\frac{5}{4}$ 干净利落地把 $a$ 和 $d$ 分开，得到 $b < 1 < a < \frac{5}{4} < d$，选项 **A 正确**。

再看选项 **B**（$d < \frac{3}{2} < c$）：
直接对 $\frac{3}{2}$ 做同次去分母验证：
- 因为 $4^2 = 16 < 27 = 3^3$，所以 $4 < 3^{\frac{3}{2}}$，由 $y = \log_3 x$ 递增得 $d = \log_3 4 < \frac{3}{2}$；
- 因为 $3^2 = 9 > 8 = 2^3$，所以 $3 > 2^{\frac{3}{2}}$，由 $y = \log_2 x$ 递增得 $c = \log_2 3 > \frac{3}{2}$。
合起来恰好构成 $d < \frac{3}{2} < c$，选项 **B 正确**。

再看选项 **C**（$a > 3^{0.2}$）：
这里最容易掉进“看指数 $0.3 > 0.2$ 就直觉觉得左边大”的陷阱，但两个数的底数并不相同（分别是 $2$ 和 $3$）。我们把 $0.3 = \frac{3}{10}$ 与 $0.2 = \frac{2}{10}$ 的公共分母 $10$ 消掉，即对两个正数 $a = 2^{\frac{3}{10}}$ 与 $3^{\frac{2}{10}}$ 同时作 $10$ 次方（由[[卡片/幂函数第一象限图像与奇偶性]]，幂函数 $y = x^{10}$ 在 $(0, +\infty)$ 上严格单调递增）：
$$a^{10} = \left(2^{\frac{3}{10}}\right)^{10} = 2^3 = 8, \qquad \left(3^{0.2}\right)^{10} = \left(3^{\frac{2}{10}}\right)^{10} = 3^2 = 9.$$
因为 $8 < 9$，所以 $a < 3^{0.2}$，选项 **C 错误**。

最后看选项 **D**（$c + d < 3$）：
从前面的估算我们已经知道 $c > \frac{3}{2}$ 且 $d < \frac{3}{2}$，这一步不能直接相加判 $< 3$，必须各自找更紧的上界分数。注意到分母为 $3$ 的简单分数 $\frac{5}{3}$ 与 $\frac{4}{3}$ 相加恰好等于 $3$，我们逐个检验：
- 检验 $c = \log_2 3$ 与 $\frac{5}{3}$：因为 $3^3 = 27 < 32 = 2^5$，所以 $3 < 2^{\frac{5}{3}} \implies c = \log_2 3 < \frac{5}{3}$；
- 检验 $d = \log_3 4$ 与 $\frac{4}{3}$：因为 $4^3 = 64 < 81 = 3^4$，所以 $4 < 3^{\frac{4}{3}} \implies d = \log_3 4 < \frac{4}{3}$。
把两个同向严格不等式相加，立得
$$c + d < \frac{5}{3} + \frac{4}{3} = 3,$$
因此选项 **D 正确**。

综上，全部正确的选项是 **ABD**。
