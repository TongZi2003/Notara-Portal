# 第13讲·练06：小于1两正底数对数不等式辨析

## 内容

已知 $0 < a < b < 1$，则下列不等式一定成立的有（　　）

A. $\log_a b < \log_b a$
B. $\log_a b + \log_b a < -2$
C. $\log_a \frac{a+b}{2} < \log_b \sqrt{ab}$
D. $\log_b \frac{a+b}{2} > \frac{1 + \log_b a}{2}$

## 参考理解

我们看到条件 $0 < a < b < 1$ 时，最常犯的错误是下意识把“小于 $1$ 的数取对数”直接等同于“负数”，进而套用负数的均值不等式得出诸如 $\log_a b + \log_b a < -2$ 的错判；另一个高频反号坑则出现在把 $\frac{a+b}{2} > \sqrt{ab}$ 代入以 $a$ 或 $b$ 为底的对数时，忘记了底数在 $(0, 1)$ 内会让对数函数单调递减，导致不等号方向少翻一次。

**为什么动手判断四个选项前，我们先花五秒把 $\log_a b$ 与 $\log_b a$ 的正负和 $1$ 界线钉死？** 由[[卡片/指对条件求值与整体代换法]]，因为 $a, b$ 同在 $(0, 1)$ 内，即底数与真数位于 $1$ 的**同一侧**，所以这两个对数全部是**正数**。再分别利用各自的单调递减性定界：
- 由于 $0 < a < 1$，$y = \log_a x$ 在 $(0, +\infty)$ 上严格递减，且 $0 < a < b < 1$，因此
  $$0 = \log_a 1 < \log_a b < \log_a a = 1.$$
- 由于 $0 < b < 1$，$y = \log_b x$ 在 $(0, +\infty)$ 上严格递减，且 $0 < a < b < 1$，因此
  $$\log_b a > \log_b b = 1.$$

有了 $0 < \log_a b < 1 < \log_b a$ 这条标尺，四个选项的对错立刻清晰展开。

先看选项 **A**（$\log_a b < \log_b a$）：
由上述两界直接得到 $\log_a b < 1 < \log_b a$，故选项 **A 正确**。

再看选项 **B**（$\log_a b + \log_b a < -2$）：
这是专为“误以为小底对数必为负”设下的符号坑。因为 $\log_a b > 0$、$\log_b a > 0$，且 $\log_a b \neq \log_b a$（前者小于 $1$、后者大于 $1$），由[[卡片/作商换底与基本不等式比大小]]的严格基本不等式：
$$\log_a b + \log_b a > 2\sqrt{\log_a b \cdot \log_b a} = 2\sqrt{1} = 2 > 0,$$
绝不可能小于 $-2$，故选项 **B 错误**。（只有当 $a, b$ 分居 $1$ 的两侧，如 $0 < a < 1 < b$ 时，两个互为倒数的对数才同为负数且和小于 $-2$。）

再看选项 **C**（$\log_a \frac{a+b}{2} < \log_b \sqrt{ab}$）：
由 $0 < a < b < 1$ 及基本不等式，四个正数满足链条：
$$0 < a < \sqrt{ab} < \frac{a+b}{2} < b < 1.$$
我们再次以 $1$ 作为分界桥梁分别框定两端：
- 左端以 $a \in (0, 1)$ 为底，$y = \log_a x$ 严格递减，而真数 $\frac{a+b}{2} > a$，所以
  $$\log_a \frac{a+b}{2} < \log_a a = 1;$$
- 右端以 $b \in (0, 1)$ 为底，$y = \log_b x$ 严格递减，而真数 $\sqrt{ab} < b$，所以
  $$\log_b \sqrt{ab} > \log_b b = 1.$$
（也可以借助换底拆出同侧项 $\log_a \frac{a+b}{2} < \log_a \sqrt{ab} = \frac{1 + \log_a b}{2} < 1 < \frac{\log_b a + 1}{2} = \log_b \sqrt{ab}$。）无论哪种走法，$1$ 都严丝合缝地把两者隔开，于是 $\log_a \frac{a+b}{2} < 1 < \log_b \sqrt{ab}$，选项 **C 正确**。

最后看选项 **D**（$\log_b \frac{a+b}{2} > \frac{1 + \log_b a}{2}$）：
先用对数运算法则把右边的 $\frac{1 + \log_b a}{2}$ 还原为单个对数形式：
$$\frac{1 + \log_b a}{2} = \frac{\log_b b + \log_b a}{2} = \frac{1}{2}\log_b(ab) = \log_b \sqrt{ab}.$$
题目本质上是在比较 $\log_b \frac{a+b}{2}$ 与 $\log_b \sqrt{ab}$。虽然真数满足 $\frac{a+b}{2} > \sqrt{ab}$，但底数 $b$ 落在 $(0, 1)$ 内，函数 $y = \log_b x$ **严格单调递减**，所以取完对数后不等号必须反转：
$$\log_b \frac{a+b}{2} < \log_b \sqrt{ab} = \frac{1 + \log_b a}{2}.$$
选项 D 把减函数当成了增函数，方向恰好写反，故选项 **D 错误**。

综上，一定成立的不等式是 **AC**。
