# 第13讲·练08：多组不同底数对数大小关系辨析

## 内容

下列关于对数大小关系的判断中，正确的有（　　）

A. $\log_5 3 < \log_7 5$ 且 $\log_7 4 < \log_{10} 7$
B. $\log_3 5 < \log_5 7$
C. $\log_4 7 > \log_7 10$
D. $\log_{0.5} \frac{5}{7} < \log_{0.5} \frac{7}{9}$

## 参考理解

很多同学背熟了“糖水越加越甜”的顺口溜后，做题时只要看见“底数和真数同时加了一个正数”，不管三七二十一就一律写“小于号”，完全不去核对对数本身究竟是小于 $1$ 还是大于 $1$，更不去检查外层对数的底数是否大于 $1$。这道多选题专门把方向相反的三类结构摆在一起，目的就是逼着我们在下笔前多做一次方向自检。

**为什么我们每次套用糖水结论前，都必须先问一句“它是真数小于底数，还是真数大于底数”？** 根据[[卡片/对数糖水不等式与取倒数减整法]]，对大于 $1$ 的正底数和正真数：
- 当 $1 < \text{真数} < \text{底数}$ 时，对数值在 $(0, 1)$ 内，底数和真数同加正数 $m$ 会使对数值**变大**（向 $1$ 靠拢）；
- 当 $1 < \text{底数} < \text{真数}$ 时，对数值在 $(1, +\infty)$ 内，取倒数后恰好变成上面那种情况再翻回来，因此底数和真数同加正数 $m$ 反而会让对数值**变小**（同样向 $1$ 压缩）。

记住“**无论在 $1$ 的哪一侧，底真同加正数永远向 $1$ 靠拢**”这句物理图景，就不会再把方向搞混。下面我们逐个选项结合正整数幂验算确认真伪。

先看选项 **A**（$\log_5 3 < \log_7 5$ 且 $\log_7 4 < \log_{10} 7$）：
这两组对数都满足 $1 < \text{真数} < \text{底数}$（$1 < 3 < 5$ 同加 $2$，以及 $1 < 4 < 7$ 同加 $3$），对数值全在 $(0, 1)$ 内，同加正数向 $1$ 靠拢即变大，所以两个不等号方向都正确。我们再用[[卡片/指对幂比大小三阶通法与中间桥]]里的分数桥独立核验一遍：
- 比较 $\log_5 3$ 与 $\log_7 5$，插入桥梁 $\frac{3}{4}$：因为 $3^4 = 81 < 125 = 5^3 \implies \log_5 3 < \frac{3}{4}$，而 $5^4 = 625 > 343 = 7^3 \implies \log_7 5 > \frac{3}{4}$，所以 $\log_5 3 < \frac{3}{4} < \log_7 5$ 成立；
- 比较 $\log_7 4$ 与 $\log_{10} 7$，插入桥梁 $\frac{4}{5}$：因为 $4^5 = 1024 < 2401 = 7^4 \implies \log_7 4 < \frac{4}{5}$，而 $7^5 = 16807 > 10000 = 10^4 \implies \log_{10} 7 > \frac{4}{5}$，所以 $\log_7 4 < \frac{4}{5} < \log_{10} 7$ 成立。
两条完全成立，故选项 **A 正确**。

再看选项 **B**（$\log_3 5 < \log_5 7$）：
这里底数和真数虽然同样是从 $3, 5$ 同步加 $2$ 变成 $5, 7$，但注意条件已经翻转为 $1 < \text{底数} < \text{真数}$（两个对数值都大于 $1$）。互换底数和真数取倒数即可看出：由于选项 A 已证 $\log_5 3 < \log_7 5$ 且两者均大于 $0$，取倒数立即反号为
$$\log_3 5 = \frac{1}{\log_5 3} > \frac{1}{\log_7 5} = \log_5 7$$
（也可直接用桥梁 $\frac{4}{3}$ 核验：$\log_3 5 > \frac{4}{3} > \log_5 7$）。选项 B 恰好把方向写反了，故选项 **B 错误**。

再看选项 **C**（$\log_4 7 > \log_7 10$）：
这里同样满足 $1 < \text{底数} < \text{真数}$（$1 < 4 < 7$ 同加 $3$），因此底真同加 $3$ 向 $1$ 压缩，数值应该**变小**。取倒数核对：由选项 A 已证 $\log_7 4 < \log_{10} 7$，取倒数得
$$\log_4 7 = \frac{1}{\log_7 4} > \frac{1}{\log_{10} 7} = \log_7 10$$
（也可直接以 $\frac{5}{4}$ 为桥看出 $\log_4 7 > \frac{5}{4} > \log_7 10$）。方向完全正确，故选项 **C 正确**。

最后看选项 **D**（$\log_{0.5} \frac{5}{7} < \log_{0.5} \frac{7}{9}$）：
真数 $\frac{5}{7}$ 与 $\frac{7}{9}$ 是标准的分式糖水结构：因为 $0 < 5 < 7$ 且同加正数 $2$，作差即证
$$\frac{7}{9} - \frac{5}{7} = \frac{49 - 45}{63} = \frac{4}{63} > 0 \implies \frac{5}{7} < \frac{7}{9}.$$
很多同学算到这里便随手照抄“$<$”写完选项 D，却漏掉了外层对数函数 $y = \log_{0.5} x$ 的底数 $0.5 \in (0, 1)$，它在 $(0, +\infty)$ 上**严格单调递减**。把 $\frac{5}{7} < \frac{7}{9}$ 代入减函数时不等号必须再次反号：
$$\log_{0.5} \frac{5}{7} > \log_{0.5} \frac{7}{9}.$$
选项 D 忘记在递减对数处反号，故选项 **D 错误**。

综上，全部正确的选项是 **AC**。
