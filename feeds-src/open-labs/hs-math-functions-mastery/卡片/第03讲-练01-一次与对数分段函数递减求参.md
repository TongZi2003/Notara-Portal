# 第03讲·练01：一次与对数分段函数递减求参

## 内容

已知函数
$$f(x) = \begin{cases} (2a - 1)x + 3a - 1, & x < 2, \\ \log_a(x - 1), & x \ge 2 \end{cases}$$
是 $\mathbb{R}$ 上的减函数，则实数 $a$ 的取值范围是（　　）

A. $\left(\dfrac{3}{7}, \dfrac{1}{2}\right)$　　　　B. $\left[\dfrac{3}{7}, \dfrac{1}{2}\right)$　　　　C. $\left(0, \dfrac{1}{2}\right)$　　　　D. $\left[\dfrac{3}{7}, 1\right)$

## 参考理解

我们看到分段函数要求在 $\mathbb{R}$ 上单调递减，最容易在考场上匆忙下笔时少列条件。按照[[卡片/分段函数单调衔接与取大取小]]的“双约束”铁律，要想让一个分段函数在整条数轴上从左到右一直下降，必须把**两段各自内部下降**与**分界点处衔接不反弹**三条条件同时攥在手里，缺一不可。

首先看两段各自内部单调递减的条件：
- 当 $x < 2$ 时，左段是一次函数 $y = (2a - 1)x + 3a - 1$。要使一次函数单调递减，一次项系数必须严格为负（若等于零则为常函数，不符合严格减函数要求）：
  $$2a - 1 < 0 \implies a < \frac{1}{2}.$$
  如果漏掉这条只管右段，就会多出 $\left[\frac{1}{2}, 1\right)$ 这部分错误区间，掉进选项 D 的陷阱。
- 当 $x \ge 2$ 时，右段是对数型函数 $y = \log_a(x - 1)$。因为 $x \ge 2$ 时真数 $x - 1 \ge 1 > 0$ 自动有意义且关于 $x$ 严格递增，所以对数函数单调递减要求底数满足：
  $$0 < a < 1.$$

其次看最关键也最容易出错的**分界点 $x = 2$ 处的衔接条件**。如果只满足上面两条，对应选项 C 的 $\left(0, \frac{1}{2}\right)$，究竟错在哪里？我们可以拿反例 $a = \frac{1}{4}$ 来检验：此时左段是 $-\frac{1}{2}x - \frac{1}{4}$（$x < 2$），在 $x = 1.9$ 处的函数值为 $-0.95 - 0.25 = -1.2$；而右段在 $x = 2$ 处起步值为 $\log_{\frac{1}{4}}(2 - 1) = 0$。从 $x = 1.9$ 走到 $x = 2$，函数值反而从 $-1.2$ 突然跳升到了 $0$，这就破坏了整体单调递减。

**为什么衔接不等式写作 $(2a - 1)\cdot 2 + 3a - 1 \ge \log_a(2 - 1)$，并且一定要保留等号？** 因为左段 $x < 2$ 时一次函数严格递减，它在 $x = 2$ 左侧无限逼近却取不到的临界位置是纵坐标 $y_左 = (2a - 1)\cdot 2 + 3a - 1 = 7a - 3$；而右段在 $x = 2$ 处是实心起点，纵坐标为 $y_右 = \log_a 1 = 0$。若 $y_左 > y_右$，所有 $x_1 < 2$ 都有 $f(x_1) > y_左 > y_右 = f(2) \ge f(x_2)$，显然整体递减；若恰好相等即 $y_左 = y_右$，那么对任意 $x_1 < 2$ 仍有严格不等式 $f(x_1) > y_左 = f(2) \ge f(x_2)$，因为左段在 $x = 2$ 处取不到 $y_左$（即便两边都是实心点，只要在一点重合接上，对任意 $x_1 < 2 < x_2$ 依然有 $f(x_1) > f(2) > f(x_2)$），所以**等号完全成立**。这里务必剪除“因为 $x < 2$ 是开区间所以不能取等号”的误区（对应陷阱选项 A）。

解衔接不等式：
$$7a - 3 \ge 0 \implies a \ge \frac{3}{7}.$$
将三条约束 $\begin{cases} a < \frac{1}{2}, \\ 0 < a < 1, \\ a \ge \frac{3}{7} \end{cases}$ 取交集（注意到 $\frac{3}{7} \approx 0.429 < \frac{1}{2} = 0.5$），得到实数 $a$ 的取值范围是 $\left[\frac{3}{7}, \frac{1}{2}\right)$，对应选项 **B**。

## 学生理解
