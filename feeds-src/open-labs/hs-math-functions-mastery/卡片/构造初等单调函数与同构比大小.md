# 构造初等单调函数与同构比大小

## 内容

当题目给出两个或三个变量满足某个混合了指数、对数与一次多项式的等式或不等式（例如 $e^a + a = \ln b + b$ 或 $2^x + 3^y = 2^{-y} + 3^{-x}$）并要求比较变量大小时，核心解法是**两边同构化成完全一致的骨架形式 $g(A) = g(B)$（或 $g(A) > g(B)$）**，然后用高一严密已知单调性的初等母函数直接脱壳。

### 1. 高一「纯初等可证单调」常见母函数清单

所有下面列出的母函数，单调性都可以仅用“增 + 增 = 增”、“增 - 减 = 增”或作差因式分解 100% 在高一严密证明，无需任何高阶工具：

| 母函数表达式 $g(t)$ | 严格单调区间与方向 | 常见考题变形信号 |
| :--- | :--- | :--- |
| $g(t) = a^t + t$（$a > 1$） | 在 $\mathbb{R}$ 上**严格递增** | 出现指数项与一次项同号相加，如 $2^x + x$ vs $\log_2 y + y$ |
| $g(t) = \log_a t + t$（$a > 1$） | 在 $(0, +\infty)$ 上**严格递增** | 常见与上条互换：$t = \log_a u \implies \log_a u + u = a^x + x$，即 $g(\log_a u)$ 与 $g(x)$ 或 $a^t+t$ 嵌套匹配 |
| $g(t) = a^t - a^{-t}$（$a > 1$） | 在 $\mathbb{R}$ 上**严格递增**且为**奇函数** | $a^x - a^{-x} > a^{-y} - a^y \iff a^x - a^{-x} > -(a^y - a^{-y})$ |
| $g(t) = a^t + b^t$（$a, b > 1$） | 在 $\mathbb{R}$ 上**严格递增** | 双底混合对称式如 $2^x + 3^x$ 与 $2^{-y} + 3^{-y}$ 同构对比 |
| $g(t) = \dfrac{a^t - b^t}{c^t}$ 或指数差型 | 如 $3^x - 4^x$ 需配同除：$\left(\frac{3}{5}\right)^x - \left(\frac{4}{5}\right)^x$ 随“减与增”合并为严增/严减 | 先同除最大/居中底数 $c^t$ 创造出“一增一减（增 - 减 = 增）”组合 |

### 2. 指对互换「跨界同构」核心恒等变换

想把看似对立的指数式与对数式写成同一个函数 $g$ 的两处取值，依赖两条绝对恒等变形（$a>0, a\neq 1, u>0$）：
$$u = \log_a(a^u), \qquad u = a^{\log_a u}.$$

**典型操作（以比较 $e^a + a = \ln b + b$ 中的 $a$ 与 $\ln b$ 大小为例）**：
- 左边结构是 **$e^a + a$**（“底为 $e$ 的指数 + 本身”）；
- 右边结构是 **$\ln b + b$**。如何把右边的 $b$ 也改造成 $e^{\text{某物}}$ 使左右同形？直接用恒等式 $b = e^{\ln b}$ 代换。
  $$\ln b + b = e^{\ln b} + \ln b.$$
- 于是原等式立即等价改写为：
  $$e^a + a = e^{\ln b} + \ln b \implies g(a) = g(\ln b),$$
  其中辅助母函数 $g(t) = e^t + t$ 在 $\mathbb{R}$ 上严格递增（“增函数 + 增函数 = 增函数”）。
- 单调递增函数相等必同变量：**$a = \ln b$**（进而可得 $e^a = b$），不用算任何数就直接秒出两字母关系。

### 3. 「同除居中底数」造单调法（应对三项多底指数不等式）

遇到像 $3^x + 4^x > 5^x$ 求实数解集这类三底并存问题：
- 两边同时除以最右侧 $5^x$（因 $5^x > 0$ 不变号）：
  $$\left(\frac{3}{5}\right)^x + \left(\frac{4}{5}\right)^x > 1.$$
- 注意底数 $\frac{3}{5}, \frac{4}{5} \in (0, 1)$，因此左边是“减函数 + 减函数 = **严格递减**”。又因为观察得 $x = 2$ 时恰好取等号 $\left(\frac{3}{5}\right)^2 + \left(\frac{4}{5}\right)^2 = 1$（勾股数 $3, 4, 5$ 信号），由严格递减立得解集 **$x < 2$**。

## 参考理解

### 严守「非单调母函数禁止直接去掉函数符号」警报

1. **先证全局严格单调，再谈脱掉 $g$**：
   并不是只要写成形式一致 $g(u) = g(v)$ 就必然推出 $u = v$。必须先核实 $g(t)$ 在当前 $u, v$ 所在区间上确实**严格单调**（只有单增或单减才能一一对应）：
   - 例如对于正值对勾结构 $g(t) = t + \frac{1}{t}$ 或先降后升的二次型结构，若一个值落在 $(0, 1)$ 另一个落在 $(1, +\infty)$，明明函数值相等（如 $t = 2$ 与 $t = \frac{1}{2}$ 函数值同为 $\frac{5}{2}$），自变量却根本不相等。一旦母函数在目标范围不是严格单调函数（不同自变量可能算出相同函数值），**必须画图分单调分支讨论**，绝不能直接抹掉函数符号 $g$。
2. **指对变形要认准“谁包谁”方向一致**：
   当遇到 $x_1 + \ln x_1 = 3$ 与 $x_2 + e^{x_2} = 3$ 放在一起求 $x_1 + x_2$ 时，除了直接按 [[卡片/指数对数反函数对称与恒过定点]] 画镜面直线看出对称外，用本卡配凑也一样秒解：将 $x_1 = e^{\ln x_1}$ 改写前式得 $e^{\ln x_1} + \ln x_1 = 3$，立刻看出 $\ln x_1 = x_2 \implies x_1 + x_2 = x_1 + \ln x_1 = 3$。两条方法相互验证，一题双保险。

### 变式追问

1. 已知实数 $x, y$ 满足 $2^x + 3^x = 2^y + 5^y$ 且 $x > y > 0$，或者已知 $2^x - 3^{-x} < 2^y - 3^{-y}$，能否分别一眼判断谁单调、如何比大小？
2. 已知正数 $x, y$ 满足 $e^x + x = 4$ 与 $y + \ln y = 4$，如果不借助平面直角坐标系对称性，只在本卡的恒等替换 $y = e^{\ln y}$ 下两行算出 $x + y$ 的确切数值是多少？
