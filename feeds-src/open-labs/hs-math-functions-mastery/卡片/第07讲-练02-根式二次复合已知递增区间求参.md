# 第07讲·练02：根式二次复合已知递增区间求参

## 内容

已知函数 $f(x) = \sqrt{x^2 - 2ax + 3a}$ 的单调递增区间为 $[1, +\infty)$，则实数 $a$ 的值是（　　）

A. $\{1\}$　　　　B. $\{-1, 1\}$　　　　C. $[-1, 1]$　　　　D. $(-\infty, 1]$

## 参考理解

第一眼看到“单调递增区间为 $[1, +\infty)$”，很多同学最容易犯两类截然相反的错误：一类是把它当成“在 $[1, +\infty)$ 上单调递增”，按对称轴 $a \le 1$ 与 $u(1) \ge 0$ 算出区间 $[-1, 1]$ 而误选 **C**（或再漏掉定义域选 **D**）；另一类虽然清醒地意识到“单调递增区间为 $[1, +\infty)$”意味着区间不能再往左扩了，却只盯着抛物线对称轴 $x = a$ 直接令 $a = 1$，进而急着选了 **A**。

**为什么只令对称轴 $a = 1$ 会漏掉另一个合法的数值？** 我们必须按照[[卡片/复合函数单调性与定义域优先]]的规范，先看内层二次函数 $u(x) = x^2 - 2ax + 3a$ 的非负定义域到底长什么样。由判别式 $\Delta = (-2a)^2 - 4 \cdot 3a = 4a(a - 3)$，整个函数的定义域实际上有两种完全不同的形态，必须分类拆解：

- **情形一：$\Delta \le 0$（即 $0 \le a \le 3$）**
  此时 $u(x) \ge 0$ 对一切实数恒成立，函数 $f(x)$ 的定义域是全体实数 $\mathbb{R}$。外层 $y = \sqrt{u}$ 在 $[0, +\infty)$ 上单调递增，内层抛物线 $u(x)$ 在对称轴右侧 $[a, +\infty)$ 上单调递增、在 $(-\infty, a]$ 上单调递减。因此 $f(x)$ 的单调递增区间恰为 $[a, +\infty)$。令 $[a, +\infty) = [1, +\infty)$，锁定对称轴等式 **$a = 1$**（检验 $1 \in [0, 3]$，确实满足 $\Delta = -8 < 0$）。

- **情形二：$\Delta > 0$（即 $a < 0$ 或 $a > 3$）**
  这时二次方程 $x^2 - 2ax + 3a = 0$ 有两个不相等的实数根 $r_1 < r_2$，它们关于对称轴 $x = a$ 对称，从而满足 $r_1 < a < r_2$。由于抛物线开口向上，非负定义域被中间截断，裂成左右两支：
  $$D = (-\infty, r_1] \cup [r_2, +\infty).$$
  在左支 $(-\infty, r_1]$ 上，$u(x)$ 递减（因为 $r_1 < a$），故 $f(x)$ 单调递减；在右支 $[r_2, +\infty)$ 上，$u(x)$ 递增（因为 $r_2 > a$），故 $f(x)$ 单调递增。也就是说，**当抛物线下方出现空洞时，函数不再是以对称轴作为单调递增的左端点，而是被定义域右支的零点 $r_2$ 卡死了起点**，此时 $f(x)$ 唯一的单调递增区间是 $[r_2, +\infty)$。

  令 $[r_2, +\infty) = [1, +\infty)$，意味着 $x = 1$ 必须是方程 $x^2 - 2ax + 3a = 0$ 的**较大根 $r_2$**：
  1. 先把 $x = 1$ 代入零点方程：$1 - 2a + 3a = 0 \implies a = -1$；
  2. 再检验 $1$ 确实是较大根（而不是较小根 $r_1$）：当 $a = -1$ 时，对称轴 $x = -1 < 1$（且 $a = -1 < 0$ 满足 $\Delta > 0$），实际上 $u(x) = x^2 + 2x - 3 = (x + 3)(x - 1)$，两个根为 $r_1 = -3$ 与 $r_2 = 1$。它的定义域是 $(-\infty, -3] \cup [1, +\infty)$，在 $[1, +\infty)$ 上严格递增，且 $1$ 的左侧邻近区域根本不在定义域内，因此单调递增区间确确实实恰好就是 $[1, +\infty)$。

**顺便对照剪枝选项 C $[-1, 1]$**：若取中间数 $a = 0$，函数变成 $f(x) = \sqrt{x^2} = |x|$，它的单调递增区间是 $[0, +\infty)$ 而不是 $[1, +\infty)$——题目只能说它在 $[1, +\infty)$ 上单调递增，却不能说它的“单调递增区间为 $[1, +\infty)$”。综上，“在 $[1, +\infty)$ 上递增”锁的是范围 $[-1, 1]$，而“单调递增区间为 $[1, +\infty)$”锁的是两个边界等式点 $\{-1, 1\}$，对应选项 **B**。
