# 第12讲·练05：对数乘积函数闭区间最值与求参

## 内容

已知函数 $f(x) = \left(\log_{\frac{1}{2}} \frac{x}{2}\right)\left(\log_{\frac{1}{2}} \frac{x}{4}\right)$，$x \in \left[\frac{1}{4}, 4\right]$。

(1) 求函数 $f(x)$ 的最小值和最大值，以及取得最值时对应的 $x$ 值；

(2) 若不等式 $f(x) \ge m\log_{\frac{1}{2}} x + 1$ 对任意 $x \in \left[\frac{1}{4}, 4\right]$ 恒成立，求实数 $m$ 的取值范围。

## 参考理解

**(1)** 我们看到题干里出现两个同底数对数的乘积，且底数为小于 $1$ 的分数 $\frac{1}{2}$。这里最容易同时踩进两个坑：一是拆分 $\log_{\frac{1}{2}} \frac{x}{2}$ 时把 $\log_{\frac{1}{2}} 2$ 误算成 $1$ 而漏掉负号；二是换元后直接按“左端点代左、右端点代右”写区间，却忽略了底数 $\frac{1}{2} \in (0, 1)$ 导致对数函数单调递减，端点大小顺序恰好颠倒。

**为什么我们先把括号里的真数除法全部拆成以 $\log_{\frac{1}{2}} x$ 为核心的多项式？** 因为对于任意 $x \in \left[\frac{1}{4}, 4\right]$，都有 $x > 0$，根据对数运算法则直接拆项并准确计算常数对数：
$$\log_{\frac{1}{2}} \frac{x}{2} = \log_{\frac{1}{2}} x - \log_{\frac{1}{2}} 2 = \log_{\frac{1}{2}} x + 1,$$
$$\log_{\frac{1}{2}} \frac{x}{4} = \log_{\frac{1}{2}} x - \log_{\frac{1}{2}} 4 = \log_{\frac{1}{2}} x + 2.$$
根据[[卡片/指对换元化二次最值与根分布]]，令 $t = \log_{\frac{1}{2}} x$。由于底数 $\frac{1}{2} \in (0, 1)$，函数 $y = \log_{\frac{1}{2}} x$ 在 $\left[\frac{1}{4}, 4\right]$ 上**严格单调递减**，因此右端点给出最小值、左端点给出最大值：
$$t_{\min} = \log_{\frac{1}{2}} 4 = -2, \qquad t_{\max} = \log_{\frac{1}{2}} \frac{1}{4} = 2,$$
即新元的精确取值范围是 $t \in [-2, 2]$。

原函数转化为关于 $t$ 的二次函数：
$$g(t) = (t + 1)(t + 2) = t^2 + 3t + 2 = \left(t + \frac{3}{2}\right)^2 - \frac{1}{4}, \qquad t \in [-2, 2].$$
利用[[卡片/含参二次函数动轴与区间最值]]分析开口向上的抛物线 $g(t)$：
- **求最小值**：对称轴 $t = -\frac{3}{2}$ 恰好落在闭区间 $[-2, 2]$ 内部，故
  $$g_{\min} = g\left(-\frac{3}{2}\right) = -\frac{1}{4}.$$
  此时回代 $\log_{\frac{1}{2}} x = -\frac{3}{2}$，得 $x = \left(\frac{1}{2}\right)^{-\frac{3}{2}} = 2^{\frac{3}{2}} = 2\sqrt{2}$（检验 $2\sqrt{2} \in \left[\frac{1}{4}, 4\right]$，成立）。
- **求最大值**：区间 $[-2, 2]$ 的中点为 $0$，对称轴 $t = -\frac{3}{2} < 0$，所以右端点 $t = 2$ 离对称轴更远，最大值为
  $$g_{\max} = g(2) = (2 + 1)(2 + 2) = 12.$$
  此时回代 $\log_{\frac{1}{2}} x = 2$，得 $x = \left(\frac{1}{2}\right)^2 = \frac{1}{4}$。

所以 $f(x)$ 在 $x = 2\sqrt{2}$ 时取得最小值 $-\frac{1}{4}$，在 $x = \frac{1}{4}$ 时取得最大值 $12$。

**(2)** 再看第二问：由换元结果可知，原不等式在 $x \in \left[\frac{1}{4}, 4\right]$ 上恒成立，等价于
$$t^2 + 3t + 2 \ge mt + 1, \qquad \forall t \in [-2, 2],$$
整理为
$$t^2 + (3 - m)t + 1 \ge 0, \qquad \forall t \in [-2, 2].$$
这里如果我们想直接把参数 $m$ 分离出去，必须先停下来想一想：**能否直接两边除以 $t$？** 不能，因为 $t$ 在 $[-2, 2]$ 上既可以取正数，也可以取 $0$ 和负数，直接除 $t$ 会改变不等号方向甚至丢失零点条件。根据[[卡片/参变分离与换主元恒成立法]]，我们既可以按 $t$ 的正负零三段分离参数，也可以直接研究左端二次函数 $h(t) = t^2 + (3 - m)t + 1$ 在 $[-2, 2]$ 上的最小值不小于 $0$。下面用符号分段分离来直观锁定边界，再与二次函数法互相印证：
- 当 $t = 0$ 时，不等式化为 $1 \ge 0$，对一切 $m \in \mathbb{R}$ 恒成立；
- 当 $t \in (0, 2]$ 时，不等号方向不变，分离得
  $$m \le t + \frac{1}{t} + 3.$$
  由对勾函数性质及基本不等式，当 $t \in (0, 2]$ 时，$t + \frac{1}{t} \ge 2\sqrt{t \cdot \frac{1}{t}} = 2$（当且仅当 $t = 1 \in (0, 2]$ 时取等号），故右侧最小值为 $2 + 3 = 5$，因此需 $m \le 5$；
- 当 $t \in [-2, 0)$ 时，除以负数 $t$ 必须把不等号反向，得
  $$m \ge t + \frac{1}{t} + 3.$$
  记 $u = -t \in (0, 2]$，则 $t + \frac{1}{t} = -\left(u + \frac{1}{u}\right) \le -2$（当且仅当 $u = 1$ 即 $t = -1 \in [-2, 0)$ 时取等号），故右侧最大值为 $-2 + 3 = 1$，因此需 $m \ge 1$。

取三段条件的交集，得 $1 \le m \le 5$。我们再用二次函数 $h(t) = t^2 + (3 - m)t + 1$ 的动轴 $t_0 = \frac{m - 3}{2}$ 复核一遍：当 $t_0 \le -2$ 即 $m \le -1$ 时，$h(-2) = 2m - 1 \ge 0 \implies m \ge \frac{1}{2}$，无解；当 $t_0 \ge 2$ 即 $m \ge 7$ 时，$h(2) = 11 - 2m \ge 0 \implies m \le \frac{11}{2}$，无解；当 $-2 < t_0 < 2$ 即 $-1 < m < 7$ 时，顶点最小值为 $h(t_0) = 1 - \frac{(3 - m)^2}{4} \ge 0 \iff (m - 3)^2 \le 4 \iff 1 \le m \le 5$。两种思路结果完全一致，最终实数 $m$ 的取值范围为 $[1, 5]$。
