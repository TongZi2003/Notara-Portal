# 第02讲·练03：二次式除以根式的闭区间值域

## 内容

函数 $f(x) = \frac{x^2 + 2x + 21}{\sqrt{x^2 + 2x + 17}}$ 在闭区间 $[-4, 2]$ 上的值域为________。

## 参考理解

我们一看到分子是二次式、分母是同底二次根式，很多同学很快就能反应过来令根号整体为 $t$ 化成 $t + \frac{4}{t}$，但接下来往往会在两个地方接连翻车：第一处是把 $x = -4$ 和 $x = 2$ 直接代进根号算 $t$ 的范围，算出 $t = 5$ 就卡住，忘了二次函数对称轴 $x = -1$ 就在 $[-4, 2]$ 正中间；第二处是好不容易算出 $t$ 的范围后，看见 $t + \frac{4}{t}$ 就习惯性地甩出一句“由基本不等式得 $t + \frac{4}{t} \ge 2\sqrt{4} = 4$”，把最小值错写成 $4$。

**为什么我们必须先把根号里的二次式配方锁定新元区间，而不能只代端点？** 因为分子和分母共同含有核心结构 $x^2 + 2x + 17 = (x + 1)^2 + 16$，根据[[卡片/根式函数值域代数与几何法]]与[[卡片/分式与对勾型函数值域法]]，令：
$$t = \sqrt{x^2 + 2x + 17} = \sqrt{(x + 1)^2 + 16}.$$
当 $x \in [-4, 2]$ 时，$-3 \le x + 1 \le 3$，从而平方项满足 $0 \le (x + 1)^2 \le 9$（最小值 $0$ 在对称轴 $x = -1 \in [-4, 2]$ 处取得，最大值 $9$ 在端点 $x = -4$ 和 $x = 2$ 处同时取得）。加 $16$ 再开方，就锁定了新元 $t$ 的精确闭区间：
$$4 \le t \le 5.$$
此时分子 $x^2 + 2x + 21 = (x^2 + 2x + 17) + 4 = t^2 + 4$，于是原函数等价转化为对勾型函数：
$$g(t) = \frac{t^2 + 4}{t} = t + \frac{4}{t}, \qquad t \in [4, 5].$$

**为什么基本不等式在这里会失效，必须换用单调性？** 如果直接套均值不等式 $t + \frac{4}{t} \ge 2\sqrt{t \cdot \frac{4}{t}} = 4$，等号成立的条件是 $t = \frac{4}{t}$ 即 $t = 2$（因为 $t > 0$）。但是我们刚刚已经严密算出 $t \in [4, 5]$，取等点 $t = 2$ **根本不在这个区间里**，所以 $4$ 这个下界是永远取不到的虚假下界。

根据[[卡片/单调性定义证明与抽象单调]]与[[卡片/分式与对勾型函数值域法]]，我们改用作差法判定 $g(t)$ 在 $[4, 5]$ 上的真实单调性：任取 $4 \le t_1 < t_2 \le 5$，作差并通分分解得
$$g(t_2) - g(t_1) = (t_2 - t_1) + \frac{4(t_1 - t_2)}{t_1 t_2} = \frac{(t_2 - t_1)(t_1 t_2 - 4)}{t_1 t_2}.$$
因为 $4 \le t_1 < t_2 \le 5$，所以 $t_2 - t_1 > 0$，$t_1 t_2 > 16 > 4$，从而 $t_1 t_2 - 4 > 0$ 且分母 $t_1 t_2 > 0$。因此 $g(t_2) - g(t_1) > 0$，即函数 $g(t)$ 在闭区间 $[4, 5]$ 上**严格单调递增**。

由此只需把闭区间的左右端点直接代入 $g(t)$ 即可求出最值：
- 当 $t = 4$（即 $x = -1$）时，取得最小值 $g(4) = 4 + \frac{4}{4} = 5$；
- 当 $t = 5$（即 $x = -4$ 或 $x = 2$）时，取得最大值 $g(5) = 5 + \frac{4}{5} = \frac{29}{5}$。

因此函数 $f(x)$ 在 $[-4, 2]$ 上的值域为 $\left[5, \frac{29}{5}\right]$。
