# 第17讲·练02：翻折二次双层复合等于k六实根

## 内容

已知函数 $f(x) = |x^2 - 4x + 3|$（$x \in \mathbb{R}$）。

(1) 若方程 $f\bigl(f(x)\bigr) = k$ 恰有 $6$ 个互不相等的实数根，求实数 $k$ 的取值范围；

(2) 在 (1) 的条件下，判断方程 $f\bigl(f(x)\bigr) = k$ 所有实数根之和是否为定值，若是，求出该定值；若不是，请说明理由。

## 参考理解

**(1)** 我们看到方程 $f\bigl(f(x)\bigr) = k$ 属于自身连续嵌套两次的复合方程。千万不要把 $|x^2 - 4x + 3|$ 再往二次式里硬塞——那样会变成带双层绝对值的四次方程，讨论区间会多到难以收场。由[[卡片/复合嵌套方程换元拆层数根法]]，我们先令中间变量 $t = f(x)$，明确内层值域为 **$t \in [0, +\infty)$**，从而原方程彻底拆成两步：第一层先在非负实数集 $[0, +\infty)$ 上求 $f(t) = k$ 的全部解 $t_i$；第二层再逐个把每个合法的 $t_i \ge 0$ 代回 $f(x) = t_i$ 累计实根个数。

先结合[[卡片/函数图像平移对称与绝对值翻折]]写出 $y = f(u) = |(u - 2)^2 - 1|$ 与水平线 $y = h$ 相交的个数分布。注意当两层都用到同一个 $f$ 时，**第一层还要额外受到 $t \ge 0$ 的定义域限制**，所以画图时把 $t < 0$ 一侧标为空白禁止区格外重要：
- 仅在 $\mathbb{R}$ 上看 $f(x) = t$ 的根数 $N(t)$：$t < 0$ 时 $0$ 个；$t = 0$ 时 $2$ 个（$x = 1, 3$）；$0 < t < 1$ 时 $4$ 个；$t = 1$ 时 $3$ 个（$x = 2, 2 \pm \sqrt{2}$）；$t > 1$ 时 $2$ 个。
- 再看第一层方程 $f(t) = k$ 在 **$t \ge 0$** 上的解分布（注意端点 $t = 0$ 处高度为 $f(0) = |0 - 0 + 3| = 3$）：
  - 当 $k < 0$ 时，$f(t) = k$ 无解，总根数为 $0$；
  - 当 $k = 0$ 时，在 $t \ge 0$ 上解得 $t_1 = 1$ 与 $t_2 = 3$，总根数为 $N(1) + N(3) = 3 + 2 = 5$；
  - 当 $0 < k < 1$ 时，$f(t) = k$ 的全部 $4$ 个解 $t_1 \in (0, 1)$、$t_2 \in (1, 2)$、$t_3 \in (2, 3)$、$t_4 > 3$ 均大于 $0$，总根数为 $N(t_1) + N(t_2) + N(t_3) + N(t_4) = 4 + 2 + 2 + 2 = 10$；
  - 当 $k = 1$ 时，由 $|(t - 2)^2 - 1| = 1$ 解得 $t_1 = 2 - \sqrt{2} \in (0, 1)$、$t_2 = 2 > 1$、$t_3 = 2 + \sqrt{2} > 1$，均满足 $t \ge 0$，总根数为 $N(t_1) + N(t_2) + N(t_3) = 4 + 2 + 2 = 8$；
  - 当 $1 < k < 3$ 时，仅在未翻折段 $(t - 2)^2 - 1 = k$ 有两解 $t_1 = 2 - \sqrt{1 + k}$ 与 $t_2 = 2 + \sqrt{1 + k}$。因为 $1 < k < 3 \implies \sqrt{2} < \sqrt{1 + k} < 2$，所以 **$t_1 \in (0, 2 - \sqrt{2}) \subset (0, 1)$** 且 **$t_2 > 2 + \sqrt{2} > 3$**，两个解都严格落入 $[0, +\infty)$，此时总根数为 $N(t_1) + N(t_2) = 4 + 2 = 6$；
  - 当 $k = 3$ 时，$t_1 = 0$ 与 $t_2 = 4$，总根数为 $N(0) + N(4) = 2 + 2 = 4$（注意由于 $t_1 = 0$ 处交点个数从 $4$ 骤降为 $2$，总根数从 $6$ 跌到 $4$）；
  - 当 $k > 3$ 时，$t_1 = 2 - \sqrt{1 + k} < 0$ 落出内层值域 $[0, +\infty)$ 之外被淘汰，仅剩 $t_2 = 2 + \sqrt{1 + k} > 4$，总根数为 $N(t_2) = 2$。

逐档排查了全实数轴上每一个临界高度后，我们清楚看到：方程 $f\bigl(f(x)\bigr) = k$ 恰有 $6$ 个互异实根，当且仅当实数 $k$ 落在开区间 **$(1, 3)$** 内。

**(2)** 再看第二问：当 $k \in (1, 3)$ 时，第一层解出的 $t_1 = 2 - \sqrt{1 + k} \in (0, 1)$ 与 $t_2 = 2 + \sqrt{1 + k} > 3$ 都是带根号的无理数，如果再把它们代回 $x^2 - 4x + 3 = \pm t_i$ 去硬求 $6$ 个嵌套双根号实数解再相加，计算量会瞬间爆炸。然而只要利用[[卡片/多零点水平截线对称消元求范围]]，把每一根水平截线的交点放回图像对称轴上观察，就能不求根而直接锁定全根之和。

注意到原函数 $f(x) = |(x - 2)^2 - 1|$ 显然满足 $f(4 - x) = |[(4 - x) - 2]^2 - 1| = |(2 - x)^2 - 1| = f(x)$，即图像整体关于直线 **$x = 2$** 轴对称：
- 对于内层高度 $t_1 \in (0, 1)$：水平线 $y = t_1$ 截出 $4$ 个互异实根 $x_1 < x_2 < 2 < x_3 < x_4$。由关于 $x = 2$ 对称性（也可由二次方程 $x^2 - 4x + 3 - t_1 = 0$ 与 $x^2 - 4x + 3 + t_1 = 0$ 的韦达定理），外侧一对与内侧一对均以 $2$ 为中点，故 $x_1 + x_4 = 4$ 且 $x_2 + x_3 = 4$，这 $4$ 个根之和为 $4 + 4 = 8$；
- 对于内层高度 $t_2 > 3$：水平线 $y = t_2$ 截出 $2$ 个互异实根 $x_5 < 2 < x_6$，它们同样关于直线 $x = 2$ 对称，故 $x_5 + x_6 = 4$。

将上述两层共 $6$ 个互异实根全部相加，与参数 $k$ 有关的无理部分在每对对称相加中完全消去：
$$S = (x_1 + x_4) + (x_2 + x_3) + (x_5 + x_6) = 4 + 4 + 4 = 12.$$
因此，在 (1) 的条件下，方程 $f\bigl(f(x)\bigr) = k$ 所有实数根之和是**定值**，该定值为 **$12$**。
