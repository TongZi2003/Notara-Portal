# 指对条件求值与整体代换法

## 内容

指数与对数条件求值题在考试中往往形式繁琐，一旦强行解出每一个字母就会掉进复杂计算陷阱；真正稳准快的核心在于**利用整体对称结构升幂/降幂**与**设辅助比例常数 $k$ 统一底数**。

### 1. 分数指数幂的升幂与降幂（对称根式代换）

遇到互为倒数的指数项（如 $x^{\frac{1}{2}} + x^{-\frac{1}{2}} = m$ 或 $a^x + a^{-x} = m$）时：
- **升幂**：两边平方立即出倍角指数项：
  $$x + x^{-1} = \left(x^{\frac{1}{2}} + x^{-\frac{1}{2}}\right)^2 - 2 = m^2 - 2.$$
- **降幂**：若已知 $x + x^{-1}$，欲求 $x^{\frac{1}{2}} - x^{-\frac{1}{2}}$，同样先求平方：
  $$\left(x^{\frac{1}{2}} - x^{-\frac{1}{2}}\right)^2 = x + x^{-1} - 2,$$
  再由题干给定 $x > 1$ 还是 $0 < x < 1$ **确定开方后的正负号**。
- **立方和差公式**：$x^{\frac{3}{2}} \pm x^{-\frac{3}{2}} = (x^{\frac{1}{2}} \pm x^{-\frac{1}{2}})(x \mp 1 + x^{-1})$。

### 2. 连等指数式「设 $k$ 取对数法」

遇到形如 $2^a = 5^b = m$ 且题目涉及 $\frac{1}{a} + \frac{1}{b}$ 或 $ab$ 关系的条件求值题：
1. 若底数不统一，先**设连等号整体等于 $k$**（如 $a^x = b^y = c^z = k > 0$，且若仅 $k=1$ 显然无解或需单独排除分母为零）；
2. 两边同时取同底对数（常取常用对数或以某一关键数如 $10$ 为底）：
   $$x = \log_a k = \frac{\lg k}{\lg a} \implies \frac{1}{x} = \frac{\lg a}{\lg k};$$
3. 利用换底公式倒数性质 $\frac{1}{\log_a k} = \log_k a$，直接把分母上的未知数翻成对数的真数：
   $$\frac{1}{a} + \frac{1}{b} = \log_m 2 + \log_m 5 = \log_m 10.$$
   再由已知数值直接还原出 $m$（如已知 $\frac{1}{a}+\frac{1}{b}=2 \implies m^2 = 10$）。

### 3. 对数换底与恒等式降维

核心三条恒等工具必须脱口而出且严格核验真数正性：
- 换底公式与链式乘积：$\log_a b = \frac{\log_c b}{\log_c a}$，推论 $\log_a b \cdot \log_b c = \log_a c$，$\log_{a^m} b^n = \frac{n}{m}\log_a b$；
- 对数恒等式：$a^{\log_a N} = N\ (N > 0)$，尤其看到底数和指数的对数同底时立即化简（如 $4^{\log_2 3} = (2^{\log_2 3})^2 = 9$）；
- 消去对数幂：$a^{\ln b} = b^{\ln a}\ (a,b>0)$，两边同时取 $\ln$ 验证即证（在复杂混合等式中极有用）。

## 参考理解

### 容易踩雷的计算细节

1. **降幂开方直接默认取正号**：
   题目只给 $x + x^{-1} = 5\ (x > 0)$ 求 $x^{\frac{1}{2}} - x^{-\frac{1}{2}}$ 时，因为没有告诉你是 $x > 1$ 还是 $0 < x < 1$，所以答案是 **$\pm\sqrt{3}$**（有两个值），而非单一的 $\sqrt{3}$。只有题设写明 $0 < x < 1$（此时 $x^{-\frac{1}{2}} > x^{\frac{1}{2}}$）才取负号，$x > 1$ 才取正号。
2. **忽视 $k=1$ 与分母为零的隐蔽特例**：
   若连等式给定 $3^a = 5^b = c$，但未说 $a, b \neq 0$，一旦条件式出现 $\frac{1}{a} + \frac{1}{b}$ 即默认隐含 $a \neq 0$ 且 $b \neq 0$，从而排除 $c = 1$；但如果是乘法式如 $a \lg 3 = b \lg 5$，千万不可随意在不知 $a, b$ 是否为零的情况下同除。
3. **对数运算法则误拆内部括号**：
   $\log_a(M + N) \neq \log_a M + \log_a N$，且 $\lg^2 x$ 与 $\lg(x^2) = 2\lg|x|$（注意偶次方真数原本只需 $x \neq 0$，拆出 $2$ 后必须补上绝对值或先核定 $x>0$）绝不可混为一谈。

### 变式追问

1. 已知 $x^{\frac{1}{2}} + x^{-\frac{1}{2}} = 3$，如何在不解出 $x$ 的前提下求出 $\frac{x^2 + x^{-2} - 3}{x + x^{-1} - 2}$ 的精确值？
2. 已知 $2^a = 3^b = 6^c$（$abc \neq 0$），如何不用任何数值近似直接证明 $\frac{1}{a} + \frac{1}{b} = \frac{1}{c}$？
