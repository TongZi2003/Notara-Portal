# 第15讲·练09：平移斜线与翻折抛物线四交点

## 内容

若直线 $y = x + b$ 与函数 $f(x) = |x^2 - 2x|$ 的图像恰有 $4$ 个不同的交点，则实数 $b$ 的取值范围是______。

## 参考理解

我们看到带有绝对值的二次函数 $f(x) = |x^2 - 2x|$ 与斜率为 $1$ 的平行直线族 $y = x + b$ 求交点个数问题时，如果只把绝对值拆开分别列三个方程去套判别式，很容易把根落在哪一段定义域里搞晕；如果只靠眼睛看图估摸，又很容易漏掉在拱形翻折峰顶附近相切的那个精确截距，或者搞不清过折点 $(0, 0)$ 时到底算 $3$ 个交点还是 $4$ 个交点。

**为什么我们先画出翻折曲线并把 $f(x)$ 拆成清晰的三段？** 根据[[卡片/水平与动直线数形结合定参法]]与绝对值「保上翻下」法则，先画出原抛物线 $y = x^2 - 2x = (x - 1)^2 - 1$：它与 $x$ 轴交于 $(0, 0)$ 和 $(2, 0)$，顶点在 $(1, -1)$。加上绝对值后，把 $0 < x < 2$ 这段位于 $x$ 轴下方的部分向上翻折，得到连续的分段函数：
$$f(x) = \begin{cases} x^2 - 2x, & x \le 0 \text{ 或 } x \ge 2, \\ -x^2 + 2x, & 0 < x < 2. \end{cases}$$
中间段 $y = -x^2 + 2x = -(x - 1)^2 + 1$ 是一个以 $(1, 1)$ 为最高顶点的向上拱起的曲线，左右两翼则是沿着 $(0, 0)$ 和 $(2, 0)$ 两个折点向两侧无限升高的抛物线外支。

现在我们保持斜率为 $1$ 不变，让直线 $y = x + b$ 随纵截距 $b$ 从下往上平移，观察它穿过多段图像时的关键临界位置：

**第一道临界：直线恰好经过左折点 $(0, 0)$（此时 $b = 0$）。**
把 $(0, 0)$ 代入 $y = x + b$ 得 $b = 0$，即直线 $y = x$。我们来代回验证此时到底有几个交点：
- 在 $x \le 0$ 或 $x \ge 2$ 段：解 $x^2 - 2x = x \implies x(x - 3) = 0$，得 $x = 0$（折点）和 $x = 3$（落在 $x \ge 2$ 上），共 $2$ 个交点；
- 在 $0 < x < 2$ 段：解 $-x^2 + 2x = x \implies x(x - 1) = 0$，落在开区间 $(0, 2)$ 内的只有 $x = 1$ 这 $1$ 个交点。
因此当 $b = 0$ 时，共有 $0, 1, 3$ 这 **$3$ 个**交点，不符合 $4$ 个交点的要求。（同理，当直线经过右折点 $(2, 0)$ 即 $b = -2$ 时，联立验算只有 $x = 2$ 这 $1$ 个交点；而当 $-2 < b < 0$ 时，直线穿过 $(0, 0)$ 与 $(2, 0)$ 之间并向右上方穿过右外支，只有 $2$ 个交点。）

**第二道临界：直线向上平移，恰好与中间翻折拱形 $y = -x^2 + 2x$（$0 < x < 2$）相切。**
只要把直线从 $y = x$ 再稍微往上提一点（$b > 0$），直线就会在 $x < 0$ 处穿过左外支（产生 $1$ 个交点），在 $x > 2$ 处穿过右外支（产生 $1$ 个交点），同时在拱形区间 $(0, 2)$ 内一举截出 $2$ 个交点，总计 **$4$ 个交点**，直到直线继续上升与拱形相切为止。
我们联立直线与拱形抛物线方程求出这个相切纵截距：
$$-x^2 + 2x = x + b \implies x^2 - x + b = 0.$$
令一元二次方程判别式 $\Delta = 0$：
$$\Delta = (-1)^2 - 4b = 0 \implies b = \frac{1}{4}.$$
**务必回代检验切点位置是否在拱形有效区间 $(0, 2)$ 内**：当 $b = \frac{1}{4}$ 时，切点横坐标为 $x_0 = \frac{1}{2}$，确实满足 $0 < \frac{1}{2} < 2$，属于有效真切点。此时在 $x < 0$ 有 $1$ 个交点，在 $(0, 2)$ 内只有切点 $\left(\frac{1}{2}, \frac{3}{4}\right)$ 这 $1$ 个交点，在 $x > 2$ 有 $1$ 个交点，总交点数重新跌回 **$3$ 个**；若 $b > \frac{1}{4}$，拱形段与直线脱离，只剩下左右外支共 $2$ 个交点。

最后再用二次方程根的分布复核一遍 $0 < b < \frac{1}{4}$ 的严格性：对于 $h(x) = x^2 - x + b = 0$，当 $0 < b < \frac{1}{4}$ 时，$\Delta = 1 - 4b > 0$，对称轴为 $x = \frac{1}{2} \in (0, 2)$，且 $h(0) = b > 0$，$h(2) = 2 + b > 0$，保证两个相异实根全部稳稳落在 $(0, 2)$ 内部；同时对于外支方程 $x^2 - 3x - b = 0$，因为 $b > 0$ 时在 $x = 0$ 处值为 $-b < 0$、在 $x = 2$ 处值为 $-2 - b < 0$，所以它必在 $(-\infty, 0)$ 与 $(2, +\infty)$ 内各交出 $1$ 个实根。

综上，当且仅当 **$b \in \left(0, \frac{1}{4}\right)$** 时，直线 $y = x + b$ 与 $f(x) = |x^2 - 2x|$ 恰有 $4$ 个不同交点。
