# 函数凹凸性与中点不等式

## 内容

在高中数学竞赛预备题和近年高一月考多选与新定义压轴题中，“**中点函数值与函数值平均数谁大**”是一个高频设问方式。这一概念（即函数曲线向上拱还是向下弯）在连续函数前提下，完全只需要高一的中点代数定义、弦中点图像与基本不等式就可以严密讲清并严格证明。

### 1. 纯初等「中点不等式」几何定义

设函数 $f(x)$ 在区间 $I$ 上任意取两个不相等的自变量 $x_1, x_2 \in I$，连接曲线上两点 $A\bigl(x_1, f(x_1)\bigr)$ 与 $B\bigl(x_2, f(x_2)\bigr)$ 的线段中点 $M$ 纵坐标为 $\frac{f(x_1)+f(x_2)}{2}$，而曲线在横坐标中点处的高低为 $f\left(\frac{x_1+x_2}{2}\right)$：

| 曲线形态 | 弦中点与曲线中点高低关系 | 纯代数判别不等式（$x_1 \neq x_2$） | 直观图形口诀 |
| :--- | :--- | :--- | :--- |
| **向下弯函数（碗形，开口向上）** | 曲线落在割线**下方** | $f\left(\dfrac{x_1 + x_2}{2}\right) < \dfrac{f(x_1) + f(x_2)}{2}$ | 像一口正放的碗，能盛水 |
| **向上拱函数（拱形，开口向下）** | 曲线落在割线**上方** | $f\left(\dfrac{x_1 + x_2}{2}\right) > \dfrac{f(x_1) + f(x_2)}{2}$ | 像一座拱桥，向上鼓起 |

（注：部分课外资料对“向上拱”与“向下弯”的具体叫法恰好相反，高一考题一律会明确写出不等号方向，做题只看**不等号朝向与曲线在弦上方还是下方**，不要靠背口头名词下结论。）

### 2. 高一基本初等函数的曲线弯曲清单（均可用初等代数/基本不等式两行自证）

| 函数表达式 | 所属区间 | 弯曲形态 | 纯高一两行自证核心依据 |
| :--- | :--- | :--- | :--- |
| $f(x) = x^2$（或 $ax^2, a>0$） | $\mathbb{R}$ | 严格**向下弯（碗形）**（$<$） | 作差：$\frac{x_1^2+x_2^2}{2} - \left(\frac{x_1+x_2}{2}\right)^2 = \frac{(x_1-x_2)^2}{4} > 0$ |
| $f(x) = \sqrt{x}$（$x^{\frac{1}{2}}$） | $[0, +\infty)$ | 严格**向上拱（拱形）**（$>$） | $\left(\frac{\sqrt{x_1}+\sqrt{x_2}}{2}\right)^2 = \frac{x_1+x_2+2\sqrt{x_1x_2}}{4} < \frac{x_1+x_2+x_1+x_2}{4} = \frac{x_1+x_2}{2}$（由基本不等式），再开正方 |
| $f(x) = \frac{1}{x}$ | $(0, +\infty)$ | 严格**向下弯（碗形）**（$<$） | 正半轴算术调和：$\frac{\frac{1}{x_1}+\frac{1}{x_2}}{2} = \frac{x_1+x_2}{2x_1x_2} > \frac{2}{x_1+x_2}$（因 $(x_1+x_2)^2 > 4x_1 x_2$） |
| $f(x) = a^x$（$a>0, a\neq 1$） | $\mathbb{R}$ | 严格**向下弯（碗形）**（$<$） | 一行基本不等式：$\frac{a^{x_1} + a^{x_2}}{2} > \sqrt{a^{x_1}\cdot a^{x_2}} = a^{\frac{x_1+x_2}{2}}$（无论 $a>1$ 还是 $0<a<1$ 均恒向下弯） |
| $f(x) = \log_a x$（$a > 1$） | $(0, +\infty)$ | 严格**向上拱（拱形）**（$>$） | 取 $\log_a\frac{x_1+x_2}{2} > \log_a\sqrt{x_1 x_2} = \frac{\log_a x_1 + \log_a x_2}{2}$（利用基本不等式 $\frac{x_1+x_2}{2}>\sqrt{x_1 x_2}$ 与增函数） |
| $f(x) = \log_a x$（$0 < a < 1$） | $(0, +\infty)$ | 严格**向下弯（碗形）**（$<$） | 因为 $0<a<1$ 递减，把上述基本不等式两边取 $\log_a$ 后不等号反向 |

## 参考理解

### 常见失误与新定义考场用法

1. **最容易记混的 $0 < a < 1$ 弯曲方向**：
   看清楚上表最后三行：
   - 指数函数 **$y = a^x$ 不论 $a > 1$ 还是 $0 < a < 1$，图像永远向下弯（碗形）**。只是 $a>1$ 朝右翘， $0<a<1$ 朝左翘；
   - 而对数函数 **$y = \log_a x$ 在 $a > 1$ 时向上拱（拱形）**，一旦底数变成 **$0 < a < 1$（将 $y=\log_a x$ 关于 $x$ 轴翻折），它立刻翻成向下弯（碗形）**。
   多选题考“若函数满足 $f\left(\frac{x_1+x_2}{2}\right) < \frac{f(x_1)+f(x_2)}{2}$，则它可以是 $f(x)=\log_{\frac{1}{2}} x$ 吗？”答案是**可以**，千万别凭模糊印象觉得所有对数都向上拱。
2. **用单变量“正负区域”防止跨界错用**：
   $f(x) = \frac{1}{x}$ 在 $(0, +\infty)$ 上严格向下弯（碗形），而在 $(-\infty, 0)$ 上翻了个面变成严格**向上拱**（拱形）。因此如果不限同侧横跨正负轴（比如取 $x_1 = -2,\ x_2 = 1$），中点不等式根本不成立。写结论之前永远检查自变量是否落入同一侧弯曲方向一致的连续区间。
3. **利用中点不等式直接估算比大小**：
   遇到多选或填空比较 $\ln\frac{a+b}{2}$ 与 $\frac{\ln a + \ln b}{2}$、或 $2^{\frac{a+b}{2}}$ 与 $\frac{2^a + 2^b}{2}$ 的大小时，不要死算数值，直接一眼认出它们分别是算术平均处函数值与函数平均值的对比，一秒作答。

### 变式追问

1. 已知函数 $f(x) = |x - 1|$ 在整个实数集 $\mathbb{R}$ 上有“折角”，它是否满足不等式 $f\left(\frac{x_1+x_2}{2}\right) \le \frac{f(x_1)+f(x_2)}{2}$？提示：直接用高一绝对值三角不等式 $|A+B| \le |A|+|B|$ 一行推导。
2. 如果新定义某函数满足“任意 $x_1 \neq x_2$ 都有 $f\left(\frac{x_1+x_2}{2}\right) > \frac{f(x_1)+f(x_2)}{2}$ 且在 $\mathbb{R}$ 上递增”，请从已学过的基本初等函数或其局部变形中找出一个合法函数例子，并再找出一个“向上拱但递减”的例子。

## 横向联系

- [[卡片/指数对数反函数对称与恒过定点]]：关于 $y=x$ 对称的镜面翻折正好解释为何递增的 $a^x$（向下弯）对称过去后 $\log_a x$ 翻转成向上拱，而递减的 $a^x$（向下弯）对称过去却依然向下弯。
- [[卡片/幂函数第一象限图像与奇偶性]]：$\alpha > 1$ 与 $\alpha < 0$ 时第一象限向下弯，$\alpha \in (0, 1)$ 时第一象限向上拱，完整对接幂函数图像形态。
- [[卡片/对数糖水不等式与取倒数减整法]]：对数曲线向上拱的特征从几何上决定了弦的斜率随真数增大而减小，直观呼应糖水不等式的渐变规律。
