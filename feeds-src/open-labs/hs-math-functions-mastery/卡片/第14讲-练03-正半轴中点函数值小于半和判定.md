# 第14讲·练03：正半轴中点函数值小于半和判定

## 内容

（多选题）下列函数中，对任意不相等的正实数 $x_1, x_2 \in (0, +\infty)$，均满足不等式
$$f\left(\frac{x_1 + x_2}{2}\right) < \frac{f(x_1) + f(x_2)}{2}$$
的有（　　）

A. $f(x) = x^2$　　　　B. $f(x) = \sqrt{x}$　　　　C. $f(x) = \log_{\frac{1}{2}} x$　　　　D. $f(x) = 2^{-x}$

## 参考理解

我们读题时，先对照[[卡片/函数凹凸性与中点不等式]]把题设不等式的几何含义翻译清楚：在正半轴 $(0, +\infty)$ 上，曲线中点的高度 $f\left(\frac{x_1 + x_2}{2}\right)$ 严格低于弦中点的高度 $\frac{f(x_1) + f(x_2)}{2}$，也就是说图像在第一或第四象限呈“碗形”向下弯曲。很多同学做这类多选题最容易踩进两个经验陷阱：一是看到对数函数 $y = \log_{\frac{1}{2}} x$ 就下意识套用“对数都是向上拱起的”，随手排除 C；二是误以为 $y = 2^{-x}$ 变成递减指数后弯曲方向也会跟着翻转，从而漏选 D。其实我们完全不必依赖任何记忆口诀，只用高一作差与基本不等式就能把四个选项逐个验明正身。

我们依次在 $(0, +\infty)$ 上取任意 $x_1 \neq x_2$ 展开检验：

**先看选项 A（$f(x) = x^2$）：**
直接用弦中点减去曲线中点做差分解：
$$\frac{f(x_1) + f(x_2)}{2} - f\left(\frac{x_1 + x_2}{2}\right) = \frac{x_1^2 + x_2^2}{2} - \left(\frac{x_1 + x_2}{2}\right)^2 = \frac{2x_1^2 + 2x_2^2 - (x_1^2 + 2x_1 x_2 + x_2^2)}{4} = \frac{(x_1 - x_2)^2}{4}.$$
因为 $x_1 \neq x_2$，所以 $(x_1 - x_2)^2 > 0$，差值严格为正，即 $f\left(\frac{x_1 + x_2}{2}\right) < \frac{f(x_1) + f(x_2)}{2}$ 恒成立，故 **A 正确**。

**再看选项 B（$f(x) = \sqrt{x}$）：**
因为 $x_1, x_2 > 0$ 且 $x_1 \neq x_2$，用基本不等式直接比较平方：
$$\left(\frac{\sqrt{x_1} + \sqrt{x_2}}{2}\right)^2 = \frac{x_1 + x_2 + 2\sqrt{x_1 x_2}}{4} < \frac{x_1 + x_2 + (x_1 + x_2)}{4} = \frac{x_1 + x_2}{2}.$$
两边均非负且严格不等，开算术平方根得 $\frac{\sqrt{x_1} + \sqrt{x_2}}{2} < \sqrt{\frac{x_1 + x_2}{2}}$，不等号恰与题设完全相反。也可以直接代入特值反例验证：取 $x_1 = 1,\ x_2 = 9$，则 $f\left(\frac{1+9}{2}\right) = \sqrt{5} > 2 = \frac{1 + 3}{2}$，故 **B 错误**。

**接着重点检查选项 C（$f(x) = \log_{\frac{1}{2}} x$）：**
这正是本题最大的定势突破点。虽然常用递增对数（如 $\ln x$、$\log_2 x$）图像向上拱起，但此处的底数是 $\frac{1}{2} \in (0, 1)$，等价于把 $y = \log_2 x$ 关于 $x$ 轴向下翻折成 $y = -\log_2 x$，“拱形”沿 $x$ 轴翻折后立刻变成“碗形”。我们用基本不等式严格证明：对任意正实数 $x_1 \neq x_2$，由算术平均严格大于几何平均得：
$$\frac{x_1 + x_2}{2} > \sqrt{x_1 x_2} > 0.$$
现在把底数为 $\frac{1}{2} \in (0, 1)$ 的**严格单调递减**对数函数 $\log_{\frac{1}{2}}(\cdot)$ 作用在不等号两边（注意递减函数会让不等号反转）：
$$\log_{\frac{1}{2}}\left(\frac{x_1 + x_2}{2}\right) < \log_{\frac{1}{2}}\left(\sqrt{x_1 x_2}\right) = \frac{\log_{\frac{1}{2}} x_1 + \log_{\frac{1}{2}} x_2}{2}.$$
不等式方向完全符合题干要求（也可以用 $x_1 = 1,\ x_2 = 4$ 心算检验：$f\left(\frac{5}{2}\right) = -\log_2 \frac{5}{2} < -\log_2 2 = -1 = \frac{0 + (-2)}{2}$），因此 **C 正确**。

**最后看选项 D（$f(x) = 2^{-x}$）：**
由于指数函数 $y = 2^{-x} = \left(\frac{1}{2}\right)^x$ 在 $\mathbb{R}$ 上严格单调递减且取值恒正，当 $x_1 \neq x_2$ 时，必有 $2^{-x_1} > 0$，$2^{-x_2} > 0$ 且 $2^{-x_1} \neq 2^{-x_2}$。直接对这两个互异正数应用基本不等式：
$$\frac{2^{-x_1} + 2^{-x_2}}{2} > \sqrt{2^{-x_1} \cdot 2^{-x_2}} = \sqrt{2^{-(x_1 + x_2)}} = 2^{-\frac{x_1 + x_2}{2}}.$$
这说明无论底数 $> 1$ 还是在 $(0, 1)$ 之间，指数函数的图像永远向下弯成碗形，因此 **D 正确**。

综上，正确选项为 **ACD**。
