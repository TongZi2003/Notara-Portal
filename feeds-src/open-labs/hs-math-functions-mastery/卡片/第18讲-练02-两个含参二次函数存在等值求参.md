# 第18讲·练02：两个含参二次函数存在等值求参

## 内容

已知函数 $f(x) = x^2 - 2x + 2a\ (x \in [-1, 2])$，$g(x) = -x^2 + 2x + a^2 - 2\ (x \in [0, 3])$。若存在 $x_1 \in [-1, 2]$ 和 $x_2 \in [0, 3]$，使得 $f(x_1) = g(x_2)$ 成立，则实数 $a$ 的取值范围是________。

## 参考理解

我们读完题目会发现，两个函数在各自闭区间上都不是单调函数，而且两个函数都带着参数 $a$——一个是一次移动项 $2a$，另一个是二次移动项 $a^2$。如果试图直接在方程 $x_1^2 - 2x_1 + 2a = -x_2^2 + 2x_2 + a^2 - 2$ 里消元解 $a$，会马上陷进双变量耦合方程；即使知道这是“值域有交集”，由于两个值域区间都随着 $a$ 以不同速度左右滑动，直接正面讨论谁在左、谁在右、谁包住谁，很容易写出一大堆分类还漏掉其中一段。

**为什么我们先分别算出两个固定对称轴抛物线的值域，再走“相离取补集”路线？** 首先注意这里两个抛物线的对称轴都不含参数 $a$，这大大简化了值域计算：
- 对于 $f(x) = (x - 1)^2 + 2a - 1$（$x \in [-1, 2]$）：开口向上，对称轴 $x = 1 \in [-1, 2]$。最小值在顶点取得：$f(1) = 2a - 1$；端点 $x = -1$ 距对称轴更远，最大值为 $f(-1) = (-1 - 1)^2 + 2a - 1 = 2a + 3$。于是 $f(x)$ 的值域为闭区间
  $$A = [2a - 1,\ 2a + 3].$$
- 对于 $g(x) = -(x - 1)^2 + a^2 - 1$（$x \in [0, 3]$）：开口向下，对称轴 $x = 1 \in [0, 3]$。最大值在顶点取得：$g(1) = a^2 - 1$；端点 $x = 3$ 距对称轴更远，最小值为 $g(3) = -(3 - 1)^2 + a^2 - 1 = a^2 - 5$。于是 $g(x)$ 的值域为闭区间
  $$B = [a^2 - 5,\ a^2 - 1].$$

根据[[卡片/双函数量词与值域包含转化法]]，命题“$\exists x_1 \in [-1, 2],\ \exists x_2 \in [0, 3]$ 使得 $f(x_1) = g(x_2)$”完全等价于两个值域的交集非空，即 **$A \cap B \neq \varnothing$**。

**为什么此时考虑补集 $A \cap B = \varnothing$ 比正面枚举交叠方式干净得多？** 在数轴上，两个闭区间 $[2a - 1, 2a + 3]$ 与 $[a^2 - 5, a^2 - 1]$ 既然要“完全没有交集”，只有整段 $A$ 严格落在 $B$ 左边，或者整段 $A$ 严格落在 $B$ 右边这两种毫不相干的可能：
1. **$A$ 严格在 $B$ 左侧**：要求 $A$ 的右端点严格小于 $B$ 的左端点，即
   $$2a + 3 < a^2 - 5 \iff a^2 - 2a - 8 > 0 \iff (a - 4)(a + 2) > 0,$$
   解得 $a < -2$ 或 $a > 4$。
2. **$A$ 严格在 $B$ 右侧**：要求 $B$ 的右端点严格小于 $A$ 的左端点，即
   $$a^2 - 1 < 2a - 1 \iff a^2 - 2a < 0 \iff a(a - 2) < 0,$$
   解得 $0 < a < 2$。

把两种相离情况合并起来，使 $A \cap B = \varnothing$ 的全部参数是 $(-\infty, -2) \cup (0, 2) \cup (4, +\infty)$。现在取它在实数集 $\mathbb{R}$ 中的补集，立即就得到使 $A \cap B \neq \varnothing$ 的充要范围：
$$[-2, 0] \cup [2, 4].$$

最后我们随手抽查几个临界点与中间点验证一下：当 $a = -2$ 时，$A = [-5, -1]$，$B = [-1, 3]$，恰好在 $-1$ 处相接（$f(-1) = -1 = g(3)$）；当 $a = 0$ 时，$A = [-1, 3]$，$B = [-5, -1]$，同样在 $-1$ 处相接；当 $a = 1$ 时，$A = [1, 5]$，$B = [-4, 0]$，确实完全错开；当 $a = 2$ 时，$A = [3, 7]$，$B = [-1, 3]$，在 $3$ 处相接；当 $a = 4$ 时，$A = [7, 11]$，$B = [11, 15]$，在 $11$ 处相接。两段闭区间完全准确，答案为 **$[-2, 0] \cup [2, 4]$**。

## 学生理解
