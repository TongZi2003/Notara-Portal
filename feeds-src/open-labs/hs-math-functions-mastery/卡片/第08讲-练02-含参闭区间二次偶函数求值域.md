# 第08讲·练02：含参闭区间二次偶函数求值域

## 内容

已知定义在闭区间 $[a - 2, 3a]$ 上的函数 $f(x) = x^2 + (b - 1)x + a$ 是偶函数，则函数 $f(x)$ 的值域为 $\underline{\hspace{5em}}$。

## 参考理解

我们看到题设只说 $f(x)$ 是偶函数，却把参数 $a$ 同时埋进了区间端点和函数常数项里，把参数 $b$ 埋进了一次项系数里。如果一开始就想靠取特殊值（比如算 $f(1) = f(-1)$）去硬解，虽然能凑出 $b = 1$，但不仅没法确定 $a$，甚至连 $x = \pm 1$ 是否真在定义域 $[a - 2, 3a]$ 里都没有根据。根据[[卡片/奇偶性判定与分段解析式补全]]，遇到含参定义域上的奇偶函数，第一把锁永远是先让定义域关于原点对称。

因为偶函数的定义域必须关于原点对称，所以闭区间 $[a - 2, 3a]$ 的左右两个端点必定互为相反数，即
$$(a - 2) + 3a = 0 \implies 4a = 2 \implies a = \frac{1}{2}.$$
得到 $a = \frac{1}{2}$ 后，我们先把左右端点代回检查区间是否合法：左端点 $a - 2 = -\frac{3}{2}$，右端点 $3a = \frac{3}{2}$，因此定义域确实是合法的非空对称闭区间 $\left[-\frac{3}{2}, \frac{3}{2}\right]$。

接下来锁定解析式中的参数 $b$。此时函数化为 $f(x) = x^2 + (b - 1)x + \frac{1}{2}$。因为它是定义在 $\left[-\frac{3}{2}, \frac{3}{2}\right]$ 上的偶函数，所以对区间内任意 $x$ 都有 $f(-x) = f(x)$，即
$$x^2 - (b - 1)x + \frac{1}{2} = x^2 + (b - 1)x + \frac{1}{2} \implies 2(b - 1)x = 0.$$
由于该等式对 $\left[-\frac{3}{2}, \frac{3}{2}\right]$ 内的一切 $x$ 恒成立，一次项系数必须为零，解得 $b - 1 = 0$，即 $b = 1$（也可直接取特值 $x = 1 \in \left[-\frac{3}{2}, \frac{3}{2}\right]$ 由 $f(1) = f(-1)$ 得到 $b = 1$，再代入验证 $f(x) = x^2 + \frac{1}{2}$ 确为偶函数）。

于是函数的完整表达式及定义域全部水落石出：
$$f(x) = x^2 + \frac{1}{2}, \qquad x \in \left[-\frac{3}{2}, \frac{3}{2}\right].$$
到这里还要挡住最后一个常见失误：千万不要顺手写成全体实数上的值域 $\left[\frac{1}{2}, +\infty\right)$，因为自变量被限制在闭区间 $\left[-\frac{3}{2}, \frac{3}{2}\right]$ 上。观察抛物线 $f(x) = x^2 + \frac{1}{2}$ 开口向上且对称轴为 $x = 0$，它在 $\left[-\frac{3}{2}, 0\right]$ 上单调递减、在 $\left[0, \frac{3}{2}\right]$ 上单调递增。因此最小值在顶点 $x = 0$ 处取得，为 $f(0) = \frac{1}{2}$；最大值在区间两端点 $x = \pm \frac{3}{2}$ 处取得，为
$$f\left(\pm \frac{3}{2}\right) = \left(\frac{3}{2}\right)^2 + \frac{1}{2} = \frac{9}{4} + \frac{1}{2} = \frac{11}{4}.$$
由于函数在闭区间上连续变化，所以函数 $f(x)$ 的值域为 $\left[\frac{1}{2}, \frac{11}{4}\right]$。
