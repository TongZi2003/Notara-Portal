# 第13讲·练09：真底数差不同的三对数比大小

## 内容

设 $a = \log_7 5$，$b = \log_{10} 7$，$c = \log_5 4$，则 $a, b, c$ 的大小关系是（　　）

A. $a < b < c$　　　　B. $b < a < c$　　　　C. $a < c < b$　　　　D. $c < b < a$

## 参考理解

我们看到这道题时，三个数全都是底数略大于真数的正对数，数值都挤在 $0.82$ 到 $0.87$ 之间。如果用常规的中间桥 $\frac{1}{2}$ 或 $\frac{2}{3}$ 去卡位，很快就会发现三者全大于 $\frac{3}{4}$ 且全小于 $1$，根本拉不开距离；而如果尝试直接套用[[卡片/对数糖水不等式与取倒数减整法]]中的同加减结论，比如把 $a = \log_7 5$ 的底数与真数同时加 $3$，只能得到 $a < \log_{10} 8$，可 $b = \log_{10} 7$ 也小于 $\log_{10} 8$，两数被同一个上界挡住，依然分不出谁大谁小。同样地，直接估算 $a$ 与 $c$、$b$ 与 $c$ 之间该用哪一个分数做桥梁，全凭盲猜高次幂不仅计算量大，还极易在考试紧张时算错方向。

**为什么我们选择用两轮“取倒数再减整数”来放大微弱差异？** 根据[[卡片/对数糖水不等式与取倒数减整法]]，当两个小于 $1$ 的正对数咬得很紧时，只要先取倒数把它们翻到大于 $1$ 的区间，再剥去相同的整数部分，剩下的小数余项仍然保留在 $(0, 1)$ 内且相对差距被大幅拉宽；接着再次取倒数，原本只差百分之一点几的对数，就会直接跳进截然不同的整数区间里。我们只需要在每一步取倒数时牢记“正数取倒数不等号反转”，就能沿着确定性流程一步步拆解到底。

我们先统一对 $a, b, c$ 进行第一轮取倒数（注意 $0 < a, b, c < 1$，取倒数后三者的大小顺序全部反转）：
$$\frac{1}{a} = \log_5 7, \qquad \frac{1}{b} = \log_7 10, \qquad \frac{1}{c} = \log_4 5.$$
观察这组大于 $1$ 的对数，因为 $5 < 7 < 5^2$、$7 < 10 < 7^2$、$4 < 5 < 4^2$，所以它们的整数部分全都是 $1$。我们把整数 $1$ 同步剥离掉（同减常数不改变大小顺序），利用 $\log_p q - 1 = \log_p \frac{q}{p}$ 得到：
$$\frac{1}{a} - 1 = \log_5 \frac{7}{5}, \qquad \frac{1}{b} - 1 = \log_7 \frac{10}{7}, \qquad \frac{1}{c} - 1 = \log_4 \frac{5}{4}.$$

此时三个余项都落在 $(0, 1)$ 内，仍不方便一眼判定谁大谁小，于是我们毫不犹豫地进入第二轮取倒数（再一次注意：三个正余项取倒数，大小顺序会第二次反转）：
$$A_2 = \frac{1}{\frac{1}{a} - 1} = \log_{\frac{7}{5}} 5, \qquad B_2 = \frac{1}{\frac{1}{b} - 1} = \log_{\frac{10}{7}} 7, \qquad C_2 = \frac{1}{\frac{1}{c} - 1} = \log_{\frac{5}{4}} 4.$$
现在把目光聚焦到 $A_2, B_2, C_2$ 的整数边界上，只需要算出底数的小整数次幂与真数对比即可：
- 对于 $A_2 = \log_{\frac{7}{5}} 5$：计算底数的 $4$ 次方与 $5$ 次方，
  $$\left(\frac{7}{5}\right)^4 = \frac{2401}{625} < \frac{3125}{625} = 5, \qquad \left(\frac{7}{5}\right)^5 = \frac{16807}{3125} > \frac{15625}{3125} = 5.$$
  由于底数 $\frac{7}{5} > 1$，对数函数单调递增，因此 **$4 < A_2 < 5$**；
- 对于 $B_2 = \log_{\frac{10}{7}} 7$：计算底数的 $5$ 次方与 $6$ 次方（此处 $7^5 = 16807$，$7^6 = 117649$），
  $$\left(\frac{10}{7}\right)^5 = \frac{100000}{16807} < \frac{117649}{16807} = 7, \qquad \left(\frac{10}{7}\right)^6 = \frac{1000000}{117649} > \frac{823543}{117649} = 7.$$
  同样由底数 $\frac{10}{7} > 1$ 单调递增，立即锁定 **$5 < B_2 < 6$**；
- 对于 $C_2 = \log_{\frac{5}{4}} 4$：计算底数的 $6$ 次方与 $7$ 次方（此处 $5^6 = 15625$，$4^7 = 16384$，$5^7 = 78125$，$4^8 = 65536$），
  $$\left(\frac{5}{4}\right)^6 = \frac{15625}{4096} < \frac{16384}{4096} = 4, \qquad \left(\frac{5}{4}\right)^7 = \frac{78125}{16384} > \frac{65536}{16384} = 4.$$
  由底数 $\frac{5}{4} > 1$ 单调递增，立即锁定 **$6 < C_2 < 7$**。

经过两轮取倒数与减整，三者的区间竟然严丝合缝地错开了：$4 < A_2 < 5 < B_2 < 6 < C_2 < 7$，从而毫无疑问地有：
$$A_2 < B_2 < C_2.$$
现在我们把方向一步步还原回来：
1. 第二轮是由正余项取倒数得到 $A_2 < B_2 < C_2$，因此反转回去得 $\frac{1}{a} - 1 > \frac{1}{b} - 1 > \frac{1}{c} - 1$；
2. 两边同时加上 $1$，得 $\frac{1}{a} > \frac{1}{b} > \frac{1}{c}$；
3. 第一轮是由正数 $a, b, c$ 取倒数得到，因此再次反转回去，恰好还原为同向关系：**$a < b < c$**。

我们也可以顺手检查一下：刚才经历的两次“取倒数”反号两次，负负得正；而中间的“同减 $1$”不改变大小方向，所以最终 $a, b, c$ 的大小顺序与第二轮结果 $A_2, B_2, C_2$ 完全一致。据此锁定唯一正确选项 **A**。
