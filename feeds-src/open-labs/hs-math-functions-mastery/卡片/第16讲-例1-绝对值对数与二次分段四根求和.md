# 第16讲·例1：绝对值对数与二次分段四根求和

## 内容

已知函数
$$f(x) = \begin{cases} |\log_2 x|, & 0 < x \le 2, \\ \frac{1}{2}x^2 - 4x + 7, & x > 2. \end{cases}$$
若存在四个互不相等的实数 $x_1 < x_2 < x_3 < x_4$ 满足 $f(x_1) = f(x_2) = f(x_3) = f(x_4)$，则 $x_1 + x_2 + x_3 + x_4$ 的取值范围是（　　）

A. $\left[10, \frac{21}{2}\right]$　　　　B. $\left(10, \frac{21}{2}\right]$　　　　C. $\left(10, \frac{21}{2}\right)$　　　　D. $\left(9, \frac{21}{2}\right)$

我们看到这道题时，四个实数被同一个函数值串联起来，第一反应可能会想把四段方程直接联立解出四个未知数再硬加；然而只要写出左边是关于对数的绝对值方程、右边是二次方程，就会发现不同分段对应的是不同类的对数方程与二次方程，硬解既找不到四元统一闭式，还会很快掉进各分支区间拼不齐的死胡同。同时四个选项之间的差别仅仅在于左右端点“能不能取到等号”，如果我们只盯着对称关系心算而不去逐个检查分段拼接处究竟是实心点还是空心点，就非常容易把本该是开区间的边界误圈成闭区间。

**为什么我们想到先作完整分段草图并设出水平截线高度 $t$？** 因为题设给出 $f(x_1) = f(x_2) = f(x_3) = f(x_4)$，这相当于把四个交点横坐标放到了函数 $y = f(x)$ 与一条水平直线 $y = t$ 的四个交点上。根据[[卡片/函数图像平移对称与绝对值翻折]]与[[卡片/水平与动直线数形结合定参法]]，我们先画出两段图像并标注空实心断点：左段 $y = |\log_2 x|$（$0 < x \le 2$）将原对数曲线在 $x \in (0, 1)$ 的负半轴部分沿 $x$ 轴向上翻折，从而在 $(0, 1]$ 上从 $+\infty$ 单调递减至 $(1, 0)$，在 $[1, 2]$ 上单调递增至**实心右端点** $(2, 1)$；右段 $y = \frac{1}{2}x^2 - 4x + 7 = \frac{1}{2}(x - 4)^2 - 1$（$x > 2$）是一段开口向上、对称轴为直线 $x = 4$ 的抛物线右支，在 $x = 2$ 处逼近纵坐标 $\frac{1}{2}(2-4)^2 - 1 = 1$ 的**空心点**，向下递减至顶点 $(4, -1)$，随后重新递增并在 $x = 6$ 处取到高度 $1$。

**为什么四交点要求水平线 $t$ 必须严格落在开区间 $(0, 1)$ 内？** 把水平尺从下往上扫过图像：当 $t < 0$ 时左段没有交点（至多 $2$ 根）；当 $t = 0$ 时左段在尖谷 $(1, 0)$ 处只有一个切点式交点，右段在 $(4-\sqrt{2}, 4+\sqrt{2})$ 有两个交点，总共只有 $3$ 个交点；而当 $t = 1$ 时（正是选项 A、B 最爱设坑的临界值），由于 $x = 2$ 仅归属左段而不归属右段，左段在 $\left(\frac{1}{2}, 1\right)$ 与 $(2, 1)$ 有 $2$ 个交点，但右段在空心点 $(2, 1)$ 处无定义，只在 $x = 6$ 处交出 $1$ 个交点，总交点数依然只有 $3$ 个，构不成四个互异实根。因此由[[卡片/多零点水平截线对称消元求范围]]，方程存在四个互异实根的充要条件是水平截线高度严格满足：
$$0 < t < 1.$$

**为什么我们把四根分成左右两对并选取 $x_2$ 作为核心单变量？** 在 $t \in (0, 1)$ 时，四个交点明确分为左对（$0 < x_1 < 1 < x_2 < 2$ 落在翻折对数支上）与右对（$2 < x_3 < 4 < x_4 < 6$ 落在二次支上）。先处理右对：因为 $x_3, x_4$ 落在对称轴 $x = 4$ 的同一抛物线两翼，直接利用轴对称中点消元得：
$$x_3 + x_4 = 2 \times 4 = 8.$$
再处理左对：由于 $x_1 \in (0, 1)$ 落在翻折上来的左翼，$x_2 \in (1, 2)$ 落在未翻折的右翼，它们同时满足方程 $|\log_2 x| = t$，拆掉绝对值得到：
$$-\log_2 x_1 = t, \qquad \log_2 x_2 = t.$$
两式相加立即消去未知高度 $t$，得 $\log_2(x_1 x_2) = 0$，故两根乘积为定值 **$x_1 x_2 = 1$**，即 $x_1 = \frac{1}{x_2}$。而由右翼关系 $x_2 = 2^t$ 且已知 $t \in (0, 1)$，由于指数函数 $y = 2^t$ 严格递增，我们立即确定主元 $x_2$ 的精确取值区间为：
$$x_2 \in (2^0, 2^1) = (1, 2).$$

于是四根之和全部化归为关于单一变量 $x_2$ 的函数：
$$S = x_1 + x_2 + x_3 + x_4 = x_2 + \frac{1}{x_2} + 8, \qquad x_2 \in (1, 2).$$
接下来需要严密求出 $h(u) = u + \frac{1}{u}$ 在开区间 $(1, 2)$ 上的值域。根据[[卡片/分式与对勾型函数值域法]]，因为对勾函数 $h(u)$ 的最低谷点落在 $u = 1$，并未落进开区间 $(1, 2)$ 内部，所以我们绝对不能直接套均值不等式把下界取成闭端点 $2$，必须用单调性确定严格范围：对任意满足 $1 < u_1 < u_2 < 2$ 的实数，作差分解得
$$h(u_2) - h(u_1) = (u_2 - u_1) + \frac{u_1 - u_2}{u_1 u_2} = (u_2 - u_1)\left(1 - \frac{1}{u_1 u_2}\right).$$
因为 $u_1 > 1$ 且 $u_2 > 1$，所以 $u_1 u_2 > 1 \implies 1 - \frac{1}{u_1 u_2} > 0$，又 $u_2 - u_1 > 0$，因此 $h(u_2) > h(u_1)$，即 $h(u)$ 在 $(1, 2)$ 上**严格单调递增**。分别代入左右开区间临界值计算两端开边界对应高度：左端取不到 $u = 1$ 对应 $h(1) = 1 + 1 = 2$，右端取不到 $u = 2$ 对应 $h(2) = 2 + \frac{1}{2} = \frac{5}{2}$，从而 $x_2 + \frac{1}{x_2} \in \left(2, \frac{5}{2}\right)$。两边同时加上常数 $8$，最终得出四根之和的精确取值范围是 $\left(10, \frac{21}{2}\right)$，对应选项 **C**。
