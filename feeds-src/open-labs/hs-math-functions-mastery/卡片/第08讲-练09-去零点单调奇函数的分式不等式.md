# 第08讲·练09：去零点单调奇函数的分式不等式

## 内容

已知定义域为 $\{x \mid x \neq 0\}$ 的奇函数 $f(x)$ 在 $(0, +\infty)$ 上单调递增，且 $f(3) = 0$，则不等式 $\dfrac{f(x) - f(-x)}{x} < 0$ 的解集为（　　）

A. $(-\infty, -3) \cup (3, +\infty)$　　　　B. $(-3, 3)$　　　　C. $(-\infty, -3) \cup (0, 3)$　　　　D. $(-3, 0) \cup (0, 3)$

## 参考理解

我们看到这个带分母 $x$ 的抽象函数不等式，首先要立刻警惕两个最常见的高频错觉：第一，看到“在 $(0, +\infty)$ 上单调递增且 $f(3) = 0$”，千万不能在脑子里默认成“全域递增”，然后把 $f(x) < 0 = f(3)$ 直接写成 $x < 3$；因为 $0$ 不在定义域内，$(-\infty, 0)$ 与 $(0, +\infty)$ 之间存在断点（如 $y = x - \frac{9}{x}$ 就是满足题设的典型例子，它在 $x$ 跨过 $0$ 时函数值从 $+\infty$ 突然掉回 $-\infty$），所以绝不能跨过 $x = 0$ 直接脱壳。第二，即使算出了 $f(x)$ 在各段的正负，也千万不要把题目问的 $\frac{f(x) - f(-x)}{x} < 0$ 错看成“求解 $f(x) < 0$”（那样就会误选选项 C），而忘记了分母还有一个随着左右半轴变号的 $x$，同时还要排除不在定义域内的 $x = 0$（防误选选项 B）。

按照[[卡片/奇偶性与单调性联合脱壳法]]，我们先利用奇函数定义 $f(-x) = -f(x)$ 化简不等式左边（此时定义域已经给出 $x \neq 0$）：
$$\frac{f(x) - f(-x)}{x} = \frac{f(x) - \bigl(-f(x)\bigr)}{x} = \frac{2f(x)}{x} < 0.$$
除以正数 $2$ 不改变不等号方向，原不等式等价于 $\frac{f(x)}{x} < 0$，也就是 **$x$ 与 $f(x)$ 必须异号**（同时注意 $x \neq 0$）。

接下来，**遇到奇函数跨零点或仅知单侧单调性，一律先画草图定出两支符号分布**，绝不盲目套单调公式：
- 先看右半轴 $(0, +\infty)$：已知 $f(x)$ 在 $(0, +\infty)$ 上单调递增且 $f(3) = 0$。于是当 $0 < x < 3$ 时，$f(x) < f(3) = 0$（取负值）；当 $x > 3$ 时，$f(x) > f(3) = 0$（取正值）。
- 再利用原点对称翻折出左半轴 $(-\infty, 0)$：因为 $f(-x) = -f(x)$，首先得出对称零点 $f(-3) = -f(3) = 0$。当 $-3 < x < 0$ 时，$0 < -x < 3 \implies f(-x) < 0 \implies f(x) = -f(-x) > 0$（取正值）；当 $x < -3$ 时，$-x > 3 \implies f(-x) > 0 \implies f(x) = -f(-x) < 0$（取负值）。

现在把“$x$ 与 $f(x)$ 异号”逐支对照上面的符号分布表：
- 当 $x > 0$ 时，要使 $\frac{f(x)}{x} < 0$，必须满足 $f(x) < 0$，从右半轴分布立刻读出 **$0 < x < 3$**；
- 当 $x < 0$ 时，要使 $\frac{f(x)}{x} < 0$，必须满足 $f(x) > 0$，从左半轴分布立刻读出 **$-3 < x < 0$**。

把两支结果并起来（且自然剔除了不在定义域内的 $x = 0$），原不等式的解集为 $(-3, 0) \cup (0, 3)$，对应选项 **D**。
