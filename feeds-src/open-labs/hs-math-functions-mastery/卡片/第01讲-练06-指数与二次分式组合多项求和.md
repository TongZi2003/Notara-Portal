# 第01讲·练06：指数与二次分式组合多项求和

## 内容

已知函数 $f(x) = \frac{25^x}{25^x + 5} + \frac{x^2}{2x^2 - 2x + 1}$，则
$$f\left(\frac{1}{2026}\right) + f\left(\frac{2}{2026}\right) + f\left(\frac{3}{2026}\right) + \dots + f\left(\frac{2025}{2026}\right)$$
的值为（　　）

A. $\frac{2025}{2}$　　　　B. $2024$　　　　C. $2025$　　　　D. $2026$

## 参考理解

我们第一眼看到要加足足 $2025$ 项，而且函数式里一边是指数分式 $\frac{25^x}{25^x + 5}$、另一边是二次分式 $\frac{x^2}{2x^2 - 2x + 1}$，显然不可能逐项代分数硬算，也别指望两项通分后能消成什么简单多项式——指数函数和有理二次函数混在一起通分只会越化越乱。

**为什么我们首先想到试算 $f(x) + f(1 - x)$，而不是 $f(x) + f(-x)$？** 看一眼被加项的自变量 $\frac{1}{2026}, \frac{2}{2026}, \dots, \frac{2025}{2026}$，它们全部成对落在 $(0, 1)$ 内且首尾两项相加恰好等于 $1$（如 $\frac{1}{2026} + \frac{2025}{2026} = 1$）。而且仔细看二次分母 $2x^2 - 2x + 1$，把 $2x^2$ 拆成 $x^2 + x^2$ 配一下方，就能一眼认出 $2x^2 - 2x + 1 = x^2 + (1 - x)^2$（该分母恒不小于 $\frac{1}{2}$，故定义域为 $\mathbb{R}$）。根据[[卡片/函数解析式换元与消元法]]与[[卡片/奇偶加常数与中心对称指对模型]]，我们分别对前后两部分做“以 $1 - x$ 代 $x$”的互补配对计算。

**第一部分**，记 $g(x) = \frac{25^x}{25^x + 5}$。将 $x$ 换成 $1 - x$ 后，把分子分母同时乘以 $25^x$ 消去负指数：
$$g(1 - x) = \frac{25^{1 - x}}{25^{1 - x} + 5} = \frac{25}{25 + 5 \cdot 25^x} = \frac{5}{5 + 25^x}.$$
于是两个分式分母完全一致，相加恰好约分：
$$g(x) + g(1 - x) = \frac{25^x}{25^x + 5} + \frac{5}{25^x + 5} = 1.$$

**第二部分**，记 $h(x) = \frac{x^2}{2x^2 - 2x + 1}$。先用 $1 - x$ 替换 $x$ 核算分母：
$$2(1 - x)^2 - 2(1 - x) + 1 = 2(1 - 2x + x^2) - 2 + 2x + 1 = 2x^2 - 2x + 1,$$
分母竟然与 $h(x)$ 的分母一模一样（本质就是 $x^2 + (1 - x)^2$ 关于 $x \leftrightarrow 1 - x$ 对称）。而分子 $(1 - x)^2 = x^2 - 2x + 1$，两式相加得：
$$h(x) + h(1 - x) = \frac{x^2 + (x^2 - 2x + 1)}{2x^2 - 2x + 1} = \frac{2x^2 - 2x + 1}{2x^2 - 2x + 1} = 1.$$

把两部分合起来，我们就得到了极其漂亮的中心对称恒等式：**对任意实数 $x \in \mathbb{R}$，恒有 $f(x) + f(1 - x) = 1 + 1 = 2$**（千万不要惯性以为每对之和是 $1$ 而误选成选项 A）。

接下来进入最后一步配对计数，这一步最容易出错的是把奇数个项直接当成偶数个项配对，漏掉或重复计算正中间那一项。从 $k = 1$ 到 $k = 2025$ 一共有 $2025$ 个加项，是**奇数**个：
- 首尾两两配对：$\left(\frac{1}{2026}, \frac{2025}{2026}\right)$，$\left(\frac{2}{2026}, \frac{2024}{2026}\right)$，直到 $\left(\frac{1012}{2026}, \frac{1014}{2026}\right)$，一共有 $1012$ 对，每对之和均为 $2$，贡献总和 $1012 \times 2 = 2024$（如果就此停笔就会错选选项 B）；
- 孤独留在正中间的项是 $k = 1013$，即 $x = \frac{1013}{2026} = \frac{1}{2}$。既可以直接在 $f(x) + f(1 - x) = 2$ 中令 $x = \frac{1}{2}$ 得 $2f\left(\frac{1}{2}\right) = 2 \implies f\left(\frac{1}{2}\right) = 1$，也可以直接代入原式验证：$f\left(\frac{1}{2}\right) = \frac{5}{5 + 5} + \frac{\frac{1}{4}}{\frac{1}{2} - 1 + 1} = \frac{1}{2} + \frac{1}{2} = 1$。

把 $1012$ 对的和与正中间这一项加起来，总和 $S = 2024 + 1 = 2025$，对应选项 **C**。
