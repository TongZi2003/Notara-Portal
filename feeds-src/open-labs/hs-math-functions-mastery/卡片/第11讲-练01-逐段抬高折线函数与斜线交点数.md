# 第11讲·练01：逐段抬高折线函数与斜线交点数

## 内容

已知定义在 $[0, +\infty)$ 上的函数 $f(x)$ 满足 $f(x + 2) = f(x) + 1$，且当 $x \in [0, 2)$ 时，$f(x) = |x - 1|$。则在闭区间 $[0, 6]$ 上，方程 $f(x) = \frac{1}{2}x$ 实数根的个数为________。

## 参考理解

我们看到这种纵向逐段加常数抬高条件 $f(x + 2) = f(x) + 1$ 与区间 $[0, 2)$ 上的对称折线 $f(x) = |x - 1|$ 时，脑海里很快就能浮现出图像向右一节一节抬升的锯齿阶梯。但考场上最致命的失误在于**画草图时顺手把相邻两段折线直接连在一起，或者忽略了每段末尾 $x = 2, 4, 6$ 处到底是实心点还是空心点**。如果没把端点空实心标死、没逐段解方程核验交点，几乎一定会把几个不存在的空心端点算进去，多出整整一倍的假根。

**为什么我们必须按[[卡片/类周期与伸缩迭代函数分析法]]把 $[0, 6]$ 拆成三个左闭右开区间以及末尾孤立点 $x = 6$ 逐段精确核实？** 让我们先算一下各段交界处的函数值：
- 在基准段 $[0, 2)$ 上：$f(0) = |0 - 1| = 1$，当 $x$ 从左侧逼近 $2$ 时，$f(x) = |x - 1|$ 趋近端值 $1$（**空心点** $(2, 1)$）；
- 一旦迈入下一段 $x = 2$，由递推式立即跳跃为 $f(2) = f(0) + 1 = 2$（**实心点** $(2, 2)$）。

这说明曲线在 $x = 2, 4, 6$ 处根本不是连续拼接的，而是每次都在整数偶数点猛然向上跳升 $1$ 个单位。下面我们写出每一段上的显式解析式，并分别与直线 $y = \frac{1}{2}x$ 联立求解检验：

第一段，$x \in [0, 2)$：$f(x) = |x - 1|$。
- 当 $x \in [0, 1]$ 时，$f(x) = 1 - x$，联立方程 $1 - x = \frac{1}{2}x \implies \frac{3}{2}x = 1 \implies x_1 = \frac{2}{3}$。检验 $\frac{2}{3} \in [0, 1]$，**有效根 $1$ 个**（交点 $\left(\frac{2}{3}, \frac{1}{3}\right)$）；
- 当 $x \in (1, 2)$ 时，$f(x) = x - 1$，联立方程 $x - 1 = \frac{1}{2}x \implies \frac{1}{2}x = 1 \implies x = 2$。检验 $2 \notin (1, 2)$，这说明直线 $y = \frac{1}{2}x$ 恰好穿过了本段的**空心右端点** $(2, 1)$，在本段内部没有实根。

第二段，$x \in [2, 4)$：通过减去 $2$ 拉回基准区间（$x - 2 \in [0, 2)$），得：
$$f(x) = f(x - 2) + 1 = |(x - 2) - 1| + 1 = |x - 3| + 1.$$
拆开绝对值分两小段联立：
- 当 $x \in [2, 3]$ 时，$f(x) = (3 - x) + 1 = 4 - x$，联立方程 $4 - x = \frac{1}{2}x \implies \frac{3}{2}x = 4 \implies x_2 = \frac{8}{3}$。检验 $2 < \frac{8}{3} < 3$，**有效根 $1$ 个**（交点 $\left(\frac{8}{3}, \frac{4}{3}\right)$）；
- 当 $x \in (3, 4)$ 时，$f(x) = (x - 3) + 1 = x - 2$，联立方程 $x - 2 = \frac{1}{2}x \implies \frac{1}{2}x = 2 \implies x = 4$。检验 $4 \notin (3, 4)$，直线又一次恰好穿过了本段的**空心右端点** $(4, 2)$，无实根。

第三段，$x \in [4, 6)$：通过减去 $4$ 拉回基准区间（$x - 4 \in [0, 2)$），套用两次递推得：
$$f(x) = f(x - 4) + 2 = |(x - 4) - 1| + 2 = |x - 5| + 2.$$
同样拆开绝对值分两小段联立：
- 当 $x \in [4, 5]$ 时，$f(x) = (5 - x) + 2 = 7 - x$，联立方程 $7 - x = \frac{1}{2}x \implies \frac{3}{2}x = 7 \implies x_3 = \frac{14}{3}$。检验 $4 < \frac{14}{3} < 5$，**有效根 $1$ 个**（交点 $\left(\frac{14}{3}, \frac{7}{3}\right)$）；
- 当 $x \in (5, 6)$ 时，$f(x) = (x - 5) + 2 = x - 3$，联立方程 $x - 3 = \frac{1}{2}x \implies \frac{1}{2}x = 3 \implies x = 6$。检验 $6 \notin (5, 6)$，直线再次穿过本段的**空心右端点** $(6, 3)$，无实根。

最后一步千万不要忘了闭区间 $[0, 6]$ 的右端点 $x = 6$。单独计算实心端点值：
$$f(6) = f(4) + 1 = f(2) + 2 = f(0) + 3 = 1 + 3 = 4.$$
而直线在 $x = 6$ 处的纵坐标为 $y = \frac{1}{2} \times 6 = 3$。显然 $f(6) = 4 \neq 3$，说明实心端点 $(6, 4)$ 跃到了直线的上方，并没有落在直线上。

回顾整个几何图像就十分清晰：每段的右端空心点 $(2, 1), (4, 2), (6, 3)$ 恰巧全都排在斜线 $y = \frac{1}{2}x$ 上，使得直线刚好擦着三个空心谷角过去，仅在每一节向下倾斜的左斜边上各截出 $1$ 个真交点。故方程在 $[0, 6]$ 上共有 **$3$** 个实数根。
