# 第14讲·练04：指对与二次式中点不等式辨析

## 内容

设实数 $a, b$ 满足 $0 < a < b$，则下列不等式恒成立的是（　　）

A. $\frac{\ln a + \ln b}{2} + \frac{2^a + 2^b}{2} < \ln\frac{a + b}{2} + 2^{\frac{a + b}{2}}$
B. $\ln\frac{a + b}{2} + \frac{a + b}{2} < \frac{\ln a + \ln b}{2} + \sqrt{\frac{a^2 + b^2}{2}}$
C. $\frac{\ln a + \ln b}{2} + 2^{\frac{a + b}{2}} + \frac{a + b}{2} < \ln\frac{a + b}{2} + \frac{2^a + 2^b}{2} + \sqrt{\frac{a^2 + b^2}{2}}$
D. $\frac{2^a + 2^b}{2} + \frac{a + b}{2} < 2^{\frac{a + b}{2}} + \sqrt{\frac{a^2 + b^2}{2}}$

## 参考理解

我们看到这道题时，四个选项把 $\frac{\ln a + \ln b}{2}$、$\ln\frac{a + b}{2}$、$2^{\frac{a + b}{2}}$、$\frac{2^a + 2^b}{2}$、$\frac{a + b}{2}$、$\sqrt{\frac{a^2 + b^2}{2}}$ 这六个表达式反复打乱拼接在不等号两边。如果我们一上来就对着单个选项硬凑放缩或带特值瞎蒙，不仅很容易被 A、B、D 这种“一部分往左偏、一部分往右偏”的拉扯式不等式绕晕，还可能在换不同测试点时遇到方向反复翻转而误判。

**为什么我们选择先一口气拆清这三组表达式对应曲线的弯曲方向，再做加减组合与特值证伪？** 根据[[卡片/函数凹凸性与中点不等式]]，题中六个表达式其实严格配成三组，每一组都是某个基本初等函数在互异正数 $a < b$ 上的中点值与弦中点值的直接较量：

1. **自然对数 $f(x) = \ln x$ 在 $(0, +\infty)$ 上图像严格向上拱**：
   由基本不等式知 $\frac{a + b}{2} > \sqrt{ab} > 0$，又 $y = \ln x$ 严格递增，故
   $$\frac{\ln a + \ln b}{2} = \ln\sqrt{ab} < \ln\frac{a + b}{2}.$$
   （即 $\ln\frac{a + b}{2}$ 严格更大）

2. **指数函数 $g(x) = 2^x$ 在 $\mathbb{R}$ 上图像严格向下弯**：
   对互异正数 $2^a \neq 2^b$ 直接用基本不等式得：
   $$2^{\frac{a + b}{2}} = \sqrt{2^a \cdot 2^b} < \frac{2^a + 2^b}{2}.$$
   （即 $\frac{2^a + 2^b}{2}$ 严格更大）

3. **二次平方函数 $h(x) = x^2$ 在 $(0, +\infty)$ 上图像严格向下弯**：
   作差 $\frac{a^2 + b^2}{2} - \left(\frac{a + b}{2}\right)^2 = \frac{(a - b)^2}{4} > 0$，开算术平方根即得：
   $$\frac{a + b}{2} < \sqrt{\frac{a^2 + b^2}{2}}.$$
   （即 $\sqrt{\frac{a^2 + b^2}{2}}$ 严格更大）

先把这三条同向严格不等式的“较小侧”和“较大侧”分别对齐之后，回头审视选项 **C**：
- 左边三项 $\frac{\ln a + \ln b}{2}$、$2^{\frac{a + b}{2}}$、$\frac{a + b}{2}$ 全是各组里严格较小的那一侧；
- 右边三项 $\ln\frac{a + b}{2}$、$\frac{2^a + 2^b}{2}$、$\sqrt{\frac{a^2 + b^2}{2}}$ 全是各组里严格较大的那一侧。

根据同向不等式的可加性，将上述三条严格不等式左右分别相加，立刻严密证出 **C** 对任意 $0 < a < b$ 恒成立。

为了确保万无一失，我们也用简洁清晰的特值反例把另外三项“异向拉扯”的选项全部击破：
- **看选项 A**：左边把对数的较小侧与指数的较大侧加在了一起。取 $a = 1,\ b = 3$，则
  $$\text{左边} = \frac{\ln 3}{2} + \frac{2 + 8}{2} = \frac{\ln 3}{2} + 5, \qquad \text{右边} = \ln 2 + 2^2 = \ln 2 + 4.$$
  因为 $2 < e < 3$，所以 $\ln 2 < 1$ 且 $\ln 3 > 1$，立得 $\text{左边} - \text{右边} = (1 - \ln 2) + \frac{\ln 3}{2} > 0$，A 不成立；
- **看选项 B**：移项等价于 $\ln\frac{a + b}{2} - \frac{\ln a + \ln b}{2} < \sqrt{\frac{a^2 + b^2}{2}} - \frac{a + b}{2}$。注意对数差具有“缩放不变性”（$a, b$ 同时缩小 $100$ 倍差值不变），而平方根平均差会随着 $a, b$ 缩小而缩小。于是取 $a = \frac{1}{100},\ b = 1$：
  - 对数差为 $\ln\frac{101/200}{1/10} = \ln\frac{101}{20} > \ln 5 > \ln e = 1$；
  - 平方根平均差满足 $\sqrt{\frac{a^2 + b^2}{2}} - \frac{a + b}{2} < \sqrt{\frac{1 + 1}{2}} - \frac{1}{2} = \frac{1}{2} < 1$；
  - 于是左边差值大于 $1$ 而右边差值小于 $\frac{1}{2}$，B 被彻底证伪；
- **看选项 D**：取 $a = 1,\ b = 3$，则
  $$\text{左边} = \frac{2 + 8}{2} + \frac{1 + 3}{2} = 5 + 2 = 7, \qquad \text{右边} = 2^2 + \sqrt{\frac{1 + 9}{2}} = 4 + \sqrt{5} < 4 + 3 = 7,$$
  显然左边严格大于右边，D 也不成立。

由此确认唯一恒成立的不等式是 **C**。
