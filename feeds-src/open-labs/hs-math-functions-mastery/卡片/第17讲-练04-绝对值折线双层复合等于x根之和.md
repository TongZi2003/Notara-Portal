# 第17讲·练04：绝对值折线双层复合等于x根之和

## 内容

已知函数 $f(x) = 2 - |2x - 1|$（$x \in \mathbb{R}$），则方程 $f\bigl(f(x)\bigr) = x$ 的所有实数根之和为__________。

## 参考理解

我们看到这道填空题时，千万不要把 $f(x) = 2 - |2x - 1|$ 简单看作“好像先求 $f(x) = x$ 得到 $-1$ 和 $1$ 就结束了”。因为 $f(x)$ 在 $x > \frac{1}{2}$ 上是严格递减分支，根据[[卡片/函数不动点与二周期点分析法]]，一旦函数带有递减段，方程 $f\bigl(f(x)\bigr) = x$ 就完全可能在不动点之外再长出成对互反的二周期点 $(u, v)$（满足 $f(u) = v$、$f(v) = u$ 且 $u \neq v$）。为了确保一个实根也不漏，我们可以用“四段折线显式拆解”直接把 $y = f\bigl(f(x)\bigr)$ 写清并画出 M 形折线交点，同时与不动点加二周期点视角交叉核对。

先把内层函数 $f(x) = 2 - |2x - 1|$ 写成不含绝对值的分段形式，分界点在 $x = \frac{1}{2}$：
$$f(x) = \begin{cases} 2x + 1, & x \le \dfrac{1}{2}, \\ 3 - 2x, & x > \dfrac{1}{2}. \end{cases}$$
先找出所有**一阶不动点**（即满足 $f(x) = x$ 的实根）：
- 当 $x \le \frac{1}{2}$ 时，由 $2x + 1 = x$ 解得 $x = -1$（满足 $-1 \le \frac{1}{2}$，检验 $f(-1) = -1$）；
- 当 $x > \frac{1}{2}$ 时，由 $3 - 2x = x$ 解得 $x = 1$（满足 $1 > \frac{1}{2}$，检验 $f(1) = 1$）。
也就是说，方程 $f(x) = x$ 贡献了两个整数实根 $x_1 = -1$ 与 $x_2 = 1$。

接下来为了把嵌套后的 $f\bigl(f(x)\bigr) = x$ 的全部根一个不落找齐，我们把 $f(x)$ 代入外层绝对值表达式：
$$f\bigl(f(x)\bigr) = 2 - \bigl|2f(x) - 1\bigr|.$$
外层绝对值拆分的分界条件是 $f(x) = \frac{1}{2}$。分别在左右两支求解 $f(x) = \frac{1}{2}$：
- 左支 $2x + 1 = \frac{1}{2} \implies x = -\frac{1}{4}$（满足 $-\frac{1}{4} \le \frac{1}{2}$）；
- 右支 $3 - 2x = \frac{1}{2} \implies x = \frac{5}{4}$（满足 $\frac{5}{4} > \frac{1}{2}$）。

结合内层折点 $x = \frac{1}{2}$（此时 $f\left(\frac{1}{2}\right) = 2 > \frac{1}{2}$），实数轴被三个节点 $-\frac{1}{4}$、$\frac{1}{2}$、$\frac{5}{4}$ 划分为四个连续区间，根据[[卡片/函数图像平移对称与绝对值翻折]]可以依次写出 $f\bigl(f(x)\bigr)$ 的四段线性解析式并直接解 $f\bigl(f(x)\bigr) = x$：
1. **当 $x \le -\frac{1}{4}$ 时**：$f(x) = 2x + 1 \le \frac{1}{2}$，故 $f\bigl(f(x)\bigr) = 2(2x + 1) + 1 = 4x + 3$。令 $4x + 3 = x$ 得 $x = -1$，满足 $-1 \le -\frac{1}{4}$；
2. **当 $-\frac{1}{4} < x \le \frac{1}{2}$ 时**：$f(x) = 2x + 1 > \frac{1}{2}$，故 $f\bigl(f(x)\bigr) = 3 - 2(2x + 1) = 1 - 4x$。令 $1 - 4x = x$ 得 $5x = 1 \implies x = \frac{1}{5}$，满足 $-\frac{1}{4} < \frac{1}{5} \le \frac{1}{2}$；
3. **当 $\frac{1}{2} < x \le \frac{5}{4}$ 时**：$f(x) = 3 - 2x \ge \frac{1}{2}$，故 $f\bigl(f(x)\bigr) = 3 - 2(3 - 2x) = 4x - 3$。令 $4x - 3 = x$ 得 $3x = 3 \implies x = 1$，满足 $\frac{1}{2} < 1 \le \frac{5}{4}$；
4. **当 $x > \frac{5}{4}$ 时**：$f(x) = 3 - 2x < \frac{1}{2}$，故 $f\bigl(f(x)\bigr) = 2(3 - 2x) + 1 = 7 - 4x$。令 $7 - 4x = x$ 得 $5x = 7 \implies x = \frac{7}{5}$，满足 $\frac{7}{5} > \frac{5}{4}$。

从图像上看，$y = f\bigl(f(x)\bigr)$ 恰好是一条依次经过折点 $\left(-\frac{1}{4}, 2\right)$、$\left(\frac{1}{2}, -1\right)$、$\left(\frac{5}{4}, 2\right)$ 的 M 形折线，而直线 $y = x$ 穿过了全部 $4$ 段分支。我们再从“二周期点对”的视角复核一遍新冒出来的两个分数根 $\frac{1}{5}$ 与 $\frac{7}{5}$：计算得 $f\left(\frac{1}{5}\right) = 2 - \left|\frac{2}{5} - 1\right| = \frac{7}{5}$，且 $f\left(\frac{7}{5}\right) = 2 - \left|\frac{14}{5} - 1\right| = \frac{1}{5}$。它们恰好就是跨在递增左支与递减右支之间、且在反函数视角下关于直线 $y = x$ 互反对称的成对点 $\left(\frac{1}{5}, \frac{7}{5}\right)$ 与 $\left(\frac{7}{5}, \frac{1}{5}\right)$（符合[[卡片/反函数交点与非对称反例辨析]]的规律）。

最终确认原方程共有 $4$ 个互不相等的实数根，全部实数根之和为：
$$-1 + \frac{1}{5} + 1 + \frac{7}{5} = \frac{8}{5}.$$

## 学生理解
