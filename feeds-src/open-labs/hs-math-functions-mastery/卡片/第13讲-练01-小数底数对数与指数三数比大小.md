# 第13讲·练01：小数底数对数与指数三数比大小

## 内容

已知 $a = \log_{0.4} 0.3$，$b = 0.4^{0.3}$，$c = \log_3 0.4$，则 $a, b, c$ 的大小关系是（　　）

A. $a > b > c$　　　　B. $b > a > c$　　　　C. $a > c > b$　　　　D. $c > b > a$

## 参考理解

我们拿到这三个数时，第一眼会发现底数既有 $0.4$ 又有 $3$，既有指数又有对数，没法直接化到同一底数或同一指数下面硬比。考场上最容易踩的坑是看到 $a = \log_{0.4} 0.3$ 里的两个小数都落在 $(0, 1)$ 内且 $0.3 < 0.4$，就直觉以为这个对数一定小于 $1$ 甚至小于 $0$，从而错把 $a$ 排在 $b$ 后面或排到负数区。

**为什么我们不用去估算小数位，而是先用 $0$ 和 $1$ 把它们分层？** 根据[[卡片/指对幂比大小三阶通法与中间桥]]，当底数和指数全不相同时，第一步永远是“零一隔断”，先看每个数各自与 $0$ 和 $1$ 的相对位置，很多时候一次分层就能排完。

先看 $a = \log_{0.4} 0.3$：这里的底数 $0.4 \in (0, 1)$，因此对数函数 $y = \log_{0.4} x$ 在 $(0, +\infty)$ 上**严格单调递减**。因为真数满足 $0 < 0.3 < 0.4$，把不等号方向反过来，立刻得到
$$a = \log_{0.4} 0.3 > \log_{0.4} 0.4 = 1.$$
这就是“同居 $(0, 1)$ 且真数更小”时对数反而大于 $1$ 的典型特征，切记不能看到小数真数就默认小于 $1$。

再看 $b = 0.4^{0.3}$：指数函数 $y = 0.4^x$ 的底数 $0.4 \in (0, 1)$，它在 $\mathbb{R}$ 上**严格单调递减**，且指数函数的函数值恒大于 $0$。由于指数 $0.3 > 0$，直接对比基准点 $x = 0$ 得
$$0 < b = 0.4^{0.3} < 0.4^0 = 1.$$

最后看 $c = \log_3 0.4$：底数 $3 > 1$，所以对数函数 $y = \log_3 x$ 在 $(0, +\infty)$ 上**严格单调递增**。因为真数 $0.4$ 与底数 $3$ 分居 $1$ 的两侧（$0 < 0.4 < 1$），对比基准点 $x = 1$ 得
$$c = \log_3 0.4 < \log_3 1 = 0.$$

于是三个数被 $0$ 和 $1$ 干净利落地彻底隔开：
$$c < 0 < b < 1 < a.$$
完全不需要任何数值近似，直接得出 $a > b > c$，对应选项 **A**。
