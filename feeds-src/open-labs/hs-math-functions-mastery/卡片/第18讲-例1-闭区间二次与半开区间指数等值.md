# 第18讲·例1：闭区间二次与半开区间指数等值

## 内容

已知函数 $f(x) = x^2 - 2x + 4\ (x \in [0, 2])$，$g(x) = 2^x + a\ (x \in (1, 3])$。若对任意 $x_1 \in [0, 2]$，总存在 $x_2 \in (1, 3]$，使得 $f(x_1) = g(x_2)$，则实数 $a$ 的取值范围是（　　）

A. $[-4, 1]$　　　　B. $[-4, 1)$　　　　C. $(-4, 1)$　　　　D. $(-4, 1]$

## 参考理解

我们看到四个选项的数字部分完全相同，清一色都是 $-4$ 和 $1$，唯一区别就在于左右两端的方括号与圆括号。面对这类题时，如果只算出了值域端点就随手全都加上等号，或者只因为看见题干里有 $(1, 3]$ 就一律写成全开区间，都会在四个长得极像的选项里栽跟头。正确的突破口是先用[[卡片/双函数量词与值域包含转化法]]确定谁包含谁，再把两个区间画到同一条数轴上，分别代回临界点核实空心圆与实心点。

**为什么这道题的值域包含方向一定是 $A \subseteq B$？** 我们记 $f(x)$ 在 $[0, 2]$ 上的值域为集合 $A$，$g(x)$ 在 $(1, 3]$ 上的值域为集合 $B$。题设说“对任意 $x_1 \in [0, 2]$，总存在 $x_2 \in (1, 3]$ 使得 $f(x_1) = g(x_2)$”，意思是无论从篮子 $A$ 里随手挑出哪一个函数值 $y = f(x_1)$，都能在篮子 $B$ 里找到完全相等的 $g(x_2)$ 来接住它。用“谁带 $\forall$ 谁站在子集侧”的法则检验，正是 **$A \subseteq B$**。

接下来准确求出集合 $A$ 和集合 $B$，务必连同端点开闭一并写准：
- 对 $f(x) = (x - 1)^2 + 3$（$x \in [0, 2]$）：对称轴 $x = 1 \in [0, 2]$，最小值为 $f(1) = 3$；左右两端点关于 $x = 1$ 对称，$f(0) = f(2) = 4$。因为定义域 $[0, 2]$ 两端均闭合，最小值与最大值都实实在在取得到，所以
  $$A = [3, 4].$$
- 对 $g(x) = 2^x + a$（$x \in (1, 3]$）：指数函数 $y = 2^x + a$ 在 $(1, 3]$ 上严格单调递增。左端点 $x = 1$ 是空心取不到的，对应下界 $2^1 + a = 2 + a$ 取不到；右端点 $x = 3$ 是实心取得到的，对应最大值 $2^3 + a = 8 + a$ 取得到，所以
  $$B = (2 + a, 8 + a].$$

**为什么左右端点的不等号一个严格小于而另一个允许小于等于？** 要使闭区间 $[3, 4]$ 完整落进半开半闭区间 $(2 + a, 8 + a]$ 内部，我们逐端检查临界情形：
- **左端点比较（$2 + a$ 与 $3$）**：因为 $3 \in A$（实心点），而 $2 + a \notin B$（空心圆），如果令 $2 + a = 3$ 即 $a = 1$，则 $B = (3, 9]$，此时取 $x_1 = 1$ 得到 $f(1) = 3$，在 $B$ 里却找不到等于 $3$ 的值，违背题意。因此左端必须严格满足：
  $$2 + a < 3 \implies a < 1.$$
- **右端点比较（$4$ 与 $8 + a$）**：因为 $4 \in A$（实心点），而 $8 + a \in B$（也是实心点），如果令 $8 + a = 4$ 即 $a = -4$，则 $B = (-2, 4]$，此时对于 $A = [3, 4]$ 中的每一个值（包括右端点 $4 = g(3)$），在 $B$ 中都能找到对应相等的值。因此右端允许取等：
  $$8 + a \ge 4 \implies a \ge -4.$$

综合左右两端，实数 $a$ 的精确取值范围是 $[-4, 1)$，对应选项 **B**。每次做完值域包含题，像这样把两个边界值 $a = -4$ 和 $a = 1$ 代回原函数口算一遍 $B$ 的集合，只需要五秒钟就能把开闭括号锁得滴水不漏。
