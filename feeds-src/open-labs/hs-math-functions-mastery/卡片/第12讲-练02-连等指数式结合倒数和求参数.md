# 第12讲·练02：连等指数式结合倒数和求参数

## 内容

已知实数 $a, b, m$ 满足 $2^a = 5^b = m$，且 $\dfrac{1}{a} + \dfrac{2}{b} = 2$，则实数 $m$ 的值为 $\underline{\hspace{5em}}$。

## 参考理解

我们看到条件里有连等指数式 $2^a = 5^b = m$，底数 $2$ 和 $5$ 互不相同，而第二个条件给的却是分式 $\frac{1}{a} + \frac{2}{b} = 2$。面对这类题目，硬把 $a = \log_2 m$、$b = \log_5 m$ 写出来后，如果接着想硬算 $\frac{1}{\log_2 m} + \frac{2}{\log_5 m} = 2$ 却忘了换底倒数公式，就会立刻卡在“未知数全在分母的底数上”这一步；反过来，如果不先确认 $m$ 的正负和能否等于 $1$，最后开方时也很容易多出一个负数伪解。

**为什么我们把 $m$ 设为公共底数来取对数，就能瞬间把倒数变成对数加法？** 先核对定义域与取值边界：因为指数函数 $2^a$ 恒为正数，所以必有 **$m > 0$**；又因为条件式 $\frac{1}{a} + \frac{2}{b} = 2$ 中 $a, b$ 处于分母位置，故隐含 $a \neq 0$ 且 $b \neq 0$，这就同时排除了 $m = 2^0 = 1$ 的可能，即 **$m > 0$ 且 $m \neq 1$**，$m$ 完全有资格充当对数的底数。

根据[[卡片/指对条件求值与整体代换法]]，先分别用对数表示 $a, b$：
$$a = \log_2 m, \qquad b = \log_5 m.$$
再利用换底公式的倒数性质 $\frac{1}{\log_c m} = \log_m c$（$c, m > 0$ 且均不为 $1$），把分母里的 $a, b$ 翻转成以 $m$ 为底的对数：
$$\frac{1}{a} = \frac{1}{\log_2 m} = \log_m 2, \qquad \frac{1}{b} = \frac{1}{\log_5 m} = \log_m 5.$$

现在把两式代入条件等式 $\frac{1}{a} + \frac{2}{b} = 2$，同底对数的倍数和相加正好合并为真数乘积：
$$\log_m 2 + 2\log_m 5 = \log_m 2 + \log_m 5^2 = \log_m(2 \times 25) = \log_m 50 = 2.$$
将对数式还原成指数式，得：
$$m^2 = 50.$$
开方得 $m = \pm 5\sqrt{2}$。千万记住前面我们已经用指数函数的值域排除了负值：因为 $m = 2^a > 0$，必须舍去 $-5\sqrt{2}$，所以实数 $m$ 的唯一精确值为 **$5\sqrt{2}$**（检验可知 $5\sqrt{2} > 1$，满足 $m \neq 1$ 且 $a, b \neq 0$）。
