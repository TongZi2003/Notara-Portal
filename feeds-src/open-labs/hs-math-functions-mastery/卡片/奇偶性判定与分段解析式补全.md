# 奇偶性判定与分段解析式补全

## 内容

函数奇偶性是关于原点对称（奇函数 $f(-x) = -f(x)$）或 $y$ 轴对称（偶函数 $f(-x) = f(x)$）的全局性质。所有高一奇偶性坑题，基本围绕“定义域是否对称”与“$0$ 点是否可取”这两步顺序展开。

### 1. 奇偶性判定的标准两步锁

1. **第一锁：先验定义域是否关于原点对称**（一票否决权）：
   若定义域不关于原点对称（如 $[0, +\infty)$、$(-2, 2]$、含分母或对数不对称截断），函数直接是非奇非偶函数，无需化简解析式。
   - 若已知某函数在区间 $[a - 1, 2a]$ 上是奇函数或偶函数，不用先算函数值，直接令区间两端点相加为零：$(a - 1) + 2a = 0 \implies a = \frac{1}{3}$。
2. **第二锁：在定义域内校验 $f(-x)$ 与 $\pm f(x)$ 的恒等关系**：
   - 等价判定：$f(-x) - f(x) = 0$（偶函数）或 $f(-x) + f(x) = 0$（奇函数）；在先确认 $f(x) \neq 0$ 时亦可用商式 $\frac{f(-x)}{f(x)} = \pm 1$（最适合分式与对数模型化简）；
   - **分段函数奇偶性判定**：必须分正区（$x > 0$ 推 $-x < 0$ 代入另一段）、负区（$x < 0$ 推 $-x > 0$ 代入第一段）以及原点（$x = 0$）三处分别验证，缺一不可。

### 2. 「$f(0) = 0$」与奇函数的真正逻辑关系

- 若 $f(x)$ 是奇函数，**且 $0$ 在定义域内**，则必有 $f(0) = -f(0) \implies f(0) = 0$（常用来秒求参数）；
- 若 $0$ **不在**定义域内（例如 $f(x) = \frac{1}{x}$ 或 $f(x) = x - \frac{1}{x}$），函数依然可以是奇函数，不能妄称必过原点；
- 反过来，$f(0) = 0$ 并不能独自保证奇偶性；而且偶函数也完全可能 $f(0)=0$（既是奇函数又是偶函数的唯一型式是在对称定义域上恒为 $f(x) = 0$）。

### 3. 由 $x > 0$ 解析式反求 $x < 0$ 与 $x = 0$ 完整表达式

设函数是 $\mathbb{R}$ 上的奇（或偶）函数，已知当 $x > 0$ 时 $f(x) = \varphi(x)$，求完整解析式或 $x < 0$ 解析式：
1. 设 **$x < 0$**，则此时 **$-x > 0$**，可以把 $-x$ 合法代入已知右侧表达式 $\varphi(-x)$；
2. 依据奇偶关系反推：
   - 若为偶函数：$f(x) = f(-x) = \varphi(-x)$；
   - 若为奇函数：$f(x) = -f(-x) = -\varphi(-x)$；
3. **补齐原点**：若原题定义域包含 $0$ 且要求全解析式，对奇函数单独标明 $f(0) = 0$（偶函数检验题目给的原点定义或把 $x=0$ 并入闭区）；最后务必看清题干问的是“求 $x<0$ 时的解析式”还是“求完整分段函数”。

## 参考理解

### 高频易错与隐形大坑

1. **假复合解析式需要先化简定义域再判定**：
   给出 $f(x) = \frac{\sqrt{1-x^2}}{|x+2| - 2}$ 判断奇偶性时，万不可未化简分母就直接把 $|x+2|$ 判为不对称——先解定义域：$1-x^2 \ge 0 \implies x \in [-1, 1]$，在此区间上 $x+2 > 0$ 恒成立。所以分母其实是 $x + 2 - 2 = x$（还需剔除 $x=0$），定义域为 $[-1, 0) \cup (0, 1]$ 关于原点对称，且化简为 $f(x) = \frac{\sqrt{1-x^2}}{x}$，妥妥的**奇函数**。
2. **「$x>0$ 带入 $-x$」忘记符号括号或误加多余负号**：
   例如奇函数 $f(x)$ 在 $x > 0$ 时 $f(x) = x^2 - 2x + 3$。求 $x < 0$ 表达式时，当 $x < 0 \implies -x > 0 \implies f(-x) = (-x)^2 - 2(-x) + 3 = x^2 + 2x + 3$，于是 $f(x) = -f(-x) = -x^2 - 2x - 3$；**千万注意常数项 $+3$ 也要随整体变号成 $-3$**，而且千万不要写 $f(0) = 0^2 - 2(0) + 3 = 3$，因为在 $x = 0$ 处若为定义在 $\mathbb{R}$ 上的奇函数，必须强行由 $f(0)=0$ 孤立分段（此时函数在 $x=0$ 处存在跳跃断点）。
3. **多参数幂指偶函数“系数凑奇偶”陷阱**：
   如 $f(x) = a\cdot 2^x + 2^{-x}$ 为偶函数，直接代入特殊值 $f(-1) = f(1)$ 虽能秒解 $a = 1$，但严格考题一定要加上验证 $a = 1$ 时确对一切 $x$ 有 $f(-x) = f(x)$（特殊点只是必要条件，需防出现无效参数使分子分母恒零等病态情况）。

### 变式追问

1. 已知定义在 $\mathbb{R}$ 上的偶函数 $f(x)$ 在 $x \ge 0$ 时为 $f(x) = x^2 - 4x$，在 $x < 0$ 时解析式里的常数项还是零，但如果换成奇函数且 $x > 0$ 时是 $x^2 - 4x + 1$，在写出全部三段解析式时哪一段必须单独成一行？
2. 为什么函数 $f(x) = \lg(1 - x) - \lg(1 + x)$ 的定义域虽然不是 $\mathbb{R}$，却依然满足奇函数定义？如果题目把两项中间的减号改成加号 $g(x) = \lg(1-x) + \lg(1+x)$，函数变成什么奇偶性？
