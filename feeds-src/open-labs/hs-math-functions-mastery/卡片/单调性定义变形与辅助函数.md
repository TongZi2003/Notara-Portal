# 单调性定义变形与辅助函数

## 内容

高一中难题常常不会直接告诉你“$f(x)$ 单调递增”，而是把单调性定义 $\frac{f(x_1) - f(x_2)}{x_1 - x_2} > 0$ 进行移项、同乘除或叠加一个线性项之后再给出，需要你一眼把变形拆回某个新辅助函数 $g(x)$ 的单调性。

### 1. 五类核心定义变形识别字典

设对区间 $I$ 上任意不相等的 $x_1, x_2$ 成立（以下全部用纯代数定义拆解）：

| 题干给出不等式条件 | 等价变形动作 | 隐藏的辅助单调函数 $g(x)$ |
| :--- | :--- | :--- |
| $\dfrac{f(x_1) - f(x_2)}{x_1 - x_2} > k$ | 改写为 $\dfrac{[f(x_1)-kx_1] - [f(x_2)-kx_2]}{x_1 - x_2} > 0$ | $g(x) = f(x) - kx$ 在 $I$ 上**递增** |
| $\dfrac{x_1 f(x_1) - x_2 f(x_2)}{x_1 - x_2} > 0$ | 分子分母同号相除，直接等价于两项同序 | $g(x) = x f(x)$ 在 $I$ 上**递增** |
| $\dfrac{x_2 f(x_1) - x_1 f(x_2)}{x_1 - x_2} > 0$（且 $I \subseteq (0, +\infty)$） | 两边同乘（或拆成）$\dfrac{\frac{f(x_1)}{x_1} - \frac{f(x_2)}{x_2}}{x_1 - x_2} \cdot x_1 x_2$ 核对正号 | $g(x) = \dfrac{f(x)}{x}$ 在 $I \subseteq (0, +\infty)$ 上**递增**（$I$ 跨异号区须格外小心） |
| $x_1 f(x_1) + x_2 f(x_2) > x_1 f(x_2) + x_2 f(x_1)$ | 移项分解因式：$(x_1 - x_2)\bigl[f(x_1) - f(x_2)\bigr] > 0$ | $f(x)$ 本身在 $I$ 上**递增**（因两括号同号） |
| $a^{x_1} f(x_1) > a^{x_2} f(x_2)$（仅知单边条件或移项后） | 当 $x_1 > x_2$ 时，直接观察括号下标完全配对 | $g(x) = a^x f(x)$（或若写成 $a^{-x_1} f(x_1)$ 则构造 $\frac{f(x)}{a^x}$）单增 |

### 2. 解题三步流程

1. **配对归边**：把含有 $x_1$ 的项全挪到同侧、含有 $x_2$ 的项全挪到另一侧，或拆解分式差商；
2. **命名新函数 $g(x)$ 并补奇偶性**：观察 $g(x)$ 在 $(0, +\infty)$ 单调后，若还要处理负自变量，务必依据原 $f(x)$ 的奇偶性推算 $g(x)$ 是奇还是偶（如“奇 $\times$ 奇 $=$ 偶”，“奇 $\div$ 奇 $=$ 偶”，“奇函数减 $kx$ 仍为奇函数”）；
3. **回代脱壳**：把题干最终要求解的不等式改写成 $g(u) > g(v)$ 形式，联合单调性与奇偶性解出范围。

## 参考理解

### 高频易错与原位核验警报

1. **交叉项提公因式时的“同除 $x_1 x_2$ 漏验正负”陷阱**：
   看第三行模型 $x_2 f(x_1) - x_1 f(x_2) > 0\ (x_1 > x_2)$：要变成 $\frac{f(x_1)}{x_1} > \frac{f(x_2)}{x_2}$，需要同除以 $x_1 x_2$。
   - 若限定在 $(0, +\infty)$ 或 $(-\infty, 0)$ 的**同一侧**，$x_1 x_2 > 0$ 不变号，确实得 $g(x) = \frac{f(x)}{x}$ 递增；
   - 如果一正一负（如 $x_1 > 0 > x_2$），$x_1 x_2 < 0$ **乘除必反号**。所以永远只在已知同号区间内构造 $\frac{f(x)}{x}$ 的单调性，越过原点另一侧改用奇偶性推导对称图像，绝对不能一条线通吃 $(-\infty, +\infty)$，而且 $x=0$ 处不在 $\frac{f(x)}{x}$ 定义域内，最后一定要单独代入检验不等式对不对。
2. **先看下标对称性，再配系数**：
   遇到题干求 $f(2m - 1) - 3m > 2f(1) + \dots$ 时，哪怕一时没看出单调变形条件里的常数 $k$，也可以反向从“所求不等式右边缺什么能与左边凑出统一结构 $g(\text{表达式})$”倒推出 $k$ 或分母结构，两者互相印证几乎不会猜错。

### 变式追问

1. 已知定义在 $\mathbb{R}$ 上的偶函数 $f(x)$ 对任意 $0 < x_1 < x_2$ 满足 $\frac{x_1 f(x_1) - x_2 f(x_2)}{x_1 - x_2} < 0$，那么 $g(x) = xf(x)$ 是奇函数还是偶函数？在 $(-\infty, 0)$ 上递增还是递减？解不等式 $a f(a) > (1-a) f(1-a)$ 时，为什么直接脱壳还是分正负讨论更不容易出错？
2. 若奇函数 $f(x)$ 在 $(0, +\infty)$ 上满足 $\frac{f(x_1) - f(x_2)}{x_1 - x_2} > 2$，且 $f(1) = 3$，请写出求 $f(x) > 2x + 1$ 解集时如何在 $x=0$ 与 $x<0$ 两处避免漏解或增解。
