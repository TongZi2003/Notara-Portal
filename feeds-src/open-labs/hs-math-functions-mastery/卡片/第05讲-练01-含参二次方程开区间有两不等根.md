# 第05讲·练01：含参二次方程开区间有两不等根

## 内容

若关于 $x$ 的方程 $x^2 - 2mx + 2m + 3 = 0$ 的两个不相等的实数根都落在区间 $(0, 4)$ 内，则实数 $m$ 的取值范围是（　　）

A. $\left(3, \frac{19}{6}\right)$　　　　B. $\left(-\frac{3}{2}, -1\right) \cup \left(3, \frac{19}{6}\right)$　　　　C. $\left(0, \frac{19}{6}\right)$　　　　D. $\left[3, \frac{19}{6}\right)$

## 参考理解

我们看到题目要求二次方程的两个**不相等**实数根全部落在开区间 $(0, 4)$ 内，先设对应的二次函数为 $f(x) = x^2 - 2mx + 2m + 3$。如果一上来只用韦达定理写 $x_1 + x_2 \in (0, 8)$ 且 $x_1 x_2 \in (0, 16)$，就会很快发现这个必要条件远远不够充分——比如两根之和在 $(0, 8)$、之积在 $(0, 16)$ 时完全可能出现一个根是 $0.5$、另一个根是 $5$ 的越界情形。因此根据[[卡片/二次方程根的分布定参法]]，最稳固的做法是画出“开口向上的抛物线在 $(0, 4)$ 内与 $x$ 轴交出两个不同交点”的草图，直接列出等价充要四要素组。

**为什么草图要求以下四条必须全部联立、一个都不能省？** 我们逐条对照图像排查四个陷阱：
1. **开口方向**：二次项系数为 $1 > 0$，开口向上已固定；
2. **判别式严格大于零**（保有两个**不相等**的实根，防止像选项 D 那样把重根点 $m = 3$ 放进来）：
   $$\Delta = (-2m)^2 - 4(2m + 3) = 4(m^2 - 2m - 3) = 4(m - 3)(m + 1) > 0 \implies m < -1 \text{ 或 } m > 3;$$
3. **对称轴落入区间 $(0, 4)$ 内部**（如果缺了这一条，就会像选项 B 那样放走两条都在 $(0, 4)$ 左侧外面的负根）：
   $$0 < m < 4;$$
4. **左右端点函数值均严格大于零**（保住两根不跨过开区间端点 $0$ 或 $4$）：
   $$f(0) = 2m + 3 > 0 \implies m > -\frac{3}{2},$$
   $$f(4) = 16 - 8m + 2m + 3 = 19 - 6m > 0 \implies m < \frac{19}{6}.$$

现在我们把这四个不等式同时取交集：由对称轴 $0 < m < 4$ 与端点条件 $-\frac{3}{2} < m < \frac{19}{6}$ 先交出 $0 < m < \frac{19}{6}$（注意此时要是漏了 $\Delta > 0$ 就会误选 C）；再与判别式条件 $m < -1$ 或 $m > 3$ 取交集，左侧的 $m < -1$ 被对称轴 $m > 0$ 干净拦截，右侧只剩下：
$$3 < m < \frac{19}{6}.$$

顺手做一次反例验证来巩固直觉：若如选项 B 保留了区间 $\left(-\frac{3}{2}, -1\right)$ 中的 $m = -\frac{5}{4}$，此时方程虽有两不等实根且满足 $f(0) > 0, f(4) > 0$，但对称轴 $x = -\frac{5}{4} < 0$，导致两个根全是负数，一个都不在 $(0, 4)$ 里；若取选项 D 中的端点 $m = 3$，方程变为 $(x - 3)^2 = 0$，两根相等而非“不相等”。综上，实数 $m$ 的取值范围是 $\left(3, \frac{19}{6}\right)$，对应选项 **A**。
