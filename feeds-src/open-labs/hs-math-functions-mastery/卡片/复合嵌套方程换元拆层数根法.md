# 复合嵌套方程换元拆层数根法

## 内容

当方程呈现出内外套娃形态（如 $f\bigl(f(x)\bigr) = c$、$\bigl[f(x)\bigr]^2 + a f(x) + b = 0$ 或 $f\bigl(g(x)\bigr) = 0$），强行把分段解析式往里硬代会生出极其恐怖的四层嵌套讨论；标准解法永远是**令 $t = \text{内层函数}$ 斩断两层联系，化为「外层方程找几个 $t_i$」＋「内层图像按 $y = t_i$ 数交点」的两步流水线**。

### 1. 「拆层计数」双步标准化流程

求解复合方程 $F\bigl(g(x)\bigr) = 0$（包含 $f(f(x))=c$ 与外层为二次式 $A[g(x)]^2 + B g(x) + C = 0$）：

1. **第一层：先解外层 $F(t) = 0$，标定内函数值域 $R_g$**
   令中间变量 $t = g(x)$（写出内函数完整值域 $R_g$），在关于 $t$ 的方程 $F(t) = 0$ 中解出所有**满足 $t_i \in R_g$** 的互异实数根：
   $$t_1 < t_2 < \dots < t_m.$$
   凡是不在内函数值域里的 $t$ 根（例如 $t$ 小于内函数最小值），对应的水平线压根碰不到内曲线，直接剔除。
2. **第二层：在内层图像 $y = g(x)$ 上逐个累加水平线交点数**
   针对每一个有效的 $t_i$，画出水平直线 $y = t_i$ 与内函数 $y = g(x)$ 的图像，记交点个数为 $N(t_i)$。因为各 $t_i$ 互不相等，这些水平直线彼此平行**永不重合**，于是不同 $t_i$ 解出的原自变量 $x$ 绝不重复，总实根数严格等于各层之和：
   $$N_{\text{总}} = \sum_{i=1}^m N(t_i).$$

### 2. 「已知总根数反求外层参数」：交点个数分解与二次根分布法

这是高一最拉分的压轴题型（典型题目：已知分段函数 $g(x)$，求方程 $[g(x)]^2 - a g(x) + b = 0$ 恰有 $5$ 个不同实数根时参数范围）：
1. **给内函数 $y = g(x)$ 画「高度—交点个数分界表」**：
   先画出精确草图（标实心点、空心点、渐近线、翻折峰顶），从下到上写清不同高度区间里的 $N(t)$，比如：
   - $t < 0 \implies N(t) = 0$；
   - $t = 0 \implies N(t) = 2$；
   - $0 < t < 1 \implies N(t) = 4$；
   - $t = 1 \implies N(t) = 3$；
   - $t > 1 \implies N(t) = 1$。
2. **列出总根数的全部合法加和分解**：
   既然外层是二次方程（最多给出 $2$ 个不同的 $t_1, t_2$），要让 $N(t_1) + N(t_2) = 5$，对照交点个数表看 $5$ 能怎么由表里数字相加出来：
   - 若可以分解成 $4 + 1$：需外层一个根落在 $(0, 1)$ 内（贡献 $4$ 个 $x$），另一个根落在 $(1, +\infty)$ 内（贡献 $1$ 个 $x$）；
   - 若可以分解成 $2 + 3$：需两根恰为 $t_1 = 0$ 与 $t_2 = 1$（**重点查漏**：直接代两根看外层参数是否相容）；
   - （若是重根 $t_1 = t_2$，只画一条水平线，只能贡献单组 $N(t_1)$，必须注意重根只能算一次）。
3. **交接二次方程根的分布求解**：
   把每个合理解分解对应到二次方程 $t^2 - at + b = 0$ 在区间上的根分布问题（必要时直接按韦达定理或二次端点函数值符号联立）。

## 参考理解

### 高频易错生死线

1. **「二次重根只算一条水平线，不可双倍计数」**：
   假设外层二次方程 $t^2 - 4t + 4 = 0$ 判别式 $\Delta = 0$，解出重根 $t_1 = t_2 = 2$。由于两条水平线重合成了同一条 $y = 2$，它对总实根数的贡献只有 **$1 \times N(2)$**，绝对不是 $2 N(2)$。因此讨论 $N_{\text{总}}$ 时，永远先按外层“$\Delta > 0$（两个不同实根 $t_1 < t_2$）”与“$\Delta = 0$（唯一重根 $t_0$）”严格分开讨论。
2. **忘记检验「交点个数变化恰好在边界高度的点」**：
   很多同学只看开区间拆法（比如 $5 = 4 + 1$ 对应 $(0,1)$ 和 $(1,+\infty)$），漏掉 $5 = 2 + 3$ 这种让两根恰好踩在边界高度 $t_1 = 0, t_2 = 1$ 的孤立点解，或者漏掉“一根踩边界、一根落区间外（贡献 $0$ 根）”如 $4 = 4 + 0$ 的情形。只要表里有 `0`, `1`, `2`, `3`, `4` 这几个输出值，**包括 $+0$ 在内的所有整数加和组合都必须在草稿纸上一一划掉核验一遍**。

### 变式追问

1. 已知函数 $f(x) = \begin{cases} |x+1|, & x \le 0, \\ \log_2 x, & x > 0, \end{cases}$ 先从下往上写出 $y = t$ 的全部交点个数表，再判断当关于 $t$ 的方程 $t^2 - m t + 1 = 0$ 要使得嵌套方程 $f^2(x) - mf(x) + 1 = 0$ 恰有 $3$ 个不同实数根时，$t_1, t_2$ 的乘积 $t_1 t_2 = 1$ 会把哪些看似可行的加和分解瞬间锁定？
2. 当外层函数与内层函数**是同一个函数 $f$**（即 $f(f(x)) = c$，且 $f$ 带绝对值翻折时），为什么不能简单说 $f(x) = t_i$ 的零点一定全是单向叠加，还需要注意哪项参数联动变化？
