# 第04讲·例1：含参二次函数闭区间最值与差

## 内容

已知函数 $f(x) = x^2 - 2ax + 3$（$a \in \mathbb{R}$），在闭区间 $[-1, 1]$ 上的最小值记为 $m(a)$，最大值记为 $M(a)$。

(1) 分别写出 $m(a)$ 与 $M(a)$ 关于 $a$ 的分段函数解析式；

(2) 记最值之差 $g(a) = M(a) - m(a)$，写出 $g(a)$ 的分段表达式，并求 $g(a)$ 的最小值。

## 参考理解

**(1)** 我们看到这是一个二次项系数为正的含参二次函数，闭区间 $[-1, 1]$ 是固定的，而对称轴 $x = a$ 会随着参数 $a$ 左右移动，属于典型的「动轴定区间」模型。面对这种题目，最忌讳还没分清问的是最小值还是最大值就统一套用同一个分段标准；更稳妥的做法是先把解析式配方，把顶点和端点值都摆到明面上：
$$f(x) = (x - a)^2 + 3 - a^2,$$
左端点值为 $f(-1) = 1 + 2a + 3 = 2a + 4$，右端点值为 $f(1) = 1 - 2a + 3 = 4 - 2a$，顶点纵坐标为 $f(a) = 3 - a^2$。

**为什么我们求最小值 $m(a)$ 要按左端点 $-1$ 和右端点 $1$ 分成三段，而求最大值 $M(a)$ 却只看中点 $0$ 分成两段？** 根据[[卡片/含参二次函数动轴与区间最值]]，因为抛物线开口向上，图像离对称轴越近越低、越远越高。求最小值时，只要顶点 $x = a$ 落入 $[-1, 1]$ 内部就能取到最低谷 $f(a)$，顶点跑出区间外则在更靠近对称轴的那个端点取到最小值，因此对称轴 $x = a$ 与左右端点 $-1, 1$ 的相对位置自然切出三段：
- 当 $a \le -1$ 时，对称轴在区间左侧，$f(x)$ 在 $[-1, 1]$ 上单调递增，故 $m(a) = f(-1) = 2a + 4$；
- 当 $-1 < a < 1$ 时，顶点落入区间内部，故 $m(a) = f(a) = 3 - a^2$；
- 当 $a \ge 1$ 时，对称轴在区间右侧，$f(x)$ 在 $[-1, 1]$ 上单调递减，故 $m(a) = f(1) = 4 - 2a$。

而求最大值时，开口向上的抛物线在闭区间上的最大值必定在两个端点 $-1$ 或 $1$ 中产生，只需比较谁离对称轴 $x = a$ 更远即可，分界线正是区间 $[-1, 1]$ 的中点 $x = \frac{-1 + 1}{2} = 0$：
- 当 $a \le 0$ 时，对称轴在中点 $0$ 左侧（或与中点重合），右端点 $1$ 距离对称轴更远（或两端点等距同高），故 $M(a) = f(1) = 4 - 2a$；
- 当 $a > 0$ 时，对称轴在中点 $0$ 右侧，左端点 $-1$ 距离对称轴更远，故 $M(a) = f(-1) = 2a + 4$。

在进入第二问前，我们可以随手核对一下分界点的衔接：在 $a = \pm 1$ 处，$m(a)$ 左右两段均等于 $2$；在 $a = 0$ 处，$M(a)$ 左右两段均等于 $4$，说明没有算错任何一项符号。

**(2)** 接下来求最值之差 $g(a) = M(a) - m(a)$。**为什么我们不能直接按三段去相减，而必须先取分界点并集拆成四段？** 很多同学容易把 $m(a)$ 的三段直接拿来用，结果到了中间段 $-1 < a < 1$ 里才发现 $M(a)$ 在 $a = 0$ 处已经悄悄从 $f(1)$ 切换成了 $f(-1)$，漏切这一刀就会导致中间两段合并出错。根据[[卡片/含参二次函数动轴与区间最值]]与[[卡片/分段函数单调衔接与取大取小]]，$m(a)$ 的分界点是 $-1, 1$，$M(a)$ 的分界点是 $0$，三者取并集把实数轴切成四段，我们逐段作差并简化：
- 当 $a \le -1$ 时，$g(a) = (4 - 2a) - (2a + 4) = -4a$；
- 当 $-1 < a \le 0$ 时，$g(a) = (4 - 2a) - (3 - a^2) = a^2 - 2a + 1 = (a - 1)^2$；
- 当 $0 < a < 1$ 时，$g(a) = (2a + 4) - (3 - a^2) = a^2 + 2a + 1 = (a + 1)^2$；
- 当 $a \ge 1$ 时，$g(a) = (2a + 4) - (4 - 2a) = 4a$。

核对各分界点衔接：$g(-1) = 4$，$(a-1)^2$ 在 $a \to -1^+$ 时趋于 $4$；$g(0) = 1$，$(a+1)^2$ 在 $a \to 0^+$ 时趋于 $1$；$g(1) = 4$，$(a+1)^2$ 在 $a \to 1^-$ 时趋于 $4$。四段不仅完全连续，而且每一段的单调性都一目了然：
- 在 $(-\infty, -1]$ 上，$g(a) = -4a$ 单调递减，最小值为 $g(-1) = 4$；
- 在 $(-1, 0]$ 上，$g(a) = (a - 1)^2$ 的对称轴 $a = 1$ 在区间右侧，因此在该区间上严格单调递减，最小值为右端点值 $g(0) = (0 - 1)^2 = 1$；
- 在 $(0, 1)$ 上，$g(a) = (a + 1)^2$ 的对称轴 $a = -1$ 在区间左侧，因此在该区间上严格单调递增，函数值满足 $1 < g(a) < 4$；
- 在 $[1, +\infty)$ 上，$g(a) = 4a$ 单调递增，最小值为 $g(1) = 4$。

从几何直觉上也能立刻印证这一结论：当 $a = 0$ 时，抛物线 $f(x) = x^2 + 3$ 恰好以 $[-1, 1]$ 的中点为对称轴，此时两端点齐平、浪费的高度落差最小；一旦对称轴向左或向右偏离中点，一侧端点就会迅速抬高，使最值之差严格增大。综上，$g(a)$ 的最小值为 **$1$**（在 $a = 0$ 处取得）。
