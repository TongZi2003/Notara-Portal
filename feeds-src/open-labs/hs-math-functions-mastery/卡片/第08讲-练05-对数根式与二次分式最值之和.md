# 第08讲·练05：对数根式与二次分式最值之和

## 内容

已知函数
$$f(x) = \ln\left(\sqrt{x^2 + 25} + x\right) + \frac{3x^2 + 7x + 3}{x^2 + 1}$$
在闭区间 $[-5, 5]$ 上的最大值为 $M$，最小值为 $m$，则 $M + m =$ $\underline{\hspace{5em}}$。

## 参考理解

我们拿到这道题时，一眼就能看出它和标准的“奇函数 $+$ 常数”求最值和问题长得几乎一模一样。但恰恰因为太眼熟，很多同学看一眼 $\ln\left(\sqrt{x^2 + 25} + x\right)$ 就凭记忆脱口而出“根式对数是奇函数”，接着把后面的假分式一拆成 $3 + \frac{7x}{x^2 + 1}$，便自信地填上 $M + m = 6$——这就正中了这道题的双重埋伏。

根据[[卡片/奇偶加常数与中心对称指对模型]]的破题准则：**看不准里面藏了多少常数时，绝对不要凭印象“盲认奇函数”，老老实实先算一遍 $f(x) + f(-x)$ 才是唯一保险的办法。**

首先确认函数在 $[-5, 5]$ 上处处有定义且连续：对任意 $x \in \mathbb{R}$，均有 $\sqrt{x^2 + 25} > \sqrt{x^2} = |x| \ge -x$，所以真数 $\sqrt{x^2 + 25} + x > 0$ 恒成立，分母 $x^2 + 1 \ge 1 > 0$ 也恒成立，故函数在闭区间 $[-5, 5]$ 上必然连续且存在最大值 $M$ 和最小值 $m$。

接着我们来逐项计算 $f(x) + f(-x)$：
- 先算根式对数部分：
  $$\ln\left(\sqrt{x^2 + 25} + x\right) + \ln\left(\sqrt{x^2 + 25} - x\right) = \ln\Bigl[\left(\sqrt{x^2 + 25} + x\right)\left(\sqrt{x^2 + 25} - x\right)\Bigr] = \ln\bigl((x^2 + 25) - x^2\bigr) = \ln 25 = 2\ln 5.$$
  看吧，正是因为根号里的常数是 $25$ 而不是 $1$，它互反相乘后剩下的不是 $1$ 而是 $25$，所以它本质上是奇函数 $\ln\left(\sqrt{\left(\frac{x}{5}\right)^2 + 1} + \frac{x}{5}\right)$ 加上了常数 $\ln 5$，两倍和便多出了 $2\ln 5$。
- 再算二次假分式部分（直接配对相加甚至比拆项更快，当然也可以分子降次写成 $\frac{3(x^2+1)+7x}{x^2+1} = 3 + \frac{7x}{x^2+1}$）：
  $$\frac{3x^2 + 7x + 3}{x^2 + 1} + \frac{3x^2 - 7x + 3}{x^2 + 1} = \frac{6x^2 + 6}{x^2 + 1} = 6.$$

把两部分结果合并，对任意 $x \in [-5, 5]$ 恒有
$$f(x) + f(-x) = 6 + 2\ln 5.$$
设对称中心纵坐标 $C = 3 + \ln 5$，构造函数 $g(x) = f(x) - (3 + \ln 5)$，则对任意 $x \in [-5, 5]$ 有
$$g(x) + g(-x) = f(x) + f(-x) - (6 + 2\ln 5) = 0,$$
即 $g(x)$ 是闭区间 $[-5, 5]$ 上的奇函数。因此 $g(x)$ 在 $[-5, 5]$ 上的最大值与最小值互为相反数，即
$$\bigl[M - (3 + \ln 5)\bigr] + \bigl[m - (3 + \ln 5)\bigr] = 0,$$
从而立即得到 $M + m = 6 + 2\ln 5$（写成 $6 + \ln 25$ 亦等价，化为 $6 + 2\ln 5$ 最简）。
