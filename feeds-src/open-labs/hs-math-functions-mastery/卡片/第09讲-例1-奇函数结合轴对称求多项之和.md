# 第09讲·例1：奇函数结合轴对称求多项之和

## 内容

已知定义在 $\mathbb{R}$ 上的奇函数 $f(x)$ 满足 $f(2 - x) = f(x)$，且当 $x \in [0, 1]$ 时，$f(x) = 2^x - 1$。记 $S = f(1) + f(2) + f(3) + \dots + f(2025)$，则 $f(2025.5) + S$ 的值为（　　）

A. $\sqrt{2} - 1$　　　　B. $\sqrt{2}$　　　　C. $\sqrt{2} + 1$　　　　D. $2 - \sqrt{2}$

我们面对这类把“奇偶性”“某个对称等式”“大自变量求值”和“两千多项求和”捆在一起的母题时，容易犯两个习惯性错误：第一，只把 $2025.5$ 往周期里拽，落在 $[1, 2]$ 区间上时发现没给这个区间的解析式，于是不管三七二十一直接代入 $2^x - 1$ 算成 $2^{1.5} - 1$；第二，算前 $2025$ 项整数和时，算出一个周期和为 $0$ 就以为总和直接是 $0$，忘了余数留下的最后一项 $f(2025)$。

**为什么我们先不背“一轴一心周期为 $4|a - b|$”的口诀，而是亲自写两行代换验证周期？** 根据[[卡片/双对称推导周期性与求值法]]，考场上写两行代换只需几秒钟，不仅不会把 $2|a-b|$ 和 $4|a-b|$ 背反，还能顺手抓出半周期反号式子。具体来说，因为 $f(x)$ 是 $\mathbb{R}$ 上的奇函数，所以 $f(-x) = -f(x)$ 且 $f(0) = 0$（核对已知分段 $[0, 1]$ 在 $x = 0$ 处恰有 $2^0 - 1 = 0$，拼接自洽）。再结合 $f(2 - x) = f(x)$（即关于直线 $x = 1$ 对称），用 $-x$ 替换 $2 - x$ 中的 $x$ 得：
$$f(2 + x) = f\bigl(2 - (-x)\bigr) = f(-x) = -f(x).$$
记下这个半周期反号式后，把 $x$ 再换成 $x + 2$ 推进半个周期：
$$f(x + 4) = -f(x + 2) = -\bigl[-f(x)\bigr] = f(x).$$
由此严格确认函数 $f(x)$ 的一个周期是 **$T = 4$**。

接下来我们先计算 $f(2025.5)$。因为 $2025.5 = 4 \times 506 + 1.5$，按周期 $4$ 缩小自变量得到：
$$f(2025.5) = f(1.5).$$
此时务必警醒：$1.5$ 落在 $(1, 2]$ 内，并不在题干给解析式的 $[0, 1]$ 区间里，不能直接套 $2^x - 1$。我们必须利用对称条件 $f(2 - x) = f(x)$ 把自变量从 $[1, 2]$ 反射回 $[0, 1]$：
$$f(1.5) = f(2 - 1.5) = f(0.5).$$
（也可以用半周期反号配合奇函数检验：$f(1.5) = -f(-0.5) = f(0.5)$，两种路径结果完全吻合。）现在 $0.5 \in [0, 1]$，终于可以放心代入解析式 $f(x) = 2^x - 1$：
$$f(0.5) = 2^{0.5} - 1 = \sqrt{2} - 1.$$

接着我们计算 $S = f(1) + f(2) + f(3) + \dots + f(2025)$。先求出一个完整周期内的四个连续整数点函数值：
- $f(1) = 2^1 - 1 = 1$；
- $f(2) = -f(0) = 0$（由 $f(x+2) = -f(x)$ 取 $x = 0$，或由对称轴 $f(2) = f(0) = 0$）；
- $f(3) = f(2 - 3) = f(-1) = -f(1) = -1$；
- $f(4) = f(0) = 0$。

因此任意连续四个整数点之和恒为 $f(1) + f(2) + f(3) + f(4) = 1 + 0 + (-1) + 0 = 0$。再将总项数 $2025$ 对周期 $4$ 做带余除法：$2025 = 4 \times 506 + 1$。这说明前 $2024$ 项恰好凑成 $506$ 个完整周期，它们的总和为 $0$，而末尾单独余下第 $2025$ 项：
$$S = 506 \times 0 + f(2025) = f(1) = 1.$$

最后把两部分加在一起：$f(2025.5) + S = (\sqrt{2} - 1) + 1 = \sqrt{2}$。对照选项，若忘记加上末尾余项 $f(1) = 1$ 就会错选 A，若求 $f(1.5)$ 时弄错对称负号变成 $1 - \sqrt{2}$ 再加上 $1$ 就会错选 D，唯有步步核实才能稳稳选出 **B**。
