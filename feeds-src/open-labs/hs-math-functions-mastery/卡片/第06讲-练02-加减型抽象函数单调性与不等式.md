# 第06讲·练02：加减型抽象函数单调性与不等式

## 内容

已知定义在 $\mathbb{R}$ 上的函数 $f(x)$ 对任意实数 $x, y$ 均满足 $f(x + y) = f(x) + f(y) - 2$，且当 $x > 0$ 时，$f(x) < 2$。若 $f(2) = 0$，

(1) 求 $f(0)$ 的值，并用单调性的定义证明 $f(x)$ 在 $\mathbb{R}$ 上单调递减；

(2) 求不等式 $f(x^2 - 2x) + f(x) > 2$ 的解集。

## 参考理解

**(1)** 面对没有给出具体解析式的抽象函数，我们的第一直觉可能是先靠猜出一个具体函数原型来探路：从 $f(x + y) = f(x) + f(y) - 2$ 联想到带常数偏移的一次函数 $f(x) = kx + 2$，再由 $x > 0$ 时 $f(x) < 2$ 以及 $f(2) = 0$ 很快就能猜出原型 $f(x) = -x + 2$。虽然具体原型能帮我们瞬间预判答案，但**原型探路只能校验方向，绝不能替代严格推理**，解答过程必须完全基于题干恒等式推进。

先用赋值法求 $f(0)$：令 $x = y = 0$，代入已知关系式得
$$f(0 + 0) = f(0) + f(0) - 2 \implies f(0) = 2f(0) - 2 \implies f(0) = 2.$$
接下来用定义证明单调性。按照[[卡片/单调性定义证明与抽象单调]]中“加和带常数型”的配凑技巧，任取 $x_1, x_2 \in \mathbb{R}$ 且 $x_1 < x_2$。手头只有加法方程，怎么把 $f(x_2) - f(x_1)$ 与“$x > 0$ 时 $f(x) < 2$”联系起来？**核心动作是把较大自变量 $x_2$ 拆成较小自变量 $x_1$ 与正差值 $(x_2 - x_1)$ 的和**。因为 $x_2 - x_1 > 0$，套用题干方程得：
$$f(x_2) = f\bigl(x_1 + (x_2 - x_1)\bigr) = f(x_1) + f(x_2 - x_1) - 2.$$
把 $f(x_1)$ 移到左边，得到差值表达式：
$$f(x_2) - f(x_1) = f(x_2 - x_1) - 2.$$
因为 $x_2 - x_1 > 0$，由已知条件 $x > 0$ 时 $f(x) < 2$，得 $f(x_2 - x_1) < 2$，即 $f(x_2 - x_1) - 2 < 0$。于是 $f(x_2) - f(x_1) < 0$，即 $f(x_1) > f(x_2)$。因此，$f(x)$ 在 $\mathbb{R}$ 上单调递减。

**(2)** 来看不等式 $f(x^2 - 2x) + f(x) > 2$。这里最容易出现的错误分支是直接忽略式子里的常数 $-2$：有同学看到左边是两个 $f$ 相加，就顺手误写成 $f(x^2 - x) > 2$，接着把 $2$ 替换成 $f(0)$，算出错误不等式 $x^2 - x < 0$。

**为什么不能直接合并成 $f(x^2 - x)$？** 对照原方程 $f(u) + f(v) - 2 = f(u + v)$，两个 $f$ 相加之后还必须跟着一个**减 $2$**，才能安全合拢成单个函数值。正好不等号右边本来就站着一个常数 $2$，只要把右边的 $2$ 移到左边变成 $-2$，两边同时完成了两件关键对齐工作：
$$f(x^2 - 2x) + f(x) - 2 > 0.$$
左边利用恒等式合并：令 $u = x^2 - 2x$、$v = x$，则
$$f(x^2 - 2x) + f(x) - 2 = f\bigl((x^2 - 2x) + x\bigr) = f(x^2 - x).$$
右边原本的 $2$ 移走后只剩 $0$，而题干恰好给了条件 $f(2) = 0$（注意千万不要把 $0$ 误看成自变量再拿 $f(0) = 2$ 去套）。于是整个不等式严丝合缝地改写为：
$$f(x^2 - x) > f(2).$$
由第 (1) 问已证得 $f(x)$ 在 $\mathbb{R}$ 上单调递减，脱去外层 $f$ 符号时不等号必须反向，得：
$$x^2 - x < 2 \iff x^2 - x - 2 < 0 \iff (x - 2)(x + 1) < 0 \iff -1 < x < 2.$$
回到开头我们用原型 $f(x) = 2 - x$ 验算一遍：$(2 - x^2 + 2x) + (2 - x) > 2 \iff x^2 - x - 2 < 0$，解集完全吻合。故原不等式的解集为 $(-1, 2)$。
