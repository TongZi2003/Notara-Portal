# 第19讲·练05：闭区间有界二次函数系数和最值

## 内容

对于二次型函数 $f(x) = ax^2 + bx + c$（$a, b, c \in \mathbb{R}$），若对任意 $x \in [-1, 1]$ 恒有 $|f(x)| \le 1$，则称 $f(x)$ 为“$[-1, 1]$-有界函数”，记它的系数绝对值之和为 $S(f) = |a| + |b| + |c|$。

(1) 判断函数 $f_1(x) = 2x^2 - 1$ 与 $f_2(x) = x^2 + x - 1$ 是否为“$[-1, 1]$-有界函数”，若是，求出对应的 $S(f_i)$；

(2) 对任意“$[-1, 1]$-有界函数” $f(x) = ax^2 + bx + c$，求 $S(f)$ 的最大值。

## 参考理解

**(1)** 我们先看第 (1) 问的两个具体函数，这一问不仅是在热身检验新定义，还暗藏着理解第 (2) 问全部玄机的两枚路标：
- 对于 $f_1(x) = 2x^2 - 1$：当 $x \in [-1, 1]$ 时，$x^2 \in [0, 1]$，于是 $2x^2 - 1 \in [-1, 1]$，即对一切 $x \in [-1, 1]$ 恒有 $|f_1(x)| \le 1$，故 **$f_1(x)$ 是“$[-1, 1]$-有界函数”**。此时 $a = 2,\ b = 0,\ c = -1$，所以
  $$S(f_1) = |2| + |0| + |-1| = 3.$$
- 对于 $f_2(x) = x^2 + x - 1$：如果我们偷懒只试算一下端点与中点，$f_2(-1) = -1$、$f_2(0) = -1$、$f_2(1) = 1$，绝对值全都不超过 $1$；但千万别就此下结论，配方看它对称轴处的真实取值：$f_2(x) = \left(x + \frac{1}{2}\right)^2 - \frac{5}{4}$，顶点 $x = -\frac{1}{2} \in [-1, 1]$，在此处 $\left|f_2\left(-\frac{1}{2}\right)\right| = \left|-\frac{5}{4}\right| = \frac{5}{4} > 1$。因此 **$f_2(x)$ 不是“$[-1, 1]$-有界函数”**。

**(2)** 既然第 (1) 问已经给出了一个合法例子 $f_1(x)$ 达到 $S(f_1) = 3$，我们自然猜想 $S(f)$ 的最大值就是 $3$。但为什么三点赋值探路时，若不讲究配对技巧就会白白放宽出一个“假上界 $4$”？这正是本题最值得深挖的地方。

**第一步：用三特征点 $x = -1, 0, 1$ 反解系数 $a, b, c$**。
依据[[卡片/必要性探路缩界与充分性回代]]，任何“$[-1, 1]$-有界函数”都必然满足 $|f(-1)| \le 1,\ |f(0)| \le 1,\ |f(1)| \le 1$。写出三点关系式：
$$\begin{cases} f(1) = a + b + c, \\ f(0) = c, \\ f(-1) = a - b + c. \end{cases}$$
由此可以把三个未知系数 $a, b, c$ 完全线性地反解出来：
$$a = \frac{f(1) + f(-1)}{2} - f(0), \qquad b = \frac{f(1) - f(-1)}{2}, \qquad c = f(0).$$

**第二步：为什么直接逐项放缩会误得出 $4$，而配对合并能把上界压到 $3$？**
如果我们机械地对 $|a|, |b|, |c|$ 分别各自用绝对值三角不等式：$|a| \le \frac{|f(1)| + |f(-1)|}{2} + |f(0)| \le 2$，$|b| \le 1$，$|c| \le 1$，相加会得到一个松散的假上界 $2 + 1 + 1 = 4$。之所以取不到 $4$，是因为要让 $|a| = 2$ 需要 $f(1) = f(-1) = \pm 1$（同号），而要让 $|b| = 1$ 却要求 $f(1) = -f(-1) = \pm 1$（异号），两个取等条件互相打架。

为了消除这种虚高，我们直接利用初等恒等式：对任意两个实数 $u, v$，总有
$$|u + v| + |u - v| = 2\max\{|u|, |v|\}$$
（只需分 $u, v$ 同号与异号核对即明：若同号或有零，$|u + v| + |u - v| = (|u| + |v|) + ||u| - |v|| = 2\max\{|u|, |v|\}$；若异号，$|u + v| + |u - v| = ||u| - |v|| + (|u| + |v|) = 2\max\{|u|, |v|\}$）。

将这一恒等式套用到 $u = f(1),\ v = f(-1)$ 上，配合[[卡片/含参绝对值最值与闭区间逼近]]中的三角不等式，先把 $|a|$ 拆开再与 $|b|$ 配对合并：
$$\begin{aligned}
S(f) &= |a| + |b| + |c| \\
&= \left|\frac{f(1) + f(-1)}{2} - f(0)\right| + \left|\frac{f(1) - f(-1)}{2}\right| + |f(0)| \\
&\le \left(\frac{|f(1) + f(-1)|}{2} + |f(0)|\right) + \frac{|f(1) - f(-1)|}{2} + |f(0)| \\
&= \frac{|f(1) + f(-1)| + |f(1) - f(-1)|}{2} + 2|f(0)| \\
&= \max\{|f(1)|, |f(-1)|\} + 2|f(0)|.
\end{aligned}$$
因为 $f$ 是“$[-1, 1]$-有界函数”，必有 $|f(1)| \le 1,\ |f(-1)| \le 1,\ |f(0)| \le 1$，从而 $\max\{|f(1)|, |f(-1)|\} \le 1$，于是得到最小上界：
$$S(f) \le 1 + 2 \times 1 = 3.$$

**第三步：充分性回代验证最大值确实可达**。
由第 (1) 问已经严格验证，具体函数 $f_1(x) = 2x^2 - 1$ 对任意 $x \in [-1, 1]$ 均满足 $|f_1(x)| \le 1$，是合法的“$[-1, 1]$-有界函数”，且 $S(f_1) = 3$。综上所述，$S(f)$ 的最大值为 **$3$**。
