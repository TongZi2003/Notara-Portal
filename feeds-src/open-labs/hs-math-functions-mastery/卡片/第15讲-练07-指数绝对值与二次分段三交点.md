# 第15讲·练07：指数绝对值与二次分段三交点

## 内容

已知函数
$$f(x) = \begin{cases} |2^x - 1|, & x < 2, \\ x^2 - 6x + 10, & x \ge 2. \end{cases}$$
若直线 $y = m$ 与函数 $y = f(x)$ 的图像恰有 $3$ 个不同的交点，则实数 $m$ 的取值范围是（　　）

A. $(1, 2)$　　　　B. $(1, 2]$　　　　C. $[1, 2]$　　　　D. $[1, 2)$

## 参考理解

我们看到四个选项的数字完全一样，都是 $1$ 和 $2$，唯一的区别就是左右端点究竟取开区间还是闭区间。遇到这种题，最怕草草画个大概形状就拍脑袋写“两头都开”或者“两头都闭”：一旦忘记检查左支渐近线 $y = 1$ 能不能取到、或者把分界点 $x = 2$ 处到底哪一段实心哪一段空心搞反，就会在毫厘之间选错。

**为什么我们必须先把两段图像以及分界点的空实心彻底标死？** 按照[[卡片/水平与动直线数形结合定参法]]的作图规范，我们逐段画出 $y = f(x)$ 的图像：
- **左段（$x < 2$）：$y = |2^x - 1|$**
  先画出 $y = 2^x - 1$，再把 $x$ 轴下方（$x < 0$）的部分翻折上来：
  - 当 $x < 0$ 时，解析式为 $y = 1 - 2^x$，当 $x \to -\infty$ 时图像从下方无限逼近**水平渐近线 $y = 1$**（但永远取不到 $1$），在 $(-\infty, 0]$ 上严格递减到尖底 $(0, 0)$；
  - 当 $0 \le x < 2$ 时，解析式为 $y = 2^x - 1$，从 $(0, 0)$ 严格递增，并在右边界 $x = 2$ 处逼近 $2^2 - 1 = 3$。注意左段定义域是 $x < 2$，所以 **$(2, 3)$ 处是空心点**。
- **右段（$x \ge 2$）：$y = x^2 - 6x + 10 = (x - 3)^2 + 1$**
  这是一段开口向上、对称轴为直线 $x = 3$ 的抛物线右半部分：
  - 左端点 $x = 2$ 属于右段，代入得 $f(2) = (2 - 3)^2 + 1 = 2$，因此 **$(2, 2)$ 处是实心点**；
  - 图像从实心点 $(2, 2)$ 向右下降到顶点 $(3, 1)$（因为 $3 > 2$，顶点也在有效图像上），随后在 $[3, +\infty)$ 上单调递增至 $+\infty$，经过 $(4, 2)$、$(3 + \sqrt{2}, 3)$ 等点。

现在我们把水平直线 $y = m$ 从下往上平推扫描，逐一记录每个高度区间及临界高度上的交点个数（左段交点数 $+$ 右段交点数）：

1. 当 $m < 0$ 时：两段均无图像，交点数为 $0 + 0 = 0$；
2. 当 $m = 0$ 时：左段只在 $(0, 0)$ 交出 $1$ 点，右段最低只到 $1$，交点数为 $1 + 0 = 1$；
3. 当 $0 < m < 1$ 时：左段在 $(-\infty, 0)$ 与 $(0, 1)$ 各有 $1$ 个交点，右段无交点，交点数为 $2 + 0 = 2$；
4. **临界校验 $m = 1$**：
   - 在左段（$x < 2$），方程 $|2^x - 1| = 1$ 中，负半轴一侧 $1 - 2^x = 1 \implies 2^x = 0$ **无解**（这正是水平渐近线 $y = 1$ 的阻断作用），只在正半轴一侧有 $2^x - 1 = 1 \implies x = 1$ 这 $1$ 个交点；
   - 在右段（$x \ge 2$），水平线恰好擦过抛物线顶点 $(3, 1)$，只有 $1$ 个交点。
   - 因此 $m = 1$ 时总交点数为 $1 + 1 = 2$ 个，**达不到 $3$ 个**（由此排除选项 C、D）。
5. 当 $1 < m < 2$ 时：
   - 左段只有正半轴支与 $y = m$ 相交（因为渐近线 $y = 1$ 下方的负半轴支高度全低于 $1$），给出 $1$ 个交点（横坐标在 $(1, \log_2 3)$ 内）；
   - 右段从顶点 $(3, 1)$ 向上低于左端点 $(2, 2)$ 的高度，左右两翼对称给出 $2$ 个交点（分别在 $(2, 3)$ 和 $(3, 4)$ 内）。
   - 总交点数为 $1 + 2 = 3$ 个，符合题意。
6. **临界校验 $m = 2$**：
   - 左段 $2^x - 1 = 2 \implies x = \log_2 3 \in (1, 2)$，贡献 $1$ 个交点；
   - 右段方程 $(x - 3)^2 + 1 = 2 \implies x = 2$ 或 $x = 4$。由于右段定义域是 $x \ge 2$，**$(2, 2)$ 是实心点**，所以 $x = 2$ 合法有效，右段依然贡献 $2$ 个交点。
   - 总交点数为 $1 + 2 = 3$ 个，**$m = 2$ 必须保留**（由此排除选项 A）。
7. 当 $2 < m < 3$ 时：左段有 $1$ 个交点，右段只剩下 $(4, +\infty)$ 这一翼的 $1$ 个交点，总共 $1 + 1 = 2$ 个交点；当 $m \ge 3$ 时，左段因为 $(2, 3)$ 空心不再有交点，只剩右段 $1$ 个交点。

综上，直线 $y = m$ 与函数 $y = f(x)$ 的图像恰有 $3$ 个不同交点时，实数 $m$ 的精确取值范围是半开半闭区间 **$(1, 2]$**，正确选项为 **B**。
