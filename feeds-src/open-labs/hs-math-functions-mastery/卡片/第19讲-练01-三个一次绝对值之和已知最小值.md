# 第19讲·练01：三个一次绝对值之和已知最小值

## 内容

已知函数 $f(x) = |x - 1| + |x - 3| + |x - a|$ 的最小值为 $4$，则实数 $a$ 的值是（　　）

A. $-1$　　　　B. $5$　　　　C. $-1$ 或 $5$　　　　D. $1$ 或 $3$

## 参考理解

我们看到三个绝对值相加并且其中一个零点含有未知数 $a$，如果老老实实去绝对值分段写解析式，就必须同时讨论 $a$ 的大小顺序和 $x$ 的所在区间，写起来既长又容易算错。根据[[卡片/含参绝对值最值与闭区间逼近]]，三个绝对值之和 $f(x) = |x - 1| + |x - 3| + |x - a|$ 在数轴上表示动点 $x$ 到三个定点 $1,\ 3,\ a$ 的距离之和。既然项数为奇数（$3$ 项），全局最小值一定在三个零点排好序后居中的那一个（**中位数**）处取得。

**为什么按 $a$ 落在区间 $(-\infty, 1]$、$(1, 3)$ 与 $[3, +\infty)$ 内的三档分类就能确定中位数点？** 我们把参数 $a$ 和两个已知定点 $1,\ 3$ 放在数轴上从小到大排一排：
- **情形一：当 $a \le 1$ 时**，三个零点的顺序是 $a \le 1 < 3$，居中的中位数固定是 **$x = 1$**。因此最小值在 $x = 1$ 处取得：
  $$f(x)_{\min} = f(1) = |1 - 1| + |1 - 3| + |1 - a| = 0 + 2 + (1 - a) = 3 - a.$$
  令 $3 - a = 4$，解得 $a = -1$。核验前提 $a = -1 \le 1$ 成立，保留 **$a = -1$**。
- **情形二：当 $1 < a < 3$ 时**，三个零点的顺序是 $1 < a < 3$，居中的中位数是 **$x = a$**。此时最小值在 $x = a$ 处取得：
  $$f(x)_{\min} = f(a) = (a - 1) + (3 - a) + 0 = 2.$$
  而题设要求最小值为 $4$，因为 $2 \neq 4$，所以此区间内无解。
- **情形三：当 $a \ge 3$ 时**，三个零点的顺序是 $1 < 3 \le a$，居中的中位数固定是 **$x = 3$**。因此最小值在 $x = 3$ 处取得：
  $$f(x)_{\min} = f(3) = (3 - 1) + 0 + (a - 3) = a - 1.$$
  令 $a - 1 = 4$，解得 $a = 5$。核验前提 $a = 5 \ge 3$ 成立，保留 **$a = 5$**。

此外我们还可以换一个直觉视角交叉验证：先把不带参数的前两项看成一个整体，由绝对值三角不等式 $|x - 1| + |x - 3| \ge |(x - 1) - (x - 3)| = 2$（当且仅当 $x \in [1, 3]$ 时取到平底最小值 $2$）。要想加上非负项 $|x - a|$ 后整体最小值能拔高到 $4$，$a$ 绝不能落进平底区间 $[1, 3]$ 内部（否则取 $x = a$ 就会让总和只有 $2$），它必须与平底 $[1, 3]$ 的外边界保持距离 $4 - 2 = 2$，于是向左偏出 $1 - 2 = -1$、向右偏出 $3 + 2 = 5$，两个解恰好关于 $[1, 3]$ 的中心 $x = 2$ 对称。很多同学心算时只想到向右走 $a = 5$ 而漏掉向左的 $a = -1$，白白误选 B。综上，实数 $a$ 的值为 $-1$ 或 $5$，本题选 **C**。

## 学生理解
