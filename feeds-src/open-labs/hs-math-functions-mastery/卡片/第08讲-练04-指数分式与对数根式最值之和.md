# 第08讲·练04：指数分式与对数根式最值之和

## 内容

已知函数
$$f(x) = \frac{3^x}{3^x + 1} + x^3 + \ln\left(\sqrt{x^2 + 1} + x\right) + 4$$
在区间 $[-6, 6]$ 上的最大值为 $M$，最小值为 $m$，则 $M + m$ 的值为（　　）

A. $4$　　　　B. $\dfrac{9}{2}$　　　　C. $8$　　　　D. $9$

## 参考理解

我们看到这个由指数分式、三次幂函数与含根号对数拼在一起的长表达式，同时又要求在闭区间 $[-6, 6]$ 上的最大值 $M$ 与最小值 $m$ 之和。如果试图直接去求函数 $f(x)$ 在 $[-6, 6]$ 上的具体单调性或者算具体端点值，立刻会发现指数项与对数项各自含无理数，根本算不出能消掉的闭式结果；而如果大意地把前面三项都当成奇函数，只把末尾的 $+4$ 看成平移常数，就会算出 $M + m = 2 \times 4 = 8$，一头撞进命题人埋好的选项 C 陷阱里。

**为什么我们不用强行去分别化简每一项，而是直接算一次 $f(x) + f(-x)$？** 根据[[卡片/奇偶加常数与中心对称指对模型]]，在关于原点对称的闭区间 $[-6, 6]$ 上，只要能把 $f(x)$ 写成“奇函数 $g(x)$ $+$ 常数 $C$”的形式，或者直接算出对任意 $x \in [-6, 6]$ 都有 $f(x) + f(-x) = 2C$ 为定值，那么最大值与最小值必然成对出现（若在 $x_0$ 处取最大值 $M$，则同一对称区间内必有 $-x_0$，利用 $f(x) - C$ 的奇性可知 $m = f(-x_0) = 2C - M$），从而立即得到 $M + m = 2C$。

我们按部就班把 $f(x)$ 与 $f(-x)$ 直接相加，逐项检验是否互相抵消或产生隐含常数：
- 第一项指数分式：
  $$\frac{3^x}{3^x + 1} + \frac{3^{-x}}{3^{-x} + 1} = \frac{3^x}{3^x + 1} + \frac{1}{1 + 3^x} = \frac{3^x + 1}{3^x + 1} = 1.$$
  这一项并不等于 $0$，而是悄悄贡献了一个常数 $1$（相当于一个奇函数加上了纵向平移 $\frac{1}{2}$）。
- 第二项三次幂：$x^3 + (-x)^3 = 0$。
- 第三项根式对数：先确认定义域，因为 $\sqrt{x^2 + 1} > |x| \ge -x$ 对一切实数成立，对数真数恒正，定义域包含 $[-6, 6]$。两项相加得
  $$\ln\left(\sqrt{x^2 + 1} + x\right) + \ln\left(\sqrt{x^2 + 1} - x\right) = \ln\Bigl[\bigl(\sqrt{x^2 + 1}\bigr)^2 - x^2\Bigr] = \ln 1 = 0.$$
- 第四项常数：$4 + 4 = 8$。

把四项全部合起来，对任意 $x \in [-6, 6]$ 恒有
$$f(x) + f(-x) = 1 + 0 + 0 + 8 = 9.$$
同时注意 $f(x)$ 的每一部分在 $[-6, 6]$ 上都是连续函数，因此最大值 $M$ 与最小值 $m$ 必然都在 $[-6, 6]$ 上取到。记 $g(x) = f(x) - \frac{9}{2}$，则由上式得 $g(x) + g(-x) = 0$，即 $g(x)$ 是 $[-6, 6]$ 上的奇函数。奇函数在关于原点对称的闭区间上最大值与最小值互为相反数，故 $g_{\max} + g_{\min} = 0$，即
$$\left(M - \frac{9}{2}\right) + \left(m - \frac{9}{2}\right) = 0 \implies M + m = 9.$$
回头看一眼几个干扰项：选项 C（$8$）是漏掉了 $\frac{3^x}{3^x+1}$ 隐含的常数 $\frac{1}{2}$，选项 B（$\frac{9}{2}$）是把对称中心纵坐标 $C = \frac{9}{2}$ 当成了 $M + m = 2C$，选项 A（$4$）则是两处错误叠加。因此正确答案是 **D**。
