# 第16讲·练02：绝对值指数与二次分段四根范围

## 内容

已知函数
$$f(x) = \begin{cases} |3^x - 1|, & x \le 1, \\ -x^2 + 6x - 7, & x > 1. \end{cases}$$
若存在四个互不相等的实数 $x_1 < x_2 < x_3 < x_4$ 满足 $f(x_1) = f(x_2) = f(x_3) = f(x_4)$，则 $3^{x_1 + x_2} + x_3 x_4$ 的取值范围是______。

## 参考理解

我们看到这道题同时出现了指数翻折绝对值和开口向下的抛物线，还要求混合表达式 $3^{x_1 + x_2} + x_3 x_4$ 的取值范围，很容易同时在两个地方出错：第一，做草图时忘了左段存在水平渐近线 $y = 1$ 或者搞错分界点 $x = 1$ 的高度，误把水平线高度定大；第二，好不容易算出目标式关于参数 $t$ 的二次表达式后，盲目把 $t$ 的开区间两端点代进去当作范围（甚至算出两头相等的假象），漏掉二次函数顶点正好落在开区间内部这一决定闭端点的关键一步。

**第一步：严谨作图并确定四根存在的水平截线区间。** 设四个根共同对应的函数值为 $t$，即考察水平直线 $y = t$ 与 $y = f(x)$ 的交点分布。按[[卡片/多零点水平截线对称消元求范围]]，先逐段画清图像高度与空实心断点：
- **左段（$x \le 1$）：$y = |3^x - 1|$**
  - 先画 $y = 3^x - 1$，再把 $x < 0$ 的负值部分沿 $x$ 轴翻折上去，得到 $(-\infty, 0]$ 上由上方的**水平渐近线 $y = 1$**（永远取不到 $1$）单调递减至尖底 $(0, 0)$；
  - 在 $[0, 1]$ 上解析式为 $y = 3^x - 1$，从 $(0, 0)$ 单调递增至**实心右端点 $(1, 2)$**。
  - 因此左段要想与 $y = t$ 产生 $2$ 个交点，高度必须严格限制在 **$0 < t < 1$**（当 $t = 0$ 时只有 $x = 0$ 这 $1$ 点；当 $1 \le t \le 2$ 时由于左翼渐近线 $y = 1$ 的截断，左段也只有 $1$ 个交点）。
- **右段（$x > 1$）：$y = -x^2 + 6x - 7 = -(x - 3)^2 + 2$**
  - 这是一段开口向下、对称轴为直线 $x = 3$ 的抛物线。先检验左侧分界点 $x = 1$ 处的高度：$-(1 - 3)^2 + 2 = -2$，所以 **$(1, -2)$ 为空心点**；
  - 图像从空心点 $(1, -2)$ 向右上方单调递增至顶点 **$(3, 2)$**（因为 $3 > 1$，最高点真落在有效分段内），随后在 $[3, +\infty)$ 上单调递减至 $-\infty$。
  - 因此右段要想与 $y = t$ 产生 $2$ 个交点，高度范围需满足 **$-2 < t < 2$**。

综合左右两段各自都要贡献 $2$ 个交点的要求，取交集 $(0, 1) \cap (-2, 2)$，可知存在四个互异实根的充要条件是水平截线高度严格满足：
$$0 < t < 1.$$
此时四根位置清晰分开：$x_1 < 0 < x_2 < \log_3 2$ 落在左段，而 $1 < x_3 < 3 < x_4 < 5$ 落在右段（我们还可顺手验算临界值：$t = 0$ 时总共只有 $3$ 根，$t = 1$ 时左段剩 $\log_3 2$ 这 $1$ 根、右段有 $2, 4$ 两根，总共也只有 $3$ 根，完全确认 $t \in (0, 1)$ 严丝合缝）。

**第二步：分双配对消元，将目标式全部化归为高度参数 $t$ 的函数。**
- 先看左段两根 $x_1, x_2$：由 $x_1 < 0 < x_2$ 拆去 $|3^x - 1| = t$ 的绝对值，得到：
  $$1 - 3^{x_1} = t \implies 3^{x_1} = 1 - t, \qquad 3^{x_2} - 1 = t \implies 3^{x_2} = 1 + t.$$
  顺手注意到 $3^{x_1} + 3^{x_2} = 2$ 为定值，而我们要用的指数和幂次 $3^{x_1 + x_2}$ 恰好等于两式相乘：
  $$3^{x_1 + x_2} = 3^{x_1} \cdot 3^{x_2} = (1 - t)(1 + t) = 1 - t^2.$$
- 再看右段两根 $x_3, x_4$：它们是二次方程 $-x^2 + 6x - 7 = t$ 的两个实根，移项整理成标准二次方程：
  $$x^2 - 6x + (7 + t) = 0.$$
  由韦达定理（两根之积）直接读出：
  $$x_3 x_4 = 7 + t.$$

把两部分表达式相加，整个待求代数式瞬间脱掉全部四个根，化简为关于单一变量 $t$ 的二次函数：
$$M(t) = 3^{x_1 + x_2} + x_3 x_4 = (1 - t^2) + (7 + t) = -t^2 + t + 8, \qquad t \in (0, 1).$$

**第三步：配方求开区间 $(0, 1)$ 上二次函数的值域（严防端点误判）。**
对二次函数 $M(t)$ 进行配方：
$$M(t) = -\left(t - \frac{1}{2}\right)^2 + \frac{33}{4}.$$
由于抛物线开口向下，对称轴 $t = \frac{1}{2}$ **恰好落在开区间 $(0, 1)$ 的正中间**，所以函数在 $\left(0, \frac{1}{2}\right]$ 上严格递增、在 $\left[\frac{1}{2}, 1\right)$ 上严格递减：
- **最大值可真实取到（闭端点）**：当 $t = \frac{1}{2} \in (0, 1)$ 时，$M(t)$ 取得最大值 $\frac{33}{4}$；
- **下界不可取到（开端点）**：在开区间左右两端边界处，$M(0) = 8$ 且 $M(1) = 8$，因为 $t$ 既取不到 $0$ 也取不到 $1$，所以 $M(t) > 8$ 且能无限逼近 $8$。

综上所述，$3^{x_1 + x_2} + x_3 x_4$ 的精确取值范围是半开半闭区间 **$\left(8, \frac{33}{4}\right]$**。
