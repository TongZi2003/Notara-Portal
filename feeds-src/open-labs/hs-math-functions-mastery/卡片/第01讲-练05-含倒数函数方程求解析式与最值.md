# 第01讲·练05：含倒数函数方程求解析式与最值

## 内容

已知函数 $f(x)$ 的定义域为 $\{x \mid x \neq 0\}$，且对任意 $x \neq 0$ 均满足：
$$2f(x) + f\left(\frac{1}{x}\right) = 12x + \frac{18}{x}.$$

(1) 求函数 $f(x)$ 的解析式；

(2) 求函数 $f(x)$ 在闭区间 $[1, 3]$ 上的值域；并判断当 $x \in (-\infty, 0)$ 时，函数 $f(x)$ 是否存在最大值，若存在，求出最大值及对应的 $x$ 值。

## 参考理解

**(1)** 我们看到关系式里只有一条方程，却同时出现 $f(x)$ 和 $f\left(\frac{1}{x}\right)$ 两个未知量。如果尝试用待定系数法去猜 $f(x) = ax + \frac{b}{x}$，虽然在小题里偶尔能凑出结果，但在解答题中并不能说明解的唯一性；如果直接把 $x = 1$ 或 $x = 2$ 代进去，又只能得到孤立的函数值而得不到一般解析式。

**为什么我们想到把所有 $x$ 统一替换成 $\frac{1}{x}$ 来构造第二条方程？** 因为在非零实数集上，置换 $\tau(x) = \frac{1}{x}$ 满足对合性质 $\tau\bigl(\tau(x)\bigr) = x$，也就是说替换之后不会冒出第三种未知表达式，仍然只包含 $f(x)$ 与 $f\left(\frac{1}{x}\right)$，从而构成封闭的二元一次方程组。根据[[卡片/函数解析式换元与消元法]]，对任意 $x \neq 0$，以 $\frac{1}{x}$ 替换原等式中的 $x$，联立得：
$$\begin{cases} 2f(x) + f\left(\frac{1}{x}\right) = 12x + \frac{18}{x}, & \text{①} \\ f(x) + 2f\left(\frac{1}{x}\right) = \frac{12}{x} + 18x. & \text{②} \end{cases}$$
为了消去 $f\left(\frac{1}{x}\right)$，我们计算 $\text{①} \times 2 - \text{②}$：
$$3f(x) = \left(24x + \frac{36}{x}\right) - \left(18x + \frac{12}{x}\right) = 6x + \frac{24}{x}.$$
两边同除以 $3$，立即得到 $f(x) = 2x + \frac{8}{x}$（$x \neq 0$）。顺手口算回代检验：$2\left(2x + \frac{8}{x}\right) + \left(\frac{2}{x} + 8x\right) = 12x + \frac{18}{x}$，与原条件完全吻合（解答题里写明定义域 $x \neq 0$ 才算严谨）。

**(2)** 得到 $f(x) = 2x + \frac{8}{x}$ 后，我们看它在 $[1, 3]$ 上的值域。因为区间 $[1, 3]$ 上的 $x$ 均为正数，最容易犯的懒惰错误是只算出最小值 $8$ 就以为端点值中较大的那个不需要比对，或者直接把 $[1, 3]$ 两个端点值当成最小值与最大值。根据[[卡片/分式与对勾型函数值域法]]，对于对勾函数 $f(x) = 2x + \frac{8}{x}$（$x > 0$），令两项相等 $2x = \frac{8}{x}$ 得拐点 $x_0 = 2$。
- 首先看最小值：因为 $x = 2$ 恰好落在了闭区间 $[1, 3]$ 内部，我们可以直接利用基本不等式：
  $$f(x) = 2x + \frac{8}{x} \ge 2\sqrt{2x \cdot \frac{8}{x}} = 8,$$
  当且仅当 $2x = \frac{8}{x}$ 即 $x = 2 \in [1, 3]$ 时取等号，所以最小值确定为 $8$。
- 再看最大值：因为对勾函数在 $(0, 2]$ 上单调递减、在 $[2, +\infty)$ 上单调递增（可用作差法验证：对任意 $0 < x_1 < x_2$，$f(x_2) - f(x_1) = 2(x_2 - x_1)\left(1 - \frac{4}{x_1 x_2}\right)$，故 $1 \le x_1 < x_2 \le 2$ 时差为负、$2 \le x_1 < x_2 \le 3$ 时差为正），所以最大值一定在两个端点 $x = 1$ 或 $x = 3$ 处取得。逐个代入比较：
  $$f(1) = 2 + 8 = 10, \qquad f(3) = 6 + \frac{8}{3} = \frac{26}{3} < 10.$$
  故最大值为 $10$，从而 $f(x)$ 在 $[1, 3]$ 上的值域为 $[8, 10]$。

最后处理 $x \in (-\infty, 0)$ 的情形。这里切忌对负数直接写基本不等式 $2x + \frac{8}{x} \ge 2\sqrt{16}$，必须先利用正负号转化保证两项皆正：令 $t = -x > 0$，则
$$f(x) = -\left(2t + \frac{8}{t}\right).$$
由上面对正半轴的分析可知 $2t + \frac{8}{t} \ge 8$（当且仅当 $t = 2$ 时取等号），两边同乘 $-1$ 不等号反向，得：
$$f(x) \le -8,$$
当且仅当 $t = 2$ 即 $x = -2 \in (-\infty, 0)$ 时取等号。因此当 $x \in (-\infty, 0)$ 时，函数 $f(x)$ 存在最大值，最大值为 $-8$，此时对应的 $x = -2$。
