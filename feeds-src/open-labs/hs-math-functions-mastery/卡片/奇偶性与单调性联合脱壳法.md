# 奇偶性与单调性联合脱壳法

## 内容

将奇偶性与单调性合起来解函数不等式，是高一期末与一轮复习最高频的“必考中档拉分题”。本质动作只有一步：**先把两边整成 $f(\text{左}) > f(\text{右})$，且确保左右括号里的自变量全部落在同一段单调区间里，然后才能安全脱去外层 $f$ 符号**。

### 1. 两大「标准脱壳路线」

设函数在已知单侧区间（如 $[0, +\infty)$ 或 $(0, +\infty)$）上单调，另一侧通过奇偶性镜像翻过去：

1. **偶函数路线：「绝对值拉回正半轴法」**
   因为偶函数满足 $f(x) = f(|x|)$，这把所有负自变量全部一键折回非负半轴 $[0, +\infty)$。
   - **转化公式**：若 $f(x)$ 在 $[0, +\infty)$ 上递增，则 $f(u) > f(v) \iff f(|u|) > f(|v|) \iff |u| > |v|$（进而平方化简 $u^2 > v^2$ 即可，绝不漏掉对称另一侧负半轴）；若在 $[0, +\infty)$ 上递减，脱壳后不等号反向为 $|u| < |v|$。
   - **优点**：完全避免讨论 $u, v$ 谁正谁负的四重分支，一步到位。

2. **奇函数（含奇+常数）路线：「移项反号全域单调法」**
   若 $f(x)$ 在 $[0, +\infty)$（或 $(0, +\infty)$）上单增且为奇函数（若含常数跳跃间断另当别论，见下方边界警报）：
   - 先验证**连续衔接处 $f(0) = 0$** 或左右一致，确保它在完整对称定义域上（或其同号内）保持全局一致单调性；
   - **遇到 $f(u) + f(v) > 0$**：绝不能直接比较 $u$ 与 $v$，必须先通过 $f(-v) = -f(v)$ 改写为：
     $$f(u) > -f(v) = f(-v);$$
   - 若为“奇函数 + 常数 $C$”（即 $f(x)+f(-x)=2C$）遇到 $f(u)+f(v) > 2C$：改写为 $f(u) > 2C - f(v) = f(-v)$；
   - 再根据全局单调方向脱壳解出 $u > -v$（增）或 $u < -v$（减）。

### 2. 必须附加的三重安全校验

脱掉 $f$ 符号之后，解集**尚未完工**，必须核对：
1. **有限定义域硬约束**：脱壳后若原函数定义域只是 $[-2, 2]$ 或 $(0, 4)$ 等有界集合，必须额外联立 **$u \in D$ 且 $v \in D$（或 $-v \in D$）**。考试常有 50% 的失分源自漏写 $-2 \le u \le 2$；
2. **分段边界含 $0$ 跳跃警报**：对于“奇函数在 $(0, +\infty)$ 单增、且 $0$ 不在定义域或有常数跳跃”的题（比如 $f(x) = x - \frac{1}{x}$ 在 $(-\infty, 0)$ 上各自单增但在跨过 $0$ 时从 $+\infty$ 突然跳回 $-\infty$），它**并非全域单调**。遇到这类“$(-\infty, 0)$ 增、$(0, +\infty)$ 也增但中间有间断”的奇函数，绝对禁止直接跨越 $0$ 点脱壳，必须分别按 $u, v$ 同正、同负、异号三大分支看符号区间。

## 参考理解

### 高频设坑点示范

1. **「各自单调」误作「全局单调」**：
   设 $f(x)$ 是定义域为 $\{x \mid x \neq 0\}$ 的奇函数，在 $(0, +\infty)$ 上单调递增且 $f(2) = 0$，解 $f(x) < 0$。
   - 错误脱壳：$f(x) < f(2) \implies x < 2$（彻底丢掉了 $(-\infty, -2)$ 实为正的图像分布）。
   - 正确画草图法：因为奇函数图像关于原点对称，且 $f(2)=0$，在 $(0, 2)$ 上函数值为负、$(2, +\infty)$ 上为正；翻折到左侧，$(-\infty, -2)$ 上为负、$(-2, 0)$ 上为正。因此 $f(x) < 0$ 的解集是 $(-\infty, -2) \cup (0, 2)$。凡遇到奇函数跨零点有跳跃或仅告知正半轴符号分布，**一律先画简图再读区间**。
2. **指对嵌套脱壳忘锁外层定义域**：
   已知定义在 $(-1, 1)$ 上的奇函数 $f(x)$ 递减，解 $f(1-a) + f(1-a^2) < 0$。除了变成 $f(1-a) < f(a^2 - 1) \implies 1-a > a^2 - 1$ 之外，必须同时联立 $-1 < 1-a < 1$ 与 $-1 < 1-a^2 < 1$（其实若 $1-a$ 与 $a^2-1$ 已满足增减关系仍必须各自落在 $(-1, 1)$ 内，如 $a=0$ 时 $1-a^2=1$ 不在开区间内就必须舍去）。

### 变式追问

1. 已知定义在 $\mathbb{R}$ 上的偶函数 $f(x)$ 在 $[0, +\infty)$ 上单调递增，且 $f\left(\frac{1}{3}\right) = 0$，求不等式 $f(\log_{\frac{1}{2}} x) > 0$ 的解集时，绝对值与对数不等号先后怎样一步步还原？
2. 为什么对于奇函数，只要它在 $(0, +\infty)$ 上递增且在 $x = 0$ 处有定义（此时 $f(0) = 0$）且当 $x \to 0^+$ 时函数值不冲向负边界之外（如连续递增），它在整个对称定义域上才真正可以一步无分支脱壳？
