# 双对称推导周期性与求值法

## 内容

高中函数题往往隐藏“周期 $T$”，转而给出两个不同位置的对称性条件（或半周期取反/倒数条件）。通过两步代数替换即可现推周期，根本不需要靠死背把“$2|a-b|$”和“$4|a-b|$”背反。

### 1. 三类双对称生成周期的直接推导

设函数 $f(x)$ 定义域为 $\mathbb{R}$（$a \neq b$）：

1. **双轴对称（$x=a$ 与 $x=b$）$\implies T = 2|a - b|$**：
   已知 $f(x) = f(2a - x)$ 且 $f(x) = f(2b - x)$，连环替换得：
   $$f\bigl(x + 2(b - a)\bigr) = f\bigl(2b - (2a - x)\bigr) = f(2a - x) = f(x).$$
   故周期为 $T = 2|a - b|$（两对称轴间距的 $2$ 倍）。
2. **双中心对称（$(a, c)$ 与 $(b, c)$ 纵坐标相等）$\implies T = 2|a - b|$**：
   已知 $f(2a - x) = 2c - f(x)$ 且 $f(2b - x) = 2c - f(x)$，连环代入得：
   $$f\bigl(x + 2(b - a)\bigr) = f\bigl(2b - (2a - x)\bigr) = 2c - f(2a - x) = 2c - \bigl[2c - f(x)\bigr] = f(x).$$
   故当两中心纵坐标相等时周期为 $T = 2|a - b|$。（若纵坐标 $c_1 \neq c_2$，则成为类周期函数 $f(x+2(b-a)) = f(x) + 2(c_2 - c_1)$。）
3. **一轴一心对称（轴 $x=a$ 与中心 $(b, c)$）$\implies T = 4|a - b|$**：
   先用一次轴与中心复合，得到**半周期和式**：
   $$f\bigl(x + 2(b - a)\bigr) = f\bigl(2b - (2a - x)\bigr) = 2c - f(2a - x) = 2c - f(x).$$
   记住中间产物还带着负号（未回到正的 $f(x)$）。必须再往前推进一次 $2(b-a)$：
   $$f\bigl(x + 4(b - a)\bigr) = 2c - f\bigl(x + 2(b - a)\bigr) = 2c - \bigl[2c - f(x)\bigr] = f(x).$$
   因此一轴一中心生成周期 $T = 4|a - b|$，这是考题出现次数最多的一条。

### 2. 三类半周期变换递推型（全为 $T = 2T_0$）

| 递推关系式（$T_0 > 0$） | 二次迭代过程 | 周期结论 |
| :--- | :--- | :--- |
| $f(x + T_0) = -f(x)$ | $f(x + 2T_0) = -f(x + T_0) = -\bigl[-f(x)\bigr] = f(x)$ | $T = 2T_0$ |
| $f(x + T_0) = \dfrac{1}{f(x)}$ | $f(x + 2T_0) = \dfrac{1}{f(x + T_0)} = \dfrac{1}{1 / f(x)} = f(x)$ | $T = 2T_0$（要求 $f \neq 0$） |
| $f(x + T_0) = -\dfrac{1}{f(x)}$ | $f(x + 2T_0) = -\dfrac{1}{f(x + T_0)} = -\dfrac{1}{-1 / f(x)} = f(x)$ | $T = 2T_0$ |

## 参考理解

### 高频易错与求值实操守则

1. **大自变量求值「先拉周期，再折进已知单侧区间」**：
   已知 $f(x)$ 是偶函数且满足 $f(x + 2) = -f(x)$，求 $f(7.5)$（已知 $[0, 1]$ 上解析式）。
   - 第一步：由 $f(x + 2) = -f(x)$ 推出周期 $T = 4$；
   - 第二步：按周期缩小自变量 $f(7.5) = f(7.5 - 2 \times 4) = f(-0.5)$；
   - 第三步：落在 $[-1, 0]$ 时不要慌，继续用**偶函数**性质 $f(-0.5) = f(0.5)$，这才成功归回 $[0, 1]$。很多题目只拉周期不配合最后的轴/中心反射，经常把负数错代入 $[0, 1]$ 解析式或算错负号。
2. **「一个周期不一定是最小正周期」**：
   上述公式推出来的 $2|a-b|$ 或 $4|a-b|$ 只是保证它**是一个周期**，未必是**最小正周期**（比如常函数 $f(x)=0$ 满足任意对称与周期，却没有最小正周期）。如果多选题问“$4$ 必为 $f(x)$ 的最小正周期”，这是假命题，只能选“$f(x+4) = f(x)$”。
3. **周期函数半周期求和技巧**：
   若同时有 $f(x) + f(x + T_0) = 2c$（如一轴一中心的半周期式子），那么相邻间隔 $T_0$ 的成对整点之和恒为 $2c$，求整区间连续 $2k T_0$ 项之和可以直接成对快速算出。

### 变式追问

1. 已知定义在 $\mathbb{R}$ 上的奇函数 $f(x)$ 满足 $f(2 - x) = f(x)$，不背口诀直接在草稿纸上写两行复合变换，它的周期是多少？若已知 $f(1) = 2$，求 $f(1) + f(2) + \dots + f(2025)$。
2. 若函数 $f(x)$ 同时满足中心对称 $(1, 0)$ 与 $(3, 2)$（两中心**纵坐标不相等**），再跑一次双心复合会得到什么等式？这说明函数图像呈现怎样的逐段规律？
