# 函数不动点与二周期点分析法

## 内容

当嵌套方程右侧不再是常数，而是自变量本身 **$f\bigl(f(x)\bigr) = x$** 时，令 $t = f(x)$ 会发现方程变成“$f(t) = x$ 且 $f(x) = t$”耦合系统，无法像常数那样先解外层再作水平线。这时必须运用“**一阶不动点**”与“**二周期点**”的结构规律破题。

### 1. 定义与核心等价定理

- **不动点**：满足 $f(x) = x$ 的实数 $x$；显然每个不动点都自动满足 $f(f(x)) = f(x) = x$，因此**不动点集必然是 $f(f(x)) = x$ 解集的子集**；
- **二周期点对（稳定点对）**：满足 $f(u) = v$、$f(v) = u$ 且 $u \neq v$ 的两个互异实数（此时 $u, v$ 都满足 $f(f(x)) = x$ 但都不是不动点）。几何上恰是曲线 $y = f(x)$ 与其反函数对应点关系在递减分支上的**关于 $y = x$ 对称且不在 $y = x$ 上的点对** $(u, v)$ 与 $(v, u)$。

**关键判定律**：
1. 若函数 $f(x)$ 在区间 $I$ 上**严格单调递增**，则 $f(f(x)) = x$ 与 $f(x) = x$ **100% 同解**（绝无二周期点）。
   - **纯 3 行反证法**：设存在 $x_0$ 满足 $f(f(x_0)) = x_0$ 但 $f(x_0) \neq x_0$。不妨设 $f(x_0) > x_0$，由 $f$ 严格递增两边再套一次 $f$ 得 $f(f(x_0)) > f(x_0) > x_0$，与 $f(f(x_0)) = x_0$ 矛盾。（$f(x_0) < x_0$ 同理矛盾。）
2. 若函数 $f(x)$ 含有**单调递减区间**，则在递减段上**可能**出现成对二周期点 $(u, v)$；如欲保证 $f(f(x)) = x$ 与 $f(x) = x$ 同解，必须验证该方程除 $f(x)=x$ 之外没有多余的实数根。

### 2. 二次函数 $f(f(x)) - x$ 的「消常数做差提因式」通用恒等式

遇到具体二次函数 $f(x) = ax^2 + bx + c$（$a \neq 0$）考 $f(f(x)) = x$，**切勿硬把 4 次多项式全部展开**。令 $y = f(x) = ax^2 + bx + c$，注意 $f(f(x)) = a y^2 + b y + c$：

1. 两式做差消去常数项 $c$：
   $$f(f(x)) - f(x) = f(y) - f(x) = a(y^2 - x^2) + b(y - x) = (y - x)\bigl[a(y + x) + b\bigr];$$
2. 在两边同时加上 $(y - x)$，把左端还原成 $f(f(x)) - x$，右端立刻自动浮现公因式 $(y - x)$：
   $$f(f(x)) - x = \bigl(f(x) - x\bigr)\bigl[a f(x) + ax + b + 1\bigr].$$
   特别地，对于常见的首一二次函数 $f(x) = x^2 + px + q$（$a = 1$）：
   $$f(f(x)) - x = \bigl(f(x) - x\bigr)\bigl(f(x) + x + p + 1\bigr) = \bigl(x^2 + (p-1)x + q\bigr)\bigl(x^2 + (p+1)x + q + p + 1\bigr).$$
   一个 4 次方程当场拆成两个极其干净的 2 次因式乘积。

## 参考理解

### 高频易错与端点闭区间丢失问题

设两因式记为 $P(x) = f(x) - x = 0$（不动点方程）和 $Q(x) = a f(x) + ax + b + 1 = 0$（余因子方程）。题目要求 **$f(f(x)) = x$ 与 $f(x) = x$ 在 $\mathbb{R}$ 上同解** 时，等价于：$Q(x) = 0$ 的**所有实数解都必须已经落在 $P(x) = 0$ 的解集之中**。这包含两种情形，考场几乎必漏第二种：
1. **情形一（主区间）**：$Q(x) = 0$ 根本**没有实数根**，即 $\Delta_Q < 0$；
2. **情形二（极其容易丢掉的闭区间端点或重根）**：$Q(x) = 0$ **有实数根，但它的根恰好全都是 $P(x) = 0$ 的根**（即不动点与二周期点在边界处发生碰撞重合）：
   - 当 $\Delta_Q = 0$ 时，$Q(x)$ 只有一个重实根 $x_0$，**必须单独算出来代进 $P(x_0)$ 检验是否等于 $0$**。往往算出来发现左右两个 $\Delta_Q = 0$ 的端点恰好都满足 $P(x_0) = 0$，于是开区间一下子变成**闭区间**。
   - 当 $\Delta_Q > 0$ 时，如果 $Q(x)$ 有两个不相等的实根且要全被 $P(x)$ 吸收，那就意味着 $Q(x)$ 与 $P(x)$ 实为同一个二次三项式（所有系数成比例），比对两二次方程的常数项与一次项往往会立即发现矛盾从而排除（但也必须写出一行核验过程以保严密）。

### 变式追问

1. 若已知分段函数在区间 $[0, 1]$ 上递减而在 $(1, +\infty)$ 上递增，直接作草图把曲线与反函数 $y = f^{-1}(x)$（关于 $y = x$ 对称画出）同时画出来，交点落在 $y=x$ 之外的那一对对称点对应什么代数方程？
2. 对具体二次函数 $f(x) = x^2 + ax + 1$ 运用因式分解法，求出使得方程 $f(f(x)) = x$ 与 $f(x) = x$ 有相同实数解集的 $a$ 的全部范围（仔细检验 $\Delta_Q = 0$ 的两个临界点）。
