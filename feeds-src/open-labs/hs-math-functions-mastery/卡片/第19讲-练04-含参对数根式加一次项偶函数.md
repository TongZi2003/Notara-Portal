# 第19讲·练04：含参对数根式加一次项偶函数

## 内容

已知函数 $f(x) = \ln\left(\sqrt{x^2 + 1} - ax\right) + bx$ 是定义在 $\mathbb{R}$ 上的偶函数，则实数对 $(a, b)$ 满足（　　）

A. 仅有唯一解 $(0, 0)$
B. 仅有唯一解 $\bigl(1, \ln(\sqrt{2} + 1)\bigr)$
C. 存在多组解，包含 $(0, 0)$ 与 $\bigl(1, \ln(\sqrt{2} + 1)\bigr)$
D. 无解

## 参考理解

我们读题时很容易联想到一个熟悉的模型：$\ln(\sqrt{x^2 + 1} - x)$ 是经典的奇函数，既然现在前面多了系数 $a$ 又在外面加上了一次项 $bx$，很多同学会忍不住用“取特值 $x = \pm 1$”来迅速猜出参数——代进 $f(1) = f(-1)$ 一算，发现当 $a = 1$ 时只要令 $b = \ln(\sqrt{2} + 1)$，居然有 $f(1) = \ln(\sqrt{2} - 1) + \ln(\sqrt{2} + 1) = 0 = \ln(\sqrt{2} + 1) - \ln(\sqrt{2} + 1) = f(-1)$，再加上 $f(0) = 0$，于是就放心选了 C（甚至误选 B）。这正是[[卡片/必要性探路缩界与充分性回代]]专门警示过的经典陷阱：仅在个别点相等，绝不等于对全体实数处处相等。

**第一步：先检验题干前提“定义在 $\mathbb{R}$ 上”对 $a$ 设下的范围限制**。
根据[[卡片/奇偶性判定与分段解析式补全]]，对数真数 $\sqrt{x^2 + 1} - ax$ 必须对所有 $x \in \mathbb{R}$ 恒正。如果 $|a| > 1$，则 $a^2 - 1 > 0$，我们只需取足够大且与 $a$ 同号的 $x$（满足 $x^2 > \frac{1}{a^2 - 1}$），就会出现 $(ax)^2 = a^2 x^2 > x^2 + 1$，此时 $\sqrt{x^2 + 1} < ax$，导致真数小于 $0$ 而无意义，定义域根本不是 $\mathbb{R}$。因此首要必要条件是：
$$|a| \le 1.$$

**第二步：用 $x = 1$ 探路锁定候选配对，再用 $x = 2$ 瞬间识破伪解**。
由偶函数定义，对一切 $x \in \mathbb{R}$ 恒有 $f(x) = f(-x)$，即
$$\ln\left(\sqrt{x^2 + 1} - ax\right) + bx = \ln\left(\sqrt{x^2 + 1} + ax\right) - bx \iff 2bx = \ln\frac{\sqrt{x^2 + 1} + ax}{\sqrt{x^2 + 1} - ax}.$$
先检验选项 B、C 提到的候选解 $(a, b) = \bigl(1, \ln(\sqrt{2} + 1)\bigr)$：它确实过了 $x = 0$ 与 $x = \pm 1$ 两关，但只要再往外走一步代 $x = 2$ 检验：
- 等式左边：$2b \cdot 2 = 4\ln(\sqrt{2} + 1) = \ln\bigl((\sqrt{2} + 1)^4\bigr) = \ln(17 + 12\sqrt{2})$；
- 等式右边：$\ln\frac{\sqrt{5} + 2}{\sqrt{5} - 2} = \ln\bigl((\sqrt{5} + 2)^2\bigr) = \ln(9 + 4\sqrt{5})$。
比较真数大小：$17 + 12\sqrt{2} > 17 + 12 \times 1.4 = 33.8$，而 $9 + 4\sqrt{5} < 9 + 4 \times 2.3 = 18.2$，两者相差甚远。因此 $f(2) \neq f(-2)$，候选解 $\bigl(1, \ln(\sqrt{2} + 1)\bigr)$ 立刻被淘汰，排除了选项 B 和 C。

**第三步：纯初等证明除了 $(0, 0)$ 之外再无其他任何实数解**。
我们先验证充分性：当 $(a, b) = (0, 0)$ 时，$f(x) = \ln\sqrt{x^2 + 1}$ 的定义域为 $\mathbb{R}$，且 $f(-x) = \ln\sqrt{(-x)^2 + 1} = f(x)$，确为定义在 $\mathbb{R}$ 上的偶函数。那么 $|a| \le 1$ 范围内还有没有其他解呢？分两种情况彻底扫清：
1. **当 $|a| < 1$ 时**：对任意 $x \ge 1$，由于 $\sqrt{x^2 + 1} \le x + 1 \le 2x$ 且 $\sqrt{x^2 + 1} > x$，于是
   $$\frac{1 - |a|}{2 + |a|} = \frac{(1 - |a|)x}{(2 + |a|)x} < \frac{\sqrt{x^2 + 1} + ax}{\sqrt{x^2 + 1} - ax} < \frac{(2 + |a|)x}{(1 - |a|)x} = \frac{2 + |a|}{1 - |a|}.$$
   这说明当 $x \ge 1$ 时，等式右边 $\ln\frac{\sqrt{x^2 + 1} + ax}{\sqrt{x^2 + 1} - ax}$ 始终被夹在一个固定常数区间 $\left(-\ln\frac{2 + |a|}{1 - |a|},\ \ln\frac{2 + |a|}{1 - |a|}\right)$ 内（有界）；而左边 $2bx$ 如果 $b \neq 0$，只要取足够大的 $x \ge 1$ 就可以让 $|2bx|$ 超过任何固定常数，必然产生矛盾。所以必须有 $b = 0$。代回 $b = 0$ 与 $x = 1$ 得 $\ln\frac{\sqrt{2} + a}{\sqrt{2} - a} = 0 \implies a = 0$。
2. **当 $|a| = 1$ 时**：若 $a = 1$，等式化为 $bx = \ln(\sqrt{x^2 + 1} + x)$（$x \in \mathbb{R}$），代 $x = 1$ 唯一解得 $b = \ln(\sqrt{2} + 1)$，而刚才在 $x = 2$ 处已经用数值对比直接推翻；若 $a = -1$，同理令 $x = 1$ 得 $b = -\ln(\sqrt{2} + 1)$，同样在 $x = 2$ 处左右真数互为倒数却依然不等，矛盾。

由此严密证明：只有 $(a, b) = (0, 0)$ 是唯一正解，本题选 **A**。
