# 第12讲·练13：负分数幂函数的含参不等式求解

## 内容

不等式 $(2a - 1)^{-\frac{2}{3}} > (a + 2)^{-\frac{2}{3}}$ 的解集为 $\underline{\qquad}$。

## 参考理解

我们看到不等式两边具有完全相同的分数指数 $-\frac{2}{3}$，自然会想到构造函数 $f(x) = x^{-\frac{2}{3}}$ 来比较自变量的大小。但这里紧接着藏着两个连环扣：第一扣是很多同学只记着“指数 $-\frac{2}{3} < 0$ 所以函数递减”，于是直接去掉底数把不等号反向写成 $2a - 1 < a + 2 \implies a < 3$，完全忘了它是一个定义在左右两半平面的**偶函数**，在 $(-\infty, 0)$ 上其实是递增的；第二扣则更加隐蔽——即使已经用偶函数绝对值脱壳法解出了 $-\frac{1}{3} < a < 3$，如果不回去核对**负指数要求底数不能为零**，就会把恰好落在这个区间正中间的 $a = \frac{1}{2}$ 一起包进答案里，导致全题零分。

**为什么我们先要把 $f(x) = x^{-\frac{2}{3}}$ 的定义域、奇偶性与单调性一次全部写清？** 依据[[卡片/幂函数第一象限图像与奇偶性]]，由于指数 $-\frac{2}{3}$ 已经是最简分数，分子 $-2$ 为负偶数、分母 $3$ 为奇数，因此函数
$$f(x) = x^{-\frac{2}{3}} = \frac{1}{\sqrt[3]{x^2}}$$
具有三条缺一不可的性质：
1. **定义域**：因为负指数把幂放到了分母上，自变量**绝对不能等于 $0$**，即定义域为 $\{x \mid x \neq 0\}$；
2. **奇偶性**：因为分子为偶数且定义域关于原点对称，$f(-x) = \frac{1}{\sqrt[3]{(-x)^2}} = f(x)$，它是**偶函数**；
3. **单调性**：因为指数 $-\frac{2}{3} < 0$，它在 $(0, +\infty)$ 上**严格单调递减**（由偶函数图像关于 $y$ 轴对称可知，在 $(-\infty, 0)$ 上严格单调递增）。

**为什么不等式 $f(u) > f(v)$ 必须同时翻译成“绝对值不等式”与“非零底数限制”？** 根据[[卡片/奇偶性与单调性联合脱壳法]]，利用偶函数满足 $f(x) = f(|x|)$ 的特性，先把左右两边的自变量全部折叠进函数单调递减的正半轴 $(0, +\infty)$ 内，同时必须明确写出定义域前提：
$$f(u) > f(v) \iff \begin{cases} u \neq 0, \\ v \neq 0, \\ f(|u|) > f(|v|). \end{cases}$$
由于 $f(x)$ 在 $(0, +\infty)$ 上严格递减，于是 $f(|u|) > f(|v|) \iff |u| < |v|$。我们注意一下：$|u| < |v|$ 虽然可以自动保证 $|v| > |u| \ge 0$（即 $v \neq 0$ 自动满足），但它**绝对无法阻止 $u = 0$**（因为 $|0| < |v|$ 照样成立）。

把 $u = 2a - 1$ 和 $v = a + 2$ 代入上述等价系统，原不等式完全等价于
$$\begin{cases} 2a - 1 \neq 0, \\ a + 2 \neq 0, \\ |2a - 1| < |a + 2|. \end{cases}$$
先解核心的绝对值不等式 $|2a - 1| < |a + 2|$：因为两边均非负，直接两边平方去绝对值：
$$(2a - 1)^2 < (a + 2)^2 \iff 4a^2 - 4a + 1 < a^2 + 4a + 4 \iff 3a^2 - 8a - 3 < 0.$$
十字相乘分解因式得
$$(3a + 1)(a - 3) < 0 \implies -\frac{1}{3} < a < 3.$$

最后执行**最关键的定义域挖孔检验**：
- $2a - 1 \neq 0 \implies a \neq \frac{1}{2}$。核对一下，$\frac{1}{2}$ 恰好落在开区间 $\left(-\frac{1}{3}, 3\right)$ 内部，如果直接代回原题左边，$(2\times \frac{1}{2} - 1)^{-\frac{2}{3}} = 0^{-\frac{2}{3}}$ 根本没有意义，因此**必须将 $a = \frac{1}{2}$ 从区间中挖除**；
- $a + 2 \neq 0 \implies a \neq -2$，而 $-2$ 本身不在 $\left(-\frac{1}{3}, 3\right)$ 内，已自动排除。

综上，原不等式的完整解集为 $\left(-\frac{1}{3}, \frac{1}{2}\right) \cup \left(\frac{1}{2}, 3\right)$。
