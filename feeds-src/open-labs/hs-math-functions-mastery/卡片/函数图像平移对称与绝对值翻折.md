# 函数图像平移对称与绝对值翻折

## 内容

在数形结合、多零点求参和复合嵌套问题中，作图快且不错的关键在于彻底理清“平移与伸缩谁先谁后”“哪一块加负号”“绝对值究竟翻折左半边还是下半边”。

### 1. 平移与伸缩变换的「只对 $x$ 本身操作」铁律

从母函数 $y = f(x)$ 变换出 $y = f(kx + b)$（$k > 0$）：
- 任何左右平移操作，都只能发生在**孤立的自变量字母 $x$ 本身**身上（将 $x$ 替换成 $x \pm h$，满足“左加右减”），绝不能在系数 $k$ 之外加减：
  $$y = f(kx) \xrightarrow{\text{把 } x \text{ 换成 } x + \frac{b}{k} \text{（向左平移 } \frac{b}{k} \text{）}} y = f\left(k\left(x + \frac{b}{k}\right)\right) = f(kx + b).$$
- **换序两路径对照**：
  - 先平移再伸缩：$f(x) \xrightarrow{\text{左移 } b} f(x + b) \xrightarrow{\text{横坐标缩为 } \frac{1}{k}} f(kx + b)$；
  - 先伸缩再平移：$f(x) \xrightarrow{\text{横坐标缩为 } \frac{1}{k}} f(kx) \xrightarrow{\text{左移 } \frac{b}{k}} f(kx + b)$。
  若遇到带负号的 $f(-x + b)$，应先翻折得到 $f(-x)$，再提出负号写成 $f\bigl(-(x - b)\bigr)$，清楚看出是把 $f(-x)$ **向右平移 $b$ 个单位**（千万别看成左移 $b$）。

### 2. 四种基本对称翻折对照表

| 变换表达式 | 对称参考直线或点 | 作图动作 |
| :--- | :--- | :--- |
| $y = f(-x)$ | 关于 $y$ 轴对称 | 左右颠倒（保留每点纵坐标，横坐标变反） |
| $y = -f(x)$ | 关于 $x$ 轴对称 | 上下颠倒（横坐标不变，纵坐标取反） |
| $y = -f(-x)$ | 关于坐标原点 $(0, 0)$ 对称 | 上下、左右各翻一次 |
| $y = f(2a - x)$ | 与 $y = f(x)$ 关于直线 $x = a$ 互对称 | 先将 $f(x)$ 关于 $y$ 轴翻成 $f(-x)$，再向右平移 $2a$ 单位 |

### 3. 两种绝对值翻折的「删左留右 vs 保上翻下」对比

1. **$y = f\bigl(|x|\bigr)$（「删左留右，偶对称」）**：
   - 当 $x \ge 0$ 时 $|x| = x$，函数与 $y = f(x)$ 完全重合；当 $x < 0$ 时函数值为 $f(-x)$，从而 $y = f(|x|)$ 必然是**偶函数**；
   - 作图步骤：保留 $y = f(x)$ 在 $y$ 轴右侧（含 $y$ 轴上）的图像，**删掉原 $y$ 轴左侧全部图像**，再把右侧图像关于 $y$ 轴对称翻折过去（如 $y = a^{|x|}$、$y = \log_2|x|$）。
2. **$y = |f(x)|$（「保上翻下，非负贴轴」）**：
   - 作图步骤：保留 $y = f(x)$ 落在 $x$ 轴上方（含 $x$ 轴上）的部分，将位于 **$x$ 轴下方**的那部分图像全部沿着 $x$ 轴向上对称翻折上去；
   - 高频模板曲线：$y = |\log_a x|$（在 $x=1$ 处呈尖谷且左侧渐近冲向 $+\infty$）、$y = |a^x - 1|$（水平渐近线 $y=0$ 在翻折后变成上方的限制水平渐近线 **$y = 1$**）、$y = |x^2 - 2x|$（两个零点之间向上翻成峰）。

## 参考理解

### 高频作图失分盲区

1. **$y = |2^x - 1|$ 等「带水平渐近线曲折线」忘记标上界渐近线**：
   原函数 $y = 2^x - 1$ 在 $x \to -\infty$ 时无限贴近但永远高于直线 $y = -1$。加上绝对值向上翻折后，左半支图像趋近于水平线 **$y = 1$** 但**永远取不到 $1$**，右半支从 $(1, 1)$ 开始向右一直冲向 $+\infty$。因此画水平线 $y = k$ 截交点时：
   - 当 $k \in (0, 1)$ 时有 $2$ 个交点；
   - 当 $k \ge 1$ 时（含 $k = 1$）左侧已经渐近截停，整个曲线只剩下右侧 **$1$ 个交点**。许多同学草草把左支画成一路冲上无穷，错算成任意 $k > 0$ 都有两根。
2. **复合绝对值作图顺序误乱**：
   如作 $y = |\log_2(x - 1)|$ 时，顺序必须是先向右平移 $1$ 个单位得到 $y = \log_2(x - 1)$（竖直渐近线跟着移到 $x = 1$，零点移到 $(2, 0)$），再把 $x$ 轴下方翻折上来。如果先翻折再左加右减很容易弄错渐近线位置；也可以记住“所有变化都在最后一步套最外层函数算符上完成”。
