# 第09讲·练04：负倒数与分式递推求大自变量值

## 内容

已知定义在 $\mathbb{R}$ 上的函数 $f(x)$ 满足对任意 $x \in \mathbb{R}$ 都有 $f(x) \neq 0$ 且 $f(x + 2) = -\frac{1}{f(x)}$；定义在 $\mathbb{R}$ 上的函数 $g(x)$ 满足对任意 $x \in \mathbb{R}$ 都有 $g(x) \notin \{-1, 0, 1\}$ 且 $g(x + 2) = \frac{1 + g(x)}{1 - g(x)}$。若 $f(1) = 3$，$g(1) = 2$，则 $f(2027) + g(2029)$ 的值为________。

## 参考理解

我们看到这种带有步长 $2$ 的分式递推式时，考场上最容易犯的错误就是“不亲自迭代一遍，只凭模糊印象把所有分式递推的周期全都背成 $4$”。其实不同的分式结构在反复代入后周期可能是 $4$，也可能是 $8$ 甚至更长；而且为了避开算错步长余数，哪怕多写两行逐项推进，也能在十秒之内把周期验明正身。

**为什么我们必须按[[卡片/双对称推导周期性与求值法]]依次做出 $f(x + 4)$ 与 $g(x + 4)$？** 因为只有亲自展开嵌套代换，才能看清两次推进后是否真的回到原函数值本身。

先看第一个函数 $f(x)$。已知 $f(x + 2) = -\frac{1}{f(x)}$ 且 $f(x) \neq 0$，将式中的 $x$ 换为 $x + 2$ 推进一次：
$$f(x + 4) = -\frac{1}{f(x + 2)} = -\frac{1}{-\frac{1}{f(x)}} = f(x).$$
由此严格证明 $f(x)$ 的一个周期为 **$T_f = 4$**。接下来把自变量 $2027$ 对 $4$ 做带余除法：$2027 = 4 \times 506 + 3$，故
$$f(2027) = f(3) = f(1 + 2) = -\frac{1}{f(1)} = -\frac{1}{3}.$$

再看第二个函数 $g(x)$，这里正是最关键的周期检验点。已知 $g(x + 2) = \frac{1 + g(x)}{1 - g(x)}$，题干保证 $g(x) \notin \{-1, 0, 1\}$ 确保每步分母均非零。我们先推进一次，把 $x$ 换为 $x + 2$：
$$g(x + 4) = \frac{1 + g(x + 2)}{1 - g(x + 2)} = \frac{1 + \frac{1 + g(x)}{1 - g(x)}}{1 - \frac{1 + g(x)}{1 - g(x)}}.$$
分子分母同乘 $1 - g(x)$（非零）化简：
$$g(x + 4) = \frac{\bigl[1 - g(x)\bigr] + \bigl[1 + g(x)\bigr]}{\bigl[1 - g(x)\bigr] - \bigl[1 + g(x)\bigr]} = \frac{2}{-2g(x)} = -\frac{1}{g(x)}.$$
看清这一步的结果：它并没有回到 $g(x)$，而是转化成了刚才见过的“负倒数关系”。如果题干给的是 $\frac{1 - g(x)}{1 + g(x)}$，推两步就会回到 $g(x)$（周期为 $4$）；但面对本题的 $\frac{1 + g(x)}{1 - g(x)}$，步长 $4$ 只是半周期的负倒数关系。我们必须再迭代一次步长 $4$：
$$g(x + 8) = -\frac{1}{g(x + 4)} = -\frac{1}{-\frac{1}{g(x)}} = g(x).$$
因此 $g(x)$ 的周期不是 $4$，而是 **$T_g = 8$**。为了防止迭代出错，我们也可以直接从 $g(1) = 2$ 出发逐项算出轨道加以交叉验算：
- $g(3) = \frac{1 + 2}{1 - 2} = -3$；
- $g(5) = \frac{1 + (-3)}{1 - (-3)} = -\frac{2}{4} = -\frac{1}{2}$；
- $g(7) = \frac{1 - \frac{1}{2}}{1 + \frac{1}{2}} = \frac{1}{3}$；
- $g(9) = \frac{1 + \frac{1}{3}}{1 - \frac{1}{3}} = 2 = g(1)$。

果然四步一循环，步长每次加 $2$ 恰对应周期 $8$（且轨道数值 $2, -3, -\frac{1}{2}, \frac{1}{3}$ 永不踩中 $\{-1, 0, 1\}$）。再对 $2029$ 按周期 $8$ 做带余除法：$2029 = 8 \times 253 + 5$（注意如果误把周期当成 $4$，会得到余数 $1$ 并错算成 $g(1) = 2$）。因此：
$$g(2029) = g(5) = -\frac{1}{2}.$$

最后求和：$f(2027) + g(2029) = -\frac{1}{3} + \left(-\frac{1}{2}\right) = -\frac{5}{6}$。
