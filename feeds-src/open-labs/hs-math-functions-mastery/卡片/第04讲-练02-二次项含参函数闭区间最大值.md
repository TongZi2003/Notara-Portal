# 第04讲·练02：二次项含参函数闭区间最大值

## 内容

已知函数 $f(x) = ax^2 - 2x + 1$（$a \in \mathbb{R}$），求 $f(x)$ 在闭区间 $[1, 2]$ 上的最大值。

## 参考理解

我们拿到解析式 $f(x) = ax^2 - 2x + 1$ 时，第一眼就要警惕参数 $a$ 坐在了**二次项系数**的位置上。如果在草稿纸上顺手就写出“对称轴为 $x = \frac{1}{a}$”，紧接着就开始比较 $\frac{1}{a}$ 和区间 $[1, 2]$ 端点或中点的大小，实际上已经犯了两个致命错误：第一，当 $a = 0$ 时分母为零，函数根本不是二次函数；第二，当 $a < 0$ 时抛物线开口向下，求最大值和开口向上时的取法完全对调，绝对不能沿用中点比较规则。因此根据[[卡片/含参二次函数动轴与区间最值]]，外层必须先按 $a = 0$、$a < 0$、$a > 0$ 三大类划开，然后再把端点值提前备好：
$$f(1) = a - 1, \qquad f(2) = 4a - 3.$$

**为什么我们先单独核实 $a = 0$ 与 $a < 0$？** 先看退化情况：
- **当 $a = 0$ 时**，$f(x) = -2x + 1$ 是一次函数，在 $[1, 2]$ 上严格单调递减，因此最大值在左端点取得，为 $f_{\max} = f(1) = -1$。

再看开口向下的情况：
- **当 $a < 0$ 时**，抛物线 $f(x) = ax^2 - 2x + 1$ 开口向下，对称轴为 $x = \frac{1}{a}$。因为 $a < 0$，必有对称轴 $\frac{1}{a} < 0 < 1$，也就是说顶点永远落在闭区间 $[1, 2]$ 的左侧外面，绝对不会跑进区间内部（顺便提醒自己：此时不必再去分什么三段，因为根本不存在 $1 < \frac{1}{a} < 2$ 的可能）。由于抛物线在对称轴右侧单调递减，所以 $f(x)$ 在 $[1, 2]$ 上严格单调递减，最大值依然在左端点取得：
$$f_{\max} = f(1) = a - 1.$$

最后进入开口向上的情况：
- **当 $a > 0$ 时**，抛物线开口向上，对称轴 $x = \frac{1}{a} > 0$。**为什么我们求最大值时只把 $\frac{1}{a}$ 与中点 $\frac{3}{2}$ 比较，而不按 $1$ 和 $2$ 切分？** 因为开口向上的抛物线在闭区间 $[1, 2]$ 上的最大值一定在左端点 $1$ 或右端点 $2$ 取得，顶点落不落入 $[1, 2]$ 只影响最小值，不影响谁离对称轴更远。区间 $[1, 2]$ 的中点是 $x = \frac{1 + 2}{2} = \frac{3}{2}$：
  - 若对称轴在中点左侧或恰好在中点上，即 $0 < \frac{1}{a} \le \frac{3}{2}$，因为 $a > 0$，两边取倒数变号解得 $a \ge \frac{2}{3}$。此时右端点 $2$ 离对称轴更远（或与左端点等距），故
    $$f_{\max} = f(2) = 4a - 3.$$
  - 若对称轴在中点右侧，即 $\frac{1}{a} > \frac{3}{2}$，结合 $a > 0$ 解得 $0 < a < \frac{2}{3}$。此时左端点 $1$ 离对称轴更远，故
    $$f_{\max} = f(1) = a - 1.$$

这里还有一个很好的自我检验角度：直接计算两端点之差 $f(2) - f(1) = (4a - 3) - (a - 1) = 3a - 2$，可以看到在 $a > 0$ 时，$a \ge \frac{2}{3}$ 恰好对应 $f(2) \ge f(1)$，$0 < a < \frac{2}{3}$ 恰好对应 $f(1) > f(2)$，代数作差和几何中点法严丝合缝。

最后我们汇总上述所有分支，惊喜地发现虽然 $a < 0$、$a = 0$ 与 $0 < a < \frac{2}{3}$ 背后的单调性成因完全不同（一个是开口向下在对称轴右侧递减，一个是直线斜率为负，一个是开口向上但对称轴靠右使左端点更高），但它们的最大值表达式恰好统一为 $a - 1$，而且在 $a = \frac{2}{3}$ 处 $a - 1 = -\frac{1}{3} = 4a - 3$ 连续衔接。因此函数 $f(x)$ 在 $[1, 2]$ 上的最大值为：
$$f_{\max} = \begin{cases} a - 1, & a < \frac{2}{3}, \\ 4a - 3, & a \ge \frac{2}{3}. \end{cases}$$
