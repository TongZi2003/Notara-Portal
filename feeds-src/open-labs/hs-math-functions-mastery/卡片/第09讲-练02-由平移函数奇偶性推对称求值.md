# 第09讲·练02：由平移函数奇偶性推对称求值

## 内容

已知定义在 $\mathbb{R}$ 上的函数 $f(x)$ 满足：$y = f(2x - 1)$ 为偶函数，$y = f(x + 1) - 2$ 为奇函数。若 $f(0) = 3$，则 $f(5) + f(-4)$ 的值为（　　）

A. $1$　　　　B. $3$　　　　C. $4$　　　　D. $5$

## 参考理解

我们看这道题时，条件没有直接给出母函数 $f(x)$ 的对称轴和对称中心，而是把它们藏进了复合函数 $y = f(2x - 1)$ 的偶性与 $y = f(x + 1) - 2$ 的奇性之中。这道题最常见、最致命的两个坑就在于“想当然地按平移规律心算”：一看到 $2x - 1 = 0$ 就误以为 $f(x)$ 的对称轴是 $x = \frac{1}{2}$；一看到 $f(x + 1) - 2$ 就按“左加右减、上加下减”错认为对称中心是 $(-1, 2)$ 或 $(1, -2)$。一旦中心或轴错了一处，后面求值就会全盘走偏。

**为什么我们必须严格套用奇偶性的定义式“只替换自变量 $x$”，而不靠口诀去平移？** 根据[[卡片/函数自身对称与两函数互对称]]，复合函数的奇偶性永远是相对于自变量 $x$ 而言的。只要记 $g(x) = f(2x - 1)$、$h(x) = f(x + 1) - 2$，再老老实实写出 $g(-x) = g(x)$ 和 $h(-x) + h(x) = 0$，母函数的对称信息就会毫不失真地显露出来。

我们先还原第一条信息：已知 $g(x) = f(2x - 1)$ 为偶函数，即对任意 $x \in \mathbb{R}$ 有 $g(-x) = g(x)$。注意这里只把 $x$ 换成 $-x$，括号里的常数 $-1$ 绝不能跟着变号，因此得到：
$$f(-2x - 1) = f(2x - 1).$$
观察等式两侧括号内的代数式，令整体 $t = 2x$，便化为 $f(-1 - t) = f(-1 + t)$（或直接把两括号相加除以 $2$：$\frac{(-2x - 1) + (2x - 1)}{2} = -1$）。这清楚地表明：**母函数 $y = f(x)$ 的图像关于直线 $x = -1$ 轴对称**，而不是 $x = \frac{1}{2}$。验证一下也是合理的：若把 $y = f(x)$ 先向右平移 $1$ 个单位变成 $y = f(x - 1)$，对称轴 $x = -1$ 便随之移到 $x = 0$（即 $y$ 轴），再把横坐标压缩为原来的 $\frac{1}{2}$ 得到 $y = f(2x - 1)$，位于 $y$ 轴上的对称轴在横向伸缩中保持不变，仍是偶函数。

接着我们还原第二条信息：已知 $h(x) = f(x + 1) - 2$ 为奇函数，即对任意 $x \in \mathbb{R}$ 有 $h(-x) + h(x) = 0$，代入表达式展开得：
$$\bigl[f(-x + 1) - 2\bigr] + \bigl[f(x + 1) - 2\bigr] = 0 \implies f(1 - x) + f(1 + x) = 4.$$
两括号相加除以 $2$ 得横坐标 $\frac{(1 - x) + (1 + x)}{2} = 1$，函数值之和除以 $2$ 得纵坐标 $\frac{4}{2} = 2$。因此：**母函数 $y = f(x)$ 的图像关于点 $(1, 2)$ 中心对称**，特别地，令 $x = 0$ 立得 $2f(1) = 4 \implies f(1) = 2$。这同样符合变换直觉：把对称中心 $(1, 2)$ 向左平移 $1$ 个单位、再向下平移 $2$ 个单位，恰落回坐标原点 $(0, 0)$，对应奇函数 $y = f(x + 1) - 2$。

现在母函数 $f(x)$ 的两个核心对称要素已经全部锁定：轴 $x = -1$（即 $f(x) = f(-2 - x)$）和中心 $(1, 2)$（即 $f(2 - x) = 4 - f(x)$）。根据[[卡片/双对称推导周期性与求值法]]，一轴一中心会生成周期 $T = 4|1 - (-1)| = 8$。但在这道具体的求值题中，我们甚至不需要盲目记周期公式，只要沿着对称路径逐个倒推 $f(5)$ 与 $f(-4)$ 即可：

- 先求 $f(5)$：由轴对称 $x = -1$ 可知，$1$ 与 $-3$ 的中点为 $-1$，故 $f(-3) = f(1) = 2$；再由中心对称 $(1, 2)$ 可知，$5$ 与 $-3$ 的中点为 $1$，故
  $$f(5) = 4 - f(-3) = 4 - 2 = 2.$$
- 再求 $f(-4)$：已知 $f(0) = 3$，先由中心对称 $(1, 2)$ 跃过 $1$，因为 $0$ 与 $2$ 关于 $1$ 对称，得
  $$f(2) = 4 - f(0) = 4 - 3 = 1.$$
  再由轴对称 $x = -1$ 跃过 $-1$，因为 $-4$ 与 $2$ 的中点恰好是 $-1$，得
  $$f(-4) = f(2) = 1.$$

于是 $f(5) + f(-4) = 2 + 1 = 3$。顺便注意如果把对称轴错当成 $x = \frac{1}{2}$，就会算出周期 $T = 4|1 - \frac{1}{2}| = 2$ 从而误得 $f(-4) = f(0) = 3$、总和为 $5$ 掉进干扰项 D 的陷阱。正确答案为 **B**。
