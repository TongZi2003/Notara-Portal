# 第09讲·练06：偶周期函数结合单调性比大小

## 内容

已知定义在 $\mathbb{R}$ 上的偶函数 $f(x)$ 满足 $f(x + 2) = f(x)$，且当 $x \in [0, 1]$ 时，$f(x)$ 单调递减。设 $a = f(\log_2 10)$，$b = f(2^{1.5})$，$c = f(-5.2)$，则 $a, b, c$ 的大小关系为（　　）

A. $a > b > c$　　　　B. $a > c > b$　　　　C. $c > a > b$　　　　D. $b > c > a$

## 参考理解

我们看到这道题将周期奇偶函数与指对幂大小比较结合在了一起，第一眼看上去似乎只要估算 $\log_2 10$、$2^{1.5}$、$-5.2$ 的数值就能排大小。但如果直接拿原自变量去比大小，或者只减一次周期落进 $[-1, 0]$ 或 $[1, 2]$ 就套用“单调递减”的性质，结果必然全错。因为题干只告诉了我们在 **$[0, 1]$** 上的单调性，而偶函数结合周期 $2$ 后在 $[1, 2]$ 上恰好变成单调递增的。

**为什么我们必须把三个自变量全部严密地拉进闭区间 $[0, 1]$ 内部，而且要精细估算到小数点后两位附近？** 根据[[卡片/双对称推导周期性与求值法]]，我们的操作铁律是“先拉周期、再偶反射、全入 $[0, 1]$”。下面对 $a, b, c$ 逐一做区间归化，并检验每一步是否真的落在了 $[0, 1]$ 内。

先处理最直观的 $c = f(-5.2)$。因为周期 $T = 2$，把自变量加上 $3$ 个周期（即 $+6$）直接拉回正区间：
$$c = f(-5.2) = f(-5.2 + 6) = f(0.8).$$
这里自变量 $0.8$ 已经稳稳落在 $[0, 1]$ 内（也可以先用偶函数得 $f(5.2) = f(1.2)$，由于 $1.2 \notin [0, 1]$ 须再减 $2$ 得 $f(-0.8) = f(0.8)$，路径不同结论一致）。

再处理 $b = f(2^{1.5})$。先把指数写成根式：$2^{1.5} = 2\sqrt{2}$。因为 $1.4^2 = 1.96 < 2 < 1.5^2 = 2.25$，所以 $2.8 < 2\sqrt{2} < 3$，这说明减掉 $1$ 个周期 $2$ 后恰好落进 $[0, 1]$：
$$b = f(2\sqrt{2}) = f(2\sqrt{2} - 2), \qquad 2\sqrt{2} - 2 \in (0.8, 1).$$
注意这一步的精度：因为 $c$ 的自变量恰好是 $0.8$，而 $2\sqrt{2} - 2$ 严格大于 $0.8$（因为 $\sqrt{2} > 1.4 \implies 2\sqrt{2} - 2 > 0.8$），不用再往下精确算，就已经确定 **$0.8 < 2\sqrt{2} - 2 < 1$**。

最后处理 $a = f(\log_2 10)$。先判断 $\log_2 10$ 的大致范围：$\log_2 8 = 3 < \log_2 10 < \log_2 16 = 4$。如果减掉 $1$ 个周期 $2$ 得到 $\log_2 10 - 2 \in (1, 2)$，依然不在 $[0, 1]$ 内；因此应该直接减掉 $2$ 个周期（即 $-4$）落入 $(-1, 0)$，再借用偶函数性质 $f(-t) = f(t)$ 翻正：
$$a = f(\log_2 10) = f(\log_2 10 - 4) = f(4 - \log_2 10).$$
把 $4 - \log_2 10$ 化为单个对数：
$$4 - \log_2 10 = \log_2 16 - \log_2 10 = \log_2 \frac{16}{10} = \log_2 1.6.$$
显然 $1 < 1.6 < 2 \implies 0 < \log_2 1.6 < 1$，成功归入 $[0, 1]$。

现在我们需要严密比较归化后的三个自变量：$\log_2 1.6$、$0.8$ 与 $2\sqrt{2} - 2$。因为我们已经知道 $0.8 < 2\sqrt{2} - 2 < 1$，只需把 $\log_2 1.6$ 与 $0.8$ 比清楚即可。取中间过渡有理数 $\frac{3}{4} = 0.75$（利用[[卡片/指对幂比大小三阶通法与中间桥]]），比较 $\log_2 1.6$ 与 $\frac{3}{4}$ 等价于比较 $1.6$ 与 $2^{\frac{3}{4}}$，两边同时四次方得：
$$1.6^4 = (1.6^2)^2 = 2.56^2 = 6.5536 < 8 = 2^3 \implies 1.6 < 2^{\frac{3}{4}} \implies \log_2 1.6 < 0.75 < 0.8.$$
（即便不凑 $0.75$ 直接与 $0.8 = \frac{4}{5}$ 比，也有 $1.6^5 = \left(\frac{8}{5}\right)^5 = \frac{32768}{3125} < 11 < 16 = 2^4$，同样严密得出 $\log_2 1.6 < 0.8$。）

综上，归化进 $[0, 1]$ 后的三个自变量严格排序为：
$$0 < 4 - \log_2 10 < 0.8 < 2\sqrt{2} - 2 < 1.$$
因为 $f(x)$ 在 $[0, 1]$ 上单调递减，所以函数值大小顺序恰好相反：
$$f(4 - \log_2 10) > f(0.8) > f(2\sqrt{2} - 2), \quad \text{即 } a > c > b.$$
因此正确答案为 **B**。
