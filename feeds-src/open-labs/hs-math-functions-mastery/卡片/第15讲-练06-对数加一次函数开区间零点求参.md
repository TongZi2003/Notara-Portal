# 第15讲·练06：对数加一次函数开区间零点求参

## 内容

已知函数 $f(x) = \log_2 x + x - a$ 在开区间 $(2, 4)$ 内存在零点，则实数 $a$ 的取值范围是______。

## 参考理解

我们读题时会注意到一个非常关键的逻辑细节：零点存在定理平时只告诉我们“如果 $f(2)f(4) < 0$，那么 $(2, 4)$ 内就有零点”，它原本只是**充分条件**；反过来如果题目直接告诉我们“在 $(2, 4)$ 内存在零点”，难道就一定能推出 $f(2)f(4) < 0$ 吗？对于一般可以上下折返的曲线来说，这并不成立（比如开口向上的抛物线完全可能让 $f(2) > 0$ 且 $f(4) > 0$，但顶点掉到 $x$ 轴下方）。因此，直接拿 $f(2)f(4) < 0$ 来列不等式之前，必须先补全“单调性”这块拼图，否则推理是不严密的；同时还要小心检验区间是开区间 $(2, 4)$ 还是闭区间 $[2, 4]$。

**第一步：先用定义确认 $f(x)$ 在 $(0, +\infty)$ 上连续且严格单调递增。** 根据[[卡片/单调性定义证明与抽象单调]]，函数 $f(x) = \log_2 x + x - a$ 的定义域为 $(0, +\infty)$，任意取 $0 < x_1 < x_2$，作差比较函数值大小：
$$f(x_2) - f(x_1) = (\log_2 x_2 - \log_2 x_1) + (x_2 - x_1).$$
因为对数函数 $y = \log_2 x$ 在 $(0, +\infty)$ 上严格单调递增，所以由 $0 < x_1 < x_2$ 可知 $\log_2 x_2 - \log_2 x_1 > 0$，同时 $x_2 - x_1 > 0$。两个正数相加仍为正数，故 $f(x_2) > f(x_1)$，即 $f(x)$ 在整个 $(0, +\infty)$ 上**连续且严格单调递增**（无论参数 $a$ 取什么实数都成立）。

**第二步：为什么严格单调递增把“在 $(2, 4)$ 内有零点”等价转化为 $f(2) < 0 < f(4)$？** 既然 $f(x)$ 在闭区间 $[2, 4]$ 上单调递增，根据单调函数的值域范围可知，当 $x$ 在开区间 $(2, 4)$ 内变动时，函数值 $f(x)$ 恰好不重不漏地取遍开区间 **$\bigl(f(2), f(4)\bigr)$** 内的所有实数：
- 如果 $f(2) < 0 < f(4)$，由[[卡片/零点存在定理与二分估界法]]，必然在 $(2, 4)$ 内存在唯一零点；
- 反过来，如果存在 $x_0 \in (2, 4)$ 使得 $f(x_0) = 0$，由于 $2 < x_0 < 4$ 且 $f(x)$ 严格单调递增，必然强制要求 $f(2) < f(x_0) < f(4)$，也就是 **$f(2) < 0$ 且 $f(4) > 0$**（不可能出现 $f(2) \ge 0$ 或 $f(4) \le 0$ 的情况）。

这就严谨证明了本题中“在 $(2, 4)$ 内存在零点”完全等价于不等式组：
$$\begin{cases} f(2) < 0, \\ f(4) > 0. \end{cases}$$

**第三步：代入端点值求解并再次核查等号陷阱。** 分别计算左右端点处的函数值：
$$f(2) = \log_2 2 + 2 - a = 1 + 2 - a = 3 - a,$$
$$f(4) = \log_2 4 + 4 - a = 2 + 4 - a = 6 - a.$$
代入严格不等式组解得：
$$\begin{cases} 3 - a < 0 \implies a > 3, \\ 6 - a > 0 \implies a < 6. \end{cases}$$
最后专门回代检查两个端点值能否取等，彻底堵死开闭区间错误：
- 当 $a = 3$ 时，$f(x) = \log_2 x + x - 3$ 仍严格递增，且 $f(2) = 0$，这意味着整个 $(0, +\infty)$ 上唯一的零点恰是 $x = 2$，而 $2 \notin (2, 4)$，因此在开区间 $(2, 4)$ 内**没有零点**，故 $a = 3$ 必须舍去；
- 当 $a = 6$ 时，$f(4) = 0$，唯一的零点恰是 $x = 4 \notin (2, 4)$，在开区间 $(2, 4)$ 内同样**没有零点**，故 $a = 6$ 也必须舍去。

综上，实数 $a$ 的取值范围是开区间 **$(3, 6)$**。
