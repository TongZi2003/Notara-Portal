# 第02讲·练02：两类二次分式函数求值域

## 内容

求下列两个函数的值域：

(1) $f(x) = \dfrac{x^2 + 3x + 1}{x^2 + x + 1}$；

(2) $g(x) = \dfrac{3x^2 - 8x - 3}{x^2 - 2x - 3}$。

## 参考理解

**(1)** 我们拿到第一个二次比二次分式 $f(x) = \frac{x^2 + 3x + 1}{x^2 + x + 1}$，第一步先确认定义域：把分母配方得到 $x^2 + x + 1 = \left(x + \frac{1}{2}\right)^2 + \frac{3}{4} > 0$，分母对一切实数 $x \in \mathbb{R}$ 恒不为零，因此定义域就是 $\mathbb{R}$。如果此时尝试“分离常数”，只能把分子改写成 $(x^2 + x + 1) + 2x$，拆出 $1 + \frac{2x}{x^2 + x + 1}$，剩下的分式分子分母同时带有 $x$，还是不能直接看出上下界。

**为什么我们转而把函数式交叉相乘，看成关于 $x$ 的方程？** 按照[[卡片/分式与对勾型函数值域法]]，求 $f(x)$ 的值域本质上是问：哪些实数 $y$ 能够让方程 $\frac{x^2 + 3x + 1}{x^2 + x + 1} = y$ 至少存在一个实数解 $x \in \mathbb{R}$。由于分母恒大于零，交叉相乘是完全等价变形，整理成关于 $x$ 的降幂方程：
$$(y - 1)x^2 + (y - 3)x + (y - 1) = 0.$$
到了这里就进入第一个极易漏掉的分类关键点：千万不要直接套用二次方程的判别式 $\Delta \ge 0$。因为只有当二次项系数 $y - 1 \neq 0$ 时它才是一元二次方程；如果随手漏掉分类讨论，一旦遇上 $y = 1$ 对应退化成矛盾等式的问题，就会把本不在值域里的数错算进来。

因此我们**先单独检验二次项系数为零的退化情形**：当 $y - 1 = 0$ 即 $y = 1$ 时，原方程退化为一次方程 $-2x = 0$，解得 $x = 0$。因为 $0$ 在定义域 $\mathbb{R}$ 内，经回代验证 $f(0) = \frac{1}{1} = 1$，所以 **$y = 1$ 确实属于值域**。

再讨论 $y \neq 1$ 的情形：此时方程为一元二次方程，存在实数解 $x \in \mathbb{R}$ 的充要条件是判别式非负：
$$\Delta = (y - 3)^2 - 4(y - 1)^2 \ge 0.$$
这里不要急着全部展开，直接套用平方差公式因式分解更稳妥：
$$\bigl[(y - 3) - 2(y - 1)\bigr]\bigl[(y - 3) + 2(y - 1)\bigr] \ge 0 \implies (-y - 1)(3y - 5) \ge 0,$$
两边同乘 $-1$ 变号得 $(y + 1)(3y - 5) \le 0$，解得 $-1 \le y \le \frac{5}{3}$（且 $y \neq 1$）。把刚才单独验证成立的 $y = 1$ 并回来，就得到 $f(x)$ 的精确值域为 $\left[-1, \frac{5}{3}\right]$。

**(2)** 再看第二个函数 $g(x) = \frac{3x^2 - 8x - 3}{x^2 - 2x - 3}$。如果有人因为第 (1) 问很顺利，直接照搬交叉相乘套判别式，就会立刻踩进一个经典的“全实数幻觉”陷阱：盲目写成 $(y - 3)x^2 - 2(y - 4)x - 3(y - 1) = 0$ 后，算得 $\Delta = 4(y - 4)^2 + 12(y - 3)(y - 1) = 4(4y^2 - 20y + 25) = 4(2y - 5)^2 \ge 0$ 对一切实数 $y$ 恒成立，从而误以为值域是 $\mathbb{R}$。

**为什么我们坚持先分解分母和分子的因式，再作判断？** 因为只要分母可能为零，交叉相乘就会悄悄抹去“分母不能取零”的限制，把不可取的空洞值混进结果里。先将分子、分母分别十字相乘分解因式：
$$g(x) = \frac{(x - 3)(3x + 1)}{(x - 3)(x + 1)}.$$
分母不为零要求 $(x - 3)(x + 1) \neq 0$，因此函数定义域是 $\{x \in \mathbb{R} \mid x \neq 3 \text{ 且 } x \neq -1\}$。在定义域内约去非零公因式 $(x - 3)$ 并分离常数，得到等价表达式：
$$g(x) = \frac{3x + 1}{x + 1} = 3 - \frac{2}{x + 1} \qquad (x \neq 3 \text{ 且 } x \neq -1).$$
现在我们把两条被约分和退化掩盖的禁忌值逐一剔除：
- 第一条禁忌来自**水平渐近线**：由于对任意 $x \neq -1$ 都有 $\frac{2}{x + 1} \neq 0$，故 $g(x) = 3 - \frac{2}{x + 1} \neq 3$。若回头用交叉相乘的方程验算 $y = 3$，也会发现 $2x - 6 = 0$ 解出 $x = 3$，而 $x = 3$ 本就不在定义域内，因此 **$y = 3$ 必须排除**。
- 第二条禁忌来自**公因式空洞点**：当 $x \neq -1$ 时，$\frac{2}{x + 1}$ 可以取遍除 $0$ 以外的一切非零实数，但题目还挖掉了 $x = 3$ 这一点。如果允许 $x = 3$，约分后的表达式会取到 $3 - \frac{2}{3 + 1} = \frac{5}{2}$；而若强令 $3 - \frac{2}{x + 1} = \frac{5}{2}$，唯一解就是被定义域排除的 $x = 3$（这也正是刚才判别式里 $(2y - 5)^2 = 0$ 对应的重根位置），因此 **$y = \frac{5}{2}$ 同样无法取到**。

剔除 $\frac{5}{2}$ 和 $3$ 这两个孤立数值后，其余一切实数都能反解出定义域内的 $x = \frac{2}{3 - y} - 1$ 与之对应。综上所述，$g(x)$ 的值域为 $\left(-\infty, \frac{5}{2}\right) \cup \left(\frac{5}{2}, 3\right) \cup (3, +\infty)$。
