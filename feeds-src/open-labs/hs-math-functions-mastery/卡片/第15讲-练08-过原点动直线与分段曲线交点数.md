# 第15讲·练08：过原点动直线与分段曲线交点数

## 内容

已知分段函数
$$f(x) = \begin{cases} 3 - x, & x < 1, \\ x^2 - 4x + 5, & x \ge 1. \end{cases}$$
设动直线 $y = kx$（$k \in \mathbb{R}$）与函数 $y = f(x)$ 的图像交点个数为 $N$，试按实数 $k$ 的取值对交点个数 $N$ 进行完整分类讨论。

## 参考理解

我们看到这道题涉及过原点的旋转直线 $y = kx$ 与分段“射线 + 抛物线”求交点个数，最容易踩中两个经典陷阱：第一个陷阱是算出抛物线相切的 $\Delta = 0$ 有两个斜率值后，不检验切点在不在有效分段 $x \ge 1$ 上，把另一侧被剪掉的虚假相切斜率也当成临界；第二个陷阱是在连接分界点 $(1, 2)$ 的斜率 $k = 2$ 附近，没有看清左支是空心、右支是实心，从而把各段交点个数加乱。

**第一步：画出清晰草图并标注空实心端点与关键斜率。** 根据[[卡片/水平与动直线数形结合定参法]]，先分别描绘出 $y = f(x)$ 的两段定曲线：
- **左支（$x < 1$）**：$y = 3 - x$ 是斜率为 $-1$ 的射线，从左上方一直向右下延伸至分界点 $(1, 2)$ 处停止，且 **$(1, 2)$ 为空心点**（经过 $(0, 3)$，$(-1, 4)$）；
- **右支（$x \ge 1$）**：$y = x^2 - 4x + 5 = (x - 2)^2 + 1$ 是开口向上、对称轴为 $x = 2$ 的抛物线右支，起点 **$(1, 2)$ 为实心点**，向下经过顶点 $(2, 1)$，之后单调递增至 $+\infty$。

接下来，我们把过原点 $(0, 0)$ 的旋转直线 $y = kx$ 在左、右两个分段上各自有多少交点分别用代数算得一清二楚，再汇总相加，绝不靠目测猜数。

**第二步：单独统计动直线 $y = kx$ 与左支 $y = 3 - x$（$x < 1$）的交点个数。**
联立方程 $kx = 3 - x$（要求解满足 $x < 1$），整理得 $(k + 1)x = 3$：
- 当 $k = -1$ 时（直线与射线平行，斜率同为 $-1$），方程化为 $0 = 3$，无解，交点数为 **$0$**；
- 当 $k \neq -1$ 时，唯一解为 $x = \frac{3}{k + 1}$。要使它落入左支定义域 $x < 1$，需解不等式 $\frac{3}{k + 1} < 1$：
  - 若 $k + 1 < 0$（即 $k < -1$），则 $\frac{3}{k + 1} < 0 < 1$ 恒成立，故有 **$1$** 个交点；
  - 若 $k + 1 > 0$（即 $k > -1$），不等式等价于 $3 < k + 1 \iff k > 2$。因此当 $k > 2$ 时有 **$1$** 个交点，而当 $-1 < k \le 2$ 时求出的交点横坐标 $\ge 1$，落在左支定义域之外（包括 $k = 2$ 时恰好穿过空心点 $(1, 2)$），交点数为 **$0$**。

小结左支结论：当 $k < -1$ 或 $k > 2$ 时，左支有 $1$ 个交点；当 $-1 \le k \le 2$ 时，左支有 $0$ 个交点。

**第三步：单独统计动直线 $y = kx$ 与右支 $y = x^2 - 4x + 5$（$x \ge 1$）的交点个数（重点校验相切点）。**
联立方程 $x^2 - 4x + 5 = kx$，即研究二次方程
$$g(x) = x^2 - (4 + k)x + 5 = 0$$
在闭区间 $[1, +\infty)$ 上不同实数根的个数。先求直线与完整抛物线相切的临界条件，令判别式 $\Delta = 0$：
$$\Delta = (4 + k)^2 - 20 = 0 \implies 4 + k = \pm 2\sqrt{5} \implies k_1 = 2\sqrt{5} - 4, \quad k_2 = -4 - 2\sqrt{5}.$$
现在必须**回代检验切点横坐标 $x_0 = \frac{4 + k}{2}$ 是否真落在有效分段 $x \ge 1$ 内**：
- 当 $k = k_1 = 2\sqrt{5} - 4$ 时，切点横坐标 $x_0 = \frac{2\sqrt{5}}{2} = \sqrt{5} \approx 2.236 \ge 1$，确实落在右支上，所以 **$k = 2\sqrt{5} - 4$ 是有效真切点斜率**（此时右支有 $1$ 个交点）；
- 当 $k = k_2 = -4 - 2\sqrt{5}$ 时，切点横坐标 $x_0 = \frac{-2\sqrt{5}}{2} = -\sqrt{5} < 1$，根本不在定义域 $[1, +\infty)$ 上，只是直线在第三象限碰到了被剪掉的那半边虚抛物线，属于**虚假切点，必须果断剔除**。

再用端点值和对称轴锁定右支在 $[1, +\infty)$ 上的其余斜率区间（注意到过分界实心点 $(1, 2)$ 的斜率为 $k = \frac{2 - 0}{1 - 0} = 2$，且 $g(1) = 1 - (4 + k) + 5 = 2 - k$）：
- 当 $k > 2$ 时：$g(1) = 2 - k < 0$，由于抛物线 $g(x)$ 开口向上，必然在 $(-\infty, 1)$ 与 $(1, +\infty)$ 内各有一个实根，因此落在 $[1, +\infty)$ 内的只有 **$1$** 个交点；
- 当 $k = 2$ 时：方程为 $x^2 - 6x + 5 = 0$，解得 $x = 1$（实心点）和 $x = 5$，均满足 $x \ge 1$，因此有 **$2$** 个交点；
- 当 $2\sqrt{5} - 4 < k < 2$ 时：此时 $\Delta > 0$，端点值 $g(1) = 2 - k > 0$，且对称轴 $x_{\text{轴}} = \frac{4 + k}{2} > \frac{2\sqrt{5}}{2} = \sqrt{5} > 1$，两个不同实根全在 $(1, +\infty)$ 内，因此有 **$2$** 个交点；
- 当 $k = 2\sqrt{5} - 4$ 时：有 **$1$** 个有效切点；
- 当 $k < 2\sqrt{5} - 4$ 时：若 $-4 - 2\sqrt{5} < k < 2\sqrt{5} - 4$，则 $\Delta < 0$ 无实根；若 $k \le -4 - 2\sqrt{5}$，虽有 $\Delta \ge 0$，但对称轴 $x_{\text{轴}} = \frac{4+k}{2} \le -\sqrt{5} < 1$ 且 $g(1) = 2 - k > 0$，两根均小于 $1$，在 $[1, +\infty)$ 上同样无根。因此对所有 $k < 2\sqrt{5} - 4$，右支交点数均为 **$0$**。

**第四步：合并左支与右支交点数，给出最终分类结果。**
注意到临界值排序为 $-1 < 2\sqrt{5} - 4 < 2$（因为 $2\sqrt{5} - 4 \approx 0.472$），我们将两支交点数逐段相加：
- 当 $k < -1$ 时：左支 $1$ 个 $+$ 右支 $0$ 个 $= 1$ 个交点；
- 当 $-1 \le k < 2\sqrt{5} - 4$ 时：左支 $0$ 个 $+$ 右支 $0$ 个 $= 0$ 个交点；
- 当 $k = 2\sqrt{5} - 4$ 时：左支 $0$ 个 $+$ 右支 $1$ 个 $= 1$ 个交点；
- 当 $2\sqrt{5} - 4 < k \le 2$ 时：左支 $0$ 个 $+$ 右支 $2$ 个 $= 2$ 个交点；
- 当 $k > 2$ 时：左支 $1$ 个 $+$ 右支 $1$ 个 $= 2$ 个交点（虽然在 $k = 2$ 处交点恰好从右侧的 $(1, 2)$ 转移到了左侧射线，但总数始终保持为 $2$）。

综上所述，交点个数 $N$ 随实数 $k$ 的完整分类结论为：
- 当 $-1 \le k < 2\sqrt{5} - 4$ 时，$N = 0$；
- 当 $k < -1$ 或 $k = 2\sqrt{5} - 4$ 时，$N = 1$；
- 当 $k > 2\sqrt{5} - 4$ 时，$N = 2$。
