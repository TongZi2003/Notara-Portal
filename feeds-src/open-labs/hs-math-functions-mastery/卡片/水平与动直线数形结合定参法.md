# 水平与动直线数形结合定参法

## 内容

已知含参方程（如 $f(x) - a = 0$、$f(x) - kx - b = 0$）实数根的个数反求参数取值范围，是高一期中期末及模拟卷最常压轴在选填后两题的“数形结合”母型。破题核心是**隔离出不含参数的清晰定曲线，让所有参数只停留在一条最简单的动直线上**。

### 1. 三类最常见的「定曲线 + 动直线」分离方案

| 方程原结构 | 标准分离形态 | 动直线运动特征 |
| :--- | :--- | :--- |
| $f(x) - m = 0$ | $y = f(x)$ 与 **$y = m$** | **水平平移直线**，高度随 $m$ 上下扫过定曲线 |
| $f(x) - k(x - x_0) - y_0 = 0$ | $y = f(x)$ 与 **$y = k(x - x_0) + y_0$** | 恒过定点 **$(x_0, y_0)$ 旋转**（$k$ 为斜率，特别常见 $y = kx$ 过原点旋转） |
| $f(x) - mx - b = 0$（含自由常数 $b$） | $y = f(x)$ 与 **$y = mx + b$** | **斜率固定、上下平移**（如 $y = x + b$ 沿纵轴平移） |

（注：遇到更巧妙的结构如 $f(x) - a g(x) = 0$ 且参数难以直接变直线时，可先看能否同除为 $\frac{f(x)}{g(x)} = a$ 降回水平线模型，或画出两已知简单曲线各自特征点比较位置。）

### 2. 确定参数区间端点开闭的「三大生死临界线」

很多同学草图画对了、大致范围看对了，偏偏在开区间与闭区间上丢掉全题分数。扫动直线数交点时，必须对每段临界点逐一敲死以下三关：

1. **空心点 vs 实心点（分段定义域开闭）**：
   画分段曲线时，**属于该段的点必须点大实心点，不属于的必须画明确空心圈**。当动直线恰好穿进那个拼接高度时，实心算 $1$ 个交点、空心算 $0$ 个交点（多一根还是少一根全靠这个等号）。
2. **水平 / 竖直渐近线（趋近却永不相交）**：
   遇到 $a^x$、$\frac{k}{x}$、$|a^x - 1|$ 时，必须用虚线画出渐近线（如 $y = 1$）。当动直线恰好与水平渐近线重合时，曲线那一侧无限逼近却**交点数直接降为 $0$**。
3. **直线与二次曲线「代数相切临界」**：
   当斜率旋转或固定斜率直线刚好擦过抛物线分支时，在纯高一范围内不用借助高阶工具，直接**联立二次方程组消去 $y$，令一元二次方程判别式 $\Delta = 0$** 即可精准锁定相切参数；解出后还必须**回代检验切点横坐标是否真落在该抛物线定义域分段内**，切在分段之外的切点是虚假临界。

## 参考理解

### 实战示范：旋转直线的“回代切点位置校验”

例如求直线 $y = kx$（过原点）与分段抛物线右支 $y = x^2 - 4x + 5\ (x \ge 1)$ 交点个数变化临界：
- 联立 $x^2 - (4 + k)x + 5 = 0$，令 $\Delta = (4+k)^2 - 20 = 0 \implies k = -4 \pm 2\sqrt{5}$；
- **必须回代验切点位置**。切点横坐标为 $x_0 = \frac{4 + k}{2}$：
  - 当 $k = 2\sqrt{5} - 4$ 时，$x_0 = \sqrt{5} > 1$（落在右支定义域 $x \ge 1$ 上，**有效真切点**）；
  - 当 $k = -4 - 2\sqrt{5}$ 时，$x_0 = -\sqrt{5} < 1$（根本不在有效图像上，只是被剪掉的左侧虚抛物线的假相切分支，必须**果断剔除**）。
- 再算连接过端点 $(1, 2)$ 的射线斜率 $k_1 = \frac{2 - 0}{1 - 0} = 2$，于是斜率从大往小（或从小往大）扫过第一象限的有效交点个数瞬间排得明明白白，绝不会出现莫名其妙的无效端点。

### 隐蔽变形提示

遇到形如方程 $f(x) = a$ 中曲线本身含未知绝对值平移，如 $|2^x - 1| = a$ 或 $||x^2 - 2x| - 1| = m$，一定先把左侧绝对值多层折线老老实实翻上来，再标出每一处极小谷值与峰顶纵坐标、以及渐近线纵坐标，最后拿一把尺子在草图上从下往上水平扫描，**每过一个特殊水平线，写一次当前交点总个数**，这是唯一 0 失误的方法。

### 变式追问

1. 已知分段函数 $f(x) = \begin{cases} x^2 + 2x, & x < 0, \\ -x^2 + 2x, & x \ge 0, \end{cases}$ 当直线 $y = kx$ 与曲线恰有 $3$ 个交点时，为什么斜率 $k$ 在端点 $(0, 0)$ 处必须特别看清抛物线从左侧和右侧穿过原点时的正负斜率边界（纯二次方程根检验）？
2. 画出函数 $f(x) = \begin{cases} 2^x, & x \le 0, \\ \log_2(x+1), & x > 0 \end{cases}$ 的草图（注意 $x=0$ 两侧的值是否接上），讨论水平线 $y = m$ 的交点个数如何随 $m$ 分段变化。
