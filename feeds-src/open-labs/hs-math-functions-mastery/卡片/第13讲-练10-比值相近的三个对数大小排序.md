# 第13讲·练10：比值相近的三个对数大小排序

## 内容

已知 $a = \log_5 3$，$b = \log_8 5$，$c = \log_{13} 8$，将 $a, b, c$ 按从小到大的顺序排列为__________。

## 参考理解

我们拿到这组数时，会立刻注意到真数和底数来自“后一项等于前两项之和”的一组数 $3, 5, 8, 13$。不少同学看到这里容易凭直觉去比较真数与底数的比值：
$$\frac{3}{5} = 0.600, \qquad \frac{5}{8} = 0.625, \qquad \frac{8}{13} \approx 0.6154.$$
如果误以为“真数除以底数越大，对数值就越大”，就会得出 $\frac{3}{5} < \frac{8}{13} < \frac{5}{8}$，进而错排成 $a < c < b$。实际上，真底之比确实在 $\frac{\sqrt{5}-1}{2} \approx 0.618$ 上下一左一右交错逼近，但这并不代表对数 $\log_p q$ 也会跟着来回摆动。再看看如果直接用[[卡片/对数糖水不等式与取倒数减整法]]里的“同加正数”模型：$a = \log_5 3$ 到 $b = \log_8 5$ 是底数 $+3$、真数 $+2$，增量不等；$b = \log_8 5$ 到 $c = \log_{13} 8$ 是底数 $+5$、真数 $+3$，增量也不等，而且按照同加减只能卡出 $\log_5 3 < \log_7 5$（比 $b$ 底数更小）或 $\log_8 5 < \log_{11} 8$（同样只能挡在 $c$ 的上侧），依然没法直接把 $a, b, c$ 排在同一条单向链条上。

**为什么我们不用比值直觉或单次糖水放缩，而是继续沿用两轮取倒数减整法？** 因为取倒数减整每一步都是绝对等价的恒等改写与单调函数反号，完全不受真底比值交错震荡的干扰；而且由于每个数前后项相加的性质，取倒数减整后的整数界限正好一步步拉开，只要算出极小次幂就能一锤定音。

先观察 $a, b, c$ 均严格位于 $(0, 1)$ 内（因为 $1 < 3 < 5$，$1 < 5 < 8$，$1 < 8 < 13$）。第一轮我们对这三个正数同时取倒数（大小顺序第一次反转）：
$$\frac{1}{a} = \log_3 5, \qquad \frac{1}{b} = \log_5 8, \qquad \frac{1}{c} = \log_8 13.$$
检查它们的整数部分：由于 $3 < 5 < 3^2$、$5 < 8 < 5^2$、$8 < 13 < 8^2$，三者的整数部分全都是 $1$。我们将整数 $1$ 统一减去（不改变大小方向），化出大于 $0$ 且小于 $1$ 的余项：
$$\frac{1}{a} - 1 = \log_3 \frac{5}{3}, \qquad \frac{1}{b} - 1 = \log_5 \frac{8}{5}, \qquad \frac{1}{c} - 1 = \log_8 \frac{13}{8}.$$

注意观察余项真数里的三个分数：$\frac{5}{3} \approx 1.667$，$\frac{8}{5} = 1.600$，$\frac{13}{8} = 1.625$，它们虽然在 $\frac{\sqrt{5}+1}{2} \approx 1.618$ 左右上下交错，但各自的底数 $3, 5, 8$ 却在迅速放大。这时我们立刻执行第二轮取倒数（大小顺序第二次反转，从而与原始 $a, b, c$ 恢复同向）：
$$A_2 = \frac{1}{\frac{1}{a} - 1} = \log_{\frac{5}{3}} 3, \qquad B_2 = \frac{1}{\frac{1}{b} - 1} = \log_{\frac{8}{5}} 5, \qquad C_2 = \frac{1}{\frac{1}{c} - 1} = \log_{\frac{13}{8}} 8.$$
现在逐一验证这三个大于 $1$ 的对数落在哪两个相邻整数之间：
- 看 $A_2 = \log_{\frac{5}{3}} 3$：计算底数 $\frac{5}{3}$ 的平方与立方，
  $$\left(\frac{5}{3}\right)^2 = \frac{25}{9} < \frac{27}{9} = 3, \qquad \left(\frac{5}{3}\right)^3 = \frac{125}{27} > \frac{81}{27} = 3.$$
  因为底数 $\frac{5}{3} > 1$，所以 **$2 < A_2 < 3$**；
- 看 $B_2 = \log_{\frac{8}{5}} 5$：计算底数 $\frac{8}{5}$ 的 $3$ 次方与 $4$ 次方，
  $$\left(\frac{8}{5}\right)^3 = \frac{512}{125} < \frac{625}{125} = 5, \qquad \left(\frac{8}{5}\right)^4 = \frac{4096}{625} > \frac{3125}{625} = 5.$$
  因为底数 $\frac{8}{5} > 1$，所以 **$3 < B_2 < 4$**；
- 看 $C_2 = \log_{\frac{13}{8}} 8$：计算底数 $\frac{13}{8}$ 的 $4$ 次方与 $5$ 次方（此处 $13^2 = 169$，$169^2 = 28561$，$8^4 = 4096$，$8^5 = 32768$），
  $$\left(\frac{13}{8}\right)^4 = \frac{28561}{4096} < \frac{32768}{4096} = 8, \qquad \left(\frac{13}{8}\right)^5 = \frac{371293}{32768} > \frac{262144}{32768} = 8.$$
  因为底数 $\frac{13}{8} > 1$，所以 **$4 < C_2 < 5$**。

于是我们清楚地看见：尽管真底比值 $\frac{3}{5}, \frac{5}{8}, \frac{8}{13}$ 在 $0.618$ 左右来回摆动，但经过两轮取倒数减整后的对数值却稳稳地跨过连续整数界限，依次落在 $(2, 3)$、$(3, 4)$、$(4, 5)$ 内：
$$2 < A_2 < 3 < B_2 < 4 < C_2 < 5.$$
由于从 $a, b, c$ 到 $A_2, B_2, C_2$ 经历了两次正数取倒数与一次同减 $1$，两次反号互相抵消，大小关系最终保持同向不变，因此严格得出：
$$a < b < c.$$
从上面这步也能直观看出：每一轮取倒数减整后整数界都在右移，说明这组对数值其实一直在稳定单调增大，完全不会被小数点后面真底比值的上下摆动带偏。故答案为 **$a < b < c$**。
