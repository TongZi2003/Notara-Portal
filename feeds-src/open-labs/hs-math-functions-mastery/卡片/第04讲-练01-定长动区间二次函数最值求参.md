# 第04讲·练01：定长动区间二次函数最值求参

## 内容

已知函数 $f(x) = x^2 - 4x + 5$ 在闭区间 $[t, t + 2]$ 上的最小值为 $2$ 或最大值为 $5$，则实数 $t$ 的所有可能取值构成的集合是（　　）

A. $\{-1, 3\}$　　　　B. $\{0, 2\}$　　　　C. $\{-1, 0, 2, 3\}$　　　　D. $\{-2, -1, 0, 1, 2, 3, 4\}$

## 参考理解

我们看到题目给出的是一个固定抛物线 $f(x) = x^2 - 4x + 5 = (x - 2)^2 + 1$ 和一个长度为 $2$ 的滑动窗口 $[t, t + 2]$。这类「定轴动区间」问题如果直接把两个端点值 $f(t)$ 与 $f(t+2)$ 分别令成 $2$ 或 $5$ 解出一堆数就全部收进集合（如选项 D 的做法），就会把本来在区间内部或另一侧取最值的伪解一并混进来；反过来如果只算了最小值忘了“或最大值为 $5$”，又会误选选项 A。根据[[卡片/含参二次函数动轴与区间最值]]，最严谨的走法是把「最小值为 $2$」和「最大值为 $5$」拆成两条独立支线，每一条都先写清 $t$ 所在的分段前提，解出候选值后立即回代检验前提是否成立。

**为什么我们先分别计算区间端点函数值与顶点值？** 因为抛物线开口向上、对称轴固定为 $x = 2$、顶点最小值为 $f(2) = 1$，而窗口 $[t, t + 2]$ 的中点是 $x = t + 1$。提前把两个端点的表达式算清，后面每段只需直接解简单方程：
$$f(t) = (t - 2)^2 + 1, \qquad f(t + 2) = (t + 2 - 2)^2 + 1 = t^2 + 1.$$

先处理第一条支线：**$f(x)$ 在 $[t, t + 2]$ 上的最小值为 $2$**。比较对称轴 $2$ 与左端点 $t$、右端点 $t + 2$ 的位置关系，分三段讨论：
- 若对称轴在区间左侧或左端点上，即 $2 \le t$，函数在 $[t, t + 2]$ 上单调递增，最小值为 $f(t) = (t - 2)^2 + 1 = 2$，解得 $(t - 2)^2 = 1 \implies t = 3$ 或 $t = 1$。核验前提 $t \ge 2$：**$t = 3$ 保留**，$t = 1$ 越界舍去（因为当 $t = 1$ 时区间为 $[1, 3]$，最小值是顶点值 $1$ 而非 $2$）；
- 若对称轴严格落入区间内部，即 $t < 2 < t + 2$（等价于 $0 < t < 2$），此时最小值必为顶点值 $f(2) = 1 \neq 2$，无解；
- 若对称轴在区间右侧或右端点上，即 $t + 2 \le 2$（等价于 $t \le 0$），函数在 $[t, t + 2]$ 上单调递减，最小值为 $f(t + 2) = t^2 + 1 = 2$，解得 $t = \pm 1$。核验前提 $t \le 0$：**$t = -1$ 保留**，$t = 1$ 再次越界舍去。

于是第一条支线得到 $t \in \{-1, 3\}$。

再处理第二条支线：**$f(x)$ 在 $[t, t + 2]$ 上的最大值为 $5$**。开口向上时最大值只比较对称轴 $2$ 与区间中点 $t + 1$ 的大小关系，只需分两段：
- 若对称轴在中点左侧或与中点重合，即 $2 \le t + 1$（等价于 $t \ge 1$），右端点 $t + 2$ 离对称轴更远，最大值为 $f(t + 2) = t^2 + 1 = 5$，解得 $t = 2$ 或 $t = -2$。核验前提 $t \ge 1$：**$t = 2$ 保留**，$t = -2$ 越界舍去（因为当 $t = -2$ 时区间为 $[-2, 0]$，左端点 $-2$ 离 $x = 2$ 更远，最大值其实是 $f(-2) = 17$）；
- 若对称轴在中点右侧，即 $2 > t + 1$（等价于 $t < 1$），左端点 $t$ 离对称轴更远，最大值为 $f(t) = (t - 2)^2 + 1 = 5$，解得 $t - 2 = \pm 2 \implies t = 4$ 或 $t = 0$。核验前提 $t < 1$：**$t = 0$ 保留**，$t = 4$ 越界舍去（因为当 $t = 4$ 时区间为 $[4, 6]$，最大值为 $f(6) = 17$）。

于是第二条支线得到 $t \in \{0, 2\}$。

因为题设要求“最小值为 $2$ **或**最大值为 $5$”，把两条支线经过越界检验后留下的解取并集，即得 $t$ 的全部可能取值集合为 $\{-1, 0, 2, 3\}$。最后用具体区间心算复核一遍：$[-1, 1]$ 的最小值为 $f(1) = 2$；$[0, 2]$ 的最大值为 $f(0) = 5$；$[2, 4]$ 的最大值为 $f(4) = 5$；$[3, 5]$ 的最小值为 $f(3) = 2$，四个值全部成立且无一遗漏，对应选项 **C**。
