# 多零点水平截线对称消元求范围

## 内容

当题目给出一类分段对数、指数或二次函数，设水平线 $y = t$ 与之产生 $3$ 个或 $4$ 个不同的交点 $x_1 < x_2 < x_3\ (< x_4)$ 满足 $f(x_1) = f(x_2) = f(x_3) = f(x_4) = t$，进而要求 $x_1 + x_2 + x_3 + x_4$、$x_1 x_2 + x_3 x_4$ 或 $x_1 x_2 x_3 x_4$ 的取值范围时，这是一道高一最经典的**“先由数形结合卡准水平截线高度范围，再用对称关系消元变成单变量函数”**的压轴好题。

### 1. 标准「四步解题流程」

1. **精准绘图，框定水平截线高度 $t$ 的开闭取值区间**：
   作出完整分段函数草图（尤其标好空实心分段界点与翻折尖角），找出能让水平线 $y = t$ **严格切出目标个数的交点**的纵坐标 $t$ 的范围 $(t_{\min}, t_{\max})$（通常左右端点多为**开区间**，因为压在分段点或谷底时交点数会减少）。
2. **分双配对，用轴对称或翻折关系消去两组变量**：
   - **抛物线 / 绝对值对称两根**：若 $x_i, x_j$ 落在对称轴为 $x = a$ 的同一抛物线（或绝对值平底翻折线）两翼上，直接得之和定值：
     $$x_i + x_j = 2a;$$
   - **绝对值对数两根（如 $|\log_a x| = t$）**：左翼 $-\log_a x_1 = t$，右翼 $\log_a x_2 = t$，两式相加得 $\log_a(x_1 x_2) = 0 \implies$ **两根之积恒为 $1$**：
     $$x_1 x_2 = 1, \quad \text{且 } x_1 = \frac{1}{x_2} \text{（或 } x_2 = a^t \text{）}.$$
   - **一般对称或二次两根**：利用韦达定理写出 $x_3 + x_4$ 与 $x_3 x_4$ 的表达式，消去对参数或保留单一代表根（通常选最右端单调支的根 $x_3$ 或 $x_4$ 作为**核心主元**）。
3. **确定主元的精确取值区间**：
   通过前面确定的截线高度范围 $t \in (t_{\min}, t_{\max})$，在单一单调段上把其余交点全部换成同一个代表元（例如由 $x_2 = 2^t$ 把 $t$ 换成 $x_2 \in (1, 2)$），或把待求目标式写成关于某一个边根（如 $x_4$）的一元函数。
4. **用高一单调性/对勾函数求解最终范围（严防开闭写错）**：
   判断最终单变量函数（常见对勾函数 $u + \frac{1}{u}$、飘带函数、一次分式或二次函数）在已锁定主元区间上的增减性——注意判断对勾拐点是否在区间内——最后代端点值输出准确区间。

### 2. 常见两翼乘积配对变化速查

| 翻折分段形式 | 令函数值同等于 $t$ 的左、右支等式 | 相加/相乘后的消元恒等式 |
| :--- | :--- | :--- |
| $y = |\log_a x|\ (a>1)$ | $-\log_a x_1 = t,\ \log_a x_2 = t$ | $x_1 x_2 = 1$（且 $x_2 = a^t > 1$） |
| $y = |\log_a(x + h)|\ (a>1)$ | $-\log_a(x_1+h) = t,\ \log_a(x_2+h) = t$ | $(x_1 + h)(x_2 + h) = 1$ |
| $y = |a^x - 1|\ (a>1)$ | $1 - a^{x_1} = t,\ a^{x_2} - 1 = t$ | $a^{x_1} + a^{x_2} = 2$（此时常要求 $2^{x_1} + 2^{x_2}$ 或先凑指数和） |
| $y = \bigl|x^2 - 2ax + b\bigr|$ 对称翼 | 对称轴始终是 $x = a$ | $x_1 + x_4 = 2a,\ x_2 + x_3 = 2a$（或者四根乘积用二次方程韦达展开） |

## 参考理解

### 高频失分坑位警报

1. **对勾函数拐点没落在定义域内却盲用基本不等式**：
   当算到 $x_1 + x_2 + x_3 + x_4 = x_2 + \frac{1}{x_2} + 8$ 时，如果由 $t \in (0, 1)$ 解得 $x_2 = 2^t \in (1, 2)$，因为主元取不到 $x_2 = 1$，最小值点在开区间 $(1, 2)$ 左端外，此时 $u + \frac{1}{u}$ **严格递增**，范围是开区间 $\left(2 + 8, \frac{5}{2} + 8\right) = \left(10, \frac{21}{2}\right)$；若换成对数支取到 $x_2 \in [2, 4]$ 同样远离 $1$ 点。永远用对勾函数单调区间的左支 $(0, 1]$ 与右支 $[1, +\infty)$ 核验取等点在不在主元范围里。
2. **忽略水平截线临界高度空心点导致多包闭端点**：
   分清左端 $x=2$ 是实心还是空心。一旦 $t$ 踩上分界高度时有一侧是空心点（只有 3 个根），那 $t$ 必须取**严格不等号**；进而反映到代表元区间上是开区间，最终目标值的区间也必须随函数严格单调性保持**对应侧为开区间**（除非该值恰好在某内部极值点上取得）。

### 变式追问

1. 若函数左段是 $|2^x - 1|$（$x \le 1$）、右段是开口向上的二次曲线 $x^2 - 6x + 9$（$x > 1$），存在三个互不相等实根满足 $f(x_1) = f(x_2) = f(x_3) = t$，求此时 $t$ 的范围及 $(x_1 + x_2 + x_3)$ 还是 $2^{x_1} + 2^{x_2}$ 才更好化简？
2. 若 4 个交点中左翼对数翻折的纵坐标高度 $t$ 能够刚好跨越二次段对称轴底峰，同时又受指数支横坐标范围约束，在用 $x_4$ 当唯一代表元反推 $x_1 + x_2$ 时怎么快速建立 $t$ 与 $x_4$ 的二次式代换？
