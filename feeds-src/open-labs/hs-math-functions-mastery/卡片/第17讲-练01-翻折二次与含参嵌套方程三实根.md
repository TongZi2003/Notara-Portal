# 第17讲·练01：翻折二次与含参嵌套方程三实根

## 内容

已知函数 $f(x) = |x^2 - 4x + 3|$，若关于 $x$ 的方程 $\bigl[f(x)\bigr]^2 - 2a f(x) + 2a - 1 = 0$ 恰有 $3$ 个互不相等的实数根，则实数 $a$ 的取值范围是__________。

## 参考理解

我们看到这道填空题时，最容易犯的错误有两个：要么习惯性地把“$3$ 个根”简单拆成某一种情况就急着下结论，漏掉外层根落在函数值域之外（对应 $0$ 个实根 $x$）的情况；要么把外层二次方程的两个相等实根 $t_1 = t_2 = 1$ 当成两条分开的线去算 $3 + 3 = 6$ 个根，白白丢掉那个隐藏的孤立解。要想在填空题里拿稳全分，我们必须按照[[卡片/复合嵌套方程换元拆层数根法]]的规范，先画清内函数图像与交点个数表，再逐类拆分外层方程。

先考察内函数 $f(x) = |x^2 - 4x + 3| = |(x - 2)^2 - 1|$ 的图像特征。根据[[卡片/函数图像平移对称与绝对值翻折]]，原抛物线 $y = x^2 - 4x + 3$ 开口向上、对称轴为 $x = 2$、零点为 $x = 1$ 与 $x = 3$、顶点为 $(2, -1)$；加上绝对值后，位于 $x$ 轴下方的 $(1, 3)$ 段沿 $x$ 轴向上翻折，翻折后的峰值恰好落在 $(2, 1)$。据此从下往上写出水平线 $y = t$ 与 $y = f(x)$ 交点数 $N(t)$ 的完整分布表：
- 当 $t < 0$ 时，$N(t) = 0$；
- 当 $t = 0$ 时，$N(0) = 2$（即 $x = 1$ 与 $x = 3$）；
- 当 $0 < t < 1$ 时，$N(t) = 4$（两侧各 $1$ 个，中间翻折弧 $2$ 个）；
- 当 $t = 1$ 时，$N(1) = 3$（中间切过峰值 $x = 2$，外加两侧 $x = 2 - \sqrt{2}$ 与 $x = 2 + \sqrt{2}$）；
- 当 $t > 1$ 时，$N(t) = 2$（仅外侧两支相交）。

接着令 $t = f(x)$，外层方程化为关于 $t$ 的一元二次方程：
$$t^2 - 2at + 2a - 1 = 0.$$
直接计算判别式并尝试因式分解，会发现结构极其干净：
$$\Delta = 4a^2 - 4(2a - 1) = 4(a - 1)^2 \ge 0,$$
且方程左边可以直接分解为 $(t - 1)\bigl(t - (2a - 1)\bigr) = 0$，于是外层必有根 $t_1 = 1$ 与 $t_2 = 2a - 1$。但这里千万不能不加区分地写 $N_{\text{总}} = N(1) + N(2a - 1)$，必须严格按 $t_1$ 与 $t_2$ 是否相等分为两大类讨论：

- **情形一：外层出现重根（即 $\Delta = 0$，$a = 1$）**。
  此时 $t_1 = t_2 = 1$，外层方程只有一个实数解 $t = 1$。在 $y = f(x)$ 图像上对应的水平直线只有唯一一条 $y = 1$，它对总实根数的贡献只能算一次 $N(1) = 3$，绝不是双倍计数成 $6$。直接回代验证原方程：当 $a = 1$ 时方程化为 $\bigl[f(x) - 1\bigr]^2 = 0 \iff f(x) = 1$，解得 $x = 2, 2 - \sqrt{2}, 2 + \sqrt{2}$，确为 $3$ 个互异实根。因此 **$a = 1$ 符合题意**。

- **情形二：外层有两个互异实根（即 $a \neq 1$，两根为 $t_1 = 1$ 与 $t_2 = 2a - 1$）**。
  因为 $1 \neq 2a - 1$，两条平行水平线 $y = 1$ 与 $y = 2a - 1$ 永不重合，所以总实根数严格等于 $N(1) + N(2a - 1) = 3 + N(2a - 1)$。要让总实根数为 $3$，就必须使 $N(2a - 1) = 0$。对照前面的交点个数表，$N(t) = 0$ 当且仅当 $t < 0$，即：
  $$2a - 1 < 0 \implies a < \frac{1}{2}.$$
  同时顺便核对其他区间以防遗漏：若 $a = \frac{1}{2}$ 则 $t_2 = 0$，得 $3 + N(0) = 5$ 个根；若 $\frac{1}{2} < a < 1$ 则 $t_2 \in (0, 1)$，得 $3 + 4 = 7$ 个根；若 $a > 1$ 则 $t_2 > 1$，得 $3 + 2 = 5$ 个根。均不是 $3$ 个根。

综上所述，合并情形一的孤立解与情形二的开区间，实数 $a$ 的完整取值范围是 $\left(-\infty, \frac{1}{2}\right) \cup \{1\}$。

## 学生理解
