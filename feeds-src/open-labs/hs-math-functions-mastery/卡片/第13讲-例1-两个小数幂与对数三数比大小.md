# 第13讲·例1：两个小数幂与对数三数比大小

## 内容

已知 $a = 0.7^{0.6}$，$b = 0.6^{0.7}$，$c = \log_5 2$，则 $a, b, c$ 的大小关系是（　　）

A. $a > b > c$　　　　B. $b > a > c$　　　　C. $a > c > b$　　　　D. $c > a > b$

## 参考理解

我们照惯例先拿 $0$ 和 $1$ 来粗分这组数，很快就会发现这一步失灵了：底数 $0.7, 0.6 \in (0, 1)$ 且指数均为正，所以 $0 < a < 1$、$0 < b < 1$；而 $c = \log_5 2$ 中底数 $5 > 1$、真数 $2 \in (1, 5)$，所以同样满足 $0 < c < 1$。三个数全都挤在 $(0, 1)$ 里面，单靠 $0$ 和 $1$ 根本分不出谁高谁低。

**为什么我们先挑出 $a = 0.7^{0.6}$ 和 $b = 0.6^{0.7}$ 做“十字拼装桥”？** 根据[[卡片/指对幂比大小三阶通法与中间桥]]，面对两个“底数、指数刚好交叉错位”的幂，最稳的办法是取出一方的底数和另一方的指数拼成中间数 $0.7^{0.7}$（也可以拼 $0.6^{0.6}$，方向同样成立），把一次跨类比较拆成同底与同指两步单调比较：
- 先看 $0.7^{0.6}$ 与 $0.7^{0.7}$：把底数固定为 $0.7 \in (0, 1)$，指数函数 $y = 0.7^x$ 在 $\mathbb{R}$ 上**严格单调递减**，因为 $0.6 < 0.7$，所以
  $$0.7^{0.6} > 0.7^{0.7}.$$
- 再看 $0.7^{0.7}$ 与 $0.6^{0.7}$：把指数固定为 $0.7 > 0$，幂函数 $y = x^{0.7}$ 在 $(0, +\infty)$ 上**严格单调递增**，因为 $0.7 > 0.6 > 0$，所以
  $$0.7^{0.7} > 0.6^{0.7}.$$

把这两条不等式串成一条传递链，立即确定 $a = 0.7^{0.6} > 0.7^{0.7} > 0.6^{0.7} = b$。

接下来只要确定 $c = \log_5 2$ 与 $b = 0.6^{0.7}$ 的大小即可（如果 $c < b$ 就全盘排定）。**为什么我们尝试用 $\frac{1}{2}$ 作为精细桥梁来隔开 $b$ 和 $c$？** 先看对数 $c = \log_5 2$：拿它和 $\frac{1}{2}$ 比，等价于看真数 $2$ 与 $5^{\frac{1}{2}} = \sqrt{5}$ 的大小，两边平方得 $2^2 = 4 < 5$，因为 $y = \log_5 x$ 单调递增，立即有
$$c = \log_5 2 < \log_5 \sqrt{5} = \frac{1}{2}.$$
再看较小的幂 $b = 0.6^{0.7}$：由于指数函数 $y = 0.6^x$ 严格单调递减且 $0.7 < 1$，不需算出具体小数就能轻松放大下界：
$$b = 0.6^{0.7} > 0.6^1 = 0.6 > \frac{1}{2}.$$

于是中间桥 $\frac{1}{2}$ 把 $c$ 与 $b$ 干脆地隔开，与前面的交叉幂传递链拼合后得到完整排序：
$$c < \frac{1}{2} < b < a,$$
即 $a > b > c$，对应选项 **A**。
