# 单调性定义证明与抽象单调

## 内容

在解答题中直接写出“该函数先增后减”常常因为没有经过定义证明而被扣步骤分；而在面对没有解析式的抽象函数（如 $f(x+y) = f(x)+f(y)$ 或 $f(xy) = f(x)+f(y)$）时，定义法更是判定单调性的唯一通法。

### 1. 显式函数定义证明「五步标准流程」

要证明 $f(x)$ 在区间 $I$ 上单调递增（或递减）：
1. **设元**：任取 $x_1, x_2 \in I$，且令 $x_1 < x_2$（不能选具体数值，也不能漏掉所属区间）；
2. **作差（或作商）**：计算 $f(x_1) - f(x_2)$（仅当能确认函数值恒正时才可用作商 $\frac{f(x_1)}{f(x_2)}$ 与 $1$ 比较）；
3. **恒等变形（核心关键）**：将差式整理为**彻底因式分解**的乘积结构（提公因式 $(x_1 - x_2)$、通分合并、分子有理化或局部配完全平方）；
4. **逐项定号**：结合 $x_1, x_2 \in I$ 及 $x_1 - x_2 < 0$ 逐个说明每个因式的严格正负号；
5. **收束结论**：得出 $f(x_1) - f(x_2) < 0$（即 $f(x_1) < f(x_2)$）或相反，明确写出在区间 $I$ 上单调递减或递增（如有多段单调区间，严禁用 $\cup$ 连接，必须用“和”或逗号分开列明）。

### 2. 抽象函数单调性的「差值 / 比值配凑法」

设任取 $x_1 < x_2$，核心困难是手头只有加法或乘法函数方程，没有加减直接对比的工具。破局思路是**利用未知自变量本身构造恒等式**：

| 函数方程结构 | 配凑变换技巧 | 需配套的局部正负条件 |
| :--- | :--- | :--- |
| **加和线性型**<br>$f(x+y) = f(x) + f(y)$ | 改写 $x_2 = x_1 + (x_2 - x_1)$，得<br>$f(x_2) - f(x_1) = f(x_2 - x_1)$ | 已知当 $t > 0$ 时 $f(t) > 0$（增）或 $f(t) < 0$（减） |
| **加和带常数型**<br>$f(x+y) = f(x) + f(y) + C$ | 令 $x_2 = x_1 + (x_2 - x_1)$，得<br>$f(x_2) - f(x_1) = f(x_2 - x_1) + C$ | 已知当 $t > 0$ 时 $f(t) > -C$ 或 $< -C$（注意常移项配成 $g(x)=f(x)+C$） |
| **加变乘指数型**<br>$f(x+y) = f(x)f(y)\ (f>0)$ | 算作差提取公因子：<br>$f(x_2) - f(x_1) = f(x_1)\bigl[f(x_2 - x_1) - 1\bigr]$ | 已知 $t > 0$ 时 $f(t) > 1$ 或 $0 < f(t) < 1$（且需先由 $f(x)=\bigl[f(\frac{x}{2})\bigr]^2 > 0$ 证恒正） |
| **乘变加对数型**<br>$f(xy) = f(x) + f(y)\ (x,y>0)$ | 令 $x_2 = x_1 \cdot \frac{x_2}{x_1}$，由 $\frac{x_2}{x_1} > 1$ 得<br>$f(x_2) - f(x_1) = f\left(\frac{x_2}{x_1}\right)$ | 已知当 $t > 1$ 时 $f(t) > 0$ 或 $f(t) < 0$（先赋值 $x=y=1$ 得 $f(1)=0$） |

## 参考理解

### 高频易错断点

1. **特例代替任意（证伪可以，证明无效）**：
   “因为 $f(1) < f(2)$ 所以递增”直接判零分；哪怕只是写出 $f(x_2) - f(x_1)$ 后没有彻底因式分解而留在加减混合态，同样无法给出全称正负判定。必须拆出 $(x_1 - x_2)$ 因子使符号一目了然。
2. **多段单调区间误用并集符号 $\cup$**：
   反比例函数 $y = \frac{1}{x}$ 在 $(-\infty, 0)$ 和 $(0, +\infty)$ 上各自递减，但绝不能写成“在 $(-\infty, 0) \cup (0, +\infty)$ 上单调递减”——因为取 $x_1 = -1 < x_2 = 1$ 时反而有 $f(-1) = -1 < f(1) = 1$。所有跨间断点单调区间必须用“和”字（或分号）分隔。
3. **乘型指数方程未先证正值就直接断言单调**：
   若仅已知 $f(x+y) = f(x)f(y)$ 且 $x>0$ 时 $f(x) > 1$，如果题干没说 $f(x)$ 恒正，要先赋值 $f(x) = \left[f\left(\frac{x}{2}\right)\right]^2 \ge 0$ 再利用反证（若存在 $f(x_0)=0$ 则处处为 $0$ 矛盾于 $f(t)>1$）严密补出 $f(x) > 0$，这样才能放心地用 $f(x_1)\bigl[f(x_2-x_1)-1\bigr]$ 定号。

### 变式追问

1. 已知定义在 $\mathbb{R}$ 上的函数 $f(x)$ 对任意 $x, y$ 满足 $f(x+y) = f(x) + f(y) - 1$，且 $x > 0$ 时 $f(x) < 1$，怎样配出 $g(x) = f(x) - 1$ 一眼看穿它的奇偶性与单调性？
2. 已知函数 $f(x) = \frac{2x + a}{x + 1}$ 在区间 $(-1, +\infty)$ 上单调递增，如何用定义作差法直接把 $a$ 的范围确定出来（先判断 $a=2$ 的常函数退化）？
