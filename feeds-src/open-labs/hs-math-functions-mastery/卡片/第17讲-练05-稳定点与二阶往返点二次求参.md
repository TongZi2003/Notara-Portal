# 第17讲·练05：稳定点与二阶往返点二次求参

## 内容

对于函数 $y = f(x)$，若实数 $x_0$ 满足 $f(x_0) = x_0$，则称 $x_0$ 为函数 $f(x)$ 的“稳定点”；若实数 $x_0$ 满足 $f\bigl(f(x_0)\bigr) = x_0$，则称 $x_0$ 为函数 $f(x)$ 的“二阶往返点”。已知二次函数 $f(x) = x^2 - 2ax + 3$（$a \in \mathbb{R}$）。

(1) 若函数 $f(x)$ 在闭区间 $[0, 2]$ 上恰有 $1$ 个稳定点，求实数 $a$ 的取值范围；

(2) 若函数 $f(x)$ 在 $\mathbb{R}$ 上的所有二阶往返点均是它的稳定点，求实数 $a$ 的取值范围。

## 参考理解

**(1)** 我们先翻译第一问的新定义：函数 $f(x)$ 在闭区间 $[0, 2]$ 上恰有 $1$ 个稳定点，等价于二次方程
$$P(x) = f(x) - x = x^2 - (2a + 1)x + 3 = 0$$
在闭区间 $[0, 2]$ 上恰有 $1$ 个互异实数根。很多同学一看到“闭区间上恰有一个根”，立刻只写 $P(0)P(2) \le 0$ 就算交卷，这恰恰是[[卡片/二次方程根的分布定参法]]里最致命的两重陷阱：第一，漏掉了抛物线**与 $x$ 轴相切（$\Delta_P = 0$）且切点恰好落入 $[0, 2]$** 时的孤立重根解；第二，没有把使得端点函数值 $P(0) = 0$ 或 $P(2) = 0$ 的边界参数代回去检查另一根是否也顺带落进闭区间内。

我们来严密分情况排查：先算两端点值与判别式，有 $P(0) = 3 > 0$（恒不为零，故 $x = 0$ 永远不是稳定点），$P(2) = 4 - 2(2a + 1) + 3 = 5 - 4a$，判别式 $\Delta_P = (2a + 1)^2 - 12$，抛物线对称轴为 $x = a + \frac{1}{2}$。
- **情形一：方程 $P(x) = 0$ 有两个相等实根（$\Delta_P = 0$）且落入 $[0, 2]$**。
  由 $(2a + 1)^2 = 12$ 得 $2a + 1 = \pm 2\sqrt{3}$，即 $a = -\frac{1}{2} \pm \sqrt{3}$。此时唯一重根就是对称轴横坐标 $x_0 = a + \frac{1}{2} = \pm \sqrt{3}$：
  - 当 $a = \sqrt{3} - \frac{1}{2}$ 时，$x_0 = \sqrt{3} \in (0, 2) \subset [0, 2]$，此时 $[0, 2]$ 上恰有 $1$ 个稳定点，符合题意；
  - 当 $a = -\sqrt{3} - \frac{1}{2}$ 时，$x_0 = -\sqrt{3} \notin [0, 2]$，舍去。
- **情形二：方程 $P(x) = 0$ 有两个不相等实根，且恰有 $1$ 个根落在 $[0, 2]$ 内**。
  因为 $P(0) = 3 > 0$，不存在以 $0$ 为根的情形，于是只需按 $P(2)$ 的符号讨论：
  - 若 $P(2) < 0$，即 $5 - 4a < 0 \implies a > \frac{5}{4}$：由 $P(0)P(2) < 0$ 且抛物线开口向上，可知一根严格在 $(0, 2)$ 内，另一根严格大于 $2$（必在 $[0, 2]$ 之外），故 $[0, 2]$ 上恰有 $1$ 个稳定点，符合题意；
  - 若 $P(2) = 0$，即 $a = \frac{5}{4}$：这是一个必须逐根验算的高危临界点，将 $a = \frac{5}{4}$ 代回方程得 $x^2 - \frac{7}{2}x + 3 = 0 \implies (x - 2)\left(x - \frac{3}{2}\right) = 0$，解得两根 $x_1 = \frac{3}{2}$ 与 $x_2 = 2$ **全部**落在闭区间 $[0, 2]$ 内，共有 $2$ 个稳定点而非 $1$ 个，因此 $a = \frac{5}{4}$ 必须舍去；
  - 若 $P(2) > 0$（即 $a < \frac{5}{4}$）且 $\Delta_P > 0$：此时由 $P(0) > 0$ 且 $P(2) > 0$，若对称轴落在 $[0, 2]$ 外则两根全在 $[0, 2]$ 外（$0$ 个稳定点），若对称轴落在 $(0, 2)$ 内则两根全在 $(0, 2)$ 内（$2$ 个稳定点），均不可能恰有 $1$ 个稳定点。

合并情形一与情形二，实数 $a$ 的完整取值范围是 $\left\{\sqrt{3} - \frac{1}{2}\right\} \cup \left(\frac{5}{4}, +\infty\right)$。

**(2)** 再来看第二问：“$\mathbb{R}$ 上的所有二阶往返点均是稳定点”，也就是方程 $f\bigl(f(x)\bigr) = x$ 的实数解集包含于 $f(x) = x$ 的实数解集之中；而另一方面每个稳定点自动满足 $f\bigl(f(x)\bigr) = f(x) = x$，所以命题等价于方程 $f\bigl(f(x)\bigr) = x$ 与方程 $f(x) = x$ 在 $\mathbb{R}$ 上**同解**。

根据[[卡片/函数不动点与二周期点分析法]]，切忌把 $\bigl(x^2 - 2ax + 3\bigr)^2 - 2a(x^2 - 2ax + 3) + 3 = x$ 硬展开成四次多项式。记 $y = f(x) = x^2 - 2ax + 3$，则 $f\bigl(f(x)\bigr) = f(y) = y^2 - 2ay + 3$。两式作差消去常数项 $3$：
$$f\bigl(f(x)\bigr) - y = f(y) - f(x) = (y^2 - x^2) - 2a(y - x) = (y - x)(y + x - 2a).$$
两边同时加上 $(y - x)$，把左端还原为 $f\bigl(f(x)\bigr) - x$，右端便自然提取出公因式 $y - x = f(x) - x$：
$$f\bigl(f(x)\bigr) - x = (y - x)(y + x - 2a + 1) = P(x) \cdot Q(x),$$
其中稳定点方程为 $P(x) = x^2 - (2a + 1)x + 3$，余因子方程为：
$$Q(x) = f(x) + x - 2a + 1 = x^2 - (2a - 1)x + 4 - 2a = 0.$$
原命题成立，当且仅当余因子方程 $Q(x) = 0$ **没有实数根，或者它的全部实数根都已经包含在 $P(x) = 0$ 的解集里**。计算 $Q(x)$ 的判别式并因式分解：
$$\Delta_Q = (2a - 1)^2 - 4(4 - 2a) = 4a^2 + 4a - 15 = (2a + 5)(2a - 3).$$
接下来按 $\Delta_Q$ 的正负逐一核查，绝不漏掉 $\Delta_Q = 0$ 的闭区间端点：
- **情况一：$\Delta_Q < 0$**，即 $(2a + 5)(2a - 3) < 0$，解得 $-\frac{5}{2} < a < \frac{3}{2}$。此时 $Q(x) = 0$ 无实数解，所有二阶往返点只能来自 $P(x) = 0$，必然均是稳定点。
- **情况二：$\Delta_Q = 0$**，即 $a = -\frac{5}{2}$ 或 $a = \frac{3}{2}$，此时 $Q(x) = 0$ 仅有一个重实根，必须分别代入验证该重根是否已被 $P(x) = 0$ 吸收：
  - 当 $a = -\frac{5}{2}$ 时，$Q(x) = x^2 + 6x + 9 = (x + 3)^2 = 0$，唯一重根为 $x = -3$；此时 $P(x) = x^2 + 4x + 3 = (x + 3)(x + 1)$，$P(-3) = 0$ 成立，说明 $x = -3$ 本身就是稳定点，故 **$a = -\frac{5}{2}$ 符合题意**；
  - 当 $a = \frac{3}{2}$ 时，$Q(x) = x^2 - 2x + 1 = (x - 1)^2 = 0$，唯一重根为 $x = 1$；此时 $P(x) = x^2 - 4x + 3 = (x - 1)(x - 3)$，$P(1) = 0$ 成立，说明 $x = 1$ 本身也是稳定点，故 **$a = \frac{3}{2}$ 同样符合题意**。
- **情况三：$\Delta_Q > 0$**，即 $a < -\frac{5}{2}$ 或 $a > \frac{3}{2}$。此时 $Q(x) = 0$ 有两个互不相等的实数根。要想这两个互异实根全部落入同样至多只有两根的首一二次方程 $P(x) = 0$ 的解集中，唯一的可能就是 $Q(x)$ 与 $P(x)$ 作为首一二次三项式完全恒等。但 $Q(x) - P(x) = 2x + 1 - 2a$ 含有非零一次项 $2x$，对任何实数 $a$ 都不可能恒等于 $0$，因此两个二次方程不可能同解，故此情况不合题意。

综上，合并情况一与情况二，满足所有二阶往返点均是稳定点的实数 $a$ 的取值范围是闭区间 **$\left[-\frac{5}{2}, \frac{3}{2}\right]$**。
