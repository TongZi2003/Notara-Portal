# 第14讲·练05：指数加倒数函数中点性质与最值

## 内容

如果函数 $f(x)$ 在区间 $I$ 上满足：对任意不相等的实数 $x_1, x_2 \in I$，都有
$$f\left(\frac{x_1 + x_2}{2}\right) < \frac{f(x_1) + f(x_2)}{2},$$
那么称 $f(x)$ 为区间 $I$ 上的“严格中点下弯函数”。

(1) 已知函数 $f(x) = 2^x + \frac{1}{x}$，求证：$f(x)$ 是 $(0, +\infty)$ 上的“严格中点下弯函数”；

(2) 已知正实数 $a, b$ 满足 $a + b = 4$，利用 (1) 的结论求代数式 $S = 2^a + 2^b + \frac{1}{a} + \frac{1}{b}$ 的最小值，并判断：若进一步限定 $a \neq b$，代数式 $S$ 是否还能取得这个最小值。

## 参考理解

**(1)** 我们拿到这道新定义压轴题时，第一问要求在没有高阶工具的条件下，用纯粹的初等代数证明 $f(x) = 2^x + \frac{1}{x}$ 在正半轴 $(0, +\infty)$ 上满足严格中点不等式。如果把整段表达式直接代进 $\frac{f(x_1) + f(x_2)}{2} - f\left(\frac{x_1 + x_2}{2}\right)$ 混为一团通分，很快就会被既有 $2^{x_1}$ 又有分母 $x_1 x_2(x_1 + x_2)$ 的混合怪式绊住脚步。

**为什么我们想到把 $f(x)$ 拆成 $2^x$ 和 $\frac{1}{x}$ 两部分各自证明、再做同向叠加？** 根据[[卡片/函数凹凸性与中点不等式]]，两个在同一个区间 $I$ 上都满足严格中点下弯不等式的函数相加后，和函数必然依然满足同一方向的不等式，而且指数项与分式项各自刚好对应最纯正的高一基本不等式与作差分解技巧。

任取 $x_1, x_2 \in (0, +\infty)$ 且 $x_1 \neq x_2$，我们分两步逐项证明：
- **先处理指数部分 $2^x$**：因为指数函数 $y = 2^x$ 在 $\mathbb{R}$ 上严格单调递增且取值恒正，由 $x_1 \neq x_2$ 可知 $2^{x_1} > 0$、$2^{x_2} > 0$ 且 $2^{x_1} \neq 2^{x_2}$。直接应用基本不等式（注意严格不等号取不到等号），得：
  $$\frac{2^{x_1} + 2^{x_2}}{2} > \sqrt{2^{x_1} \cdot 2^{x_2}} = \sqrt{2^{x_1 + x_2}} = 2^{\frac{x_1 + x_2}{2}}.$$
- **再处理反比例部分 $\frac{1}{x}$**：直接对算术平均值与中点函数值作差通分，利用 $x_1, x_2 > 0$ 且 $x_1 \neq x_2$ 判断符号：
  $$\frac{\frac{1}{x_1} + \frac{1}{x_2}}{2} - \frac{1}{\frac{x_1 + x_2}{2}} = \frac{x_1 + x_2}{2x_1 x_2} - \frac{2}{x_1 + x_2} = \frac{(x_1 + x_2)^2 - 4x_1 x_2}{2x_1 x_2 (x_1 + x_2)} = \frac{(x_1 - x_2)^2}{2x_1 x_2 (x_1 + x_2)}.$$
  由于 $x_1 \neq x_2$，分子 $(x_1 - x_2)^2 > 0$；又 $x_1, x_2 > 0$，分母 $2x_1 x_2 (x_1 + x_2) > 0$，因此整个分式严格大于 $0$，即：
  $$\frac{\frac{1}{x_1} + \frac{1}{x_2}}{2} > \frac{1}{\frac{x_1 + x_2}{2}}.$$

将上述两道同向严格不等式左右两边直接相加，整理即得：
$$\frac{f(x_1) + f(x_2)}{2} = \frac{2^{x_1} + 2^{x_2}}{2} + \frac{\frac{1}{x_1} + \frac{1}{x_2}}{2} > 2^{\frac{x_1 + x_2}{2}} + \frac{1}{\frac{x_1 + x_2}{2}} = f\left(\frac{x_1 + x_2}{2}\right).$$
由此严格证明了 $f(x)$ 是 $(0, +\infty)$ 上的“严格中点下弯函数”。

**(2)** 接下来我们看第二问：已知正实数 $a, b$ 满足 $a + b = 4$，求 $S = 2^a + 2^b + \frac{1}{a} + \frac{1}{b}$ 的最小值。如果企图用 $b = 4 - a$ 代入硬算单变量 $g(a) = 2^a + 2^{4-a} + \frac{1}{a} + \frac{1}{4-a}$ 在 $(0, 4)$ 上的单调性，同时应对指数对称和与分式对称和的叠加单调区间会非常吃力。

**为什么利用 (1) 的结论能两行求出这个最值，并且一眼看清能否取等？** 先把所求式子按对称结构重新分组写成：
$$S = \left(2^a + \frac{1}{a}\right) + \left(2^b + \frac{1}{b}\right) = f(a) + f(b).$$
因为 $a, b \in (0, +\infty)$ 且满足 $a + b = 4$，中点始终固定在 $\frac{a + b}{2} = 2$。我们对 $a$ 与 $b$ 是否相等进行分类讨论：
- **当 $a = b$ 时**：由 $a + b = 4$ 唯一解得 $a = b = 2 \in (0, +\infty)$，此时直接算得
  $$S = 2f(2) = 2\left(2^2 + \frac{1}{2}\right) = 2 \times \frac{9}{2} = 9.$$
- **当 $a \neq b$ 时**：根据第 (1) 问已经证明的性质，$f(x)$ 是 $(0, +\infty)$ 上的“严格中点下弯函数”，因此对互异正数 $a, b$ 严格成立：
  $$S = f(a) + f(b) > 2f\left(\frac{a + b}{2}\right) = 2f(2) = 9.$$

合并这两种情形，恒有 $S \ge 9$，且等号当且仅当 $a = b = 2$ 时成立。于是代数式 $S$ 的最小值为 **$9$**。同时也就顺理成章地回答了后半问的细节：由于 $a \neq b$ 时不等号为严格大于（$S > 9$），所以若进一步限定 $a \neq b$，虽然 $S$ 可以无限逼近 $9$，但**不能取得最小值 $9$**（此时该代数式不存在最小值）。
