# 第08讲·练08：有限开区间单调奇函数解不等式

## 内容

已知定义在 $(-2, 2)$ 上的奇函数 $f(x)$ 在其定义域上单调递减，则关于实数 $a$ 的不等式 $f(1 - a) + f(1 - a^2) < 0$ 的解集为 $\underline{\hspace{5em}}$。

## 参考理解

我们看到这道题结构非常简短，却是一道失分率极高的“有限定义域陷阱题”。很多同学顺手把 $f(1 - a^2)$ 移到右边变成 $-f(1 - a^2) = f(a^2 - 1)$，再利用单调递减直接脱去外层 $f$ 符号解出 $1 - a > a^2 - 1$，算出 $(-2, 1)$ 就急着交卷了——然而只要拿左边界外的一点（比如 $a = -\frac{3}{2}$）代回原式检验，立刻会发现 $1 - a = \frac{5}{2} > 2$，根本不在函数定义域 $(-2, 2)$ 里面，连 $f(1 - a)$ 都没有意义。

根据[[卡片/奇偶性与单调性联合脱壳法]]的三重安全校验，面对定义域为有限区间 $D = (-2, 2)$ 的抽象函数不等式，**任何脱壳步骤之前，先把原式里出现的每一个括号变量统统锁进 $(-2, 2)$**，与脱壳后的大小关系联立成一个三元不等式组：
$$\begin{cases} -2 < 1 - a < 2, \\ -2 < 1 - a^2 < 2, \\ f(1 - a) + f(1 - a^2) < 0. \end{cases}$$

我们先处理前两条定义域硬约束：
1. 由 $-2 < 1 - a < 2$，三边同时减 $1$ 再乘以 $-1$ 变号，得 $-1 < a < 3$；
2. 由 $-2 < 1 - a^2 < 2$，三边减 $1$ 得 $-3 < -a^2 < 1$，即 $-1 < a^2 < 3$。其中 $a^2 > -1$ 恒成立，而 $a^2 < 3$ 解得 $-\sqrt{3} < a < \sqrt{3}$。

将前两条定义域约束先求交集，得到参数 $a$ 的合法前提范围是
$$-1 < a < \sqrt{3}.$$
（特别留意边界 $a = -1$ 时，$1 - a = 2$ 恰好踩在开区间 $(-2, 2)$ 的右开端点外，取不到等号，故 $a = -1$ 同样必须排除。）

再来化简并脱壳第三条函数不等式：把 $f(1 - a^2)$ 移到不等号右侧，利用 $f(x)$ 是奇函数（即 $-f(x) = f(-x)$），改写为
$$f(1 - a) < -f(1 - a^2) = f(a^2 - 1).$$
注意到当 $1 - a^2 \in (-2, 2)$ 时，它的相反数 $a^2 - 1$ 必然同样落在对称定义域 $(-2, 2)$ 内，因此左右两边的自变量都在同一个单调递减区间 $(-2, 2)$ 里。根据单调递减反向脱去外层 $f$ 符号，得
$$1 - a > a^2 - 1 \iff a^2 + a - 2 < 0 \iff (a + 2)(a - 1) < 0,$$
解得 $-2 < a < 1$。

最后，把脱壳所得区间 $(-2, 1)$ 与前面定义域硬约束区间 $(-1, \sqrt{3})$ 取交集：
$$(-2, 1) \cap (-1, \sqrt{3}) = (-1, 1).$$
可见 $(-2, -1]$ 这一段虽然满足代数不等式 $a^2 + a - 2 < 0$，却被定义域条件 $-2 < 1 - a < 2$ 精准切掉了。因此原不等式的最终解集为 $(-1, 1)$。
