# 第13讲·练02：两个对数与负分数幂三数比大小

## 内容

已知 $a = \log_3 2$，$b = \log_5 3$，$c = 2^{-0.5}$，则 $a, b, c$ 的大小关系是（　　）

A. $a < b < c$　　　　B. $b < a < c$　　　　C. $c < a < b$　　　　D. $a < c < b$

## 参考理解

我们先试着用常规的 $0, 1$ 和 $\frac{1}{2}$ 来做粗分隔断：因为 $2^2 = 4 > 3 \implies a = \log_3 2 > \frac{1}{2}$，同理 $3^2 = 9 > 5 \implies b = \log_5 3 > \frac{1}{2}$，而 $c = 2^{-0.5} = \frac{1}{\sqrt{2}} = \frac{\sqrt{2}}{2} > \frac{1}{2}$。三个数全都挤在 $\left(\frac{1}{2}, 1\right)$ 这段窄区间里，而且既有对数又有无理幂，靠“十字拼装”也没法把底数和指数配成相同项。

**为什么我们先测试紧挨着 $\frac{1}{2}$ 上方的简单分数 $\frac{2}{3}$？** 根据[[卡片/指对幂比大小三阶通法与中间桥]]，比较对数 $\log_p q$ 与有理数 $\frac{m}{n}$ 时，只要同时利用对数与指数的单调性转化为正整数次幂比较 $q^n$ 与 $p^m$ 即可，计算量极小。把 $a, b$ 分别和 $\frac{2}{3}$ 对比：
- 比较 $a = \log_3 2$ 与 $\frac{2}{3}$：因为 $2^3 = 8 < 9 = 3^2$，两边同时开 $3$ 次方（幂函数 $x^{\frac{1}{3}}$ 在 $(0, +\infty)$ 单增）得 $2 < 3^{\frac{2}{3}}$，再结合 $y = \log_3 x$ 单增，得
  $$a = \log_3 2 < \frac{2}{3}.$$
- 比较 $b = \log_5 3$ 与 $\frac{2}{3}$：因为 $3^3 = 27 > 25 = 5^2$，同理得 $3 > 5^{\frac{2}{3}}$，结合 $y = \log_5 x$ 单增，得
  $$b = \log_5 3 > \frac{2}{3}.$$
- 顺便检查 $c = \frac{\sqrt{2}}{2}$ 与 $\frac{2}{3}$：两边平方（均为正数）得 $c^2 = \frac{1}{2} = \frac{9}{18} > \frac{8}{18} = \frac{4}{9} = \left(\frac{2}{3}\right)^2$，故 $c > \frac{2}{3}$。

于是 $\frac{2}{3}$ 这第一座桥梁已经确定出 $a < \frac{2}{3} < b$ 且 $a < \frac{2}{3} < c$，把 $a$ 锁定为最小。接下来只需进一步分清 $b = \log_5 3$ 与 $c = 2^{-0.5} = \frac{\sqrt{2}}{2}$ 的先后顺序。

**如何寻找 $b$ 与 $c$ 之间的第二座精细有理数桥梁？** 我们先估一下 $c = \frac{\sqrt{2}}{2}$ 紧邻的有理数下界：因为 $7^2 = 49 < 50 = (\sqrt{50})^2$，即 $\left(\frac{7}{10}\right)^2 = \frac{49}{100} < \frac{1}{2} = c^2$，且两者均为正数，所以立即看出一个极简洁的贴近下界 $\frac{7}{10}$：
$$c = 2^{-0.5} > \frac{7}{10}.$$
现在只需检验 $b = \log_5 3$ 是否小于 $\frac{7}{10}$。按照“指数幂去分母化正整数次方”的统一规则，$\log_5 3 < \frac{7}{10} \iff 3 < 5^{\frac{7}{10}} \iff 3^{10} < 5^7$。我们逐步算出两个正整数幂：
- $3^{10} = (3^5)^2 = 243^2 = 59049$；
- $5^7 = 5^4 \cdot 5^3 = 625 \times 125 = 78125$。

显然 $59049 < 78125$，即 $3^{10} < 5^7 \implies 3 < 5^{\frac{7}{10}}$，再由 $y = \log_5 x$ 严格递增得
$$b = \log_5 3 < \frac{7}{10}.$$

综合两座有理数桥梁，三个数的完整顺序被严密拉开：
$$a < \frac{2}{3} < b < \frac{7}{10} < c,$$
即 $a < b < c$，对应选项 **A**。
