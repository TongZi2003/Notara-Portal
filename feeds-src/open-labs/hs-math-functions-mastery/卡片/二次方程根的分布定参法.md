# 二次方程根的分布定参法

## 内容

讨论一元二次方程 $f(x) = ax^2 + bx + c = 0$（设已确认 $a > 0$；若 $a<0$ 先全体乘 $-1$ 或翻正）在给定区间内根的个数与范围，本质上是通过画出满足条件的抛物线草图，列出等价充要条件组。

### 1. 四要素联立对照表（设 $a > 0$，区间端点 $m < n$）

| 分布要求 | 等价充要不等式组（四要素按需选用） | 注意要点 |
| :--- | :--- | :--- |
| **两不等实根都 $> m$** | $\Delta > 0$，且 $-\frac{b}{2a} > m$，且 $f(m) > 0$ | 若用韦达 $(x_1-m)+(x_2-m)>0$ 且 $(x_1-m)(x_2-m)>0$ 也等价 |
| **两不等实根都在 $(m, n)$ 内** | $\Delta > 0$，且 $m < -\frac{b}{2a} < n$，且 $f(m) > 0$，且 $f(n) > 0$ | 四条缺一不可：缺对称轴会跑到同侧外，缺 $\Delta$ 会无实根 |
| **两实根分居 $m$ 两侧（一左一右）** | 仅需 $f(m) < 0$ | 当 $a>0$ 时 $f(m)<0$ 自动迫使 $\Delta>0$，无需额外写 $\Delta$ 或对称轴 |
| **开区间 $(m, n)$ 内恰有一根（重点坑）** | 必须拆为以下**三种互斥情况之并**：<br>① $f(m)f(n) < 0$；<br>② $\Delta = 0$ 且 $m < -\frac{b}{2a} < n$；<br>③ 另一根恰好落在端点 $m$ 或 $n$（即 $f(m)=0$ 或 $f(n)=0$ 时，求出参数后**回代检验另一根是否落在 $(m, n)$ 内**） | 千万不能直接写死 $f(m)f(n) < 0$ |

### 2. 为什么必须把「四要素」变成「先画图再列式」

- 若只凭背诵，最容易把“两根都在 $(m, n)$”漏掉对称轴限制，或者把“一个根在 $(m, n)$ 内、另一个根在 $(p, q)$ 内”写漏条件；
- 正确姿势是先随手画一条满足开口方向且穿越位置符合题意的抛物线，再看图自检四件事：**① 判别式正负确定有没有交点；② 对称轴确定顶点左右范围；③ 端点函数值正负卡死曲线穿过高度；④ 若有重根或端点刚好是根，单独检验等号**。

## 参考理解

### 考场典型丢分盲区

1. **「开区间 $(m, n)$ 恰有一根」漏掉情况 ② 与 ③**：
   以方程 $x^2 - 3x + a = 0$ 在 $(0, 2)$ 内恰有一根为例：
   - ① 若用 $f(0)f(2) < 0$，得 $a(a-2) < 0 \implies 0 < a < 2$；
   - ② 若相切于 $(0, 2)$ 内，$\Delta = 9 - 4a = 0 \implies a = \frac{9}{4}$，此时唯一根 $x = \frac{3}{2} \in (0, 2)$，**符合题意**；
   - ③ 若有一根恰好踩在边界 $x = 0$（即 $a = 0$），方程变成 $x^2 - 3x = 0$，两根为 $0$ 和 $3$，在 $(0, 2)$ 内有 $0$ 个根（舍）；若有一根踩在边界 $x = 2$（即 $a = 2$），方程两根为 $1$ 和 $2$，其中 $x = 1 \in (0, 2)$，在开区间 $(0, 2)$ 内恰有一个根，**符合题意**。
   因此完整答案是 $a \in (0, 2] \cup \left\{\frac{9}{4}\right\}$，直接写 $f(0)f(2)<0$ 会一口气丢掉两个边界解。
2. **闭区间与「至少一根」的补集法**：
   如果要求二次方程在闭区间 $[m, n]$ 上**至少有一根**，情况一多容易遗漏，此时强烈建议用正难则反：**先求在 $[m, n]$ 内无实根的参数范围**（即 $\Delta < 0$，或 $\Delta \ge 0$ 且两根全在 $[m, n]$ 同侧外，如两根都 $< m$ 或都 $> n$ 或一小于 $m$ 另一大于 $n$），再取补集或分类枚举。

### 变式追问

1. 若将上述示例改成“方程 $x^2 + ax + 1 = 0$ 在 $[0, 2]$ 上至少有一个实根”，正面列举和补集排除哪种更不易写漏重根相切情形？
2. 若一元二次方程的二次项系数本身含参数 $k$（即 $kx^2 + (k-2)x - 1 = 0$），在考虑 $k=0$ 退化为一次方程时需要注意哪一步？
