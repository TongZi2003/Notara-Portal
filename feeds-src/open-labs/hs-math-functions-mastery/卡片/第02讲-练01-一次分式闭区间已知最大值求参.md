# 第02讲·练01：一次分式闭区间已知最大值求参

## 内容

已知函数 $f(x) = \frac{2x + 1}{x - a}$ 在闭区间 $[1, 3]$ 上的最大值为 $5$，则实数 $a$ 的值为（　　）

A. $\frac{2}{5}$　　　　B. $\frac{8}{5}$　　　　C. $\frac{2}{5}$ 或 $\frac{8}{5}$　　　　D. $-\frac{1}{2}$ 或 $\frac{2}{5}$

## 参考理解

我们读完题干时，一个非常诱人的捷径念头是：“一次分式在区间上要么递增要么递减，最大值肯定就在端点 $x = 1$ 或 $x = 3$ 处取到，直接解 $f(1) = 5$ 和 $f(3) = 5$ 不就行了吗？”如果照这条路硬算，立刻会得出 $a = \frac{2}{5}$ 和 $a = \frac{8}{5}$，然后毫不犹豫地选成 C。然而这个“捷径”其实藏着一个致命漏洞：它没有先检查分母零点 $x = a$ 是否落进了闭区间 $[1, 3]$ 里面，也没有核对算出来的端点值究竟是**最大值**还是**最小值**。

**为什么我们必须先标定分母零点的禁区，并把分式拆成分离常数形式？** 根据[[卡片/分式与对勾型函数值域法]]，函数 $f(x) = \frac{2x + 1}{x - a}$ 要在闭区间 $[1, 3]$ 上完整定义并有最大值，首先分母 $x - a$ 在 $[1, 3]$ 上绝对不能取到零，也就是要求间断点 $a \notin [1, 3]$，即：
$$a < 1 \quad \text{或} \quad a > 3.$$
仅这一条前置安检，就已经把 $a = \frac{8}{5} \in [1, 3]$ 提前枪毙了（因为当 $a = \frac{8}{5}$ 时，函数在 $x = \frac{8}{5}$ 处无意义，且在 $\frac{8}{5}$ 右侧趋向 $+\infty$，根本不存在最大值 $5$）。

接着对解析式作分离常数变形，看清分子系数与分母正负号决定的单调性方向：
$$f(x) = \frac{2(x - a) + 2a + 1}{x - a} = 2 + \frac{2a + 1}{x - a}.$$
我们按 $a < 1$ 与 $a > 3$ 两大分支严谨讨论：

- **情形一：$a > 3$**。此时对所有 $x \in [1, 3]$，分母 $x - a < 0$ 而分子 $2a + 1 > 7 > 0$，因此分式部分 $\frac{2a + 1}{x - a} < 0$，于是整条曲线在 $[1, 3]$ 上始终满足 $f(x) < 2$，最大值绝不可能达到 $5$，本情形无解。
- **情形二：$a < 1$**。此时对所有 $x \in [1, 3]$，分母 $x - a > 0$ 且随着 $x$ 增大而增大，函数的增减完全取决于分子 $2a + 1$ 的正负号：
  - 若 $2a + 1 = 0$，即 $a = -\frac{1}{2}$，则 $f(x) \equiv 2$（定义域为 $x \neq -\frac{1}{2}$），在 $[1, 3]$ 上恒等于 $2$，最大值不是 $5$（排除选项 D）；
  - 若 $2a + 1 < 0$，即 $a < -\frac{1}{2}$，则 $\frac{2a + 1}{x - a}$ 在 $[1, 3]$ 上严格单调递增，最大值在右端点 $x = 3$ 处取得，令 $f(3) = \frac{7}{3 - a} = 5$，解得 $a = \frac{8}{5}$，既与前提 $a < -\frac{1}{2}$ 矛盾，又落在了禁用区间 $[1, 3]$ 内，舍去；
  - 若 $2a + 1 > 0$，即 $-\frac{1}{2} < a < 1$，则 $\frac{2a + 1}{x - a}$ 在 $[1, 3]$ 上严格单调递减，最大值在左端点 $x = 1$ 处取得，令 $f(1) = \frac{3}{1 - a} = 5$，解得 $1 - a = \frac{3}{5}$，即 $a = \frac{2}{5}$。回代检验：$-\frac{1}{2} < \frac{2}{5} < 1$ 满足所有前提条件，且右端点 $f(3) = \frac{7}{3 - \frac{2}{5}} = \frac{35}{13} < 5$，确为最大值。

综上，实数 $a$ 的唯一合法取值是 $\frac{2}{5}$，正确选项为 **A**。
