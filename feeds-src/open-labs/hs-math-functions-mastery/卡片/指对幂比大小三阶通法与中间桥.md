# 指对幂比大小三阶通法与中间桥

## 内容

面对选择题里混在一起的三个或四个指、对、幂数值，考场最稳定的解题流水线是**先同底或同指、再做零一隔断、最后架设精细中间桥**，确保 80% 以上的比大小问题能在 30 秒内零误差定序。

### 1. 一阶与第二步：直接单调性对比

1. **一阶·底数相同（或可化同底）$\implies$ 指数/对数单调法**
   利用底数统一原则（如 $4^a = 2^{2a}$、$\log_4 b = \frac{1}{2}\log_2 b$、$\log_{\frac{1}{a}} b = -\log_a b$），化到同一底数后，按底数 $a > 1$ 单增、$0 < a < 1$ 单减比较指数或真数。
2. **第二步·指数相同（常见于 $a^m$ vs $b^m$）$\implies$ 幂函数第一象限单调性**
   把“同指异底”的两个幂视为同一幂函数 $y = x^m$ 在两个底数点上的函数值：
   - 当 $m > 0$ 时，$y = x^m$ 在 $(0, +\infty)$ 单增（底越大值越大）；
   - 当 $m < 0$ 时，$y = x^m$ 在 $(0, +\infty)$ 单减（底越大值越小）。

### 2. 三阶：异底异指「中间桥」分层隔断术

当三个数的底数和指数全不相同时，按以下三级阶梯插桥：

1. **粗分桥：$0$ 与 $1$ 隔断（最常用、必先排）**
   先逐个判定每个数的符号（与 $0$ 比较，即看对数真数与 $1$ 在同侧还是异侧）以及是否超过 $1$（指数看底数与指数同侧还是异侧；对数看真数与底数大小）。
   - 例如 $\log_{0.3} 2 < 0 < 0.3^{0.2} < 1 < 2^{0.3}$，无需任何进一步估算一步排定。
2. **双桥串联：$a^m$ 与 $b^n$ 的“十字拼装桥”**
   遇到全在同一区间的异底异指幂（例如比较 $0.6^{0.5}$ 与 $0.5^{0.6}$），直接取出一方的底数与另一方的指数拼装一个中间数 $0.6^{0.6}$：
   $$0.6^{0.5} > 0.6^{0.6} \quad (\text{底数 } 0.6 \in (0, 1) \text{ 指数函数单减}), \qquad 0.6^{0.6} > 0.5^{0.6} \quad (\text{指数 } 0.6 > 0 \text{ 幂函数单增}).$$
   因此立即传递出 $0.6^{0.5} > 0.5^{0.6}$。
3. **精细分数与对数幂次锚桥**：
   当所有数同在 $(0, 1)$ 或 $(1, 2)$ 内且无法直接十指拼桥时，改插简单有理数 $\frac{1}{2}, \frac{1}{3}, \frac{2}{3}, \frac{3}{2}$ 作桥梁：
   - 例如比较 $\log_5 2$ 与 $\log_8 3$：先和 $\frac{1}{2}$ 比（即对真数平方与底数比较）：$2^2 = 4 < 5 \implies \log_5 2 < \frac{1}{2}$，$3^2 = 9 > 8 \implies \log_8 3 > \frac{1}{2}$，立分高低；
   - 比较更接近的值可先同乘整数（或同时幂次）或借由 $\frac{1}{3}, \frac{2}{3}$ 验证真数的三次方大小（如 $2^3 = 8 < 9$ 判 $\log_3 2 < \frac{2}{3}$）。

## 参考理解

### 高频易错与提速细节

1. **只盯局部指数，忘记真数底数分居 $1$ 两侧判负**：
   例如看 $\log_{\frac{1}{2}} 3$ 与 $\log_3 \frac{1}{2}$：只要底数与真数**分居 $1$ 的两侧**（一个 $>1$、一个 $\in (0, 1)$），对数值必然严格小于 $0$（简称“同侧为正、异侧为负”）。再比如 $\log_{0.4} 0.3$ 同居 $(0, 1)$ 内，数值为正；而因为 $y=\log_{0.4} x$ 递减，所以 $0.3 < 0.4 \implies \log_{0.4} 0.3 > \log_{0.4} 0.4 = 1$。记牢“先定正负，再与 $1$ 比”几乎能干掉半数压轴选择题中的最易混项。
2. **中间桥选取失效时的换路信号**：
   当你把 $\frac{1}{2}, \frac{1}{3}, \frac{2}{3}$ 都试过，发现两个数依然同时落在区间 $\left(\frac{1}{2}, \frac{2}{3}\right)$ 内且死活拉不开差距时，说明常规分数桥精度不够——立刻切换到[[卡片/作商换底与基本不等式比大小]]、[[卡片/对数糖水不等式与取倒数减整法]]或[[卡片/构造初等单调函数与同构比大小]]，不要在分母越凑越大的盲试里浪费考场时间。

### 变式追问

1. 已知 $a = \log_2 0.2$，$b = 2^{0.2}$，$c = 0.2^{0.3}$，如何用零一隔断法十秒钟排定 $a, b, c$？
2. 已知 $a = \log_3 2$，$b = \log_5 3$，$c = \frac{3}{5}$，三者都落在 $(0.5, 0.7)$ 附近，尝试用 $\frac{2}{3}$ 和乘方比较（比较 $3^5$ 与 $5^3$）一次拉开它们。
