# 第一阶｜函数三要素与值域求法（第1–3讲）

高一刚学函数时最容易丢分的反而是前面看似基础的三要素与值域题，问题大都出在括号里的式子一变就乱代、换元忘了补新变量范围，或者见到双根式硬平方把式子算成四次。这三讲把这些坑按顺序列出来。

## 第 1 讲｜抽象函数定义域替换与解析式换元

定义域永远指自变量 $x$ 的取值范围，同一对应法则 $f$ 括号内的整体必须落在相同区间里；做换元法求解析式时，写出新变量 $t$ 的取值范围同样关键。

- [ ] 先试做 [[卡片/第01讲-练01-抽象复合与分式根式定义域]]，注意从 $f(1-2x)$ 到 $f(x-1)$ 时外层分母、根号与零次幂也要一起取交集
- [ ] 再看方法卡 [[卡片/抽象函数定义域替换法]] 把括号整体同范围的规则理清，顺手做 [[卡片/第01讲-练02-含参对数定义域与值域为R对比]]，对比「定义域为 $\mathbb{R}$」和「值域为 $\mathbb{R}$」的判别式方向差异及 $m=0$ 退化情形
- [ ] 把这两类条件合并起来练一道多选题 [[卡片/第01讲-练03-复合函数定义域与值域辨析]]，重点排查内层值域没盖住外层要求以及定义域空集的情况
- [ ] 接着转向求解析式，看方法卡 [[卡片/函数解析式换元与消元法]]，紧接着做 [[卡片/第01讲-练04-复合指数式求解析式与值域]]，感受换元漏写 $t>1$ 后值域会怎么算错
- [ ] 当题干同时给出 $f(x)$ 和 $f(1/x)$ 时改用消元法，先练 [[卡片/第01讲-练05-含倒数函数方程求解析式与最值]] 构造方程组求解，再看一道结合倒数互补的求和题 [[卡片/第01讲-练06-指数与二次分式组合多项求和]]

## 第 2 讲｜分式、对勾与双根式函数值域

分式函数值域要注意区间内有无分母零点、对勾拐点是否在区间内，以及判别式法遇二次项系数归零的情形；遇到双根号里面都是二次式时，配成两点间距离比硬平方快得多。

- [ ] 先看方法卡 [[卡片/分式与对勾型函数值域法]] 梳理分离常数、对勾单调区间与判别式法各自的适用前提
- [ ] 用一次含参分式 [[卡片/第02讲-练01-一次分式闭区间已知最大值求参]] 热身（先排除闭区间内的分母零点），再做分子分母都是二次的 [[卡片/第02讲-练02-两类二次分式函数求值域]]，对比约去公因式挖掉的点和判别式遇首项为零的处理
- [ ] 换成根号和对数做外衣后再练两道：[[卡片/第02讲-练03-二次式除以根式的闭区间值域]]（均值不等式取不到等号时回退单调性）与 [[卡片/第02讲-练04-含对数分式在去点区间的值域]]（换元后被中间断点拆成两支）
- [ ] 转入无理根式值域，先看方法卡 [[卡片/根式函数值域代数与几何法]] 区分换元法和几何距离法
- [ ] 先练单根号换元防漏非负限的 [[卡片/第02讲-练05-一次项减一次根式求值域]]，再在同区间上对比 [[卡片/第02讲-练06-两个一次根式和与差的值域]] 里相加平方与相减单调性的区别
- [ ] 最后看不能靠平方算的双平方和根式 [[卡片/第02讲-例1-两个二次根式和与差的最值]]（[[可视化/V01-第02讲例1-两个二次根式和与差的几何构造.html|图解]]），看懂怎么把根号配方成 $x$ 轴动点到两定点的距离之和与距离之差，并注意距离之差取等要验射线交 $x$ 轴

## 第 3 讲｜分段函数全局单调与「取大取小」图像

分段函数在 $\mathbb{R}$ 上单调，既要各段单调方向一致，更要卡住分界点左值与右值的大小关系；遇到 $\max\{f,g\}$ 或 $\min\{f,g\}$ 时，画两条曲线求交点后拼图比硬拆五六段不等式清楚得多。

- [ ] 再看方法卡 [[卡片/分段函数单调衔接与取大取小]] 总结上下图像取法与分界点等号判断规则
- [ ] 接着练两道分段全局单调求参数题：先用 [[卡片/第03讲-练01-一次与对数分段函数递减求参]] 检验一次线段与对数在接缝处的端点衔接
- [ ] 再用二次函数配指数函数做一次强化 [[卡片/第03讲-练02-二次与指数分段函数递增求参]]，注意把抛物线对称轴位置和指数底数范围一起列全
