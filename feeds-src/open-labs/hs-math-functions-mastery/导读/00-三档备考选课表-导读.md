# 高一函数三档备考选课表

根据自己的具体需求来选择进度安排，如果你马上要考试了，那么我们的节奏可以放快一点，尽量多熟悉一些具体的解题套路，如果你还有一段时间才考试，我们可以把节奏稍微放慢一点，做到每一个部分都能理解其函数本质。

## 20 课时同步巩固（兼顾解题套路与性质理解）

学完一讲的方法卡和例题后，跟着把当讲的配套练习题做一遍，练熟常规中档题和常见变式。

- [ ] 第 1–3 课时：[[导读/01-第一阶-函数三要素与值域求法-导读]]（3 讲、5 张方法卡、基础与中档练习）
- [ ] 第 4–5 课时：[[导读/02-第二阶-二次函数动轴最值与根的分布-导读]]（2 讲、2 张方法卡、5 道变式练习）
- [ ] 第 6–8 课时：[[导读/03-第三阶-单调性证明与奇偶性综合应用-导读]]（3 讲、6 张方法卡、期中核心证明与不等式练习）
- [ ] 第 9–11 课时：[[导读/04-第四阶-函数对称性周期性与类周期问题-导读]]，期中前结合 [[白板/01-函数性质与多零点嵌套决策树.canvas]] 串讲前四阶内容
- [ ] 第 12–15 课时：[[导读/05-第五阶-指对幂函数性质与比大小方法-导读]]（3 讲、9 张方法卡、指对换元与比大小练习）
- [ ] 第 16–18 课时：[[导读/06-第六阶-函数图像零点与复合嵌套方程-导读]]（3 讲、7 张方法卡、多零点消元与复合方程练习）
- [ ] 第 19–20 课时：[[导读/07-第七阶-恒成立双量词与含参绝对值问题-导读]]，考前结合 [[白板/01-函数性质与多零点嵌套决策树.canvas]] 与 [[白板/02-二次根分布比大小与恒成立双量词路线图.canvas]] 过一遍全部题型

## 28 课时完整训练（吃透函数本质与综合变式）

把 37 张方法卡、123 道例题与作业全部做透，并逐一解决每张方法卡末尾的「变式追问」，彻底打通压轴小题和大题最后一问。

- [ ] 第 1–12 课时：按顺序完成第 1–4 阶全部 11 讲（[[导读/01-第一阶-函数三要素与值域求法-导读]] 至 [[导读/04-第四阶-函数对称性周期性与类周期问题-导读]]）中的所有难题和「变式追问」
- [ ] 第 13–26 课时：按顺序完成第 5–7 阶全部 8 讲（[[导读/05-第五阶-指对幂函数性质与比大小方法-导读]] 至 [[导读/07-第七阶-恒成立双量词与含参绝对值问题-导读]]）中的压轴题与规范证明步骤
- [ ] 第 27–28 课时：对照 [[白板/01-函数性质与多零点嵌套决策树.canvas]] 与 [[白板/02-二次根分布比大小与恒成立双量词路线图.canvas]] 脱离笔记自查定义退化、端点开闭与充分性回代
