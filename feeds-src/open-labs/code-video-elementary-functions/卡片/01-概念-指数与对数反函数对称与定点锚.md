# 指数与对数反函数对称与双锚点模型

## 内容

设底数 $a > 0$ 且 $a \ne 1$。考虑指数函数 $f(x) = a^x$ 与对数函数 $g(x) = \log_a x$：

1. 已知点 $P(t, a^t)$ 落在 $y = a^x$ 的图像上，用反函数定义解释为什么其关于直线 $y = x$ 的对称点 $P'(a^t, t)$ 必落在 $y = \log_a x$ 上，并指出两条曲线各自恒过的定点和渐近线；
2. 当底数在 $a > 1$ 与 $0 < a < 1$ 之间切换，甚至在同一象限比较 $a = 2$ 与 $a = 3$ 两条曲线谁更贴近坐标轴时，给出不靠死背口诀的直观判断方法。

## 参考理解

- **一条对称定律省掉一半记忆**：
  - 由 $y = a^x \iff x = \log_a y$，交换 $x,y$ 即得对数函数 $y = \log_a x$。点 $P(t, a^t)$ 与 $P'(a^t, t)$ 的中点 $(\frac{t+a^t}{2}, \frac{t+a^t}{2})$ 恰好落在 $y=x$ 上，连线斜率为 $-1$，故二者的**图像、值域与定义域、渐近线**全部按 $x \leftrightarrow y$ 一一互换：
    - $y=a^x$：定义域 $\mathbb{R}$，值域 $(0,+\infty)$，定点 $(0,1)$，水平渐近线 $y=0$（负半轴趋近 $0$ 当 $a>1$；正半轴趋近 $0$ 当 $0<a<1$）。
    - $y=\log_a x$：定义域 $(0,+\infty)$，值域 $\mathbb{R}$，定点 $(1,0)$，竖直渐近线 $x=0$。
- **不背口诀的“过一轴线定底大小”**：
  - 若把一组指数函数 $y = a_1^x, a_2^x, \dots$ 画在同一坐标系，直接画竖线 **$x = 1$**：与曲线交点的纵坐标就是底数本身 $a_i$！所以在右侧 $x>0$（与左侧 $x<0$ 相反）无需死记谁靠 $y$ 轴，画一条 $x=1$ 从高到低读交点即可。
  - 同理，对一组对数函数 $y = \log_{a_i} x$ 画横线 **$y = 1$**，交点横坐标就是底数本身 $a_i$！
- **常见错题关联**：指对混合求值不要漏掉换底公式 $\log_a b = \frac{\ln b}{\ln a}$ 与恒等式 $a^{\log_a N} = N$（$N>0$）；进一步探讨两曲线何时相交见 [[卡片/04-反例-指对交点不一定都在y=x上]]。
