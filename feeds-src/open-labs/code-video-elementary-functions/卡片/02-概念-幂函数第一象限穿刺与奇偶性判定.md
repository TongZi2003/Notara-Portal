# 幂函数第一象限过一翻转与分数指数奇偶性

## 内容

## 参考理解

- **第一象限核心律：锚定 $(1,1)$ 的「过一翻转」**：
  - 任意实数 $\alpha$ 都满足 $1^\alpha = 1$，且只有 $\alpha = 0$ 时才在 $x>0$ 上恒为水平线 $y=1$。
  - 因为对固定 $x \in (0, 1)$ 有 $\ln x < 0$，把 $x^\alpha = e^{\alpha \ln x}$ 看作关于 $\alpha$ 的指数函数，底数 $x < 1$，所以 **$\alpha$ 越大，$x^\alpha$ 反而越小**（图像贴近 $x$ 轴）；当 $x > 1$ 时 $\ln x > 0$，**$\alpha$ 越大，$x^\alpha$ 越大**。跨过 $(1,1)$ 必然出现两条幂函数互相穿越的「交叉翻转」。
  - **三档弧线弯曲感**（对 $x > 0$）：
    - **$\alpha > 1$**（如 $x^2, x^3$）：递增且下凹（先慢后猛冲，图像落在 $y=x$ 直线在 $(0,1)$ 的下方、$(1,+\infty)$ 的上方）。
    - **$0 < \alpha < 1$**（如 $x^{\frac{1}{2}}$）：递增且上凸（先陡后平缓，在 $(0,1)$ 上拱到直线 $y=x$ 上方）。
    - **$\alpha < 0$**（如 $x^{-1}$）：严格递减，不过原点 $(0,0)$，以坐标轴为渐近线。
- **分数指数的定义域与奇偶性防踩坑步骤**：
  - **第 1 步，必须先把有理指数 $\frac{p}{q}$ 化为互质最简分数**（$q \in \mathbb{N}^+, \gcd(|p|, q) = 1$）。按中学与通用幂函数约定，分数指数必须先约成最简，$\frac{2}{4}$ 本质就是 $\frac{1}{2}$，$x^{\frac{1}{2}} = \sqrt{x}$ 定义域仅是 $[0, +\infty)$，非奇非偶！
  - **第 2 步，看分母 $q$ 定定义域，看分子 $p$ 定奇偶**：
    - 若 **$q$ 为偶数**：不能开负数偶次方，定义域不含负半轴（$\alpha>0$ 为 $[0,+\infty)$，$\alpha<0$ 为 $(0,+\infty)$），定义域不关于原点对称 $\implies$ **非奇非偶**。
    - 若 **$q$ 为奇数**：允许负实数开奇次方（若 $\alpha < 0$ 还要抠掉 $x=0$），定义域关于原点对称；此时看分子 $p$：$p$ 为偶数则为**偶函数**（如 $y = x^{\frac{2}{3}}$，一、二象限对称且原点尖峰）；$p$ 为奇数则为**奇函数**（如 $y = x^{\frac{1}{3}}, x^{-1}$）。
- **延伸运用**：对比比大小里的幂指混合桥接，见 [[卡片/03-方法-指对幂比大小三阶通法与中间桥]]。
