# 反例：互为反函数的 $y=a^x$ 与 $y=\log_a x$ 交点不一定都在 $y=x$ 上

## 内容

教材指出 $y = a^x$ 与 $y = \log_a x$（$a > 0, a \ne 1$）互为反函数，图像关于直线 $y = x$ 对称。许多同学据此推论：

> “两条图像关于 $y = x$ 对称，所以无论底数 $a$ 取多少，它们的公共交点如果存在，**必然全部落在直线 $y = x$ 上**；且当 $0 < a < 1$ 时（一减一减？不对，注意同为减函数），它们**至多只有 $1$ 个交点**。”

1. 请举出一个能口算验证的**具体底数 $a$**，指出 $y = a^x$ 与 $y = \log_a x$ 的全部交点坐标，反驳上述说法；
2. 分别说明为何当 $a > 1$ 时交点确实不可能离开 $y = x$（且切点临界值是多少），而当 $0 < a < 1$ 时为什么会突然在 $y = x$ 两侧成对裂出第 $2$、第 $3$ 个交点？

## 参考理解

- **秒杀口算级反例：取底数 $a = \frac{1}{16}$**：
  - 验证点 $M\left(\frac{1}{4},\ \frac{1}{2}\right)$：
    - 代入指数函数：$\left(\frac{1}{16}\right)^{\frac{1}{4}} = \frac{1}{2} \implies M$ 在 $y = \left(\frac{1}{16}\right)^x$ 上；
    - 代入对数函数：$\log_{\frac{1}{16}}\frac{1}{4} = \frac{1}{2} \implies M$ 也在 $y = \log_{\frac{1}{16}} x$ 上！
  - 由 $y = x$ 对称性立刻白捡第二个交点 $N\left(\frac{1}{2},\ \frac{1}{4}\right)$（因为 $\left(\frac{1}{16}\right)^{\frac{1}{2}} = \frac{1}{4}$ 且 $\log_{\frac{1}{16}}\frac{1}{2} = \frac{1}{4}$）；
  - 再加上 $y = x$ 必有的对角交点 $(x_0, x_0)$（约 $(0.364, 0.364)$），两条曲线在 $a = \frac{1}{16}$ 时共有 **$3$ 个交点**，其中有 $2$ 个根本不在 $y = x$ 上！
- **为什么增函数“绝不可能”偏离 $y = x$，而减函数却可以？（完整分类谱）**：
  - **当 $a > 1$（严格增函数）**：假设存在交点 $(u, v)$ 且 $u < v$，因两点都在原函数与反函数上故必有 $a^u = v$ 与 $a^v = u$。但 $u < v$ 且底数 $a > 1$ 推出 $a^u < a^v$，即 $v < u$，矛盾！因此递增反函数的交点**只能**落在 $y = x$ 上。令 $a^x = x \implies \ln a = \frac{\ln x}{x}$，最大值在 $x = e$ 处取得 $\frac{1}{e}$，即相切临界 **$a_c = e^{\frac{1}{e}} \approx 1.445$**：
    - $a > e^{\frac{1}{e}}$：$0$ 个交点；
    - $a = e^{\frac{1}{e}}$：$1$ 个相切交点 $(e, e)$；
    - $1 < a < e^{\frac{1}{e}}$：$2$ 个交点，全在 $y = x$ 上。
  - **当 $0 < a < 1$（严格减函数）**：$u < v$ 推出 $a^u > a^v$ 即 $v > u$——不但不矛盾，而且天然适配！换言之，对角不动点 $x_0$ 始终存在唯一 $1$ 个；当复合函数 $h(x) = a^{a^x}$ 在 $x_0$ 处的斜率超过 $1$ 时，曲线穿过 $y=x$ 就会上下“多拐一个 $S$ 弯”裂出对称的一对交点。求导得 $h'(x_0) = (x_0 \ln a)^2 = (\ln x_0)^2 > 1$（因 $0 < x_0 < 1$，等价于 $\ln x_0 < -1 \iff x_0 < \frac{1}{e}$），代回 $a = x_0^{1/x_0}$ 得另一个著名临界底数 **$a_s = e^{-e} \approx 0.0660$**：
    - $e^{-e} \le a < 1$：$1$ 个交点（在 $y = x$ 上）；
    - $0 < a < e^{-e}$（例如 $\frac{1}{16} = 0.0625 < 0.0660$）：**$3$ 个交点**（$1$ 个在 $y = x$ 上，$2$ 个关于 $y = x$ 对称落在两侧）！
