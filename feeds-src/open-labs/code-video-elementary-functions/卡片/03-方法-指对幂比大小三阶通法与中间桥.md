# 指对幂比大小三阶通法与中间桥策略

## 内容

比较下列三组常见指对幂数值的大小（要求优先使用几何/图像单调性思路，不要盲目硬算）：

1. $a_1 = \log_{0.3} 2$，$b_1 = 0.3^{0.2}$，$c_1 = 2^{0.3}$；
2. $a_2 = 0.6^{0.5}$，$b_2 = 0.5^{0.6}$，$c_2 = \log_{0.5} 0.6$；
3. $a_3 = e^{0.1} - 1$，$b_3 = \ln 1.1$，$c_3 = 0.1$。

## 参考理解

- **指对幂比大小三阶决策表（从快到稳，按序排查）**：
  - **第一阶：$0$ 与 $1$ 分区隔断（5 秒秒杀）**
    - 对指数函数 $a^x$：永远 $>0$；$a>1$ 且 $x>0$（或 $0<a<1$ 且 $x<0$）时 $>1$，否则在 $(0,1)$ 之间。
    - 对对数函数 $\log_a x$：当底数 $a$ 与真数 $x$ 在 **$1$ 的同侧**（同大于 $1$ 或同在 $(0,1)$）时 $\log_a x > 0$；在 **$1$ 的异侧**时 $\log_a x < 0$；进一步比较 $\log_a x$ 与 $1$ 只需把 $x$ 和 $a$ 比大小。
    - **演练第 1 组**：$a_1 = \log_{0.3} 2 < 0$（异侧）；$0 < b_1 = 0.3^{0.2} < 0.3^0 = 1$；$c_1 = 2^{0.3} > 2^0 = 1$。直接秒得 **$c_1 > b_1 > a_1$**！
  - **第二阶：同区间搭「单调函数中间桥」**
    - 当两个数都落在 $(0, 1)$ 或 $(1, +\infty)$ 里且底数指数全不相同（如 $0.6^{0.5}$ 与 $0.5^{0.6}$），优先搭 **“取左边底数 + 右边指数”** 的混合桥（如 $0.6^{0.6}$ 或 $0.5^{0.5}$）或常数桥 $\frac{1}{2}, 2, e$：
    - **演练第 2 组**：
      - 先比 $c_2 = \log_{0.5} 0.6$ 与 $1$：因为 $0.5 < 0.6$ 且底 $0.5 < 1$，所以 $c_2 = \log_{0.5} 0.6 < \log_{0.5} 0.5 = 1$；再找桥 $\frac{1}{2} = \log_{0.5}(0.5^{0.5}) = \log_{0.5}\frac{\sqrt{2}}{2} \approx \log_{0.5} 0.707$。因为 $0.6 < 0.707$ 且减函数，$\log_{0.5} 0.6 > \frac{1}{2}$！
      - 再看 $b_2 = 0.5^{0.6} < 0.5^{0.5} \approx 0.707$，甚至拿桥 $0.6^{0.6}$：先利用 $y=0.6^x$ 递减得 $a_2 = 0.6^{0.5} > 0.6^{0.6}$，再利用 $y=x^{0.6}$ 递增得 $0.6^{0.6} > 0.5^{0.6} = b_2$，于是 $a_2 > b_2$！最后还要区分 $a_2 = \sqrt{0.6}$ 与 $c_2$：平方比较或估界得 $a_2^2 = 0.6 \implies \sqrt{0.6} \approx 0.775$，而 $\log_{0.5}0.6 = \log_2 \frac{5}{3} \approx 0.737$（更严密验证：$2^{0.75} = 2^{3/4} = \sqrt[4]{8}$，对比 $\frac{5}{3}$：$(\frac{5}{3})^4 = \frac{625}{81} < 8 = (\sqrt[4]{8})^4 \implies \log_2\frac{5}{3} < 0.75$；而 $(0.75)^2 = 0.5625 < 0.6 \implies a_2 > 0.75 > c_2$！）。从而 **$a_2 > c_2 > b_2$**（注：$\frac{3}{4}=0.75$ 这类极简有理桥极为好用，无需估算小数！）。
  - **第三阶：贴得极近时用「作商 / 切线放缩 / 构造单调函数」**
    - **演练第 3 组**：取基本切线不等式（源自 [[卡片/01-概念-指数与对数反函数对称与定点锚]] 与切线放缩边界）：对任意 $t \ne 0$，$e^t > 1 + t$ 且 $\ln(1+t) < t$（$t > -1, t \ne 0$）。代入 $t = 0.1$ 立即得出 $e^{0.1} - 1 > 0.1 > \ln 1.1$，即 **$a_3 > c_3 > b_3$**！
