# 放缩圆临界相切几何方程与考场防扣分模板

## 内容

宽为 $d$ 的条形区域 $0 \le x \le d$ 内存在垂直纸面向里的匀强磁场 $B$。质量为 $m$、电荷量为 $+q$ 的粒子从原点 $O(0,0)$ 以速率 $v$ 沿与 $+x$ 轴成 $\theta = 30^\circ$ 向右下方射入磁场（不计重力）。

1. 求粒子恰好**不从右边界穿出**（与右边界 $x = d$ 相切）时的临界半径 $R_c$ 与对应临界速率 $v_c$；
2. 考生甲直接套用口诀“相切即直径等于宽度，故 $2R = d \implies R = 0.5d$”，请指出其致命错误并核对此时粒子最远只能到达何处。

## 参考理解

- **考场 4 步规范采分模板（压轴大题防扣步骤分）**：
  1. **动力学建式（+2 分）**：洛伦兹力提供向心力，$q v B = m \frac{v^2}{R} \implies R = \frac{mv}{qB}$。
  2. **定圆心画临界直角三角形（+3 分）**：由左手定则，圆心 $O'$ 位于初速度垂线上且在磁场内部，横坐标 $x_c = R\sin\theta$。粒子轨迹最右端横坐标为 $x_{\max} = x_c + R = R(1 + \sin\theta)$。恰好与右边界相切时：
     $$
     R_c(1 + \sin 30^\circ) = d \implies R_c = \frac{2}{3}d
     $$
  3. **联立求临界速率（+2 分）**：$v_c = \frac{q B R_c}{m} = \frac{2 q B d}{3 m}$。
  4. **分界结论（+2 分）**：$v \le v_c$ 从左边界射出；$v > v_c$ 从右边界穿出。
- **排雷复盘（为什么 $2R=d$ 是错的）**：
  - $2R=d$ 仅在粒子**沿左边界垂直向上/向下贴边射入**（$\theta = 90^\circ$，圆心横坐标 $x_c = R$）时才成立！
  - 当 $\theta = 30^\circ$ 斜射入时，若取 $R = 0.5d$，圆心仅在 $x_c = 0.25d$，最远横坐标 $x_{\max} = 0.25d + 0.5d = 0.75d < d$，距离右边界还差整整 $0.25d$。
- **横向关联**：在 [[卡片/02-综合-时间跳变与旋转圆打击区间]] 中进一步比较“速率变（放缩圆）”与“方向变（旋转圆）”两套模型。
